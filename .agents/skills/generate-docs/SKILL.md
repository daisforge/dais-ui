# Документация компонента

Документация ui-kit — это Storybook. Из неё парсер `generators/meta-info`
собирает метаданные для MCP-сервера, которым пользуются агенты потребителей.
Неправильное оформление ломает не только страницу, но и подсказки агентам.

Главный источник правил — [GUIDE.md](../../../generators/meta-info/GUIDE.md).
Прочитай его перед работой; ниже — короткая выжимка и порядок.

## Из чего состоит

| Что      | Где                                                   | Содержание                                    |
| -------- | ----------------------------------------------------- | --------------------------------------------- |
| JSDoc    | `packages/ui-kit/src/components/<Name>/types.ts`      | описание компонента и каждого пропса          |
| Docs MDX | `packages/storybook/src/stories/<Name>/<Name>.mdx`    | назначение, особенности, `<Stories />`        |
| API MDX  | `packages/storybook/src/stories/<Name>/<Name>API.mdx` | `<TypeSourceViewer>` на каждый тип            |
| Stories  | `packages/storybook/src/stories/<Name>/*.stories.tsx` | примеры, `tags: ['!autodocs']`, без JSDoc     |
| Мета     | `generators/meta-info/config/meta-config.json`        | `type`, `category`, `description`, `keywords` |

## Порядок

1. Прочитай код: `types.ts`, компонент, stories. Пиши только то, что есть в
   коде; не придумывай пропсы, дефолты и поведение.
2. JSDoc: над типом пропсов — одно-два предложения о назначении; над каждым
   пропсом — что делает, допустимые значения, значение по умолчанию
   (`@default`), `@deprecated` с заменой, если проп устарел.
3. Docs MDX: структура и обязательные секции — по GUIDE.md. Пиши для
   разработчика приложения: когда использовать, чем отличается от похожих
   компонентов, ограничения.
4. API MDX: отдельный `<TypeSourceViewer>` для каждого публичного типа,
   включая compound-части.
5. Новый компонент — запись в `meta-config.json`: описание одной фразой и
   ключевые слова, по которым его будут искать (по-русски и по-английски).
6. Проверь: `npx nx run storybook:typecheck`, `npm run format:md` для `.md`,
   `npm run mcp:check`, если менялись MDX или `meta-config.json`.

## Стиль

- По-русски, кратко: одна мысль — один абзац.
- Примеры кода — рабочие, с импортами из `@daisforge/ui`.
- Внутренние детали реализации — только если они влияют на использование.
