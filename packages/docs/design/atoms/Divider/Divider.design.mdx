# Divider

Разделитель — компонент, который разделяет блоки контента в списках и макетах. Визуально отделяет блоки друг от друга и помогает выстроить ритм страницы. Компонент не интерактивен.

Визуал: {{Pixso URL Divider Doc Block 1}}

---

## Анатомия

Divider — это тонкая линия-разделитель. Её толщина и цвет заданы компонентом, а ширина настраивается под макет.

---

## Размеры и отступы

| Параметр | Значение |
|---|---|
| **Width** | Произвольная ширина. Линия растягивается под нужный размер макета. |

Ширина задаётся свойством Width и может принимать произвольные параметры — Divider подстраивается под контейнер, в котором размещён.

---

## Настройки (Props)

### subTheme

Свойство subTheme отвечает за цвет разделителя и его поведение при смене темы.

| Значение | Поведение |
|---|---|
| **Default** | Цвет Divider зависит от темы. |
| **onDark** | При смене темы Divider остаётся светлым. |
| **onLight** | При смене темы Divider остаётся тёмным. |
| **Inverse** | Цвет Divider зависит от темы. |

## FAQ

### Для дизайнеров

**Q: Как задать ширину разделителя?**
A: Свойство Width = Fill — линия растягивается под ширину контейнера/макета. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Divider Doc Block 1}}.

**Q: Как сделать так, чтобы цвет разделителя зависел от темы?**
A: Выбрать subTheme → Default — цвет Divider будет меняться вместе с темой. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Divider Doc Block 1}}.

**Q: Как оставить разделитель светлым при смене темы?**
A: Выбрать subTheme → onDark — Divider останется светлым независимо от темы. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Divider Doc Block 1}}.

**Q: Как оставить разделитель тёмным при смене темы?**
A: Выбрать subTheme → onLight — Divider останется тёмным независимо от темы. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Divider Doc Block 1}}.

**Q: Какие значения есть у свойства subTheme?**
A: Четыре: Default, onDark, onLight и Inverse. Default и Inverse привязывают цвет к теме, onDark фиксирует светлый цвет, onLight — тёмный. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Divider Doc Block 1}}.

**Q: Разделитель кликабельный?**
A: Нет, компонент не интерактивен — он только визуально группирует содержимое.
