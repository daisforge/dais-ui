# Popover

Всплывающее окно — появляется при наведении или клике на элемент, используется для отображения одного контента поверх другого.

Визуал: {{Pixso URL PopoverDF Doc Block 1}}

---

## Анатомия

1. **Title** — заголовок всплывающего окна.
2. **Description** — основной текст под заголовком.
3. **Label** — текстовые подписи на кнопках действия.
4. **Кастомный слот** — блок для кастомизации. Можно заменить его на любой компонент через «Instance swap».

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Popover" />`.

### Position

Положение всплывающего окна относительно триггера.

| Position | Результат |
|---|---|
| Top | Положение относительно триггера сверху. |
| Bottom | Положение относительно триггера снизу. |
| Left | Положение относительно триггера слева. |
| Right | Положение относительно триггера справа. |

### Tail Place

Выравнивание хвостика (указателя) относительно тела всплывающего окна.

| Tail Place | Результат |
|---|---|
| Start | Выравнивание хвостика в начале тела Popover. |
| Center | Выравнивание хвостика в центре тела Popover. |
| End | Выравнивание хвостика в конце тела Popover. |

### Buttons

Количество кнопок действия во всплывающем окне.

| Buttons | Результат |
|---|---|
| 1 | В popover одна акцентная кнопка (свойства можно изменить на уровне компонента Button). |
| 2 | В popover 2 кнопки: акцентная и вторичная (свойства можно изменить на уровне компонента Button). |

### SubTitle

Дополнительное текстовое поле.

| SubTitle | Результат |
|---|---|
| True | Включено отображение дополнительного текстового поля. |
| False | Выключено отображение дополнительного текстового поля. |

### Resize

Возможность растягивать всплывающее окно.

| Resize | Результат |
|---|---|
| True | Включено свойство ресайза. |
| False | Выключено свойство ресайза. |

### Кастомный слот

Кастомный слот — блок для кастомизации содержимого всплывающего окна. Его можно заменить на любой компонент через «Instance swap».

## Механика и взаимодействия

- **Появление.** Всплывающее окно открывается при наведении или клике на элемент-триггер — какой именно сценарий используется, продукт выбирает под свой кейс.
- **Позиционирование.** Окно размещается относительно триггера: сверху, снизу, слева или справа (Position). Хвостик-указатель выравнивается по началу, центру или концу тела окна (Tail Place).
- **Содержимое.** Внутри — заголовок (Title), описание (Description) и до двух кнопок действия (Buttons). Дополнительно можно включить SubTitle. Кастомный слот позволяет вставить произвольный компонент.
- **Растягивание.** При включённом Resize пользователь может менять размер окна.

Детали реализации (захват фокуса, отступы, ограничения размеров при ресайзе) — в Storybook: {{Storybook URL PopoverDF}}.

## FAQ

### Для дизайнеров

**Q: Как разместить всплывающее окно относительно триггера?**
A: Через свойство Position — Top, Bottom, Left или Right. Подробнее — в Pixso-документации компонента, блок «Position»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Как выровнять хвостик-указатель?**
A: Через свойство Tail Place — Start (в начале тела), Center (по центру) или End (в конце тела). Подробнее — в Pixso-документации компонента, блок «Tail Place»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Как добавить кнопки действия?**
A: Через свойство Buttons — 1 (одна акцентная кнопка) или 2 (акцентная и вторичная). Свойства кнопок можно изменить на уровне компонента Button. Подробнее — в Pixso-документации компонента, блок «Buttons»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Как включить дополнительное текстовое поле?**
A: Через свойство SubTitle → True. Подробнее — в Pixso-документации компонента, блок «SubTitle»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Как сделать всплывающее окно растягиваемым?**
A: Включить свойство Resize → True. Подробнее — в Pixso-документации компонента, блок «Resize»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Как вставить произвольный контент во всплывающее окно?**
A: Использовать Кастомный слот — блок для кастомизации, который можно заменить на любой компонент через «Instance swap». Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL PopoverDF Doc Block 1}}.

**Q: Какие размеры есть у всплывающего окна?**
A: Два: M и S. Они различаются шрифтами заголовка и текста. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL PopoverDF Doc Block 2}}.

**Q: Когда использовать Popover, а когда другой компонент?**
A: Popover подходит для отображения контента и действий поверх элемента по наведению или клику. Если нужна короткая подсказка — посмотрите [Tooltip]({{Storybook URL Tooltip}}), если выбор из списка — [Dropdown]({{Storybook URL Dropdown}}).

### Для разработчиков

**Q: Как задать положение всплывающего окна?**
A: Через проп `placement` со значениями `top` / `bottom` / `left` / `right` — соответствует свойству Position. Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.

**Q: Как включить возможность растягивать окно?**
A: Через проп `resizable` — он принимает `boolean` либо объект с направлениями и ограничениями размеров (minWidth, minHeight, maxWidth, maxHeight и др.). Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.

**Q: Как управлять открытием и закрытием?**
A: Состоянием управляют пропы `opened` и `onToggle`, а способ открытия задаётся пропом `trigger`. Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.

**Q: Как добавить хвостик-указатель?**
A: Передать проп `hasArrow`. Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.

**Q: Как задать элемент-триггер?**
A: Через проп `target` — он может быть как ReactNode, так и RefObject. Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.

**Q: Как удержать фокус внутри всплывающего окна?**
A: Через проп `isFocusTrapped` — при `true` навигация по `Tab` / `Shift + Tab` зацикливается внутри окна. Примеры кода — в Storybook: {{Storybook URL PopoverDF}}.
