# Radiobox

Элемент для выбора одного состояния из нескольких вариантов. Radiobox предоставляет пользователю возможность выбрать один из ряда предложенных взаимоисключающих вариантов. Чтобы дать возможность выбрать несколько — лучше подходит Checkbox.

Визуал: {{Pixso URL Radiobox Doc Block 1}}

---

## Анатомия

1. **Радиокнопка** — круглый индикатор выбора слева. В невыбранном состоянии — обводка, в выбранном — заполненный центр.
2. **Лейбл** — текстовый лейбл варианта (опционально, управляется свойством hasTitle).
3. **Описание** — текстовое описание под лейблом (опционально, управляется свойством hasDescription).

## Размеры и отступы

| Размер | Диаметр радиокнопки | Отступ радиокнопка → текст | Высота строки | Шрифт Лейбл | Шрифт Описание |
|---|---|---|---|---|---|
| **M** | 24 | 12 | 20 | Body/BodyM N | Body/BodyS N |
| **S** | 16 | 8 | 20 | Body/BodyM N | Body/BodyS N |

Ширина блока — hug (по содержимому); отступ между лейблом и описанием — 2px.

## Состояния

| Состояние | Описание |
|---|---|
| **Checked = False** | Параметр не выбран (пустая обводка). |
| **Checked = True** | Параметр выбран (заполненный центр). |
| **Disabled = False** | Взаимодействие с радиокнопкой включено. |
| **Disabled = True** | Взаимодействие с радиокнопкой выключено. |

## FAQ

### Для дизайнеров

**Q: Когда использовать Radiobox, а когда Checkbox?**
A: Radiobox — для выбора одного варианта из нескольких взаимоисключающих. Если нужно выбрать несколько — используйте Checkbox.

**Q: Какие размеры есть у радиокнопки?**
A: Два: M (диаметр радиокнопки 24) и S (диаметр радиокнопки 16). У обоих лейбл — Body/BodyM N, описание — Body/BodyS N. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Radiobox Doc Block 1}}.

**Q: Как скрыть лейбл или описание?**
A: В макете лейбл и описание включаются и выключаются отдельными тогглами — оставьте видимым только то, что нужно. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Radiobox Doc Block 1}}.

**Q: Как показать вариант выбранным по умолчанию?**
A: Переключите радиокнопку в выбранное состояние — пустая обводка станет заполненным центром. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Radiobox Doc Block 1}}.

**Q: Как показать заблокированную радиокнопку?**
A: Используйте отключённое состояние — взаимодействие с радиокнопкой выключено. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Radiobox Doc Block 1}}.

**Q: Как объединить несколько радиокнопок в группу?**
A: В дизайне группа собирается вручную — расположите радиокнопки одного выбора в автолейауте; в такой группе всегда активен ровно один вариант (взаимоисключающий выбор). В коде для этого есть готовый помощник (RadioGroup) — см. Storybook: {{Storybook URL Radiobox}}.

### Для разработчиков

**Q: Как добавить лейбл или описание?**
A: Лейбл и описание появляются, когда вы передаёте текст в `label` и `description` (в дизайне им соответствуют тогглы `hasTitle` и `hasDescription`). Примеры кода — в Storybook: {{Storybook URL Radiobox}}.

**Q: Как отметить вариант выбранным по умолчанию?**
A: Используйте проп `defaultChecked` (включён через `include`); ему соответствует состояние `Checked = True` в дизайне. Точное имя пропа для управляемого состояния уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Radiobox}}.

**Q: Как заблокировать радиокнопку?**
A: В дизайне это состояние `Disabled = True`. Имя пропа для отключённого состояния уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Radiobox}}.

**Q: Как задать размер в коде?**
A: В дизайне есть размеры M и S. Имя пропа для размера уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Radiobox}}.
