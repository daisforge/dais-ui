# Progress

Индикатор хода выполнения задачи.

Визуал: {{Pixso URL Progress Doc Block 1}}

Семейство Progress включает два типа индикатора: **Liner** — линейный прогресс-бар (основная часть этого документа) и **Circular** — круговой прогресс-бар (описан ниже в разделе «ProgressBarCircular»). В дизайне оба типа собраны в одной документации, поэтому здесь описаны вместе.

---

## Общее

- Компоненты прогресса по умолчанию принимают значение в диапазоне **от 0 до 100**. При необходимости можно работать с источником данных, где значения выходят за пределы этого диапазона.
- Заполнение прогресс-бара всегда должно только расти.

## Анатомия (Liner)

Линейный прогресс-бар может включать хедер с текстовым описанием над полосой заполнения.

1. **Title** — заголовок хедера (шрифт Body/BodyM B).
2. **Text** — пояснительный текст хедера (шрифт Body/BodyS N).
3. **Label** — подпись со значением прогресса.
4. **Полоса заполнения** — индикатор хода выполнения.

Визуал: {{Pixso URL Progress Doc Block 2}}

## Размеры (Liner)

Размер задаётся свойством **Size**. В дизайне у линейного прогресс-бара два размера.

| Размер | Шрифт Title | Шрифт Text |
|---|---|---|
| **M** | Body/BodyM B | Body/BodyS N |
| **S** | — | — |

### View

Цветовая тема линейного прогресс-бара.

| Вид | Назначение |
|---|---|
| **Default** | Дефолтный прогресс-бар. |
| **Secondary** | Вторичный. |
| **Accent** | Акцентный. |
| **Success** | Успешное завершение. |
| **Warning** | Предупреждение. |
| **Negative** | Негативный сценарий. |
| **AccentGradient** | Акцентный с градиентной заливкой. |

### Хедер

Отображение хедера над полосой заполнения можно включить или выключить. Хедер содержит заголовок (Title), текст (Text) и подпись со значением (Label).

## ProgressBarCircular

Круговой индикатор прогресса. Заполнение начинается из верхней точки (12 часов) и идёт по часовой стрелке — это рекомендованное направление дизайн-системы.

Визуал: {{Pixso URL Progress Doc Block 3}}

- Во всех вариантах, кроме **16 XXS**, в центре круга есть область для любого контента.
- Чтобы задать размер варианта **Scalable** в макете, высоту и ширину выставляют вручную: если контент в центре включён — сначала задают нужную ширину, а к высоте прибавляют **22 px**; если контент выключен — высоту и ширину выставляют с одинаковым значением.

### Размеры

Размер задаётся свойством **Size**.

| Размер | Значение |
|---|---|
| **XXL** | 128 |
| **XL** | 88 |
| **L** | 56 |
| **M** | 48 |
| **S** | 36 |
| **XS** | 24 |
| **XXS** | 16 |
| **Scalable** | Масштабируемый — высота и ширина выставляются вручную. |

### Настройки (Props)

> Полный список пропсов с типами — в dev-документации через `<PropsTable name="ProgressBarCircular" />`.

#### View

Цветовая тема кругового прогресс-бара.

| Вид | Назначение |
|---|---|
| **Default** | Дефолтный. |
| **Secondary** | Вторичный. |
| **Accent** | Акцентный. |
| **Success** | Успешное завершение. |
| **Warning** | Предупреждение. |
| **Negative** | Негативный сценарий. |
| **Info** | Информирующий. |

#### SubTheme

Поведение цвета прогресс-бара при смене темы.

| Значение | Описание |
|---|---|
| **Default** | Цвета прогресс-бара зависят от темы. |
| **onDark** | При смене темы прогресс-бар остаётся светлым. |
| **onLight** | При смене темы прогресс-бар остаётся тёмным. |
| **Inverse** | Инвертированные токены подтемы Default. |

#### hasTrack

Дополнительная серая линия дорожки прогресса.

| Значение | Описание |
|---|---|
| **True** | Включает дополнительную серую линию дорожки. |
| **False** | Выключает дополнительную серую линию дорожки. |

**Недоступно в размере 16 XXS.**

#### hasContent

Контент внутри круга прогресса.

| Значение | Описание |
|---|---|
| **True** | Включает контент внутри круга с прогрессом. |
| **False** | Выключает контент внутри круга с прогрессом. |

**Недоступно в размере 16 XXS.**

## FAQ

### Для дизайнеров

**Q: Какое значение принимает прогресс-бар?**
A: По умолчанию — в диапазоне от 0 до 100. При необходимости можно работать с источником данных, где значения выходят за пределы этого диапазона. Заполнение всегда должно только расти. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL Progress Doc Block 1}}.

**Q: Чем отличаются типы Liner и Circular?**
A: Liner — линейный прогресс-бар, Circular — круговой. В дизайне это два типа одного семейства. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Progress Doc Block 1}}.

**Q: Какие виды (View) есть у линейного прогресс-бара?**
A: Default, Secondary, Accent, Success, Warning, Negative и AccentGradient (с градиентной заливкой). Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Progress Doc Block 1}}.

**Q: Что входит в хедер линейного прогресс-бара?**
A: Заголовок (Title, шрифт Body/BodyM B), пояснительный текст (Text, шрифт Body/BodyS N) и подпись со значением (Label). Отображение хедера можно включить или выключить. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Progress Doc Block 1}}.

**Q: С какой точки начинается заполнение кругового прогресс-бара?**
A: Из верхней точки (12 часов), по часовой стрелке — это рекомендованное направление ДС. Подробнее — в Pixso-документации компонента, блок «ProgressBarCircular»: {{Pixso URL Progress Doc Block 1}}.

**Q: Какие размеры есть у кругового прогресс-бара?**
A: XXL (128), XL (88), L (56), M (48), S (36), XS (24), XXS (16) и масштабируемый вариант Scalable. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Progress Doc Block 1}}.

**Q: Как разместить контент внутри круга?**
A: Включить свойство hasContent — в центре круга появится область для любого контента. Доступно во всех размерах, кроме 16 XXS. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Progress Doc Block 1}}.

**Q: Что делает свойство SubTheme у кругового прогресс-бара?**
A: Управляет цветом при смене темы: Default — цвета зависят от темы; onDark — остаётся светлым; onLight — остаётся тёмным; Inverse — инвертированные токены подтемы Default. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Progress Doc Block 1}}.

**Q: Как задать масштабируемый круговой прогресс-бар (Scalable)?**
A: Высоту и ширину выставляют вручную: при включённом контенте сначала задают ширину, а к высоте прибавляют 22 px; при выключенном — высоту и ширину делают равными. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Progress Doc Block 1}}.

### Для разработчиков

**Q: Как задать значение прогресса?**
A: Через проп `value` (число). Для кругового прогресс-бара значение автоматически ограничивается диапазоном от 0 до `maxValue`. Примеры кода — в Storybook: {{Storybook URL Progress}}.

**Q: Как задать вид линейного прогресс-бара в коде?**
A: Через проп `view` со значениями `default` / `secondary` / `accent` / `success` / `warning` / `error`. Вид Negative из дизайна соответствует `error`. Примеры кода — в Storybook: {{Storybook URL Progress}}.

**Q: Как показать подпись со значением у линейного прогресс-бара?**
A: Передать булев проп `displayValue`. Примеры кода — в Storybook: {{Storybook URL Progress}}.

**Q: Как задать размер кругового прогресс-бара?**
A: Через проп `size` со значениями `xxl` / `xl` / `l` / `m` / `s` / `xs` / `xxs`. Примеры кода — в Storybook: {{Storybook URL ProgressBarCircular}}.

**Q: Как задать вид кругового прогресс-бара?**
A: Через проп `view` со значениями `default` / `secondary` / `accent` / `info` / `positive` / `warning` / `negative`. Вид Success из дизайна соответствует `positive`. Примеры кода — в Storybook: {{Storybook URL ProgressBarCircular}}.

**Q: Как разместить контент внутри круга и поменять максимум?**
A: Контент передают через `children`; максимальное значение диапазона — через `maxValue`. Контент недоступен в размере `xxs`. Примеры кода — в Storybook: {{Storybook URL ProgressBarCircular}}.

**Q: Как изменить толщину линии кругового прогресс-бара?**
A: Через проп `strokeSize` (число). Примеры кода — в Storybook: {{Storybook URL ProgressBarCircular}}.
