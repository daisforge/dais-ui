# Sheet

Панель с дополнительным функционалом, которая выдвигается с нижней части экрана. Sheet выдвигается снизу экрана и позволяет менять режим отображения.

Визуал: {{Pixso URL BottomSheet Doc Block 1}}

---

## Анатомия

Sheet объединяет три части, которые задаются через отдельно собранные компоненты.

1. **Header** — заголовочная часть панели.
2. **Body** — основная область с контентом.
3. **Footer** — нижняя часть панели.

Также рядом с панелью может отображаться индикатор в виде горизонтальной линии (handle).

---

## Размеры и отступы

| Параметр | Значение |
|---|---|
| **Height** | Поддерживает два режима отображения — максимальное и минимальное. |
| **Width** | Принимает значение контейнера, в который помещён Sheet. |
| **Corner Radius** | XL (20px). |

Внутренние отступы между частями — 16.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Sheet" />`.

### Header

| Свойство | Назначение |
|---|---|
| **Отображение хедера** | Включает или выключает отображение части Header. |
| **Закрепление хедера** | Фиксирует Header в одном положении — при появлении прокрутки контент скроллится под него. Без закрепления Header скроллится вместе с контентом. |

### Footer

| Свойство | Назначение |
|---|---|
| **Отображение футера** | Включает или выключает отображение части Footer. |
| **Закрепление футера** | Фиксирует Footer в одном положении — при появлении прокрутки контент скроллится под него. Без закрепления Footer скроллится вместе с контентом. |

### Индикатор (handle)

Индикатор — горизонтальная линия, обозначающая возможность управления панелью.

| Положение | Результат |
|---|---|
| **Inner** | Индикатор отображается внутри основного контента компонента. |
| **Outer** | Индикатор отображается вне основного контента компонента. |
| **None** | Выключает отображение индикатора. |

## Состояния

| Состояние | Описание |
|---|---|
| **Минимальное** | Панель раскрыта частично. |
| **Максимальное** | Панель раскрыта на максимальную высоту. |

Переключение между режимами отображения доступно пользователю.

---

## Механика и взаимодействия

- **Выдвижение снизу.** Sheet появляется из нижней части экрана и закреплён к его низу.
- **Смена режима отображения.** Пользователь переключает панель между минимальным и максимальным режимами по высоте.
- **Затемнение через Overlay.** Если Sheet нужно наложить поверх затемнённого экрана, используйте фон с токенами цвета из группы Overlay.

## FAQ

### Для дизайнеров

**Q: Как сделать панель, выдвигающуюся снизу экрана?**
A: Используйте компонент Sheet — он закреплён к низу экрана и позволяет пользователю менять режим отображения. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Из каких частей состоит панель?**
A: Из трёх частей — Header, Body, Footer, которые задаются через отдельно собранные компоненты. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Как сделать так, чтобы заголовок оставался на месте при прокрутке?**
A: Включите закрепление хедера — Header фиксируется в одном положении, а контент скроллится под него. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Как сделать так, чтобы футер оставался на месте при прокрутке?**
A: Включите закрепление футера — Footer фиксируется в одном положении, а контент скроллится под него. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Как скрыть заголовок или футер?**
A: Отображение хедера и футера можно включать и выключать соответствующими свойствами. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Как настроить индикатор-линию у панели?**
A: Положением индикатора управляют значения Inner (внутри контента), Outer (вне контента) и None (индикатор выключен). Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Какие размеры по высоте у панели?**
A: Sheet поддерживает два режима отображения — максимальное и минимальное; ширина принимает значение контейнера, скругление углов — XL (20px). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL BottomSheet Doc Block 1}}.

**Q: Как наложить панель поверх затемнённого экрана?**
A: Используйте фон с токенами цвета из группы Overlay. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL BottomSheet Doc Block 1}}.

### Для разработчиков

**Q: Как закрепить заголовок и футер при прокрутке?**
A: Передайте пропы `isHeaderFixed` и `isFooterFixed` (boolean) — при появлении прокрутки контент будет скроллиться под них. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.

**Q: Как задать контент заголовка, тела и футера?**
A: Контент заголовка — через `contentHeader`, футера — через `contentFooter`, тело — напрямую через `children`. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.

**Q: Как управлять открытием и закрытием панели?**
A: Видимость задаётся пропом `opened`, закрытие обрабатывается через `onClose`. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.

**Q: Как убрать подложку, чтобы взаимодействовать с контентом вне панели?**
A: Передайте `withOverlay={false}` — без затемнённой подложки пользователь может взаимодействовать с контентом вне шторки. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.

**Q: Как добавить размытие подложки?**
A: Передайте проп `withBlur` — к подложке добавится эффект размытия. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.

**Q: Как включить или выключить отображение хедера и футера?**
A: Уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL BottomSheet}}.
