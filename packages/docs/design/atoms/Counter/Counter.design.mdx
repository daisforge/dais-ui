# Counter

Элемент для отображения количества новых уведомлений. Числовой индикатор количества: показывает счётчик (например, число непрочитанных уведомлений) и не предназначен для ввода значений. Counter сам по себе не интерактивен, но может наследовать состояние родительского компонента (например, disabled от таба, к которому он привязан).

## Размеры и отступы

У всех размеров скругление полное — Corner Radius: Rounded (1000px): это нужно, чтобы счётчик оставался круглым на любом размере. Размер задаёт высоту и шрифт лейбла.

| Размер | Высота | Corner Radius | Шрифт лейбла |
|---|---|---|---|
| **L** | 28 | Rounded (1000px) | Body/BodyS N |
| **M** | 24 | Rounded (1000px) | Body/BodyXS N |
| **S** | 20 | Rounded (1000px) | Body/BodyXXS N |
| **XS** | 16 | Rounded (1000px) | Body/BodyXXS N |
| **XXS** | 12 | Rounded (1000px) | Body/BodyXXS N |

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Counter" />`.

### Вид

Цветовая тема счётчика.

| Вид | Назначение |
|---|---|
| Default | Дефолтный счётчик. |
| Accent | Акцентный счётчик. |
| Positive | Информирует о позитивном сценарии. |
| Negative | Информирует о негативном сценарии. |
| Warning | Предупреждение. |
| Black | Чёрный счётчик, не изменяет цвет при переключении тем. |
| White | Белый счётчик, не изменяет цвет при переключении тем. |

### Ширина (Width)

Управляет шириной счётчика.

| Значение | Поведение |
|---|---|
| **Minimal** | Ширина фиксирована и равна высоте (квадрат); счёт работает только для цифр. |
| **Auto** | Ширина подстраивается под число. |

### Подтема (SubTheme)

Определяет, как счётчик реагирует на тему окружения.

| Значение | Назначение |
|---|---|
| **Default** | Цвета счётчика изменяются в зависимости от темы. |
| **onLight** | Используется, если вне зависимости от темы счётчик остаётся на светлом фоне. |
| **onDark** | Используется, если вне зависимости от темы счётчик остаётся на тёмном фоне. |
| **Inverse** | Используется, если требуется инвертированный вариант счётчика. |

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у счётчика?**
A: Пять: L (28px), M (24px), S (20px), XS (16px), XXS (12px). Скругление у всех полное (Rounded 1000px), различаются высотой и шрифтом лейбла. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Counter Doc Block 1}}.

**Q: Можно ли вводить число в счётчик?**
A: Нет. Counter — это статичный числовой индикатор для отображения количества (например, новых уведомлений). Counter сам по себе не интерактивен, но может наследовать состояние родительского компонента (например, disabled от таба, к которому он привязан), и не служит для ввода. Для ввода чисел используется отдельный компонент. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Counter Doc Block 1}}.

**Q: Чем отличаются ширины Minimal и Auto?**
A: Minimal фиксирует ширину счётчика (счёт работает только для цифр), Auto подстраивает ширину под число. Подробнее — в Pixso-документации компонента, блок «Ширина (Width)»: {{Pixso URL Counter Doc Block 1}}.

**Q: Для чего нужна подтема SubTheme?**
A: Она задаёт, как счётчик ведёт себя относительно темы: Default следует за темой, onLight/onDark фиксируют поведение на светлом/тёмном фоне, Inverse даёт инвертированный вариант. Подробнее — в Pixso-документации компонента, блок «Подтема (SubTheme)»: {{Pixso URL Counter Doc Block 1}}.

### Для разработчиков

**Q: Как задать цветовую тему счётчика?**
A: Пропом `view`: `primary` (дефолт), `accent`, `positive`, `negative`, `warning`, `dark`, `light`. Виды `dark` и `light` не меняют цвет при переключении тем. В дизайн-макете вид Default = `primary`, Black/White = `dark`/`light`. Примеры кода — в Storybook: {{Storybook URL Counter}}.

**Q: Как задать размер?**
A: Пропом `size` со значениями `l` / `m` / `s` / `xs` / `xxs` — это высоты 28 / 24 / 20 / 16 / 12 соответственно. Примеры кода — в Storybook: {{Storybook URL Counter}}.

**Q: Как задать отображаемое число?**
A: Пропом `count` (число, не может быть меньше 1). Значение задаётся в коде — см. Storybook: {{Storybook URL Counter}}.

**Q: Как ограничить максимальное отображаемое число?**
A: Пропом `maxCount` (число, не может быть меньше 1): при превышении вместо реального значения показывается `maxCount`. Значение задаётся в коде — см. Storybook: {{Storybook URL Counter}}.

**Q: Есть ли в коде пропы для Width и SubTheme?**
A: Точные пропы для Width (Minimal / Auto) и SubTheme (Default / onLight / onDark / Inverse) уточните в Storybook или в чате поддержки дизайн-системы: {{Storybook URL Counter}}.
