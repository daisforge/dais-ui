# Chip

Чипы — это компактные интерактивные элементы, которые представляют пользователю возможность вводить информацию, делать выбор, фильтровать контент или запускать действия.

Визуал: {{Pixso URL Chip Doc Block 1}}

В дизайне у компонента два типа: **Chip** (отдельный чип) и **ChipGroup** (группа чипов). Оба описаны в одной общей документации, поэтому здесь собраны оба. ChipGroup вынесен в отдельный раздел ниже.

---

## Типы

| Тип | Описание | Визуал |
|---|---|---|
| **Chip** | Чип для отображения компактной информации, совершения действий или фильтрации. | {{Pixso URL Chip Doc Block 1}} |
| **ChipGroup** | Группа чипов для выбора одного или нескольких значений из предложенных. | {{Pixso URL Chip Doc Block 3}} |

---

## Анатомия

1. **Label** — текстовый лейбл чипа.
2. **ContentLeft** — содержимое слева от текста: иконка или аватар (опционально).
3. **Close** — кнопка закрытия справа (опционально).

---

## Размеры и отступы

Размер задаётся свойством **Size**. В дизайне четыре размера.

| Размер | Высота | Corner Radius | Шрифт лейбла | Размер иконки | Отступ слева | Отступ справа |
|---|---|---|---|---|---|---|
| **M** | 40 | calc[m-2] (10px) | Body/BodyM N | 24px | 6 | 8 |
| **S** | 32 | S (8px) | Body/BodyS N | 16px | 4 | 6 |
| **XS** | 24 | XS (6px) | Body/BodyXS N | 12px | 4 | 4 |
| **XXS** | 20 | XS (6px) | Body/BodyXXS N | 12px | 2 | 2 |

Ширина чипа подстраивается под содержимое (hug).

## Настройки (Props)

> Здесь — визуальное поведение из дизайна. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Chip" />`.

### View

Цветовая тема чипа.

| Вид | Назначение |
|---|---|
| **Default** | Дефолтный чип. |
| **Secondary** | Второстепенный чип. |
| **Accent** | Акцентный чип. |

В макете показаны три вида. Полный набор доступных видов уточните в Pixso или в чате поддержки.

### ContentLeft

Содержимое слева от текста.

| Значение | Описание |
|---|---|
| **Empty** | Выключает отображение контента слева. |
| **Icon** | Включает отображение иконки слева. |
| **Avatar** | Включает отображение аватара слева. |

### hasClose

Отображение кнопки закрытия (Close) справа.

| Значение | Описание |
|---|---|
| **True** | Включает отображение кнопки Close. |
| **False** | Выключает отображение кнопки Close. |

### Shape

Скругление углов чипа.

| Значение | Результат |
|---|---|
| **Default** | Квадратные чипы (скругление по Corner Radius из таблицы размеров). |
| **Pilled** | Скруглённые чипы (полное скругление). |

### Disabled

| Значение | Описание |
|---|---|
| **True** | Выключает возможность взаимодействия с чипом. |
| **False** | Включает возможность взаимодействия с чипом. |

## ChipGroup

ChipGroup — группа чипов, которая используется для выбора одного или нескольких значений из предложенных. Это обёртка, в которую вкладываются отдельные чипы.

Визуал: {{Pixso URL Chip Doc Block 3}}

### Два варианта поведения группы

1. **Группа выбранных атрибутов.** Пользователь видит столько чипов, сколько атрибутов он добавил (категория, контакт, любая другая информация). Все видимые чипы считаются выбранными и могут иметь разный стиль. Если вы выбираете чип с кнопкой Close, то все чипы в группе должны отображаться с ней.
2. **Группа для выбора.** Пользователь сразу видит все доступные для выбора атрибуты и выбирает нажатием нужные. В этом случае нужно изначально определить два стиля чипов: один указывает на дефолтные, другой — на выбранные. Если вы выбираете чип с кнопкой Close, то только выбранные чипы в группе должны отображаться с ней.

### Размеры группы

Размер группы задаётся свойством **Size** и определяет шрифт лейбла всех чипов внутри.

| Размер | Шрифт лейбла |
|---|---|
| **M** | Body/BodyM N |
| **S** | Body/BodyS N |
| **XS** | Body/BodyXS N |
| **XXS** | Body/BodyXXS N |

### Настройки группы (Props)

> Здесь — визуальное поведение из дизайна. Полный список пропсов с типами — в dev-документации через `<PropsTable name="ChipGroup" />`.

#### Quantity

Количество чипов в группе. В макете задаётся значениями от **2 до 10**.

#### Gap

Отступы между чипами.

| Значение | Отступ |
|---|---|
| **Dense** | 2px между чипами. |
| **Wide** | 8px между чипами. |

#### isWrapped

| Значение | Описание |
|---|---|
| **True** | Включает перенос на новую строку, размещая в заданной ширине всей группы максимальное количество чипов на каждой строке. |
| **False** | Все чипы располагаются в одну строку. |

### Маппинг ChipGroup: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Size (M / S / XS / XXS) | `size` | `m` / `s` / `xs` / `xxs` | Применяется ко всем чипам группы. |
| View | `view` | см. dev-документацию | Задаёт общий вид всех чипов группы. |
| Общий стиль чипов | `isCommonChipStyles` | boolean | При `false` каждый чип внутри сохраняет собственные `size` и `view`. |
| Gap (Dense / Wide) | `gap` | `dense` / `wide` | Dense — 2px, Wide — 8px. |
| isWrapped | — | boolean | Свойство переноса на новую строку. Точный проп уточните в Storybook или в чате поддержки ДС. |
| Quantity | — | — | Макетное свойство дизайна (2–10). В коде количество чипов задаётся вложенными элементами `Chip`. |

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Size (M / S / XS / XXS) | `size` | `m` / `s` / `xs` / `xxs` | Прямое соответствие размерам M / S / XS / XXS. |
| View | `view` | см. dev-документацию | В дизайне показаны Default / Secondary / Accent; полный набор видов — в коде. |
| ContentLeft: Icon | `contentLeft` | иконка (ReactNode) | Иконка слева от текста. |
| ContentLeft: Avatar | `contentLeft` | аватар (ReactNode) | Аватар слева от текста. |
| ContentLeft: Empty | — | — | Без `contentLeft`. |
| Close (hasClose) | `hasClear` | boolean | Кнопка закрытия справа. По умолчанию включена; `hasClear={false}` скрывает её. |
| Кастомная иконка закрытия | `contentClearButton` | иконка (ReactNode) | Позволяет передать собственную иконку для кнопки закрытия. |
| Shape (Default / Pilled) | `pilled` | boolean | Default — квадратные; Pilled — скруглённые. Точный проп уточните в Storybook или в чате поддержки ДС. |
| Disabled | `disabled` | boolean | Выключает взаимодействие с чипом. |
| Label | `text` | строка | Текстовый лейбл. Контент можно также передать через `children`. |

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у чипа?**
A: Четыре: M (40px), S (32px), XS (24px), XXS (20px). Каждый со своим скруглением углов, шрифтом лейбла и размером иконки. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Chip Doc Block 2}}.

**Q: Как добавить иконку или аватар слева от текста?**
A: Через свойство ContentLeft: значение Icon показывает иконку, Avatar — аватар, Empty — выключает контент слева. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Chip Doc Block 1}}.

**Q: Как показать или скрыть кнопку закрытия?**
A: Через свойство hasClose: True включает кнопку Close, False — скрывает её. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Chip Doc Block 1}}.

**Q: Как сделать чип со скруглёнными краями?**
A: Выбрать свойство Shape → Pilled — чип получит полное скругление. Значение Default даёт квадратные чипы со скруглением по Corner Radius из таблицы размеров. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Chip Doc Block 1}}.

**Q: Как сделать чип неактивным?**
A: Включить свойство Disabled — оно выключает возможность взаимодействия с чипом. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Chip Doc Block 1}}.

**Q: Какие виды (View) есть у чипа?**
A: В макете показаны Default, Secondary и Accent. Полный набор доступных видов уточните в Pixso или в чате поддержки. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Chip Doc Block 1}}.

**Q: Как собрать группу чипов и задать ей общий размер?**
A: Использовать ChipGroup и задать свойство Size (M / S / XS / XXS) — оно определяет шрифт лейбла всех чипов группы. Количество чипов задаётся свойством Quantity (2–10). Подробнее — в Pixso-документации компонента, блок «ChipGroup»: {{Pixso URL Chip Doc Block 3}}.

**Q: Как настроить отступы между чипами в группе и перенос на новую строку?**
A: Отступы — через свойство Gap: Dense (2px) или Wide (8px). Перенос — через isWrapped: True размещает чипы на нескольких строках в пределах ширины группы, False оставляет всё в одну строку. Подробнее — в Pixso-документации компонента, блок «ChipGroup»: {{Pixso URL Chip Doc Block 3}}.

### Для разработчиков

**Q: Как задать размер чипа?**
A: Через проп `size` со значениями `m` / `s` / `xs` / `xxs` — прямое соответствие размерам M / S / XS / XXS. Примеры кода — в Storybook: {{Storybook URL Chip}}.

**Q: Как добавить иконку или аватар слева и иконку/контент в текст?**
A: Содержимое слева — через `contentLeft` (ReactNode): туда можно передать иконку или аватар. Текст — через `text` или напрямую через `children`. Примеры кода — в Storybook: {{Storybook URL Chip}}.

**Q: Как управлять кнопкой закрытия?**
A: Кнопка закрытия включена по умолчанию; чтобы скрыть её, передайте `hasClear={false}`. Свою иконку закрытия можно передать через `contentClearButton`. Примеры кода — в Storybook: {{Storybook URL Chip}}.

**Q: Как сделать чип неактивным?**
A: Передать проп `disabled` — он выключает взаимодействие с чипом. Примеры кода — в Storybook: {{Storybook URL Chip}}.

**Q: Какие виды (`view`) доступны и как их задать?**
A: Вид задаётся пропом `view`. Доступные значения смотрите в `<PropsTable name="Chip" />` и в Storybook. В дизайне показаны Default / Secondary / Accent; полный набор — в коде. Примеры кода — в Storybook: {{Storybook URL Chip}}.

**Q: Как собрать группу чипов и задать общий размер и вид?**
A: Обернуть чипы в `ChipGroup` и задать пропы `size` и `view` — они применяются ко всем чипам группы. Чтобы каждый чип сохранял собственный размер и вид, передайте `isCommonChipStyles={false}`. Примеры кода — в Storybook: {{Storybook URL ChipGroup}}.

**Q: Как задать отступы между чипами в группе?**
A: Через проп `gap` со значениями `dense` (2px) или `wide` (8px). Примеры кода — в Storybook: {{Storybook URL ChipGroup}}.
