# Skeleton

Графическая имитация блоков контента, используемая в качестве заполнителя во время загрузки реального контента.

Визуал: {{Pixso URL Skeleton Doc Block 1}}

---

## Общее

- Skeleton должен обеспечить близкое представление конечного макета страницы и содержимого после загрузки.
- Если визуальный формат загружаемого контента неизвестен или нужно указать обработку/изменение данных — не рекомендуется использовать Skeleton. В таком случае можно адаптировать пустое состояние с иконкой загрузки.
- В дизайне созданы компоненты с верным токеном внутри, которые можно использовать на блоках.

---

## Анатомия

Skeleton — это набор компонентов-заполнителей. В дизайне выделены два типа.

| Тип | Назначение |
|---|---|
| **LineSkeleton** | Отображает загрузку текстового содержимого, например абзацев. |
| **RectSkeleton** | Отображает загрузку графических элементов, таких как значки, аватары и небольшие изображения. |

### Токены поверхности

Цвет заливки заполнителя задаётся токенами. В дизайне созданы компоненты с верным токеном внутри.

| Токен | Назначение |
|---|---|
| **SurfaceSkeletonGradient** | Стандартный токен Skeleton в подтеме по умолчанию. |
| **SurfaceSkeletonDeepGradient** | Более яркий вариант для отображения Skeleton в подтеме по умолчанию. |
| **onDarkSurfaceSkeletonGradient** | Значение SurfaceSkeletonGradient из тёмной темы. |
| **onDarkSurfaceSkeletonDeepGradient** | Значение SurfaceSkeletonDeepGradient из тёмной темы. |
| **onLightSurfaceSkeletonGradient** | Значение SurfaceSkeletonGradient из светлой темы. |
| **onLightSurfaceSkeletonDeepGradient** | Значение SurfaceSkeletonDeepGradient из светлой темы. |
| **InverseSurfaceSkeletonGradient** | Инвертированное значение SurfaceSkeletonGradient подтемы default. |
| **InverseSurfaceSkeletonDeepGradient** | Инвертированное значение SurfaceSkeletonDeepGradient подтемы default. |

## Механика и взаимодействия

- Skeleton отображается анимированным во время загрузки контента — мерцание/пульсация, которые показывают, что данные ещё подгружаются.

## FAQ

### Для дизайнеров

**Q: Чем Skeleton отличается от Spinner/Loader?**
A: Skeleton имитирует структуру и макет будущего контента (заполнитель), а Loader/Spinner — это просто индикатор процесса. Для мгновенного отклика системы (0.5–1 сек) подойдёт обычный Loader или Skeleton. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL Skeleton Doc Block 1}}.

**Q: Когда не стоит использовать Skeleton?**
A: Если визуальный формат загружаемого контента неизвестен или нужно указать обработку/изменение данных. В этом случае лучше адаптировать пустое состояние с иконкой загрузки. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL Skeleton Doc Block 1}}.

**Q: Какие типы Skeleton есть в дизайне?**
A: Два: LineSkeleton — для текстового содержимого (например, абзацев), и RectSkeleton — для графики (иконок, аватаров, небольших изображений). Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Skeleton Doc Block 1}}.

**Q: Можно ли показать Skeleton на целый блок, а не на отдельные элементы?**
A: Да. Возможны оба варианта: отдельные заполнители на разные элементы или один Skeleton на весь блок. Подробнее — в Pixso-документации компонента, блок «Примеры использования»: {{Pixso URL Skeleton Doc Block 1}}.

**Q: Каким должен быть цвет заливки заполнителя?**
A: Цвет задаётся токенами поверхности — по умолчанию используется стандартный токен, для более яркого варианта есть «глубокий». Есть также значения для тёмной, светлой и инверсной подтем. В дизайне уже созданы компоненты с верным токеном внутри. Подробнее — в Pixso-документации компонента, блок «Токены поверхности»: {{Pixso URL Skeleton Doc Block 1}}.

### Для разработчиков

**Q: Как настроить анимацию заполнителя?**
A: Через `animationType`: `shimmer` (бегущий градиент, по умолчанию) или `pulse` (пульсация фона). Примеры кода — в Storybook: {{Storybook URL Skeleton}}.

**Q: Какие компоненты использовать для текста и для графики?**
A: `LineSkeleton` — для загрузки текстового содержимого, `RectSkeleton` — для графических элементов (иконки, аватары, небольшие изображения). Примеры кода — в Storybook: {{Storybook URL Skeleton}}.

**Q: Как задаётся токен поверхности в коде?**
A: Токен (SurfaceSkeletonGradient, SurfaceSkeletonDeepGradient и варианты для тёмной/светлой/инверсной подтем) задаётся внутри компонента в дизайне; выбор токена в коде уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Skeleton}}.
