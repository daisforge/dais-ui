# TextArea

Элемент формы, который создаёт многострочное поле для ввода текста. Обеспечивает возможность ввода или взаимодействия с данными.

Визуал: {{Pixso URL TextArea Doc Block 1}}

---

## Анатомия

1. **Title** — заголовок поля над инпутом (опционально, через Title Caption).
2. **Label** — лейбл поля. Может располагаться снаружи поля (Outer) или внутри (Inner), либо быть выключен (None).
3. **Placeholder** — текст-подсказка в пустом поле, отображается пока Value не введено.
4. **Value** — введённое значение.
5. **Helper Text** — блок подсказок под полем, состоит из Caption (слева) и Counter (справа).
6. **Caption** — текстовая подсказка под полем.
7. **Counter** — счётчик под полем справа.
8. **ContentRight** — иконка в правой части поля (опционально).
9. **ScrollBar** — полоса прокрутки внутри поля (в заполненных вариантах с фокусом).

> При вытягивании TextArea из библиотеки она имеет компактный вид с включённым Helper Text — чтобы визуально отличать её от TextField. При выключении Helper Text TextArea становится в одну строку.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="TextArea" />`.

### View

Вид отвечает за цветовое оформление поля.

| Вид | Назначение |
|---|---|
| **Default** | Дефолтное поле ввода. |
| **Warning** | Поле ввода для предупреждений (только в заполненных вариантах). |
| **Error** | Поле ввода для критических сценариев. |

### Value

Состояние содержимого поля.

| Value | Назначение |
|---|---|
| **Empty** | Текст ещё не введён (показан Placeholder). |
| **Single** | Заполненное состояние с одним значением. |

### LabelPlacement

Расположение лейбла относительно поля.

| LabelPlacement | Результат |
|---|---|
| **None** | Лейбл выключен. |
| **Inner** | Лейбл внутри поля ввода (кроме размера 32 XS). |
| **Outer** | Лейбл снаружи поля ввода. |

### RequiredPlacement

Расположение индикатора обязательного заполнения.

| RequiredPlacement | Результат |
|---|---|
| **None** | Индикатора нет. |
| **Left** | Индикатор слева. |
| **Right** | Индикатор справа. |

> В обновлённых полях индикатор Required располагается только справа.

### Подсказки и заголовок

| Свойство | Назначение |
|---|---|
| **Title Caption** | Включает заголовок (Caption) над инпутом. |
| **hasHint** | Включает подсказку-тултип. |
| **HelperText** | Включает блок Helper Text (Caption и Counter). |
| **Caption** | Включает Caption под полем. |
| **Counter** | Включает Counter под полем. |
| **Optional** | Включает подсказку «не обязательно к заполнению». |

### Прочие свойства

| Свойство | Назначение |
|---|---|
| **Focused** | Включает состояние фокуса. |
| **Disabled** | Включает состояние Disabled. |
| **ReadOnly** | Включает состояние ReadOnly. |
| **Required** | Включает индикатор обязательного заполнения. |
| **ScrollBar** | Включает полосу прокрутки (в заполненном поле с фокусом). |

## Состояния

| Состояние | Поведение |
|---|---|
| **Default** | Поле доступно для ввода. |
| **Focused** | Поле в фокусе, доступен ввод и прокрутка. |
| **Disabled** | Поле заблокировано. Может стать доступным при манипуляциях (например, при заполнении другого поля или возврате на шаг назад). Может быть пустым. Выделение и копирование текста мышью внутри поля недоступно. |
| **ReadOnly** | Поле только в режиме просмотра. Редактирование недоступно, разблокировка не предусмотрена. Текст из поля можно скопировать. |
| **Required** | Поле обязательно для заполнения — отображается специальный индикатор. |

## Механика и взаимодействия

Высоту поля можно регулировать двумя способами в зависимости от сценария.

### Кейс 1 — ограничение по высоте + скролл

Когда нужно ограничить поле фиксированной высотой: тексту задаётся Truncate на нужное количество строк и включается ScrollBar. При этом важно заново привязать шрифт к стилю.

### Кейс 2 — Hug текста, поле расширяется при написании

Когда не нужно ограничивать поле фиксированной высотой: текст пишется как есть, поле расширяется по содержимому. Для этого сценария важно указать для разработчика, есть ли предел расширения поля.

> Важно: описывайте поведение компонента для разработчика в стикере к макету, чтобы в коде поле работало так, как задумано в дизайне.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| View | `view` | default / positive / warning / negative | View Error в дизайне соответствует `negative` в коде. |
| Size | `size` | s | В библиотеке представлен размер S. |
| Label | `label` | строка | Текстовый лейбл поля. |
| Placeholder | `placeholder` | строка | Текст-подсказка пустого поля. |
| Value | `value` / `defaultValue` | строка | Введённое значение (управляемое / неуправляемое). |
| Helper Text (Caption слева / справа) | `leftHelper`, `rightHelper` | строка | Подсказка снизу слева и/или справа. |
| Title Caption | `titleCaption` | строка | Заголовок над полем. |
| hasHint (тултип) | `hintText` | строка | Текст подсказки-тултипа. |
| Required | `required`, `hasRequiredIndicator` | boolean | Обязательность поля и наличие индикатора. |
| RequiredPlacement | `requiredPlacement` | left / right | Расположение индикатора. |
| ContentRight | `contentRight` | иконка (ReactNode) | Иконка в правой части поля. |
| Авто-расширение (Кейс 2) | `autoResize`, `minAuto`, `maxAuto` | boolean / число | Авто-высота по содержимому, мин./макс. число строк. |
| Размеры поля | `height`, `width`, `rows`, `cols` | число | Высота/ширина и фиксированное число строк/столбцов. |
| Слот над текстом | `headerSlot` | ReactNode | Дополнительный контент над вводимым текстом. |

> Для остальных дизайн-свойств (Inner Label, LabelPlacement, ScrollBar, Disabled, ReadOnly, Optional) уточните соответствие в Storybook или в чате поддержки ДС.

## FAQ

### Для дизайнеров

**Q: Как ограничить TextArea по высоте?**
A: Задайте тексту Truncate на нужное количество строк и включите ScrollBar — поле получит фиксированную высоту со скроллом. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Как сделать, чтобы поле расширялось при написании текста?**
A: Используйте сценарий Hug — текст пишется как есть, поле расширяется по содержимому. Укажите в стикере для разработчика предел расширения поля, если он нужен. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Когда использовать TextArea?**
A: Когда нужен ввод длинного многострочного текста — комментарии, описания, примечания. Для короткого однострочного ввода используйте однострочное поле. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Как сделать поле обязательным?**
A: Включите Required — появится индикатор. Расположение задаётся через RequiredPlacement; в обновлённых полях индикатор располагается только справа. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Как добавить заголовок и подсказки к полю?**
A: Заголовок над полем включается через Title Caption, подсказки снизу — через Helper Text (Caption и Counter), подсказка-тултип — через hasHint. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Как сделать поле в режиме просмотра?**
A: Включите ReadOnly — поле доступно только для просмотра, текст можно скопировать, но редактировать нельзя. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL TextArea Doc Block 1}}.

**Q: Можно ли использовать TextArea с множественными значениями (чипами)?**
A: Нет. Вид Value → Multiple существует как техническое наследование от поля ввода, но в TextArea (как и в TextField) множественные значения не используются ни при каких обстоятельствах.

### Для разработчиков

**Q: Как задать вид поля?**
A: Через проп `view` со значениями `default` / `positive` / `warning` / `negative`. Вид Error в дизайне соответствует `negative` в коде. Примеры кода — в Storybook: {{Storybook URL TextArea}}.

**Q: Как включить авто-расширение по содержимому?**
A: Передайте `autoResize`, а пределы задайте через `minAuto` и `maxAuto` (минимальное и максимальное число строк). Примеры кода — в Storybook: {{Storybook URL TextArea}}.

**Q: Как задать размеры поля?**
A: Высота и ширина — через `height` и `width`; фиксированное число строк и столбцов — через `rows` и `cols`. Примеры кода — в Storybook: {{Storybook URL TextArea}}.

**Q: Как вывести подсказки и заголовок?**
A: Подсказки снизу — `leftHelper` и/или `rightHelper`, тултип — `hintText`, заголовок сверху — `titleCaption`. Примеры кода — в Storybook: {{Storybook URL TextArea}}.

**Q: Как сделать поле обязательным и задать индикатор?**
A: Обязательность — через `required`, наличие индикатора — через `hasRequiredIndicator`, расположение — через `requiredPlacement` (`left` / `right`). Примеры кода — в Storybook: {{Storybook URL TextArea}}.

**Q: Как добавить контент над вводимым текстом?**
A: Через проп `headerSlot` — в него передаётся произвольный контент. Примеры кода — в Storybook: {{Storybook URL TextArea}}.
