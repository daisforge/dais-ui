# Notification

Всплывающий элемент — уведомление поверх контента. Появляется в правом углу страницы и может содержать кнопки. Используется, чтобы обозначить результат целевого действия пользователя.

Визуал: {{Pixso URL Notification Doc Block 1}}

---

## Анатомия

1. **Иконка** — залитая иконка слева от контента (опционально, см. IconPlacement).
2. **Title** — заголовок уведомления. Можно скрыть (hasTitle).
3. **Text** — дополнительное текстовое поле под заголовком. Можно скрыть (hasText).
4. **Группа кнопок (Label)** — кнопки с действиями. Можно скрыть (hasActions).
5. **Иконка закрытия** — крестик в правом верхнем углу. Можно скрыть (hasClose).

---

## Типы

Ориентация уведомления.

| Ориентация | Описание | Визуал |
|---|---|---|
| **Vertical** | Notification в вертикальной ориентации: иконка и заголовок сверху, текст под ними, группа кнопок снизу. | {{Pixso URL Notification Doc Block 3}} |
| **Horizontal** | Notification в горизонтальной ориентации: иконка слева, заголовок и текст в одну колонку, группа кнопок и крестик справа в строку. | {{Pixso URL Notification Doc Block 2}} |

---

## Размеры и отступы

- **Title font:** Body/BodyS B
- **Text font:** Body/BodyS N
- **Corner radius:** Calc: crm (14)
- **Iconsize:** 24px
- **Отступ от краёв страницы:** 40px

Рекомендуемая ширина уведомления — не более 700px, высота — не более 114px. Максимальное количество символов: Title — 2 строки, Text — 2 строки.

### Style

Цветовое оформление уведомления.

| Style | Назначение |
|---|---|
| Default | Дефолтное оформление на светлом фоне. |
| OnDark | Оформление на тёмном фоне. |
| Inverse | Инвертированное оформление. |
| OnLight | Оформление на светлом фоне. |

В горизонтальной ориентации также используются статусные варианты иконки и подложки (информационный, успех, предупреждение, ошибка) — соответствующая залитая иконка слева. Иконки по умолчанию выставлены в компоненте; если в кейсе нужна другая иконка, можно написать в чат поддержки ДС.

### IconPlacement

Расположение иконки.

| IconPlacement | Результат |
|---|---|
| Left | Иконка расположена слева от контента. |
| None | Компонент без иконки. |

### Флаги отображения

| Флаг | True | False |
|---|---|---|
| hasTitle | Заголовок отображается. | Заголовок скрыт. |
| hasText | Дополнительное текстовое поле отображается. | Текстовое поле скрыто. |
| hasActions | Группа кнопок отображается. | Группа кнопок скрыта. |
| hasClose | Иконка закрытия (крестик) отображается. | Иконка закрытия скрыта. |

## Состояния

- **Появление** — уведомление всплывает в правом углу поверх контента.
- **Автозакрытие** — уведомление само исчезает по истечении заданного времени; продукт может оставить его на экране бессрочно.
- **Закрытие крестиком** — пользователь закрывает уведомление вручную через иконку закрытия (при hasClose: True).
- **С кнопками / без кнопок** — при hasActions отображается группа кнопок (Label) с действиями.

## Механика и взаимодействия

### Когда использовать

Если нужно обозначить результат целевого действия пользователя — используйте уведомление. Например, результат создания сущности → уведомление «[Сущность] создана», так как это целевое действие при создании сущности. Техническое оповещение, не являющееся целевым действием (например, «Обновлено» после обновления таблицы), — это сценарий тоста.

### Расположение

Уведомление появляется в правом нижнем углу страницы с отступом 40px от краёв. Уведомление содержит контент (иконку, заголовок, текст) и может содержать кнопки действий.

### Появление и автозакрытие

Уведомление всплывает поверх контента и автоматически исчезает по истечении заданного времени. Продукт может оставить уведомление на экране бессрочно. Детали тайминга (через сколько появляется и исчезает уведомление, fade-time) уточняются — см. Storybook.

### Несколько уведомлений

- **1–2 уведомления** — располагаются друг под другом с отступом 12px.
- **3 и более** — при большом количестве уведомлений самые старые пропадают, показываются новые. Максимальное количество уведомлений на экране определяется продуктом, максимум 1–3.
- **Объединение уведомлений** — если в кейсе нужно показать количество выполненных пунктов, их можно объединить в пару уведомлений: одно с успехом, одно с неудачей.

### Кнопки и закрытие

Группа кнопок (Label) показывается при hasActions. Крестик закрытия показывается при hasClose. Если нужен сценарий с другой иконкой или новым типом — напишите в чат поддержки ДС.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Style | `view` | значения уточняются | Style в дизайне (Default / OnDark / Inverse / OnLight, статусные варианты) задаётся пропом `view`. Доступные значения — см. Storybook. |
| Заголовок (Title) | `title` | строка | Текст заголовка. |
| Текст (Text) | `children` | ReactNode | Дополнительное текстовое поле / содержимое. |
| Иконка (IconPlacement Left) | `icon` | иконка (ReactNode) | Залитая иконка слева от контента. |
| Цвет заголовка | `titleColor` | CSS-цвет | Переопределяет цвет заголовка. |
| Цвет текста | `textColor` | CSS-цвет | Переопределяет цвет текста контента. |
| Ширина | `width`, `maxWidth` | CSS-значение | Ширина и максимальная ширина уведомления. |
| Расположение в углу | `placement` (у `NotificationsProvider`) | center / top / bottom / right / left и комбинации (например `top-right`) | Позиционирование задаётся на провайдере. |
| Автозакрытие | `timeout` (в `addNotification`) | мс | Время до автозакрытия; `0` или `null` — уведомление висит бессрочно. |

## FAQ

### Для дизайнеров

**Q: Когда использовать уведомление, а когда тост?**
A: Если нужно обозначить результат целевого действия пользователя — используйте уведомление (например, «[Сущность] создана»). Для технических оповещений, не являющихся целевым действием, — тост. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Notification Doc Block 1}}.

**Q: Где появляется уведомление на странице?**
A: В правом нижнем углу страницы с отступом 40px от краёв. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Notification Doc Block 1}}.

**Q: Чем отличаются Vertical и Horizontal?**
A: Vertical — иконка и заголовок сверху, текст под ними, группа кнопок снизу; Horizontal — иконка слева, заголовок и текст в колонку, кнопки и крестик справа в строку. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Notification Doc Block 1}}.

**Q: Как сделать уведомление без заголовка, текста, кнопок или крестика?**
A: Через флаги hasTitle / hasText / hasActions / hasClose — каждый включает или выключает соответствующий элемент. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Notification Doc Block 1}}.

**Q: Как убрать иконку?**
A: Через свойство IconPlacement: Left — иконка слева от контента, None — компонент без иконки. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Notification Doc Block 1}}.

**Q: Какие есть варианты оформления (Style)?**
A: Default, OnDark, Inverse, OnLight; в горизонтальной ориентации добавляются статусные варианты иконки и подложки (информация, успех, предупреждение, ошибка). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Notification Doc Block 1}}.

**Q: Как показать сразу несколько уведомлений?**
A: 1–2 уведомления располагаются друг под другом с отступом 12px; при 3 и более старые пропадают, показываются новые (максимум на экране задаёт продукт, до 1–3). Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Notification Doc Block 1}}.

**Q: Сколько помещается текста в уведомление?**
A: Title — до 2 строк, Text — до 2 строк; рекомендуемая ширина не более 700px, высота не более 114px. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Notification Doc Block 1}}.

**Q: Нужна другая иконка или новый тип уведомления — что делать?**
A: Иконки по умолчанию выставлены в компоненте; если в кейсе нужна другая иконка или новый тип — напишите в чат поддержки ДС. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Notification Doc Block 1}}.

### Для разработчиков

**Q: Как вызвать уведомление?**
A: Используйте `NotificationsProvider` и метод `addNotification` (вторым аргументом — `timeout` в мс). Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как задать автозакрытие или сделать уведомление бессрочным?**
A: Через `timeout` (в мс) в `addNotification`; передайте `0` или `null`, чтобы уведомление висело бессрочно. Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как закрыть уведомление программно?**
A: `addNotification` возвращает `id`, по которому уведомление закрывается через `closeNotification`. Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как задать позиционирование уведомления?**
A: Через `placement` у `NotificationsProvider` (`center` / `top` / `bottom` / `right` / `left` и комбинации, например `top-right`). Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как задать оформление и переопределить цвета?**
A: Оформление — через `view`; цвета заголовка и текста — через `titleColor` и `textColor`; для наследования цвета от `view` используйте значение `inherit`. Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как задать ширину уведомления?**
A: Через `width` и `maxWidth` — принимают любые валидные CSS-значения. Примеры кода — в Storybook: {{Storybook URL Notification}}.

**Q: Как задать заголовок, текст и иконку?**
A: `title` — заголовок, `children` — содержимое/текст, `icon` — иконка слева. Примеры кода — в Storybook: {{Storybook URL Notification}}.
