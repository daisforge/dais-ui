# Tree

Иерархическая структура списка, которая позволяет пользователям перемещаться по вложенным наборам информации или функций.

Визуал: {{Pixso URL Tree Doc Block 1}}

> **Рекомендация:** чтобы избежать потери введённого контента, сначала настраивайте свойства Tree верхнеуровнего, а после изменяйте варианты TreeItem.

---

## Анатомия

1. **Header** — заголовок списка. Содержит Title, опциональный TitleCaption и опциональную подсказку-тултип справа от заголовка. Отображение Header можно включить или выключить.
2. **TreeItem** — элемент списка. Бывает родительским (раскрывает вложенные элементы) и дочерним (отображается при раскрытии родителя). Внутри TreeItem располагаются:
   - **Title** — основной текст элемента.
   - **TitleCaption** — подпись над заголовком (опционально).
   - **Description** — описание элемента (опционально).
   - **Иконка слева** — опциональная иконка перед заголовком.
   - **Action-иконка справа** — опциональная иконка действия в правой части.
   - **Стрелка раскрытия** — у родительского элемента, для раскрытия и сворачивания вложенных элементов.
3. Во вложенных слотах TreeItem можно размещать дополнительные компоненты: **Checkbox** (в списке с визуальным элементом выбора), **Counter**, **DropdownMenu**, **Divider**.

> Дочерний элемент списка отображается при свойстве Opened = True у родительского элемента.

## Размеры и отступы

Ширина компонента фиксирована, высота зависит от количества включённых открытых или закрытых элементов.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Tree" />`.

### Свойства Tree (верхнего уровня)

| Свойство | Значения | Назначение |
|---|---|---|
| **TypeSelection** | Highlight / CheckBox | Highlight — вид списка без визуального элемента выбора. CheckBox — список с визуальным элементом выбора (в элементы вложен компонент Checkbox). |
| **ArrowPlacement** | Left / Right | Расположение стрелки для раскрытия и сворачивания вложенных элементов — слева или справа. |
| **hasSideMargins** | True / False | Включает или выключает боковые отступы у заголовка и у элементов списка. |
| **hasHeader** | True / False | Включает или выключает отображение Header. |
| **hasTitleCaption** | True / False | Включает или выключает отображение TitleCaption. Свойство отображается при hasHeader = True. |
| **hasHint** | True / False | Включает или выключает отображение тултипа справа от заголовка. Свойство отображается при hasHeader = True. |

### Свойства TreeItem

| Свойство | Значения | Назначение |
|---|---|---|
| **Level** | Level 1 / Level 2 / Level 3 | Уровень вложенности элемента. Level 1 — верхний уровень (родительский элемент), Level 2 и Level 3 — дочерние вложенные элементы. |
| **hasNesting** | True / False | Включает или выключает отображение стрелки для раскрытия и сворачивания вложенных элементов. |
| **hasIcon** | True / False | Включает или выключает отображение иконки слева. |
| **hasAction** | True / False | Включает или выключает отображение action-иконки справа. |
| **SingleLineText** | True / False | Свойство на уровне Text. True — контент в одну строку, при нехватке места обрезается многоточием (высота элемента фиксирована). False — контент в несколько строк (высота элемента по контенту). |

> Для дочерних элементов свойства hasIcon и hasAction относятся к крайним элементам ветки (FirstChildItem и LastChildItem).

## Состояния

| Состояние | Значения | Описание |
|---|---|---|
| **Selected** | True / False | Включает или выключает выделение элемента. |
| **Opened** | True / False | True — раскрывает вложенный элемент, False — скрывает. |
| **Disabled** | True / False | Включает или выключает неактивное состояние элемента. |
| **Loading** | True / False | Свойство в коде. При загрузке дочерних элементов вместо стрелки раскрытия отображается спиннер. В дизайне это состояние можно показать, заменив иконку-стрелку на SpinnerScalable. |

## Механика и взаимодействия

Дизайн-суть поведения:

- **Раскрытие и сворачивание веток.** Родительский элемент содержит стрелку, по которой ветка раскрывается (Opened = True) и сворачивается (Opened = False). Расположение стрелки задаётся свойством ArrowPlacement (слева или справа). Отображение самой стрелки управляется свойством hasNesting.
- **Навигация по вложенным наборам.** Элементы выстраиваются по уровням (Level 1–3): верхний уровень — родительские элементы, ниже — дочерние. Дочерние элементы появляются при раскрытии родителя.
- **Выбор элементов.** В режиме CheckBox в элементы вложен компонент Checkbox — пользователь выбирает элементы галочками. В режиме Highlight список работает без визуального элемента выбора, активный элемент подсвечивается состоянием Selected.
- **Загрузка вложенных элементов.** При асинхронной подгрузке детей родителя вместо стрелки раскрытия показывается спиннер (состояние Loading). Само свойство загрузки реализовано в коде; в дизайне его отображают заменой стрелки на SpinnerScalable.

Детали реализации (контролируемый и неконтролируемый режимы, виртуализация, drag and drop, асинхронная подгрузка) — в Storybook: {{Storybook URL Tree}}.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| TypeSelection: CheckBox | `checkable` | boolean | Режим CheckBox = `checkable`. Отображение чекбоксов настраивается на уровне Tree. |
| Selected (выбор элемента) | `selectedKeys` / `onTreeSelect` | массив ключей | Выделение элементов в списке. |
| Opened (раскрытие ветки) | `expandedKeys` / `onTreeExpand` | массив ключей | Раскрытие и сворачивание веток. `defaultExpandAll` раскрывает все ветки сразу. |
| CheckBox (отметка элемента) | `checkedKeys` / `onTreeCheck` | массив ключей | Состояние отмеченных чекбоксами элементов. |
| Disabled | `disabled` | boolean | Задаётся в данных элемента (поле `disabled` в TreeItem). |
| Иконка слева (hasIcon) | `icon` | иконка (ReactNode) | Задаётся в данных элемента. |
| Action-иконка справа (hasAction) | `contentRight` | ReactNode | Контент справа от элемента. |
| Title | `title` | строка / ReactNode | Заголовок элемента. |
| Уровни и вложенность (Level) | `children` | массив элементов | Дочерние элементы задаются массивом `children` внутри элемента. |
| Loading | `loadData` / `onLoadData` / `isLeaf` | — | Асинхронная подгрузка вложенных элементов. |

## FAQ

### Для дизайнеров

**Q: Как раскрыть вложенные элементы у родительского элемента?**
A: Включить у родительского элемента свойство Opened — раскроются дочерние элементы. Отображение самой стрелки раскрытия управляется свойством hasNesting. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: Как переместить стрелку раскрытия влево или вправо?**
A: Задать свойство ArrowPlacement: Left — стрелка слева, Right — стрелка справа. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: Как сделать список с чекбоксами?**
A: Выбрать TypeSelection → CheckBox — в элементы будет вложен компонент Checkbox. Отображение чекбокса настраивается на уровне Tree. Вид без чекбоксов — TypeSelection → Highlight. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: Как показать заголовок списка с подписью и подсказкой?**
A: Включить hasHeader для отображения Header. При hasHeader = True становятся доступны hasTitleCaption (подпись TitleCaption) и hasHint (тултип-подсказка справа от заголовка). Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: Какие размеры есть у Tree?**
A: Четыре: L (56), M (48), S (40), XS (32). Каждый со своим скруглением углов, шрифтами Title / Description / TitleCaption и размером иконки. Ширина фиксирована, высота зависит от количества открытых или закрытых элементов. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Tree Doc Block 1}}.

**Q: Как сделать текст элемента в одну строку с обрезкой?**
A: Включить свойство SingleLineText на уровне Text — контент будет в одну строку и обрежется многоточием при нехватке места, высота элемента фиксирована. При SingleLineText = False текст переносится на несколько строк, высота элемента подстраивается по контенту. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: Как показать состояние загрузки вложенных элементов?**
A: При загрузке дочерних элементов вместо стрелки раскрытия отображается спиннер (состояние Loading). Само свойство загрузки реализовано в коде; в дизайне его отображают, заменив иконку-стрелку на SpinnerScalable. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Tree Doc Block 1}}.

**Q: При раскрытии списка ширина элемента «съезжает» — как поправить?**
A: При раскрытии списка в слоях элемента Fill может смениться на Fix. Чтобы поправить, выключите и снова включите иконку в этом элементе. Подробнее — в Pixso-документации компонента, блок «Рекомендации»: {{Pixso URL Tree Doc Block 1}}.

### Для разработчиков

**Q: Как задать данные дерева?**
A: Через обязательный массив `items`. Каждый элемент содержит `key`, `title` и опционально `children`, `icon`, `disabled`, `contentRight`. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как включить чекбоксы?**
A: Передать проп `checkable`. Отмеченные элементы хранятся в `checkedKeys`, изменения обрабатывает `onTreeCheck`. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как управлять раскрытием веток?**
A: В контролируемом режиме — через `expandedKeys` и `onTreeExpand`. Чтобы раскрыть все ветки сразу — `defaultExpandAll`. Чтобы раскрыть путь до нужного ключа — `autoExpandParent`. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как реализовать выбор элементов?**
A: Через `selectedKeys` и `onTreeSelect`. Для выделения по всей ширине элемента — `fullWidthItemSelection`. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как включить виртуализацию для больших списков?**
A: Обязательны два свойства — `height` и `itemHeight`. Дополнительно есть флаг `virtual` для явного включения или отключения виртуализации. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как включить drag and drop?**
A: Включить свойство `draggable`. Основной обработчик — `onDrop`; ограничить места сброса можно через `allowDrop`. Логика перемещения настраивается на стороне клиента. Примеры кода — в Storybook: {{Storybook URL Tree}}.

**Q: Как настроить асинхронную загрузку вложенных элементов?**
A: Через `loadData`, `onLoadData` и `isLeaf`. При загрузке детей вместо стрелки раскрытия показывается спиннер. Примеры кода — в Storybook: {{Storybook URL Tree}}.
