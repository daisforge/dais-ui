# DatePicker

Элемент выбора даты или диапазона дат посредством ввода текста, либо путём выбора даты из календаря.

DatePicker наследует все свойства и стили вложенных компонентов: поле ввода (TextField) и всплывающий календарь (Calendar). Компонент Calendar имеет фиксированные значения ширины и высоты в каждом размере, выведен в абсолют и не влияет на размер компонента.

Визуал: {{Pixso URL DatePicker Doc Block 1}}

---

## Анатомия

1. **Поле ввода (DatePickerTrigger)** — поле, в которое можно ввести дату вручную или открыть календарь. Реализовано на компоненте TextField. У него есть Label, Placeholder, подсказка, индикатор обязательности и слот для иконки справа.
2. **Calendar** — всплывающий календарь, который открывается под полем (или сбоку для диапазона). Это отдельный компонент со своей документацией — здесь он показан как вложенный.

Для диапазона дат в компоненте два поля ввода (начало и конец) и общий календарь.

## Размеры и отступы

Размер компонента равен размеру DatePickerTrigger (поля ввода на компоненте TextField). Высота тянется в заданном диапазоне в зависимости от содержимого (подсказка, индикатор обязательности и т. д.). Размер всплывающего календаря фиксирован и от размера компонента не зависит.

| Размер | Минимальная высота | Максимальная высота |
|---|---|---|
| **S** | 40px | 84px |
| **XS** | 32px | 70px |

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="DatePicker" />` и `<PropsTable name="DatePickerRange" />`.

### Opened

Управляет видимостью всплывающего календаря: открыт он или скрыт.

| Значение | Результат |
|---|---|
| True | Календарь открыт. |
| False | Календарь скрыт. |

### PickerType

Количество календарей во всплывающем окне.

| Значение | Результат |
|---|---|
| Single | Отображается одинарный календарь. |
| Double | Отображается двойной календарь. |

### Placement

Положение всплывающего календаря относительно поля ввода (для диапазона дат).

| Значение | Результат |
|---|---|
| Left | Положение календаря слева. |
| Right | Положение календаря справа (выровнен по элементу RightContent компонента Range). |

### Пресеты (shortcuts)

Пресеты — быстрые варианты выбора (например, «Сегодня», «Неделя»), которые отображаются рядом с календарём.

| Свойство | Назначение |
|---|---|
| hasShortcuts | Включает или выключает пресеты в календаре. |
| ShortcutsPlacement | Положение пресетов: слева или справа от календаря. |
| hasScrollBar | Включает или выключает скроллбар в блоке пресетов. |

### Автозакрытие после выбора

Поведение закрытия всплывающего календаря после выбора даты (настраивается в коде).

| Значение | Результат |
|---|---|
| True | Календарь закрывается автоматически после выбора значения. |
| False | Календарь закрывается по клику вне области календаря либо остаётся на усмотрение пользователя. |

## Состояния

Состояния DatePicker наследуются от вложенного поля ввода (TextField): обычное, с фокусом, заполненное, с ошибкой и с индикацией успешного ввода. Для обязательного поля рядом с лейблом отображается индикатор обязательности; его положение настраивается. Подробнее о состояниях поля — в документации TextField.

---

## Механика и взаимодействия

Дата задаётся двумя способами:

1. **Ввод текста в поле** — пользователь вводит дату вручную в заданном формате. При вводе и при выборе из календаря значение приводится к заданному формату.
2. **Выбор из календаря** — по клику в поле открывается всплывающий компонент Calendar, в котором выбирается дата (или диапазон для DatePicker Range).

Для диапазона выбираются две даты — начало и конец. Календарь может быть одинарным или двойным (см. PickerType). Рядом с календарём могут отображаться пресеты для быстрого выбора. После выбора даты календарь либо закрывается автоматически, либо остаётся открытым (автозакрытие настраивается в коде).

Детали реализации (форматы, маскирование ввода, валидация, локализация, события календаря) — в Storybook: {{Storybook URL DatePicker}}.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Размер S / XS | `size` | s / xs | Прямое соответствие. |
| PickerType (Single / Double) | `isDoubleCalendar` | boolean | Single = `false`; Double = `true`. |
| Opened | `opened` | boolean | Управляет видимостью календаря. |
| closeAfterDateSelect | `closeAfterDateSelect` | boolean | Помечено в источнике как «свойство в коде». |
| Поле: Label | `label` | строка | Лейбл поля ввода. |
| Поле: Placeholder | `placeholder` (для Range — `firstPlaceholder`, `secondPlaceholder`) | строка | Текст-заглушка в поле. |
| Поле: подсказка | `leftHelper` | строка | Подсказка под полем. |
| Иконка справа в поле | `contentRight` | иконка (ReactNode) | Слот в правой части поля. |
| Индикатор обязательности | `required`, `hasRequiredIndicator`, `requiredPlacement` | boolean / boolean / left \| right | Обязательность поля и положение индикатора. |

## FAQ

### Для дизайнеров

**Q: Как сделать выбор диапазона дат вместо одной даты?**
A: Использовать тип DatePicker Range — у него два поля ввода (начало и конец) и общий календарь. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL DatePicker Doc Block 1}}.

**Q: Как показать сразу два календаря рядом?**
A: Выбрать PickerType → Double — отображается двойной календарь. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL DatePicker Doc Block 1}}.

**Q: Какие размеры есть у DatePicker?**
A: Два: S (высота от 40px до 84px) и XS (высота от 32px до 70px). Размер компонента равен размеру поля ввода DatePickerTrigger. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL DatePicker Doc Block 2}}.

**Q: Влияет ли размер календаря на размер компонента?**
A: Нет. Calendar имеет фиксированные ширину и высоту в каждом размере, выведен в абсолют и на размер компонента не влияет. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL DatePicker Doc Block 1}}.

**Q: Как разместить календарь слева или справа от поля?**
A: Через свойство Placement: Left — слева, Right — справа (выровнен по элементу RightContent компонента Range). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL DatePicker Doc Block 1}}.

**Q: Как добавить пресеты быстрого выбора рядом с календарём?**
A: Включить hasShortcuts, задать положение через ShortcutsPlacement (слева или справа от календаря) и при необходимости включить скроллбар через hasScrollBar. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL DatePicker Doc Block 1}}.

**Q: Как сделать так, чтобы календарь закрывался сразу после выбора даты?**
A: Автозакрытие календаря после выбора — это настройка в коде. По умолчанию календарь закрывается после выбора даты; иначе закрывается по клику вне области. Уточните в Storybook: {{Storybook URL DatePicker}}.

**Q: Где описаны состояния поля ввода и календаря?**
A: Состояния поля наследуются от TextField, всплывающий календарь — это компонент Calendar. Подробнее — в документации компонентов TextField и Calendar.

### Для разработчиков

**Q: Как переключить компонент на выбор диапазона дат?**
A: Использовать `DatePickerRange` вместо `DatePicker`. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как показать двойной календарь?**
A: Передать проп `isDoubleCalendar` (boolean) — в дизайне это PickerType со значением Double. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как задать размер?**
A: Через проп `size` со значениями `s` / `xs` — прямое соответствие размерам S / XS. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как настроить формат и язык даты?**
A: Через `format` (например, `DD.MM.YYYY`) и `lang` (`ru` / `en`); `maskWithFormat` включает маскирование ввода. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как сделать поле обязательным и сдвинуть индикатор?**
A: Через `required`, отображение индикатора — `hasRequiredIndicator`, его положение — `requiredPlacement` (`left` / `right`). Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как отобразить ошибку или успешный ввод даты?**
A: Через `valueError` и `valueSuccess` (boolean); валидацию удобно вызывать в обработчике `onCommitDate`. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как управлять открытием календаря и его автозакрытием?**
A: Видимость — пропом `opened`, автозакрытие после выбора — `closeAfterDateSelect`. Примеры кода — в Storybook: {{Storybook URL DatePicker}}.

**Q: Как добавить пресеты быстрого выбора и скроллбар к ним?**
A: Это блок shortcuts из дизайна (hasShortcuts / ShortcutsPlacement / hasScrollBar). Точные имена пропов и примеры — в Storybook или в чате поддержки ДС: {{Storybook URL DatePicker}}.
