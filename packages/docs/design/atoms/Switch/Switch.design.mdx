# Switch

Компонент, который используется для переключения между двумя состояниями. Switch инициирует переключение состояния немедленно, без дополнительного подтверждения выбора.

Визуал: {{Pixso URL Switch Doc Block 1}}

---

## Анатомия

1. **Переключатель (тумблер)** — сам переключающийся элемент с двумя положениями.
2. **Label** — текстовый лейбл (Title). Можно скрыть.
3. **Description** — дополнительное текстовое поле под лейблом. Можно скрыть.

---

## Размеры и отступы

Размер компонента (Size) задаёт шрифты лейбла и описания. Размер самого тумблера (ToggleSize) задаётся отдельно.

| Размер | Шрифт лейбла (Label) | Шрифт описания (Description) |
|---|---|---|
| **L** | Body/BodyL N | Body/BodyM N |
| **M** | Body/BodyM N | Body/BodyS N |
| **S** | Body/BodyS N | Body/BodyXS N |

Размер тумблера (ToggleSize):

| ToggleSize | Значение |
|---|---|
| **L** | 28 |
| **S** | 20 |

Отступ между тумблером и текстовым блоком — фиксированный, 12px.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Switch" />`.

### Лейбл

Свойство hasLabel управляет отображением текстового лейбла (Title). При включённом — лейбл виден, при выключенном — скрыт.

### Описание

Свойство hasSubtitle управляет отображением дополнительного текстового поля под лейблом. При включённом — описание видно, при выключенном — скрыто.

### Активное состояние (Turn On)

Свойство Turn On переводит переключатель в активное (включённое) или неактивное (выключенное) состояние.

### Размер

Свойство Size задаёт размер компонента: S, M, L. От него зависят шрифты лейбла и описания (см. «Размеры и отступы»).

### Размер тумблера

Свойство ToggleSize задаёт размер самого тумблера независимо от размера компонента: S (20) или L (28).

## Состояния

| Состояние | Описание |
|---|---|
| **Default** | Базовое состояние. |
| **Disabled** | Взаимодействие с переключателем выключено. |

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| hasLabel | `label` | строка / скрыт | В дизайне булев тумблер показа лейбла; в коде лейбл задаётся текстом пропа `label`. |
| hasSubtitle | `description` | строка / скрыт | В дизайне булев тумблер показа доп. поля; в коде задаётся текстом пропа `description`. |
| Turn On | `defaultChecked` | boolean | True — активное состояние, False — неактивное. |
| Disabled | уточнить в Storybook | boolean | Состояние Disabled показано в дизайне; проп уточните в Storybook или в чате поддержки дизайн-системы. |
| Size | `size` | s / m / l | Прямое соответствие. Задаёт шрифты лейбла и описания. |
| ToggleSize | `toggleSize` | s (20) / l (28) | В дизайне свойство называется «ToggleSize», в коде — проп `toggleSize`. |

## FAQ

### Для дизайнеров

**Q: Когда выбрать Switch, а не Checkbox?**
A: Берите Switch, когда переключение должно срабатывать сразу — состояние меняется немедленно, без отдельного подтверждения выбора.

**Q: Как задать размер переключателя?**
A: Размер компонента задаёт шрифты лейбла и описания, а размер самого тумблера настраивается отдельно — так можно оставить компактный тумблер при крупном тексте и наоборот. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Switch Doc Block 1}}.

**Q: Как добавить к переключателю текст?**
A: Включите показ лейбла (Title), а при необходимости — и описания под ним. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Switch Doc Block 1}}.

**Q: Как сделать переключатель без подписи?**
A: Скройте лейбл и описание — в дизайне за это отвечают свойства hasLabel/hasSubtitle в положении False, останется только сам тумблер. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Switch Doc Block 1}}.

**Q: Как сделать переключатель изначально включённым?**
A: В дизайне за стартовое активное положение отвечает свойство Turn On. Подробнее — в Pixso-документации компонента, блок «Активное состояние»: {{Pixso URL Switch Doc Block 1}}.

**Q: Как отключить взаимодействие с переключателем?**
A: Используйте состояние Disabled — взаимодействие с переключателем будет выключено. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Switch Doc Block 1}}.

### Для разработчиков

**Q: Какими пропами задаются размеры?**
A: Размер компонента (шрифты лейбла и описания) задаётся пропом `size` (s/m/l), а размер самого тумблера — отдельным пропом `toggleSize` (s — 20 / l — 28). Примеры кода — в Storybook: {{Storybook URL Switch}}.

**Q: Какими пропами задаются лейбл, описание и стартовое состояние?**
A: Лейбл задаётся пропом `label` (дизайн-свойство hasLabel), описание под ним — пропом `description` (hasSubtitle), а изначально включённое положение — пропом `defaultChecked` (дизайн-свойство Turn On). Примеры кода — в Storybook: {{Storybook URL Switch}}.

**Q: Каким пропом задаётся размер тумблера?**
A: Размер тумблера задаётся пропом `toggleSize` (дизайн-свойство «ToggleSize»): s — 20 / l — 28. Примеры кода — в Storybook: {{Storybook URL Switch}}.
