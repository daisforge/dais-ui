# Toolbar

Вспомогательная панель с набором инструментов для работы на основном экране. Состоит из пяти равнозначных секций, в которые по умолчанию вложен компонент ButtonGroup — его можно заменить на более подходящий. Количество разделений дивайдером регулируется количеством отображаемых секций.

Визуал: {{Pixso URL ToolBar Doc Block 1}}

---

## Анатомия

1. **Header** — заголовок панели.
2. **Description** — описание панели.
3. **Секции** — пять равнозначных секций для размещения инструментов. В каждую секцию по умолчанию вложен ButtonGroup, который можно заменить на более подходящий контент.
4. **Дивайдер** — разделитель между секциями.

---

## Типы

Тип отвечает за ориентацию панели.

| Тип | Описание | Визуал |
|---|---|---|
| **Horizont** | Горизонтальная панель инструментов, закреплённая сверху или снизу. | {{Pixso URL ToolBar Doc Block 2}} |
| **Vertical** | Вертикальная панель инструментов, закреплённая слева или справа. | {{Pixso URL ToolBar Doc Block 3}} |

---

## Размеры и отступы

| Размер | Corner Radius | Эффект | Назначение |
|---|---|---|---|
| **S** | calc[l-2] (14px) | Shadow Down Soft S | Секции предназначены для компонентов с высотой 40px. |
| **XS** | m (12px) | Shadow Down Soft S | Секции предназначены для компонентов с высотой 32px. |

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Toolbar" />`.

### SectionQuantity

Количество отображаемых секций. Регулирует число разделений дивайдером.

| Значение | Результат |
|---|---|
| 5 | Пять секций. |
| 4 | Четыре секции. |
| 3 | Три секции. |
| 2 | Две секции. |
| 1 | Одна секция. |

### hasDivider

Управляет отображением разделителей между секциями.

| hasDivider | Результат |
|---|---|
| True | Включает разделители между секциями. |
| False | Выключает разделители между секциями. |

### hasShadow

Управляет тенью панели.

| hasShadow | Результат |
|---|---|
| True | Включает тень. |
| False | Выключает тень. |

## Состояния

Toolbar — контейнер для инструментов. Состояния (hover, pressed, disabled) отрабатывают вложенные элементы — кнопки и иконки-кнопки внутри секций.

## FAQ

### Для дизайнеров

**Q: Как сделать горизонтальную или вертикальную панель?**
A: Выбрать тип Horizont (горизонтальная, закрепляется сверху или снизу) или Vertical (вертикальная, закрепляется слева или справа). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Какие размеры есть у панели?**
A: Два: S (для компонентов высотой 40px, Corner Radius calc[l-2] 14px) и XS (для компонентов высотой 32px, Corner Radius m 12px). У обоих эффект Shadow Down Soft S. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Как изменить количество секций?**
A: Через свойство SectionQuantity — доступны значения от 1 до 5. Количество разделений дивайдером регулируется числом отображаемых секций. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Как включить или выключить разделители между секциями?**
A: Через свойство hasDivider: True — включает разделители, False — выключает. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Как убрать тень у панели?**
A: Через свойство hasShadow: False — выключает тень, True — включает. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Что разместить внутри секций?**
A: По умолчанию в каждую из пяти равнозначных секций вложен компонент ButtonGroup — его можно заменить на более подходящий контент. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL ToolBar Doc Block 1}}.

**Q: Где размещается заголовок и описание панели?**
A: В элементах Header (заголовок) и Description (описание). Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL ToolBar Doc Block 1}}.

### Для разработчиков

**Q: Как задать ориентацию панели?**
A: Через проп `orientation` со значениями `horizontal` или `vertical`. Тип Horizont в дизайне = `horizontal`, Vertical = `vertical`. Примеры кода — в Storybook: {{Storybook URL ToolBar}}.

**Q: Как задать размер панели?**
A: Через проп `size` со значениями `s` или `xs` — прямое соответствие размерам S / XS. Примеры кода — в Storybook: {{Storybook URL ToolBar}}.

**Q: Как передать содержимое панели?**
A: Через `children` — компонент Toolbar должен содержать контент, переданный в `children`. Примеры кода — в Storybook: {{Storybook URL ToolBar}}.

**Q: Как разделить элементы внутри панели?**
A: Использовать отдельный компонент `ToolbarDivider` между элементами. Примеры кода — в Storybook: {{Storybook URL ToolBar}}.
