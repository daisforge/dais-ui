# Attach

Компонент для прикрепления ссылки на локальный файл. Attach предоставляет возможность прикреплять ссылки на локальные файлы, не загружая их на сервер. Отображает триггер-кнопку загрузки и прикреплённый файл (имя, иконка формата, кнопка удаления).

Визуал: {{Pixso URL Attach Doc Block 1}}

---

## Анатомия

1. **Trigger (кнопка загрузки)** — кнопка «Загрузить файл», по которой открывается системное окно выбора файла. Построена на компоненте BasicButton. Включается/выключается свойством hasTrigger.
2. **Прикреплённый файл** — элемент с именем файла (например, `File_Name.pdf`), иконкой формата и кнопкой удаления. Построен на компоненте Cell. Отображается при hasAttachment = True.
3. **Иконка формата файла** — справа от имени файла автоматически отображается иконка с подгруженным форматом. Attach распознаёт форматы: PDF, DOC, XLS, TXT, CSV. Для остальных форматов используется иконка File / BlankOutline (заглушка).
4. **Кнопка удаления (✕)** — крестик справа от имени файла для открепления файла.
5. **Title** — заголовок над компонентом (опционально, свойство Title).
6. **Required-индикатор** — индикатор обязательного заполнения у Title (свойство Required, позиция через RequiredPlacement).
7. **Optional-подсказка** — подсказка «не обязательно к заполнению» (свойство Optional).
8. **Caption** — подпись под триггером (опционально, свойство hasCaption).
9. **Hint (тултип)** — подсказка-тултип (опционально, свойство hasHint).

> Размер компонента строится из сабкомпонентов: **40 S** = BasicButton 40 S + Cell S; **32 XS** = BasicButton 32 XS + Cell XS.

## Размеры и отступы

Ширина компонента фиксированная и задаётся самостоятельно. По умолчанию у элемента прикреплённого файла ширина Hug Content, но если эта величина превышает общую ширину компонента Attach, название файла сокращается через многоточие за один символ до конца названия (см. в размерах S и XS — например, `F...e.pdf`).

| Размер | Высота триггера | Состав | Визуал (Horizontal) | Визуал (Vertical) |
|---|---|---|---|---|
| **40 S** | 40 | BasicButton 40 S + Cell S | {{Pixso URL Attach Doc Block 2}} | {{Pixso URL Attach Doc Block 3}} |
| **32 XS** | 32 | BasicButton 32 XS + Cell XS | {{Pixso URL Attach Doc Block 2}} | {{Pixso URL Attach Doc Block 3}} |

> Точные отступы и паддинги — в Pixso-документации компонента: {{Pixso URL Attach Doc Block 1}}.

## Типы

Тип отвечает за расположение прикреплённых файлов относительно триггера.

| Тип | Описание |
|---|---|
| **Horizontal** | Прикреплённые файлы располагаются горизонтальным списком справа от триггера. |
| **Vertical** | Прикреплённые файлы располагаются вертикальным списком под триггером. |

| Состояние | Результат |
|---|---|

| False | Все прикреплённые файлы отображаются одним списком. |

В свёрнутом виде на кнопке **More** отображается счётчик количества скрытых файлов.

## Состояния

- **Default** — дефолтное отображение компонента.
- **Negative** — негативный сценарий (ошибка), управляется свойством View.
- **С прикреплённым файлом** — hasAttachment = True: отображается имя файла, иконка формата и кнопка удаления.
- **Без прикреплённого файла** — hasAttachment = False: виден только триггер.

> Триггер-кнопка (BasicButton) имеет интерактивные состояния **Hover, Active, Focus** (из макета сабкомпонента BasicButton).

## Механика и взаимодействия

- **Прикрепление файла** — клик по триггеру «Загрузить файл» открывает системное окно выбора локального файла. Если заданы ограничения на формат или размер, в системном окне доступны к прикреплению только валидные файлы.
- **Иконка формата** — после прикрепления справа от имени файла автоматически подставляется иконка распознанного формата (PDF, DOC, XLS, TXT, CSV) либо иконка-заглушка File / BlankOutline для остальных форматов.
- **Сокращение имени** — если ширина имени файла превышает общую ширину компонента, имя сокращается многоточием за один символ до конца названия (`File_Name.pdf` → `F...e.pdf`).
- **Удаление файла** — клик по крестику (✕) справа от имени откреплет файл.
- **Множественное прикрепление** — при QuantityFiles = many можно прикрепить несколько файлов; при Clip = True список сворачивается в кнопку **More** с выпадающим списком.

## FAQ

### Для дизайнеров

**Q: Как переключить расположение файлов — в строку или столбец?**
A: Через тип компонента: Horizontal — файлы располагаются горизонтальным списком справа от триггера; Vertical — вертикальным списком под триггером. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Attach Doc Block 1}}.

**Q: Как показать сразу несколько прикреплённых файлов?**
A: Включить возможность прикреплять несколько файлов; при длинном списке его можно свернуть в кнопку More с выпадающим списком, чтобы он не растягивал компонент. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Attach Doc Block 1}}.

**Q: Какие форматы файлов распознаются по иконке?**
A: PDF, DOC, XLS, TXT, CSV — для них справа от имени автоматически подставляется иконка формата. Для остальных форматов используется иконка-заглушка File / BlankOutline. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Attach Doc Block 1}}.

**Q: Почему имя файла обрезается многоточием?**
A: Ширина компонента фиксированная. Если имя файла шире компонента, оно сокращается многоточием за один символ до конца названия (`File_Name.pdf` → `F...e.pdf`), чтобы не ломать вёрстку. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Attach Doc Block 1}}.

**Q: Как показать негативный сценарий (ошибку)?**
A: Переключить вид компонента на Negative — это отображение ошибки. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Attach Doc Block 1}}.

**Q: Какие размеры есть у компонента?**
A: Два: 40 S (BasicButton 40 S + Cell S) и 32 XS (BasicButton 32 XS + Cell XS). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Attach Doc Block 1}}.

**Q: Чем Attach отличается от Dropzone?**
A: Dropzone отвечает за зону приёма файлов перетаскиванием (drag-and-drop), а Attach — за триггер-кнопку и отображение прикреплённого файла.

### Для разработчиков

**Q: Каким пропом переключить расположение файлов?**
A: Пропом `flow`: `horizontal` (справа от триггера), `vertical` (под триггером) или `auto` (подстройка под ширину контейнера). Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Как разрешить прикрепление нескольких файлов?**
A: Пропом `multiple` (`true`). В дизайне это `QuantityFiles = many`; значение `1` — одиночный режим (`multiple` = `false`). Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Как ограничить допустимые форматы файлов?**
A: Пропом `acceptedFileFormats` — массивом строк, например `['.pdf', '.doc']`; тогда в системном окне доступны к выбору только валидные файлы. Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Как показать негативный сценарий и текст подсказки?**
A: Видом подсказки `helperTextView="negative"` (дизайн-вид Negative); сам текст — пропом `helperText`. Не путать с пропом `view` (`accent` / `secondary`), который задаёт вид кнопки-триггера. Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Как обрабатывать удаление и выбор файла?**
A: Открепление прикреплённого файла — колбэком `onClear`; выбор файла — колбэком `onChange`. Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Как добавить заголовок, индикатор обязательности и тултип?**
A: Через обвязку компонентом `InformationWrapper`: заголовок — `label`, индикатор обязательности — `hasRequiredIndicator`, тултип — `hintText`, подсказка — `leftHelper` / `helperText`. Примеры кода — в Storybook: {{Storybook URL Attach}}.

**Q: Есть ли прямые пропы для Title, Required, Optional, Clip, hasAttachment?**
A: Эти свойства из дизайн-макета реализуются через обёртку `InformationWrapper`; точное соответствие пропам — уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Attach}}.
