# Autocomplete

Поле ввода с возможностью подстановки значения из предварительно заполненного выпадающего списка по мере ввода данных.

Визуал: {{Pixso URL Autocomplete Doc Block 1}}

---

## Анатомия

1. **Триггер (поле ввода)** — поле, в котором пользователь набирает текст. Построено на базе компонента [TextField]({{Storybook URL TextField}}): поддерживает Label, Placeholder, Value, Description и сопутствующие элементы.
2. **DropDown** — выпадающий список значений. Выведен в абсолют и не влияет на размер компонента; ширина DropDown задаётся триггером, высота зависит от размера и количества вложенных элементов.
3. **Item** — айтем, из которого собирается DropDown. Внутри Item вложен компонент Cell с настраиваемыми свойствами.
4. **LazyLoading (ленивая загрузка)** — элемент подзагрузки списка в DropDown: вид загрузки (Loading) и кнопка перезагрузки списка (Reload, «Обновить»).
5. **EmptyState (пустое состояние)** — пустое состояние выпадающего списка Autocomplete (тип `notFound`, «Ничего не нашлось») с опциональной кнопкой.

## Состояния

- **Empty / Filled** — триггер не заполнен либо заполнен значением.
- **Focused** — поле ввода в фокусе.
- **Item: Focused / Disabled** — айтем выпадающего списка подсвечен либо недоступен для выбора.
- **DropDown: загрузка** — отображается элемент LazyLoading (вид Loading) во время подзагрузки списка.
- **Пустое состояние** — список пуст: показывается EmptyState `notFound` («Ничего не нашлось») с опциональной кнопкой.

## Механика и взаимодействия

Дизайн-суть взаимодействия:

- По мере ввода данных в триггер выпадающий список фильтрует подсказки и подставляет подходящие значения.
- DropDown открывается под триггером, его ширина равна ширине триггера, а сам список выведен в абсолют (поверх контента) и не влияет на размер компонента.
- Выбор пункта (Item) из списка подставляет его значение в поле ввода.
- При большом количестве значений список поддерживает ScrollBar и ленивую подзагрузку (LazyLoading): подгружаемая порция отображается элементом Loading, а при необходимости — кнопкой Reload («Обновить»).
- Если подходящих значений нет, список показывает пустое состояние (EmptyState `notFound` — «Ничего не нашлось»), которое может содержать кнопку.

Детали реализации (пороги открытия, виртуализация, кастомная фильтрация, клавиатурная навигация) — в Storybook.

| Value | `value` | строка | Текущее значение триггера. |
| — (изменение значения) | `onChange` | callback | Реакция на ввод в триггер. |
| Выбор пункта (Item) | `onSuggestionSelect` | callback | Срабатывает при выборе подсказки из списка. |
| Label | `label` | строка | Лейбл поля ввода (из базового TextField). |
| Placeholder | `placeholder` | строка | Плейсхолдер поля ввода (из базового TextField). |
| Description / подпись | `leftHelper` | строка | Вспомогательный текст под полем (из базового TextField). |
| Высота списка (DropDown) | `listMaxHeight` | строка (CSS) | Максимальная высота выпадающего списка. |
| Кастомный Item | `renderItem` | callback | Кастомная отрисовка элемента списка. |
| Пустое состояние / EmptyState | `renderList` | callback | Кастомная отрисовка содержимого списка (в т.ч. EmptyState и ошибки). |
| LazyLoading (подзагрузка) | `renderListEnd`, `onScroll`, `threshold` | callback / число | Подгрузка элементов и порог открытия списка. |

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у Autocomplete?**
A: Два размера триггера — S (40px) и XS (32px). Размер компонента равен размеру триггера (TextField); DropDown выведен в абсолют и не влияет на размер компонента. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Чем отличается DropDown Normal от Tight?**
A: Normal — список с вложенными элементами стандартной высоты (обычный список), Tight — список с элементами меньшей высоты (сжатый список). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Как собрать выпадающий список из элементов?**
A: DropDown собирается из айтемов Item (или Item Tight для сжатого списка); внутри Item вложен компонент Cell с настраиваемыми свойствами. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Как показать вложенный список у пункта?**
A: Включить у Item свойство Disclosure — справа появится индикатор, отображающий вложенный выпадающий список. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Как показать состояние загрузки списка?**
A: Использовать LazyLoading: вид Loading отображает подзагрузку списка, а Reload — кнопку перезагрузки списка («Обновить»). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Как оформить ситуацию, когда ничего не нашлось?**
A: Включить пустое состояние (EmptyState) — оно показывает тип `notFound` с текстом «Ничего не нашлось» и опциональной кнопкой. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Как добавить разделитель между пунктами списка?**
A: Включить у Item свойство Divider — между элементами появится разделитель списка. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Autocomplete Doc Block 1}}.

**Q: Когда использовать Autocomplete?**
A: Когда нужно поле ввода с подстановкой значения из заранее заполненного выпадающего списка по мере ввода. Если нужен ввод с единичным или множественным выбором и возможностью добавить своё значение в список — используется Combobox; если нужен выбор данных без ввода — используется Select.

### Для разработчиков

**Q: Как передать список подсказок?**
A: Через проп `suggestions` — массив объектов `{ label, contentLeft?, contentRight? }`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как отследить выбор подсказки из списка?**
A: Через колбэк `onSuggestionSelect`, который срабатывает при выборе пункта; текущее значение поля задаётся через `value` / `onChange`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как задать максимальную высоту выпадающего списка?**
A: Через проп `listMaxHeight` (CSS-значение, например `"250px"`). Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как сделать ленивую подгрузку элементов (LazyLoading)?**
A: Через `onScroll` и `renderListEnd` (например, со спиннером в конце списка), при необходимости понизив `threshold`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как показать пустое состояние или ошибку в списке?**
A: Через проп `renderList`, отрисовав в нём компонент `EmptyState`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как кастомизировать элемент выпадающего списка?**
A: Через проп `renderItem` — колбэк с параметром `item`, в котором можно вернуть, например, компонент `Cell`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как виртуализировать большой список?**
A: Передать проп `virtual` и при необходимости ограничить высоту через `listMaxHeight`. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.

**Q: Как вынести выпадающий список выше по DOM (portal)?**
A: Через проп `portal`, который принимает `ref` либо `id` html-тега — полезно, когда у родительского блока есть скролл и список обрезается. Примеры кода — в Storybook: {{Storybook URL Autocomplete}}.
