# Spinner

Компонент, который используется для уведомления пользователей о том, что загрузка началась. Индикатор-крутилка с бесконечной анимацией: показывает, что процесс идёт, но без указания конкретного прогресса.

Визуал: {{Pixso URL Spinner Doc Block 1}}

---

## Типы

| Тип | Описание | Визуал |
|---|---|---|
| **Spinner XXS-XXL** | Базовый индикатор в фиксированных размерах от XXS до XXL. | {{Pixso URL Spinner Doc Block 2}} |
| **Spinner Scalable** | Масштабируемый индикатор — без фиксированного размера, подстраивается под контейнер. | {{Pixso URL Spinner Doc Block 3}} |

---

## Размеры и отступы

Размер задаётся свойством **Size**. В дизайне доступны фиксированные размеры:

| Размер | Значение (px) |
|---|---|
| **XL** | 88 |
| **L** | 56 |
| **M** | 48 |
| **S** | 36 |
| **XS** | 24 |
| **XXS** | 16 |

Для типа **Spinner Scalable** фиксированный размер не задаётся — индикатор масштабируется под контейнер.

## Настройки (Props)

> Здесь — визуальное поведение из дизайна. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Spinner" />`.

### View

Свойство View задаёт цвет индикатора. Цвет (hex градиента) наследуется от соответствующего текстового токена.

| Вид | Назначение | Источник цвета |
|---|---|---|
| **Default** | Дефолтный индикатор. | токен textPrimary |
| **Secondary** | Второстепенный индикатор. | токен textSecondary |
| **Accent** | Акцентный индикатор. | токен textAccent |
| **Positive** | Для позитивных сценариев. | токен textPositive |
| **Negative** | Для критических сценариев. | токен textNegative |
| **Warning** | Для предупреждения. | токен textWarning |
| **Info** | Для информирования. | токен textInfo |

### SubTheme

Свойство SubTheme определяет, как цвет индикатора реагирует на смену темы оформления.

| Значение | Поведение |
|---|---|
| **Default** | Цвет индикатора зависит от темы. |
| **onDark** | При смене темы индикатор остаётся светлым. |
| **onLight** | При смене темы индикатор остаётся тёмным. |
| **Inverse** | Цвет индикатора зависит от темы и является противоположным дефолтному. |

### Типы Loader

Свойство **LoaderType** задаёт характер индикации загрузки.

| LoaderType | Описание |
|---|---|
| **Progress** | Индикация загрузки конечным прогрессом. |

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у Spinner?**
A: Фиксированные размеры от XXS до XXL: XL (88), L (56), M (48), S (36), XS (24), XXS (16). Размер задаётся свойством Size. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Spinner Doc Block 1}}.

**Q: Что такое масштабируемый Spinner (Scalable)?**
A: Это отдельный тип «Spinner Scalable» — индикатор без фиксированного размера, который подстраивается под контейнер. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Spinner Doc Block 1}}.

**Q: Как задать цвет Spinner?**
A: Через свойство View — доступны Default, Secondary, Accent, Positive, Negative, Warning, Info. Цвет (hex градиента) наследуется от соответствующего текстового токена (например, Accent — от textAccent). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Spinner Doc Block 1}}.

**Q: Как настроить поведение цвета при смене темы?**
A: Через свойство SubTheme: Default — цвет зависит от темы; onDark — остаётся светлым; onLight — остаётся тёмным; Inverse — цвет противоположен дефолтному. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Spinner Doc Block 1}}.

**Q: Когда использовать Spinner?**
A: Когда нужно сообщить пользователю, что загрузка началась и процесс идёт, но конкретный прогресс показать нельзя (бесконечная индикация). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Spinner Doc Block 1}}.

**Q: Чем Loader отличается по типам индикации?**
A: У Loader есть свойство LoaderType с двумя значениями: Progress — индикация конечным прогрессом, Spinner — индикация бесконечным прогрессом. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Loader Doc Block 1}}.

**Q: Какие размеры доступны у Loader?**
A: Размер задаётся отдельно для каждого типа: ProgressSize и SpinnerSize — оба от XXS (16) до XXL (128), включая XS (24), S (36), M (48), L (56), XL (88). Подробнее — в Pixso-документации компонента, блок «Размеры Loader»: {{Pixso URL Loader Doc Block 1}}.

### Для разработчиков

**Q: Как задать размер Spinner?**
A: Через проп `size`. Точный набор строковых значений и их соответствие размерам дизайна (XXS–XXL) уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL Spinner}}.

**Q: Как задать цвет (View) и поведение при смене темы (SubTheme) в коде?**
A: В дизайне это свойства View и SubTheme. Соответствующие пропсы в коде уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL Spinner}}.

**Q: Как сделать масштабируемый Spinner (Scalable) в коде?**
A: В дизайне это отдельный тип «Spinner Scalable». Соответствующий проп в коде уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL Spinner}}.
