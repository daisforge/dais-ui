# Breadcrumbs

Компонент даёт возможность пользователям определить текущее местоположение относительно всего сайта/приложения и перейти на родительский уровень или к предыдущему шагу.

Визуал: {{Pixso URL BreadCrumbs Doc Block 1}}

---

## Анатомия

Компонент состоит из 3 основных частей: Item, Shorter и Separator.

1. **Item** — айтем, из которого собирается компонент. Один Item соответствует одному уровню пути.
2. **Shorter** — троеточие, которое заменяет айтемы для сокращённого варианта компонента. По нажатию на Shorter открывается список со скрытыми айтемами.
3. **Separator** — компонент, который разделяет айтемы между собой. По умолчанию это иконка, но её можно заменить на нужный символ.

---

## Размеры и отступы

Размер задаётся на уровне компонента и применяется ко всем его айтемам.

| Размер | Шрифт | Размер иконки | Отступ айтем↔сепаратор |
|---|---|---|---|
| **M** | Body/BodyM N | 24px | 6 |
| **S** | Body/BodyS N | 16px | 4 |
| **XS** | Body/BodyXS N | 16px | 0 |

### Item

Внутренние отступы Item (иконка↔текст):

| Размер | Шрифт | Размер иконки | Отступ |
|---|---|---|---|
| **M** | Body/BodyM N | 24px | 6 |
| **S** | Body/BodyS N | 16px | 4 |
| **XS** | Body/BodyXS N | 16px | 6 |

### Сокращение (Shorter)

Свойство Shorter отвечает за сокращение пути: лишние айтемы скрываются за троеточием.

| Shorter | Результат |
|---|---|
| Включено | Включает сокращение — часть айтемов сворачивается в троеточие. |
| Выключено | Выключает сокращение — все айтемы видны. |

### Количество (Quantity)

Свойство Quantity задаёт количество отображаемых айтемов. Доступные значения: 2, 3, 4, 5.

### Айтем (Item)

Каждый Item собирается из текста и иконок.

| Свойство Item | Назначение |
|---|---|
| Text | Включает или выключает текст айтема. |
| ContentLeft | Включает или выключает иконку слева. |
| ContentRight | Включает или выключает иконку справа. |

### Separator

Разделитель между айтемами. По умолчанию это иконка-стрелка, но её можно заменить на нужный символ.

## Состояния

### Ограничение ширины

Для Item максимальная ширина — 300px. При превышении этого значения текст сокращается с использованием truncate.

### Загрузка

У айтема есть состояние загрузки — пока данные подгружаются, на месте текста отображается плейсхолдер «Загрузка».

### Многострочность

При выключенном Shorter компонент поддерживает многострочность. Ширина компонента принимает фиксированное значение (fix).

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Item | `items` | массив элементов пути | Айтемы собираются из массива `items`. Каждый элемент задаёт `title` и опционально `href` / `onClick` / `disabled` / `renderItem`. |
| Shorter (сокращение) | `showItems` | число | Задаёт, сколько айтемов показать; остальные сворачиваются в троеточие. |
| Quantity (количество) | `items` | массив элементов пути | Количество айтемов определяется длиной массива `items`. |
| Текст айтема | `title` | строка | Заголовок одного айтема. |
| Ссылка айтема | `href` | строка | Если не указана, айтем не кликабелен. |
| Айтем выключен | `disabled` | boolean | Делает айтем выключенным. |
| Кастомный айтем (в т.ч. Separator/Shorter) | `renderItem` | функция, возвращает ReactNode | Позволяет отрисовать произвольный элемент. |

## FAQ

### Для дизайнеров

**Q: Из каких частей состоит компонент?**
A: Из трёх: Item (айтем пути), Shorter (троеточие для сокращённого варианта) и Separator (разделитель между айтемами). Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Как сократить длинный путь?**
A: Включить свойство Shorter — лишние айтемы свернутся в троеточие, по нажатию на которое открывается список скрытых айтемов. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Сколько айтемов можно показать?**
A: Свойство Quantity задаёт количество отображаемых айтемов — 2, 3, 4 или 5. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Какие размеры есть у компонента?**
A: Три: M (Body/BodyM N, иконка 24px), S (Body/BodyS N, иконка 16px) и XS (Body/BodyXS N, иконка 16px). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Что произойдёт с очень длинным текстом айтема?**
A: Максимальная ширина Item — 300px. При превышении текст сокращается с использованием truncate. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Можно ли заменить разделитель?**
A: Да, Separator по умолчанию — иконка-стрелка, но её можно заменить на нужный символ. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Как сделать многострочный компонент?**
A: Выключить Shorter — тогда компонент поддерживает многострочность, а его ширина принимает фиксированное значение (fix). Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL BreadCrumbs Doc Block 1}}.

**Q: Как добавить иконку в айтем?**
A: В айтеме включить ContentLeft (иконка слева) или ContentRight (иконка справа); сам текст управляется свойством Text. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL BreadCrumbs Doc Block 1}}.

### Для разработчиков

**Q: Как собрать компонент из айтемов?**
A: Передать массив в проп `items` — каждый элемент задаёт `title` и опционально `href`, `onClick`, `disabled` или `renderItem`. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.

**Q: Как сократить путь до нужного числа айтемов?**
A: Передать проп `showItems` (число) — он задаёт, сколько айтемов показать, остальные сворачиваются в троеточие. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.

**Q: Как сделать айтем со ссылкой?**
A: Указать у элемента `href`. Если ссылка не указана, айтем не кликабелен. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.

**Q: Как навесить обработчик клика на айтем?**
A: Задать у элемента `onClick`. При использовании этого варианта свойства `href` у того же элемента недоступны. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.

**Q: Как выключить отдельный айтем?**
A: Передать у элемента `disabled: true`. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.

**Q: Как отрисовать кастомный айтем?**
A: Задать у элемента `renderItem` — функцию, возвращающую ReactNode (например, выпадающий список через `Dropdown`). При использовании этого варианта остальные свойства того же элемента недоступны. Примеры кода — в Storybook: {{Storybook URL BreadCrumbs}}.
