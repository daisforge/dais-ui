# Segment

Компонент, который позволяет разделить контент на большие смысловые блоки. Работает как переключатель: айтемы ведут себя как радиокнопки для перезагрузки контента и обозначения текущего раздела.

Визуал: {{Pixso URL Segment Doc Block 1}}

В компоненте доступно отображение максимум 10 айтемов, которые можно включить на уровне SegmentGroup.

---

## Анатомия

1. **SegmentGroup** — контейнер-обёртка, которая управляет набором айтемов (до 10 штук) и общими настройками: ориентацией, общим фоном, формой.
2. **SegmentItem** — отдельный сегмент. Состоит из трёх частей:
   - **Content Left** — иконка слева (опционально).
   - **Label** — текстовый лейбл сегмента.
   - **Content Right** — контент справа: иконка, вспомогательный текст или счётчик (опционально).

---

## Типы

### Ориентация

Ориентация задаётся на уровне SegmentGroup.

| Тип | Описание | Визуал |
|---|---|---|
| **Segment Horizontal** | Айтемы расположены в горизонтальной ориентации. Размер компонента определяется только размерами вложенных айтемов. | {{Pixso URL Segment Doc Block 2}} |
| **Segment Vertical** | Айтемы расположены в вертикальной ориентации. Ширина компонента фиксированная, а высота зависит от количества включённых SegmentItem. | {{Pixso URL Segment Doc Block 3}} |

---

## Размеры и отступы

Размер задаётся на уровне айтема.

| Размер | Шрифт лейбла | Шрифт вспом. текста | Размер иконки | Corner Radius |
|---|---|---|---|---|
| **40 S** | Body/BodyS B | Body/BodyS | 24px | calc[m-2] (10px) |
| **32 XS** | Body/BodyXS B | Body/BodyXS B | 16px | S (8px) |

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="SegmentGroup" />` и `<PropsTable name="SegmentItem" />`.

### Настройки SegmentGroup

#### hasBackground

Включает или выключает отображение общего фона компонента Segment. Оболочка выступает на 2px по всем сторонам компонента, но находится в отрицательном значении, не увеличивая размер всего компонента.

| Значение | Результат |
|---|---|
| Включено | Общий фон компонента отображается. |
| Выключено | Общий фон компонента скрыт. |

#### Stretch

При включении свойства появляется возможность настройки ширины компонента (Fix, Fill). Вложенные айтемы будут растягиваться по всей ширине компонента. При выключенном свойстве ширина компонента задаётся шириной вложенных айтемов.

#### Shape

Отвечает за форму углов сегмента и вложенных в него айтемов.

| Shape | Результат |
|---|---|
| **Default** | Сегмент и вложенные в него айтемы квадратной формы. |
| **Pilled** | Сегмент и вложенные в него айтемы скруглённой формы. |

### Настройки SegmentItem

#### ContentLeft

Включает или выключает отображение контента (иконки) слева от лейбла.

#### ContentRight

Управляет содержимым справа от лейбла.

| Значение | Результат |
|---|---|
| **None** | Контент справа скрыт. |
| **Text** | Отображается вспомогательный текст справа. |
| **Counter** | Отображается счётчик справа. |
| **Icon** | Отображается иконка справа. |

#### SelectView

Определяет стиль выбранного айтема.

| Значение | Результат |
|---|---|
| **None** | Айтем не выбран. |
| **Primary** | Выбранный айтем в дефолтном стиле. |
| **Secondary** | Выбранный айтем во второстепенном стиле. |
| **Accent** | Выбранный айтем в акцентном стиле. |

## Состояния

| Состояние | Описание |
|---|---|
| **Selected** | Состояние выбранного айтема. Включается, когда айтем является активным разделом. |
| **Disabled** | Состояние недоступного айтема. Айтем виден, но недоступен для выбора. |

---

## Механика и взаимодействия

Сегменты работают как переключатель: выбор одного айтема делает его активным и перезагружает связанный с ним контент. Активный айтем обозначается через SelectView (Primary / Secondary / Accent). Размер компонента определяется размерами вложенных айтемов; вертикальная ориентация фиксирует ширину, а высота зависит от количества включённых SegmentItem.

Детали реализации выбора (управляемый и неуправляемый режимы, обязательный активный айтем) — в Storybook.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Контейнер SegmentGroup | `SegmentGroup` | — | Контейнер-обёртка для набора айтемов. |
| Айтем SegmentItem | `SegmentItem` | — | Отдельный сегмент с лейблом. |
| Ориентация (Horizontal / Vertical) | `orientation` | vertical | Vertical задаётся через `orientation="vertical"` на SegmentGroup; Horizontal — значение по умолчанию. |
| hasBackground | `hasBackground` | boolean | Общий фон компонента. |
| Shape (Default / Pilled) | `pilled` | boolean | Свойство **Shape → Pilled** в дизайне = проп `pilled` в коде. |
| SelectView | `view` | default / secondary | Стиль выбранного айтема задаётся пропом `view` на SegmentItem. |
| Label | `label` | строка | Текстовый лейбл айтема. |
| ContentLeft (иконка без текста) | `SegmentIconItem` + `icon` | иконка (ReactNode) | Для сегментов только с иконкой используется отдельный компонент `SegmentIconItem`. |

## FAQ

### Для дизайнеров

**Q: Как сделать вертикальный сегмент?**
A: Задать ориентацию Segment Vertical на уровне SegmentGroup — айтемы расположатся вертикально, ширина компонента станет фиксированной, а высота будет зависеть от количества включённых SegmentItem. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Segment Doc Block 1}}.

**Q: Сколько айтемов можно добавить в сегмент?**
A: Максимум 10 айтемов, которые включаются на уровне SegmentGroup. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL Segment Doc Block 1}}.

**Q: Какие размеры есть у сегмента?**
A: Два: 40 S и 32 XS. Каждый со своим шрифтом лейбла, шрифтом вспомогательного текста, размером иконки и Corner Radius. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Segment Doc Block 1}}.

**Q: Как сделать сегмент со скруглёнными краями?**
A: Выбрать свойство Shape → Pilled — сегмент и вложенные в него айтемы получат скруглённую форму. Default даёт квадратную форму. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Segment Doc Block 1}}.

**Q: Как включить общий фон у сегмента?**
A: Включить свойство hasBackground на уровне SegmentGroup — отобразится общий фон компонента. Оболочка выступает на 2px по всем сторонам, но не увеличивает размер всего компонента. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Segment Doc Block 1}}.

**Q: Как растянуть сегмент по ширине?**
A: Включить свойство Stretch — появится возможность настроить ширину компонента (Fix, Fill), и вложенные айтемы растянутся по всей ширине. Без него ширина задаётся шириной вложенных айтемов. Подробнее — в Pixso-документации компонента, блок «Свойства»: {{Pixso URL Segment Doc Block 1}}.

**Q: Как добавить иконку, счётчик или вспомогательный текст к айтему?**
A: Иконка слева — через Content Left. Справа через Content Right можно показать иконку, вспомогательный текст или счётчик (значения Icon / Text / Counter). Подробнее — в Pixso-документации компонента, блок «SegmentItem»: {{Pixso URL Segment Doc Block 4}}.

**Q: Как показать, какой айтем выбран?**
A: Через свойство SelectView у айтема: Primary — дефолтный стиль выбранного, Secondary — второстепенный, Accent — акцентный, None — айтем не выбран. Подробнее — в Pixso-документации компонента, блок «SegmentItem»: {{Pixso URL Segment Doc Block 4}}.

### Для разработчиков

**Q: Как сделать вертикальный сегмент?**
A: Передать `orientation="vertical"` на `SegmentGroup`. Горизонтальная ориентация — значение по умолчанию. Примеры кода — в Storybook: {{Storybook URL Segment}}.

**Q: Как включить скруглённые края?**
A: Передать проп `pilled` (boolean) — даёт скруглённую форму (свойство Shape → Pilled в дизайне). Примеры кода — в Storybook: {{Storybook URL Segment}}.

**Q: Как включить общий фон сегмента?**
A: Передать проп `hasBackground` на `SegmentGroup`. Примеры кода — в Storybook: {{Storybook URL Segment}}.

**Q: Как сделать сегмент только с иконкой?**
A: Использовать компонент `SegmentIconItem` и передать ему иконку через проп `icon`. Примеры кода — в Storybook: {{Storybook URL Segment}}.

**Q: Как задать стиль выбранного айтема?**
A: Через проп `view` на `SegmentItem` (например, `default`, `secondary`) — это соответствует свойству SelectView в дизайне. Примеры кода — в Storybook: {{Storybook URL Segment}}.

**Q: Как сделать так, чтобы один айтем всегда был выбран?**
A: Эта механика управляется на уровне обёртки выбора. Точную настройку обязательного активного айтема уточните в Storybook или в чате поддержки ДС: {{Storybook URL Segment}}.
