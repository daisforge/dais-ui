# Indicator

Компонент, который выделяет элемент страницы и информирует пользователя о том, что требует его внимания. Представляет собой небольшую цветную точку без текста; смысл передаётся цветом (видом).

Визуал: {{Pixso URL Indicator Doc Block 1}}

---

## Анатомия

Индикатор — атомарный компонент без вложенных слотов. Это одна цветная точка фиксированного размера. Текст, иконки и другой контент внутри не размещаются.

## Настройки (Props)

### Вид

Цвет индикатора. Цвет несёт смысл — он сообщает о типе состояния или сценария.

| Вид | Назначение |
|---|---|
| Default | Индикатор дефолтного цвета. |
| Accent | Индикатор акцентного цвета. |
| Positive | Индикатор для позитивных сценариев. |
| Warning | Индикатор для предупреждения. |
| Negative | Индикатор для критических сценариев. |
| Black | Индикатор чёрного цвета, не изменяется при переключении тем. |
| White | Индикатор белого цвета, не изменяется при переключении тем. |
| Inactive | Неактивный индикатор. |

### Размер

Диаметр точки — L / M / S. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Indicator Doc Block 1}}.

## FAQ

### Для дизайнеров

**Q: Что такое индикатор?**
A: Небольшая цветная точка без текста, которая выделяет элемент страницы и привлекает к нему внимание. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Indicator Doc Block 1}}.

**Q: Какие размеры есть у индикатора?**
A: Три: L (12px), M (8px), S (6px) — это диаметр точки. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Indicator Doc Block 1}}.

**Q: Какие виды (цвета) бывают у индикатора и что они означают?**
A: Дефолтный, акцентный, позитивный, предупреждающий, критический (негативный), чёрный, белый и неактивный. Цвет несёт смысл — например, позитивный обозначает позитивный сценарий, негативный — критический. Подробнее — в Pixso-документации компонента, блок «Вид»: {{Pixso URL Indicator Doc Block 1}}.

**Q: Какие виды не меняют цвет при переключении тем?**
A: Чёрный и белый — они зафиксированы и не реагируют на смену темы. Подробнее — в Pixso-документации компонента, блок «Вид»: {{Pixso URL Indicator Doc Block 1}}.

**Q: Можно ли поместить текст или иконку внутрь индикатора?**
A: Нет. Индикатор — это только цветная точка фиксированного размера, без вложенного контента. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Indicator Doc Block 1}}.

### Для разработчиков

**Q: Какие значения принимает проп `view`?**
A: `default`, `accent`, `positive`, `warning`, `negative`, `black`, `white`, `inactive`. Каждое задаёт цвет, который несёт смысл (например, `positive` — позитивный сценарий, `negative` — критический). Примеры кода — в Storybook: {{Storybook URL Indicator}}.

**Q: Виды чёрный/белый называются `black`/`white`?**
A: Да. В коде это значения `black` и `white` пропа `view`, они совпадают с дизайном и не меняются при переключении тем. Примеры кода — в Storybook: {{Storybook URL Indicator}}.

**Q: Какие значения у пропа `size`?**
A: `l` / `m` / `s` — это диаметр точки: L = 12px, M = 8px, S = 6px. Примеры кода — в Storybook: {{Storybook URL Indicator}}.

**Q: Есть ли вид Dark?**
A: Да. Вид Dark есть в дизайне (тёмный полупрозрачный, не изменяется при переключении тем). Его представление в коде уточните в Storybook или в чате поддержки дизайн-системы: {{Storybook URL Indicator}}.
