# TextField

Обеспечивает возможность ввода или взаимодействия с данными.

Визуал: {{Pixso URL TextField Doc Block 1}}

> **Важно.** Множественные значения в TextField на практике использовать **НЕЛЬЗЯ ни при каких обстоятельствах**. Вид Value = Multiple существует только как техническое наследование (значения отображались бы чипами через компонент ChipEmbeddedGroup) — в дизайне он не применяется.

В дизайне поле представлено двумя вариантами оформления: **TextField** (с залитым фоном) и **TextFieldClear** (без фона, с опциональным разделителем). Оба используют один набор свойств — отличия указаны в соответствующих разделах.

---

## Анатомия

1. **Label** — текстовый лейбл поля. Может быть скрыт или вынесен наружу / внутрь поля (см. LabelPlacement).
2. **Inner Label** — лейбл внутри поля ввода (при LabelPlacement = Inner). Недоступен в размере 32 XS.
3. **Value / Placeholder** — основное содержимое: введённое значение (Value) либо подсказка-плейсхолдер до ввода.
4. **Title Caption** — подпись над полем, в правой части (опционально).
5. **Caption** — подпись под полем. Может содержать текст подсказки и/или счётчик символов (Counter).
6. **ContentLeft** — контент (иконка) в левой части поля (опционально).
7. **ContentRight** — контент (иконка и/или тултип-подсказка) в правой части поля (опционально). При HintPlacement = Inner состоит из иконки и тултипа, которые включаются независимо.
8. **TextBefore (TB) / TextAfter (TA)** — дополнительный текст до и после основного значения (опционально). TextAfter используется, например, для подписи валюты.
9. **Кнопка очистки (Clear)** — иконка-крестик для очистки поля (опционально, см. «Механика и взаимодействия»).
10. **Divider** — нижний разделитель. Доступен только в варианте TextFieldClear (опционально).
11. **ChipEmbeddedGroup** — технический компонент для отображения множественных значений (Value = Multiple). Настраивается по аналогии с ChipGroup.

### Маски ввода

Маски используются для полей с заранее известным форматом. Вводимое значение форматируется автоматически: разделители и пробелы из маски появляются сразу после ввода предыдущего символа, а введённые пользователем разделители и пробелы в поле не добавляются. Ввод недопустимого или лишнего символа заблокирован, при этом пользователю сообщается об ошибке.

Общий обзор масок: {{Pixso URL TextField Doc Block 3}}

| Маска | Формат по умолчанию | Поведение | Визуал |
|---|---|---|---|
| **Маска телефона** | `+7 000 000-00-00` | По умолчанию принимает только цифры. Количество вводимых символов ограничено маской. Код страны задаётся и отображается первой цифрой; при вводе или вставке номера первая цифра, соответствующая коду, удаляется из введённых данных (например, +7 или 8 для России). | {{Pixso URL TextField Doc Block 4}} |
| **Маска даты** | `ДД.ММ.ГГ` | По умолчанию принимает только цифры; при необходимости можно добавить символьные значения. После ввода одной цифры нажатие пробела, точки или запятой переводит курсор на следующую часть даты. Запятая, слеш (/), буквы «б» и «ю» заменяются на точку. | {{Pixso URL TextField Doc Block 5}} |
| **Маска времени** | `00:00` | После ввода одной цифры нажатие пробела, двоеточия, точки или запятой переводит курсор на следующую единицу измерения времени. Запятая, точка, слеш (/), буквы «б» и «ю» заменяются на двоеточие. | {{Pixso URL TextField Doc Block 6}} |
| **Маска валюты** | `₽` (символ задаётся через TextAfter) | Принимает числовой формат, точку и запятую. Точка, слеш (/), буквы «б» и «ю» заменяются на запятую, при этом курсор переходит на 1-й символ после запятой. Нули перед числом вводятся без ограничений; при потере фокуса значение форматируется и лишние нули удаляются. Символ валюты пишется в свойстве TextAfter и может принимать любое значение (например, `млн ₽`). | {{Pixso URL TextField Doc Block 7}} |

**Отображение маски.** У масок телефона, даты и времени маска может отображаться всегда (показывается как плейсхолдер формата) либо появляться только при вводе данных (до ввода виден обычный плейсхолдер, например «Введите телефон»).

**Значение по умолчанию (маска даты).** Маска может быть предзаполнена (часть значения подставлена, остальная часть показана плейсхолдером формата) либо не предзаполнена (показан только плейсхолдер формата).

**Валюта.** В дизайне приведены примеры для RUB (₽), USD ($), EUR (€) и INR (₹) — символ валюты задаётся через TextAfter и не ограничен этим списком.

|---|---|---|---|---|---|---|

## Состояния

- **Empty** — поле без введённого значения (виден плейсхолдер).
- **Single / Multiple** — поле с одним значением либо с множественным набором значений (чипы).
- **Focused** — поле в фокусе.
- **Disabled** — поле недоступно.
- **ReadOnly** — поле только для чтения.
- **View: Success / Warning / Error** — заполненные состояния со статусной окраской (Success и Warning доступны только в заполненных вариантах).

## Механика и взаимодействия

### Маски ввода

Маска автоматически форматирует ввод по заранее заданному формату (телефон, дата, время, валюта). Разделители и пробелы маски подставляются автоматически; вводимые пользователем разделители и пробелы в поле не попадают. Ввод недопустимого или лишнего символа блокируется, и пользователю сообщается об ошибке. Подробное поведение каждой маски — в разделе «Типы → Маски ввода». Детали реализации форматирования — в Storybook.

### Очистка поля (Clear)

Очистка реализована через иконку Close (крестик) и включается отдельным свойством. Крестик появляется при вводе первого символа и сохраняется в состоянии Default, если введён текст. Если у поля есть иконка справа, крестик отображается слева от иконки. Очистка применима к TextField, TextArea и Autocomplete.

**Когда очистку использовать уместно:**

- поле может быть пустым по смыслу, состояние empty/none валидно (например: поиск, фильтр, необязательные параметры);
- очистка не приводит к ошибке и не требует подтверждения;
- пользователь часто меняет значение;
- очистка безопасна и не приводит к потере данных.

**Когда очистку не использовать:**

- пустое значение невалидно;
- при очистке сбрасываются смежные поля (очистка влияет не только на себя);
- вместо пустого состояния есть значение «не выбрано» или дефолтное;
- поле обязательное (очистка заблокирует продолжение сценария).

### Множественные значения (Value = Multiple)

На практике множественные значения в TextField **не используются ни при каких обстоятельствах**. Вид Value = Multiple существует только как техническое наследование от поля ввода (значения отображались бы чипами через компонент ChipEmbeddedGroup) — применять его в дизайне нельзя.

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у поля?**
A: Два: 40 S (высота 40, Corner Radius 10px) и 32 XS (высота 32, Corner Radius 8px). Размер задаётся свойством Size; шрифты и IconSize различаются. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL TextField Doc Block 2}}.

**Q: Чем TextField отличается от TextFieldClear?**
A: TextField — поле с залитым фоном; TextFieldClear — без фона, с опциональным нижним разделителем (Divider). Набор свойств одинаковый. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL TextField Doc Block 1}}.

**Q: Как разместить лейбл внутри поля?**
A: Через LabelPlacement = Inner. Этот вариант недоступен в размере 32 XS. Также есть Outer (снаружи) и None (лейбл выключен). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL TextField Doc Block 1}}.

**Q: Какие маски ввода доступны?**
A: Телефон (`+7 000 000-00-00`), дата (`ДД.ММ.ГГ`), время (`00:00`) и валюта (символ через TextAfter). Маска может отображаться всегда или появляться при вводе. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL TextField Doc Block 1}}. Принципы оформления плейсхолдеров и форматов полей — также в редполитике, раздел «Плейсхолдеры и тексты для полей» (4.4).

**Q: Как настроить валюту в маске валюты?**
A: Символ валюты пишется в свойстве TextAfter и может принимать любое значение (например, `₽`, `$`, `€`, `₹`, `млн ₽`). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL TextField Doc Block 1}}. Правила оформления форматов и единиц — также в редполитике, раздел «Плейсхолдеры и тексты для полей» (4.4).

**Q: Когда стоит добавлять кнопку очистки (крестик)?**
A: Когда поле может быть пустым по смыслу, очистка безопасна, не приводит к ошибке и не требует подтверждения (поиск, фильтр, необязательные параметры). Не стоит — если пустое значение невалидно, поле обязательное или очистка сбрасывает смежные поля. Подробнее — в Pixso-документации компонента, блок «Очистка полей»: {{Pixso URL TextField DocGuide Block 1}}.

**Q: Где появляется крестик очистки относительно иконки справа?**
A: Крестик появляется при вводе первого символа; если справа есть иконка, крестик отображается слева от неё. Подробнее — в Pixso-документации компонента, блок «Очистка полей»: {{Pixso URL TextField DocGuide Block 1}}.

**Q: Можно ли показать несколько значений (чипы) в одном поле?**
A: Нет — множественные значения в TextField не используются ни при каких обстоятельствах. Технически вид Value = Multiple существует (наследие поля ввода), но применять его нельзя.

**Q: Где разместить индикатор обязательности?**
A: Индикатор обязательности располагается справа (RequiredPlacement). Значение None убирает индикатор. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL TextField Doc Block 1}}.

**Q: Как добавить дополнительный текст до и после значения?**
A: Через TextBefore (до основного значения) и TextAfter (после; используется, в частности, для подписи валюты). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL TextField Doc Block 1}}.

### Для разработчиков

**Q: Как задать размер поля?**
A: Через проп `size` со значениями `s` (40 S) и `xs` (32 XS). Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Каким пропом включается вариант без фона (TextFieldClear) и разделитель?**
A: Через `appearance` (`default` / `clear`): TextFieldClear = `clear`. Разделитель в этом варианте — проп `hasDivider`. Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Какие значения принимает проп `view` и как они соотносятся с дизайном?**
A: `default` / `positive` / `warning` / `negative`. В дизайне они называются Default / Success / Warning / Error соответственно. Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Как выводятся подсказки (снизу, сверху, тултип)?**
A: Подсказка снизу — `leftHelper`, подсказка сверху справа — `titleCaption`, тултип — `hintText` (с `hintView` и `hintSize`). Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Как сделать поле обязательным и настроить индикатор?**
A: `required` (обязательность), `hasRequiredIndicator` (наличие индикатора), `requiredPlacement` (`left` / `right`). Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Как добавить иконки слева и справа?**
A: `contentLeft` и `contentRight` (ReactNode). Примеры кода — в Storybook: {{Storybook URL TextField}}.

**Q: Как вводить значения как чипы (множественный выбор)?**
A: Режим включается через `enumerationType="chip"` с пропами `chips`, `chipView`, `chipType`, `chipValidator`. В dev-документации этот режим помечен DEPRECATED — актуальный способ уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL TextField}}.

## TextFieldGroup

Компонент для объединения связанных полей TextField в группу.

Визуал: {{Pixso URL TextFieldGroup}}

### Анатомия

1. **Группа полей** — набор из нескольких TextField, размещённых вертикально или горизонтально.
2. **Границы группы** — внешнее оформление группы, задаётся свойством Shape.
3. **Отступы между полями** — расстояние между соседними TextField, задаётся свойством Gap (зависит от Shape).

### Размеры и отступы

Размер группы задаётся свойством **Size** и по умолчанию применяется ко всем полям внутри. Размеры полей соответствуют размерам TextField (40 S / 32 XS).

### Настройки (Props)

| Свойство | Описание |
|---|---|
| **Size** | Размер полей группы; по умолчанию применяется ко всем полям. Можно отключить общее переопределение стилей — тогда каждое поле имеет свой размер. |
| **Shape** | Оформление границ группы: сегментированное (Segmented) или дефолтное (Default). |
| **Orientation** | Ориентация группы: вертикальная или горизонтальная. |
| **Gap** | Отступы между полями; набор значений зависит от Shape: при Default — `dense` / `wide`; при Segmented — `none` / `dense`. |

### Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Size | `size` | `s` / `xs` | Применяется ко всем полям. Отключение общих стилей — `isCommonTextFieldStyles={false}`. |
| Shape | `shape` | `default` / `segmented` | Оформление границ группы. |
| Orientation | `orientation` | `vertical` / `horizontal` | Ориентация группы. |
| Gap | `gap` | `dense` / `wide` / `none` | При `shape="default"` — `dense` / `wide`; при `shape="segmented"` — `none` / `dense`. |
| View | `view` | например `secondary` | Вид группы; набор значений уточните в Storybook или в чате поддержки ДС. |
