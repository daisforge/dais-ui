# Tabs

Элемент навигации, в котором контент скрывается и отображается посредством переключения вкладок. В макете (Pixso) предусмотрено включение до 10 табов на уровне TabsGroup; на практике количество табов может быть больше.

Визуал: {{Pixso URL Tabs Doc Block 1}}

---

## Анатомия

Компонент состоит из контейнера-группы и вложенных в него табов.

1. **TabsGroup** — контейнер, который объединяет табы в единую группу и задаёт их общее поведение (ориентация, обрезка, дивайдер, растягивание). В макете предусмотрено до 10 табов (ограничение Pixso; на практике может быть больше).
2. **TabItem** — отдельная вкладка. Состоит из трёх частей:
   - **ContentLeft** — иконка слева (опционально).
   - **Label** — текстовый лейбл вкладки.
   - **ContentRight** — контент справа: иконка, вспомогательный текст (HelpText) или счётчик (опционально).
3. **TabsHeader** — заголовочный вариант таба (TabItemHeader) для акцентной навигации заголовками H1–H5. Состоит из лейбла Label и опционального вспомогательного текста HelpText справа.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Tabs" />`.

### Clip — обрезка контейнера

Управляет тем, как ширина компонента ведёт себя относительно вложенных табов.

| Clip | Поведение |
|---|---|
| **None** | Ширина компонента подстраивается под общую ширину отображённых табов. |
| **Show All** | Ширина компонента подстраивается под общую ширину отображённых табов. Вместо последнего таба появляется кнопка-триггер, которая раскрывает выпадающий список с дополнительными айтемами. |
| **Scroll** | Ширина компонента фиксирована, а контент (табы) обрезается по границам контейнера. Появляется возможность горизонтального скролла. |

### Position — позиционирование активного таба

Применяется, если `Clip = Scroll`.

| Position | Поведение |
|---|---|
| **Start** | Активный Tab находится в начале, позиционируется к левому краю, есть возможность скролла вправо. |
| **Center** | Активный Tab находится в центре, позиционируется по центру, есть возможность скролла вправо и влево. |
| **End** | Активный Tab находится в конце, позиционируется к правому краю, есть возможность скролла влево. |

### Strech — растягивание

| Strech | Поведение |
|---|---|
| **True** | Появляется возможность настройки ширины компонента (Fix, Fill). Вложенные табы будут растягиваться по всей ширине компонента. |
| **False** | Ширина компонента задаётся шириной вложенных табов. |

### hasDivider — общий дивайдер

| hasDivider | Поведение |
|---|---|
| **True** | Включает отображение общего дивайдера. |
| **False** | Выключает отображение общего дивайдера. |

### hasContentLeft — контент слева во всех табах

Свойство уровня группы для вертикальных табов.

| hasContentLeft | Поведение |
|---|---|
| **True** | Во всех табах включён контент слева. |
| **False** | Во всех табах выключен контент слева. |

### ContentRight — контент справа в TabItem

| ContentRight | Поведение |
|---|---|
| **None** | Выключает отображение контента справа. |
| **Text** | Включает отображение вспомогательного текста справа. |
| **Counter** | Включает отображение счётчика справа. |
| **Icon** | Включает отображение иконки справа. |

## Состояния

Состояния задаются на уровне отдельного таба (TabItem и TabsHeader).

| Состояние | Описание |
|---|---|
| **Default** | Обычный невыбранный таб. |
| **Selected** | Состояние выбранного (активного) таба. Включается свойством Selected. |
| **Disabled** | Состояние недоступного таба. Включается свойством Disabled. |

Для TabsHeader дополнительно доступно свойство **hasHelpText** — отображение вспомогательного текста справа.

## Механика и взаимодействия

- Tabs — это элемент навигации: при переключении вкладки один контент скрывается, а связанный с активным табом — отображается. Сами табы устроены как радиокнопки для перезагрузки контента и обозначения текущего раздела.
- В одной группе TabsGroup в макете предусмотрено до 10 табов (ограничение Pixso; на практике может быть больше).
- При `Clip = Show All` лишние табы прячутся в выпадающий список: вместо последнего таба показывается кнопка-триггер, раскрывающая список с дополнительными айтемами.
- При `Clip = Scroll` ширина контейнера фиксируется, табы обрезаются по границам, появляется горизонтальный скролл; положение активного таба при скролле задаётся свойством Position (Start / Center / End).
- Клавиатурная навигация по вкладкам поддерживается: для горизонтальных табов — стрелки влево/вправо, Home, End; для вертикальных — стрелки вверх/вниз, Home, End. Детали поведения и кода — в Storybook: {{Storybook URL Tabs}}.

## FAQ

### Для дизайнеров

**Q: Сколько табов можно отобразить в одной группе?**
A: В макете (Pixso) предусмотрено до 10 табов на уровне TabsGroup — это ограничение макета; на практике табов может быть больше. Подробнее — в Pixso-документации компонента, блок «Общее»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Какие типы табов есть?**
A: Три: Tabs H1-H5 (заглавные акцентные табы в горизонтальной ориентации), Tabs Horizontal (горизонтальные) и Tabs Vertical (вертикальные). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Как сделать так, чтобы лишние табы прятались в выпадающий список?**
A: Выбрать свойство Clip → Show All: вместо последнего таба появится кнопка-триггер, раскрывающая выпадающий список с дополнительными айтемами. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Как включить горизонтальный скролл по табам?**
A: Выбрать свойство Clip → Scroll — ширина контейнера зафиксируется, табы обрежутся по границам и появится горизонтальный скролл. Положение активного таба при скролле задаётся свойством Position (Start / Center / End). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Как растянуть табы на всю ширину компонента?**
A: Включить свойство Strech → True — появится возможность настройки ширины (Fix, Fill), и вложенные табы растянутся по всей ширине компонента. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Что можно показать справа в табе?**
A: Через свойство ContentRight: вспомогательный текст (Text), счётчик (Counter) или иконку (Icon); значение None выключает контент справа. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Как сделать таб недоступным или активным?**
A: Состояние выбранного таба включается свойством Selected, недоступного — свойством Disabled. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Tabs Doc Block 1}}.

**Q: Какие размеры есть у табов?**
A: У Tabs Horizontal и Tabs Vertical — три размера: M (48px), S (40px), XS (32px). У заглавных Tabs H1-H5 — пять: H1 (52px), H2 (36px), H3 (30px), H4 (26px), H5 (24px). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Tabs Doc Block 1}}.

### Для разработчиков

**Q: Как задать ориентацию табов?**
A: Через проп `orientation` со значениями `horizontal` (по умолчанию) и `vertical`. Примеры кода — в Storybook: {{Storybook URL Tabs}}.

**Q: Как задать размер табов?**
A: Через проп `size` со значениями `m` / `s` / `xs` — прямое соответствие размерам M / S / XS. Примеры кода — в Storybook: {{Storybook URL Tabs}}.

**Q: Как растянуть табы на всю ширину?**
A: Передать проп `stretch` — вложенные табы растянутся по ширине компонента. Это соответствует свойству Strech в дизайне. Примеры кода — в Storybook: {{Storybook URL Tabs}}.

**Q: Как показать выпадающий список с лишними табами?**
A: Использовать `clip="showAll"`: показываются первые табы, а остальные выносятся в выпадающий список через кнопку-триггер вместо последнего таба. Примеры кода — в Storybook: {{Storybook URL Tabs}}.

**Q: Как добавить вспомогательный текст и иконку в таб?**
A: Вспомогательный текст справа задаётся пропом `value`, иконка слева — `contentLeft`, иконка справа — `contentRight`. Пропсы `value` и `contentRight` взаимоисключающие: если передано одно, второе передать нельзя. Примеры кода — в Storybook: {{Storybook URL Tabs}}.

**Q: Как включить клавиатурную навигацию по табам?**
A: Дополнительно прокинуть пропсы `index`, `itemIndex`, `onIndexChange`. Для горизонтальных табов работают стрелки влево/вправо, Home, End; для вертикальных — стрелки вверх/вниз, Home, End. Примеры кода — в Storybook: {{Storybook URL Tabs}}.
