# Select

Компонент с возможностью выбора одного или нескольких вариантов в выпадающем списке.

Визуал: {{Pixso URL Select Doc Block 1}}

### Когда использовать Select, когда Combobox

Select подходит, когда нужно выбрать значение из заранее подготовленного списка вариантов. Если пользователю нужно ввести значение вручную или добавить своё значение в список, используйте [Combobox]({{Storybook URL Combobox}}).

---

## Анатомия

1. **Триггер (target)** — поле, на которое нажимает пользователь, чтобы раскрыть список. Триггер может мимикрировать под текстовое поле (TextField) или под кнопку (Button). Содержит выбранное значение (**Value**) или подсказку (**Placeholder**), а также опционально **Label**, **Caption** и иконку слева (**ContentLeft**).
2. **DropDown** — выпадающий список значений. Выведен в абсолют (поверх контента) и не влияет на размер компонента. Ширина задаётся триггером, высота — размером и количеством вложенных элементов.
3. **Item Select** — айтем одиночного выбора, из которого собирается DropDown. Внутри айтема вложен компонент Cell с настраиваемыми свойствами.
4. **Item CheckBox** — айтем с чекбоксом для множественного выбора. Также собран на основе Cell.
5. **LazyLoading** — элемент подзагрузки списка в DropDown: вид загрузки и кнопка «Обновить».
6. **EmptyState** — пустое состояние списка с текстом «Пока ничего нет» и опциональной кнопкой.

---

## Типы

Тип определяет, как пользователь выбирает значения (одно или несколько) и как выглядит триггер (мимикрия под TextField или под Button).

| Тип | Выбор | Триггер | Визуал |
|---|---|---|---|
| **Select Single** | Одиночный | Мимикрирует под TextField | {{Pixso URL Select Doc Block 2}} |
| **Select Multiple** | Множественный | Мимикрирует под TextField | {{Pixso URL Select Doc Block 3}} |
| **SelectButton Single** | Одиночный | Button | {{Pixso URL Select Doc Block 4}} |
| **SelectButton Multiselect** | Множественный | Button | {{Pixso URL Select Doc Block 5}} |

Варианты с триггером-TextField подходят, когда нужно сохранить консистентность в формах, где рядом с компонентом находятся текстовые поля. Варианты с триггером-Button используются, когда роль элемента ближе к кнопке.

### Одиночный выбор

Пользователь выбирает один вариант из списка. При выборе DropDown закрывается, выбранное значение отображается в триггере.

### Множественный выбор

Пользователь выбирает несколько вариантов. Айтемы списка собираются с чекбоксами (Item CheckBox), DropDown остаётся открытым при выборе очередного элемента.

## Размеры и отступы

У компонента два размера — **S** и **XS**. Размер компонента равен размеру триггера; DropDown выведен в абсолют и на размер компонента не влияет.

### Триггер

| Размер | Высота триггера |
|---|---|
| **S** | 40 |
| **XS** | 32 |

### Айтемы списка

Высота айтема зависит от размера компонента и от вида списка (обычный или сжатый).

| Айтем | Размер | Высота | Шрифт лейбла | Corner Radius |
|---|---|---|---|---|
| **Item** | S | 40 | Body/BodyS N | S (8px) |
| **Item** | XS | 32 | Body/BodyXS N | cRXS (6px) |
| **Item Tight** | S | 32 | Body/BodyS N | S (8px) |
| **Item Tight** | XS | 24 | Body/BodyXS N | cRXS (6px) |

**Item Tight** — айтем для сжатого списка, имеет меньшие по высоте отступы. Обычный **Item** — для стандартного списка со стандартными отступами.

### Пустое состояние

| Размер | Шрифт лейбла | Шрифт текста | Иллюстрация |
|---|---|---|---|
| **S** | Body/BodyS B | Body/BodyS N | notFound |
| **XS** | Body/BodyXS B | Body/BodyXS N | notFound |

### Подзагрузка (LazyLoading)

| Айтем | Размер | Шрифт лейбла | Corner Radius | Размер иконки |
|---|---|---|---|---|
| **Item** | S | Body/BodyS N | S (8px) | 24px |
| **Item** | XS | Body/BodyXS N | cRXS (6px) | 24px |
| **Item Tight** | S | Body/BodyS N | S (8px) | 16px |
| **Item Tight** | XS | Body/BodyXS N | cRXS (6px) | 16px |

|---|---|---|

| ContentLeft | True / False | Включает или выключает контент (иконку) слева. |
| Disabled | True / False | Состояние «недоступно». |
| ReadOnly | True / False | Состояние «только для чтения». |

### Триггер (SelectButton Single / SelectButton Multiselect)

| Свойство | Значения | Назначение |
|---|---|---|
| Opened | True / False | Раскрывает или скрывает DropDown. |
| EmptyState | True / False | Включает вариант, где вместо списка в DropDown показывается пустое состояние. |

### DropDown

| Свойство | Значения | Назначение |
|---|---|---|
| View | Normal / Tight | Normal — элементы стандартной высоты (обычный список). Tight — элементы меньшей высоты (сжатый список). |
| ScrollBar | True / False | Включает или выключает скроллбар. |
| LazyLoading | True / False | Включает подзагрузку / пустое состояние списка. |

### Айтем (Item Select / Item CheckBox)

| Свойство | Значения | Назначение |
|---|---|---|
| Selected | True / False | Состояние выбранного айтема. |
| Focused | True / False | Состояние фокуса. |
| Disabled | True / False | Состояние «недоступно». |
| Disclosure | True / False | Disclosure справа — отображает вложенный выпадающий список. |
| Divider | True / False | Разделитель списка. |

### Подзагрузка (LazyLoading)

| Свойство | Значения | Назначение |
|---|---|---|
| View | Loading / Reload | Loading — вид подзагрузки списка. Reload — кнопка «Обновить» (перезагрузить список). |

### Пустое состояние (EmptyState)

| Свойство | Значения | Назначение |
|---|---|---|
| Button | True / False | Включает или выключает кнопку в пустом состоянии. |

## Состояния

Состояния задаются на уровне триггера и на уровне айтемов списка.

| Состояние | Где | Описание |
|---|---|---|
| **Empty / Filled** | Триггер | Триггер пуст (показан Placeholder) или заполнен выбранным значением. |
| **Opened** | Триггер | DropDown раскрыт. |
| **Disabled** | Триггер, айтем | Недоступно для взаимодействия. |
| **ReadOnly** | Триггер | Только для чтения. |
| **Selected** | Айтем | Айтем выбран. |
| **Focused** | Айтем | Айтем в фокусе. |

## Механика и взаимодействия

### Раскрытие списка

Нажатие на триггер раскрывает DropDown (свойство Opened). DropDown выведен в абсолют поверх контента и не влияет на размер компонента: ширина задаётся триггером, высота — размером и количеством вложенных элементов. При большом количестве элементов появляется скроллбар (свойство ScrollBar).

### Одиночный выбор

В типах Select Single и SelectButton Single айтемы собираются на основе Item Select. После выбора варианта DropDown закрывается, значение отображается в триггере (состояние Filled).

### Множественный выбор с чекбоксами

В типах Select Multiple и SelectButton Multiselect айтемы собираются на основе Item CheckBox — у каждого айтема есть чекбокс. Список остаётся открытым при выборе нескольких значений.

### Вложенные списки

Айтем со свойством Disclosure показывает справа управление раскрытием вложенного выпадающего списка. Так строится иерархия из нескольких уровней.

### Ленивая загрузка (LazyLoading)

Когда список подгружается, в DropDown показывается элемент подзагрузки: вид загрузки (Loading) или кнопка «Обновить» (Reload) для повторной попытки. Подзагрузка доступна для обычного и для сжатого списка (LazyLoading / LazyLoadingTight).

### Пустое состояние (EmptyState)

Если показывать нечего, вместо списка в DropDown отображается пустое состояние с иллюстрацией notFound и текстом «Пока ничего нет». Опционально в пустом состоянии доступна кнопка (свойство Button).

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Тип: Single / Multiple | `multiselect` | boolean | Множественный выбор включается пропом `multiselect`. |
| Триггер: TextField-like / Button-like | `target` | textfield-like / button-like | Select Single/Multiple = `textfield-like`; SelectButton = `button-like`. |
| DropDown View: Normal / Tight | `variant` | tight | Сжатый список (Tight) = `variant="tight"`. |
| hasContentBeforeList + ◇ ContentBeforeList | `beforeList` | ReactNode | Два свойства дизайна объединены в коде в единый проп `beforeList`. |
| ContentLeft | `contentLeft` | ReactNode | Иконка/контент слева в триггере. |
| Caption | `helperText` | строка | Подпись под триггером. |
| EmptyState | `emptyStateDescription` | строка | Содержимое пустого состояния списка. |
| Value (Empty / Filled) | `value` | string / string[] | В single — `string`, в multiselect — `string[]`. |
| Disclosure (вложенный список) | вложенные `items` | массив | Вложенные элементы передаются через `items` внутри `items`. |

## FAQ

### Для дизайнеров

**Q: Когда брать Select, а когда Combobox?**
A: Select — для выбора из заранее подготовленного списка. Если пользователю нужно ввести значение вручную или добавить своё значение в список — используйте Combobox.

**Q: Какие типы Select есть?**
A: Четыре: Select Single и Select Multiple (триггер мимикрирует под TextField) и SelectButton Single и SelectButton Multiselect (триггер — Button). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Select Doc Block 1}}.

**Q: Какие размеры у компонента?**
A: Два — S (триггер высотой 40) и XS (триггер высотой 32). Размер компонента равен размеру триггера, DropDown на него не влияет. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Select Doc Block 1}}.

**Q: Чем отличается обычный список от сжатого (Tight)?**
A: Свойство View у DropDown: Normal — элементы стандартной высоты, Tight — элементы меньшей высоты (сжатый список). У сжатого списка айтемы Item Tight с меньшими отступами. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Select Doc Block 1}}.

**Q: Как сделать множественный выбор?**
A: Взять тип Select Multiple или SelectButton Multiselect — айтемы списка собираются с чекбоксами (Item CheckBox). Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Select Doc Block 1}}.

**Q: Что показывается, когда выбирать не из чего?**
A: Пустое состояние EmptyState с иллюстрацией notFound и текстом «Пока ничего нет». Опционально можно включить кнопку. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Select Doc Block 1}}.

**Q: Как показать загрузку списка?**
A: Через элемент LazyLoading в DropDown: вид Loading (загрузка) или Reload (кнопка «Обновить»). Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Select Doc Block 1}}.

**Q: Как сделать вложенный список?**
A: Включить у айтема свойство Disclosure — справа появится управление раскрытием вложенного выпадающего списка. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Select Doc Block 1}}.

### Для разработчиков

**Q: Как включить множественный выбор?**
A: Передать проп `multiselect`. В single-режиме `value` имеет тип `string`, в multiselect — `string[]`. Примеры кода — в Storybook: {{Storybook URL Select}}.

**Q: Как выбрать вид триггера — TextField-like или Button-like?**
A: Пропом `target`: `textfield-like` (по умолчанию) или `button-like`. Select Single/Multiple = `textfield-like`, SelectButton = `button-like`. Примеры кода — в Storybook: {{Storybook URL Select}}.

**Q: Как включить сжатый список (дизайнерский View → Tight)?**
A: Через проп `variant="tight"`. Примеры кода — в Storybook: {{Storybook URL Select}}.

**Q: Как задать контент перед списком (дизайнерские hasContentBeforeList / ContentBeforeList)?**
A: В коде это единое свойство `beforeList` (ReactNode). Примеры кода — в Storybook: {{Storybook URL Select}}.

**Q: Как передать вложенные списки?**
A: Внутри `items` у элемента можно передать вложенный массив `items` — это и есть Disclosure из дизайна. Примеры кода — в Storybook: {{Storybook URL Select}}.

**Q: Как настроить пустое состояние списка?**
A: Через `emptyStateDescription` для содержимого пустого состояния. Примеры кода — в Storybook: {{Storybook URL Select}}.
