# Image

Технический компонент отображения изображений.

Визуал: {{Pixso URL Image Doc Block 1}}

---

## Размеры и отступы

Ширину и высоту компонента Image можно задать двумя способами:

- Произвольными значениями в px.
- Задать ширину компонента произвольным значением, выбрать соотношение сторон через свойство Ratio.

### Соотношение сторон

Пропорциональное отношение ширины к высоте. Компонент Image имеет 8 доступных соотношений (7 именованных + Custom).

| Значение | Описание |
|---|---|
| 1:1 | Квадрат. |
| 1:2 | Вертикальное соотношение. |
| 3:4 | Вертикальное соотношение. |
| 9:16 | Вертикальное соотношение. |
| 2:1 | Горизонтальное соотношение. |
| 4:3 | Горизонтальное соотношение. |
| 16:9 | Горизонтальное соотношение. |
| Custom | Произвольное соотношение сторон — можно задать любое. |

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Ratio | — | 1:1 / 1:2 / 3:4 / 9:16 / 2:1 / 4:3 / 16:9 / Custom | В dev-коде ширина/высота задаются через `width` / `height`. Точное имя пропа соотношения сторон уточните в Storybook или в чате поддержки дизайн-системы. |
| Ширина | `width` | px (строка, напр. `"320px"`) | Подтверждено в dev-коде. |
| Высота | `height` | px (строка, напр. `"320px"`) | Подтверждено в dev-коде. |
| Источник изображения | `src` | путь / URL | Подтверждено в dev-коде. В дизайне отдельным свойством не описан. |
| Альтернативный текст | `alt` | строка | Подтверждено в dev-коде. В дизайне отдельным свойством не описан. |

## FAQ

### Для дизайнеров

**Q: Что это за компонент?**
A: Технический компонент отображения изображений.

**Q: Как задать размер изображения?**
A: Двумя способами — произвольными значениями ширины и высоты в px, либо задать ширину и выбрать соотношение сторон через свойство Ratio. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Image Doc Block 1}}.

**Q: Какие соотношения сторон доступны?**
A: Семь именованных: 1:1, 1:2, 3:4, 9:16, 2:1, 4:3, 16:9, а также Custom для произвольного соотношения. Подробнее — в Pixso-документации компонента, блок «Соотношение сторон»: {{Pixso URL Image Doc Block 1}}.

**Q: Как задать произвольное соотношение сторон?**
A: Выбрать значение Custom в свойстве Ratio. Подробнее — в Pixso-документации компонента, блок «Соотношение сторон»: {{Pixso URL Image Doc Block 1}}.

### Для разработчиков

**Q: Как передать изображение и его размеры?**
A: Источник задаётся пропом `src` (путь или URL), размеры — пропами `width` и `height` в px (строкой, например `"320px"`). Альтернативный текст — проп `alt`. Примеры кода — в Storybook: {{Storybook URL Image}}.

**Q: Есть ли проп для соотношения сторон?**
A: В dev-коде ширина и высота задаются через `width` / `height`. Точное имя пропа соотношения сторон уточняйте в Storybook или в чате поддержки дизайн-системы: {{Storybook URL Image}}.
