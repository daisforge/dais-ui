# Cell

Универсальная ячейка-контейнер — небольшой блок контента или функциональности. Состоит из трёх частей: Left Content / Center Content / Right Content. В каждую из них по умолчанию вложены компоненты с вариантами реализации, но при необходимости любую часть можно заменить на другой компонент.

Визуал: {{Pixso URL Cell Doc Block 1}}

---

## Анатомия

1. **Left Content** — левая часть ячейки. По умолчанию вложены Icon (16 / 24 / 36) или Avatar (24 / 36 / 48). Можно скрыть или заменить на любой компонент.
2. **Center Content** — центральная текстовая часть. Содержит Label, Title и Subtitle.
3. **Right Content** — правая часть ячейки. По умолчанию Icon, IconButton или Disclosure (стрелочка). Можно скрыть или заменить на любой компонент.

Внутри центральной части:

- **Label** — верхняя подпись (опционально).
- **Title** — основной текст ячейки.
- **Subtitle** — нижняя подпись (опционально).

---

## Размеры и отступы

Размер задаёт шрифты текстовых частей и отступы (padding) ячейки. Доступны четыре размера — L / M / S / XS.

| Размер | Шрифт Title | Шрифт Label / Subtitle | Padding | Скругление |
|---|---|---|---|---|
| **L** | Body/BodyL N | Body/BodyM N | 16px / 16px | 12 |
| **M** | Body/BodyM N | Body/BodyS N | 12px / 12px | 12 |
| **S** | Body/BodyS N | Body/BodyXS N | 12px / 8px | 8 |
| **XS** | Body/BodyXS N | Body/BodyXXS N | 8px / 8px | 8 |

Рекомендации по отступам:

- Размер паддинга должен быть кратен четырём (например: 8px, 12px, 16px).

Рекомендации по скруглениям:

- Скругления должны подходить к скруглениям внешнего контейнера и размерам компонента.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Cell" />`.

### Left Content

Левая часть ячейки. Включается / выключается, а также выбирается её содержимое.

| Содержимое | Назначение |
|---|---|
| Icon 16 | В левой части иконка 16px. |
| Icon 24 | В левой части иконка 24px. |
| Icon 36 | В левой части иконка 36px. |
| Avatar 24 | В левой части аватар 24px. |
| Avatar 36 | В левой части аватар 36px. |
| Avatar 48 | В левой части аватар 48px. |

Если ни один из предложенных вариантов не подходит — можно заменить левую часть на любой другой компонент: выделите в ячейке слой Left Content и замените компонент в правой панели (Instance swap).

### Center Content

Центральная часть с текстом. Title отображается всегда, Label и Subtitle можно включать и выключать по отдельности.

| Элемент | Поведение |
|---|---|
| Label | Включает / выключает отображение лейбла в центральной части ячейки. |
| Title | Основной текст ячейки. |
| Subtitle | Включает / выключает отображение сабтайтла в центральной части ячейки. |

### Right Content

Правая часть ячейки. Включается / выключается, а также выбирается её содержимое.

| Содержимое | Назначение |
|---|---|
| Icon | Правая часть ячейки заполняется иконкой. |
| IconButton | Правая часть ячейки заполняется кнопкой с иконкой. |
| Disclosure | Правая часть ячейки заполняется стрелочкой. |

Если ни один из предложенных вариантов не подходит — можно заменить правую часть на любой другой компонент: выделите в ячейке слой Right Content и замените компонент в правой панели (Instance swap).

### Заливка, обводка и цвет текста

- Для заливки компонента можно использовать цвета из группы Surface.
- Для обводки используются цвета группы Outline.
- Цвет текста можно менять в группе Text/Icon.
- По потребности можно менять стиль текста из токенов библиотеки.
- Возможно использование некоторых цветов из группы Data — требует согласования с командой ДС.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Left Content | `contentLeft` | компонент (ReactNode) | В левую часть подставляется любой компонент: Icon, Avatar или другой. |
| Right Content | `contentRight` | компонент (ReactNode) | В правую часть подставляется любой компонент: Icon, IconButton, Disclosure или другой. |
| Size (L / M / S / XS) | `size` | l / m / s / xs | Прямое соответствие. |
| Title | `title` | строка | Основной текст ячейки. |
| Subtitle | `subtitle` | строка | Нижняя подпись. |
| Label | `label` | строка | Верхняя подпись. |
| Center Content (расширенный) | `children` | `CellTextbox` со слотами | Вместо `title` / `subtitle` / `label` можно передать вложенный `CellTextbox` с компонентами `CellTextboxLabel`, `CellTextboxTitle`, `CellTextboxSubtitle` и произвольным контентом. |

## FAQ

### Для дизайнеров

**Q: Из каких частей состоит ячейка?**
A: Из трёх: Left Content (слева), Center Content (по центру) и Right Content (справа). Левую и правую части можно скрыть или заменить на другой компонент. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Cell Doc Block 1}}.

**Q: Какие размеры есть у ячейки?**
A: Четыре: L, M, S, XS. Каждый задаёт свои шрифты Title и Label / Subtitle, а также отступы и скругление. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Cell Doc Block 1}}.

**Q: Как поместить в левую часть аватар или иконку?**
A: В Left Content по умолчанию доступны Icon 16 / 24 / 36 и Avatar 24 / 36 / 48 — выберите подходящий вариант. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Cell Doc Block 1}}.

**Q: Как добавить в правую часть стрелочку или кнопку?**
A: В Right Content по умолчанию доступны Icon, IconButton и Disclosure (стрелочка) — выберите нужный вариант. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Cell Doc Block 1}}.

**Q: Как показать ячейку только с заголовком, без Label и Subtitle?**
A: Title отображается всегда, а Label и Subtitle можно выключить по отдельности. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Cell Doc Block 1}}.

**Q: Что делать, если нужного компонента нет в вариантах левой или правой части?**
A: Выделите в ячейке слой Left Content или Right Content и замените компонент в правой панели (Instance swap) — в часть можно поместить любой компонент. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Cell Doc Block 1}}.

**Q: Какие цвета можно использовать для заливки и обводки?**
A: Для заливки — цвета группы Surface, для обводки — группы Outline, для текста — группы Text/Icon. Цвета группы Data требуют согласования с командой ДС. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Cell Doc Block 1}}.

### Для разработчиков

**Q: Как задать размер ячейки?**
A: Через проп `size` со значениями `l` / `m` / `s` / `xs` — прямое соответствие размерам L / M / S / XS. Примеры кода — в Storybook: {{Storybook URL Cell}}.

**Q: Как задать текст ячейки?**
A: Через пропы `title`, `subtitle` и `label` (строки). Примеры кода — в Storybook: {{Storybook URL Cell}}.

**Q: Как поместить компонент в левую или правую часть?**
A: Через пропы `contentLeft` и `contentRight` (ReactNode) — туда можно передать Avatar, иконку, кнопку, Disclosure или любой другой компонент. Примеры кода — в Storybook: {{Storybook URL Cell}}.

**Q: Как задать собственное содержимое центральной части?**
A: Вместо `title` / `subtitle` / `label` передайте вложенный `CellTextbox` со слотами `CellTextboxLabel`, `CellTextboxTitle`, `CellTextboxSubtitle` и любым произвольным контентом. Примеры кода — в Storybook: {{Storybook URL Cell}}.

**Q: Какие значения принимает `size`?**
A: `l` / `m` / `s` / `xs`. Каждое задаёт шрифты текста и отступы. Примеры кода — в Storybook: {{Storybook URL Cell}}.

**Q: Можно ли использовать ячейку без левой или правой части?**
A: Да — просто не передавайте `contentLeft` и/или `contentRight`. Примеры кода — в Storybook: {{Storybook URL Cell}}.
