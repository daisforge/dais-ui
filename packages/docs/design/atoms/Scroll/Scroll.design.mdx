# Scroll

Интерактивный индикатор для горизонтального и вертикального перемещения по контенту. Показывает положение видимой области внутри прокручиваемого блока и позволяет перемещаться по нему.

Визуал: {{Pixso URL ScrollBar Doc Block 1}}

---

## Анатомия

1. **Ползунок (Bar)** — подвижный индикатор, отражающий положение видимой области внутри контента. Ширина ползунка — 4px.
2. **Дорожка (Track)** — индикатор общего количества контента под ползунком. Отображается опционально (см. настройку Track).

---

## Размеры и отступы

| Параметр | Значение |
|---|---|
| Ширина ползунка | 4px |
| Высота (длина) | Произвольная — задаётся под размер прокручиваемой области |

Для горизонтального скролла макет ползунка поворачивается на 90° — ширина становится толщиной, а длина задаётся по горизонтали.

---

## Настройки (Props)

### Тема (subTheme)

Отвечает за цвет ползунка и его связь с темой оформления.

| Значение | Назначение |
|---|---|
| **Default** | Токены цвета зависят от текущей темы. |
| **onDark** | При смене темы ползунок остаётся тёмным. |
| **onLight** | При смене темы ползунок остаётся светлым. |
| **Inverse** | Цвет зависит от темы (инверсный вариант). |

### Дорожка (Track)

Отвечает за отображение дорожки — индикатора общего количества контента под ползунком.

| Значение | Результат |
|---|---|
| **Включена** | Дорожка отображается под ползунком. |
| **Выключена** | Дорожка скрыта, виден только ползунок. |

## Состояния

| Состояние | Описание |
|---|---|
| **Default** | Обычное отображение ползунка. |
| **Hover (наведение)** | При наведении курсора ползунок темнеет (становится контрастнее). |

---

## Механика и взаимодействия

- **Перемещение по контенту.** Ползунок отражает положение видимой области и перемещается вместе с прокруткой — вертикально или горизонтально.
- **Горизонтальный скролл.** Для добавления горизонтального скролла макет ползунка поворачивается на 90°.
- **Изменение при наведении.** При наведении курсора ползунок темнеет (становится более заметным); ширина при этом не меняется. Поведение при наведении настраивается в разработке — уточните в Storybook или в чате поддержки ДС.

## FAQ

### Для дизайнеров

**Q: Из чего состоит ползунок?**
A: Из подвижного ползунка (ширина 4px) и опциональной дорожки под ним, которая показывает общий объём контента. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL ScrollBar Doc Block 1}}.

**Q: Как сделать горизонтальный скролл?**
A: Поверните макет ползунка на 90° — длина задаётся по горизонтали, а толщина остаётся 4px. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL ScrollBar Doc Block 1}}.

**Q: Что происходит при наведении на ползунок?**
A: При наведении курсора ползунок темнеет (становится контрастнее); ширина при этом не меняется.

**Q: Зачем нужна дорожка и как её показать?**
A: Дорожка — это индикатор общего количества контента под ползунком. Её отображение включается и выключается настройкой Track. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL ScrollBar Doc Block 1}}.

**Q: Как ползунок ведёт себя при смене темы?**
A: Это задаётся темой (subTheme): Default и Inverse зависят от текущей темы, onDark всегда остаётся тёмным, onLight — всегда светлым. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL ScrollBar Doc Block 1}}.

**Q: Можно ли задать произвольную длину ползунка?**
A: Да. Ширина фиксирована (4px), а длину можно задать произвольно под размер прокручиваемой области. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL ScrollBar Doc Block 1}}.

### Для разработчиков

**Q: Как настроить поведение ползунка при наведении?**
A: Поведение при наведении настраивается в разработке — уточните в Storybook или в чате поддержки ДС.
