# List

Компонент List используется для отображения информации списком.

Визуал: {{Pixso URL List Doc Block 1}}

---

## Анатомия

1. **Item** — айтем, из которого собирается список. В Item вложен компонент Cell с настраиваемыми свойствами.

Item — самостоятельный элемент списка. Его типы и свойства:

| Тип Item | Описание | Визуал |
|---|---|---|
| **Item** | Айтем с ячейкой Cell для значения списка. | {{Pixso URL List Doc Block 2}} |
| **Item Tight** | Сжатый вариант айтема. | {{Pixso URL List Doc Block 2}} |

**Свойства Item:**

| Свойство | Значения | Назначение |
|---|---|---|
| **Disclosure** | True / False | Включает Disclosure справа — отображает вложенный выпадающий список. |
| **Disabled** | True / False | Включает состояние Disabled. |
| **Hovered** | True / False | Включает состояние Hovered. |
| **hasDivider** | True / False | Включает разделитель (Divider) у айтема. |
| **ItemType** | Default / Divider | Default — айтем, в котором лежит ячейка; Divider — айтем, в котором лежит дивайдер. |

**Размеры и отступы Item:**

| Размер Item | Шрифт лейбла | Corner Radius |
|---|---|---|
| **XL** | Body/BodyL N | Calc:[L−2] (14px) |
| **L** | Body/BodyL N | M (12px) |
| **M** | Body/BodyM N | calc[m−2] (10px) |
| **S** | Body/BodyS N | S (8px) |
| **XS** | Body/BodyXS N | cRXS (6px) |

## Размеры и отступы

Высота списка всегда зависит от количества включённых Item и их контента. По ширине список бывает Hug (подстраивается под контент) и Fix (фиксированная ширина).

| Размер | Высота | Ширина |
|---|---|---|
| **XL** | Зависит от количества включённых Item и контента | Hug / Fix |
| **L** | Зависит от количества включённых Item и контента | Hug / Fix |
| **M** | Зависит от количества включённых Item и контента | Hug / Fix |
| **S** | Зависит от количества включённых Item и контента | Hug / Fix |
| **XS** | Зависит от количества включённых Item и контента | Hug / Fix |

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="List" />`.

### Style

Свойство Style отвечает за то, как токены реагируют на тему.

| Style | Назначение |
|---|---|
| **Default** | Значения токенов меняются в зависимости от темы. |
| **onDark** | Статические значения токенов из тёмной темы, не меняются при переключении темы. |
| **onLight** | Статические значения токенов из светлой темы, не меняются при переключении темы. |
| **Inverse** | Инвертированные значения токенов подтемы default. |

---

## Состояния

Состояния задаются на уровне отдельного Item:

- **Default** — обычный айтем.
- **Hovered** — айтем под курсором.
- **Disabled** — недоступный айтем.

Дополнительно у Item включаются Disclosure (вложенный выпадающий список) и разделитель (hasDivider).

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Style | `view` | default | Цветовая тема списка. |
| Size (размер) | `size` | s | Размер списка. |
| Тип: Normal / Tight | `variant` | normal | Тип плотности списка. |
| Disabled (у Item) | `disabled` | boolean | Недоступное состояние айтема. |
| Disclosure / контент справа (у Item) | `contentRight` | иконка (ReactNode) | Контент в правой части айтема. |

## FAQ

### Для дизайнеров

**Q: Как сделать список более плотным?**
A: Выбрать тип Tight — это сжатый список с меньшими отступами. По умолчанию используется Normal. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL List Doc Block 1}}.

**Q: Какие размеры есть у списка?**
A: Пять: XL, L, M, S, XS. Каждый размер задаёт свой шрифт лейбла и скругление углов айтема. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL List Doc Block 1}}.

**Q: От чего зависит высота списка?**
A: Высота всегда зависит от количества включённых Item и их контента — список тянется по содержимому. По ширине доступны Hug (под контент) и Fix (фиксированная). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL List Doc Block 1}}.

**Q: Что такое Disclosure у айтема?**
A: Это переключатель, который добавляет элемент раскрытия справа и отображает вложенный выпадающий список. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL List Doc Block 1}}.

**Q: Как добавить разделитель между айтемами?**
A: Включить у Item свойство hasDivider — появится разделитель. Также можно использовать отдельный айтем типа Divider, в котором лежит дивайдер. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL List Doc Block 1}}.

**Q: Как сделать айтем недоступным или показать его под курсором?**
A: Через свойства Item: Disabled — недоступное состояние, Hovered — состояние под курсором. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL List Doc Block 1}}.

**Q: Что лежит внутри айтема?**
A: В Item вложен компонент Cell с настраиваемыми свойствами — он отвечает за содержимое строки. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL List Doc Block 1}}.

**Q: Зачем нужен Style и его варианты onDark / onLight / Inverse?**
A: Style управляет реакцией токенов на тему: Default меняется вместе с темой, onDark/onLight фиксируют значения тёмной/светлой темы, Inverse даёт инвертированные значения подтемы default. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL List Doc Block 1}}.
