# Avatar

Компонент, предназначенный для идентификации пользователя.

Визуал: {{Pixso URL Avatar Doc Block 1}}

В коде это **два** компонента: `Avatar` (отдельный аватар) и `AvatarGroup` (обёртка для объединения аватаров в список). В дизайне они описаны в одной общей документации, поэтому здесь собраны оба.

---

## Типы

| Тип | Описание | Визуал |
|---|---|---|
| **Avatar S-XXL** | Базовый аватар в размерах от S до XXL. | {{Pixso URL Avatar Doc Block 1}} |
| **Avatar Scalable** | Масштабируемый аватар — без свойств, только возможность вставить изображение. | {{Pixso URL Avatar Doc Block 3}} |
| **Avatar Group** | Компонент для объединения аватаров в один список. | {{Pixso URL Avatar Doc Block 4}} |

---

## Анатомия

1. **Изображение / Инициалы** — основное содержимое: фотография (вид Image) либо инициалы из имени (вид Initials).
2. **Indicator (статус)** — индикатор активного/неактивного статуса пользователя (опционально).
3. **Дополнительный элемент (Badge / Counter)** — закреплён в одном из углов аватара (опционально).

---

## Размеры и отступы

В дизайне у обычного аватара 4 размера. Размер задаётся свойством **Size**.

| Размер | Размер аватара | Шрифт инициалов | Размер иконки (IconSize) |
|---|---|---|---|
| **XXL** | 88 | SB Sana Display/Semibold/32 | 36px |
| **L** | 48 | SB Sana Display/Semibold/20 | 24px |
| **M** | 36 | SB Sana Display/Semibold/14 | 24px |
| **S** | 24 | SB Sana Display/Semibold/8 | 16px |

## Настройки (Props)

> Здесь — визуальное поведение из дизайна. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Avatar" />`.

### View (изображение / инициалы)

Отвечает за основное содержимое аватара.

| Вид | Описание |
|---|---|
| **Image** | Аватар с изображением. |
| **Initials** | Вариант без изображения, с инициалами из имени. |

Изображение задаётся ссылкой на фотографию; инициалы формируются из имени (когда фотографии нет). Желательный формат имени — «Имя Фамилия».

### Status

Статус пользователя, отображается через Indicator.

| Значение | Описание |
|---|---|
| **Default** | Обычное отображение (без индикатора). |
| **Active** | Активный статус. |
| **Inactive** | Неактивный статус. |

Значение **Default** — это обычное отображение без индикатора. Для вспомогательных технологий статус озвучивается («Активен» / «Неактивен»).

### Дополнительный контент

Включает отображение дополнительного элемента (Badge / Counter) в углу аватара.

### Placement (положение доп. элемента)

Доступно при включённом дополнительном контенте. Угол, в котором закреплён дополнительный элемент.

| Значение | Описание |
|---|---|
| **Top Left** | В верхнем левом углу. При увеличении длины текста растёт вправо до правой границы аватара, далее текст сокращается многоточием. |
| **Top Right** | В верхнем правом углу. При увеличении длины текста растёт влево до левой границы аватара, далее текст сокращается многоточием. |
| **Bottom Left** | В нижнем левом углу. При увеличении длины текста растёт вправо до правой границы аватара, далее текст сокращается многоточием. |
| **Bottom Right** | В нижнем правом углу. При увеличении длины текста растёт влево до левой границы аватара, далее текст сокращается многоточием. |

### Type (тип доп. элемента)

Доступно при включённом дополнительном контенте.

| Значение | Описание |
|---|---|
| **Badge** | Дополнительный элемент — Badge. **В размере 24 S не предусмотрен.** |
| **Counter** | Дополнительный элемент — Counter. |

В углу аватара может быть Badge или Counter. У дополнительного элемента настраивается значение — текст для Badge либо число для Counter.

### Avatar Scalable

Масштабируемый аватар — без свойств, только возможность вставить изображение. В дизайне представлен отдельным типом «Avatar Scalable».

### Доступность

Аватар поддерживает корректную работу с вспомогательными технологиями. При наличии имени отдельная подпись не требуется. Статус озвучивается в комбинации с именем.

## AvatarGroup (группа аватаров)

Avatar Group — обёртка для объединения аватаров в один список.

- В дизайне группа представлена только в **1 размере (24 S)**.
- Максимальное количество отображаемых вариантов в дизайне — **4**; в коде количество аватаров может быть любым.
- В дизайне число элементов задаётся макетным свойством **Quantity** (варианты раскладки: 2 / 3 / Many).
- Параметры количества — общее число элементов и число видимых (остальные сворачиваются в счётчик «+N»). Точные пропсы в коде — см. Storybook.

## Маппинг: дизайн → код

В таблице — свойства с подтверждённым пропом в коде. Параметры количества AvatarGroup управляются в коде иначе — точные пропсы см. в Storybook.

| Свойство в дизайне | Проп в коде | Компонент | Примечание |
|---|---|---|---|
| Size (XXL / L / M / S) | `size` | Avatar | `"xxl"` / `"l"` / `"m"` / `"s"`. В коде есть дополнительно `"fit"` — вероятно, соответствует варианту Scalable в дизайне; точное соответствие уточните в Storybook или в чате поддержки. |
| View: Image | `url` | Avatar | Изображение задаётся ссылкой `url`. |
| View: Initials | `name` | Avatar | Инициалы из имени (без `url`). Формат — «Имя Фамилия». |
| Status: Active / Inactive | `status` | Avatar | `"active"` / `"inactive"`. |
| Status: Default | — | Avatar | Дефолтное состояние без индикатора статуса. |
| Озвучка статуса | `statusLabels` | Avatar | Задаётся в коде. По умолчанию `{ active: 'Активен', inactive: 'Неактивен' }`. |
| hasExtra | `hasExtra` | Avatar | Булев проп. |
| Placement | `extraPlacement` | Avatar | `"top-left"` / `"top-right"` / `"bottom-left"` / `"bottom-right"`. |
| Type: Badge / Counter | `type` | Avatar | `"badge"` / `"counter"`. Badge недоступен в размере S. |
| Вид Badge / Counter | `badgeView` / `counterView` | Avatar | Например `warning`, `negative` / `positive`, `accent`. |
| Значение Badge / Counter | `text` / `count` | Avatar | Текст бейджа / число счётчика. |
| Avatar Scalable (тип) | `isScalable` | Avatar | В дизайне отдельный тип; в коде — булев проп. |
| Доступность | `role`, `tabIndex`, `aria-label` | Avatar | Задаётся в коде. |
| Quantity (2 / 3 / Many) | — | AvatarGroup | Макетное свойство дизайна. Количество в коде регулируется параметрами — см. Storybook. |

## FAQ

### Для дизайнеров

**Q: Какие размеры и форма есть у аватара?**
A: В дизайне четыре размера — XXL (88), L (48), M (36), S (24). Размер задаётся свойством Size. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Avatar Doc Block 2}}.

**Q: Как показать инициалы вместо фотографии?**
A: Использовать вид View → Initials — аватар без изображения, с инициалами из имени (формат «Имя Фамилия»). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Avatar Doc Block 1}}.

**Q: Как показать статус-индикатор (активен/неактивен)?**
A: Через свойство Status: Active или Inactive. Значение Default — это обычное отображение без индикатора. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Avatar Doc Block 1}}.

**Q: Как добавить дополнительный элемент (Badge / Counter) в угол аватара?**
A: Включить дополнительный контент и выбрать угол через Placement (Top Left / Top Right / Bottom Left / Bottom Right), а тип элемента — Badge или Counter. Badge не предусмотрен в размере 24 S. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Avatar Doc Block 1}}.

**Q: Что такое масштабируемый аватар (Scalable)?**
A: Это отдельный тип «Avatar Scalable» — масштабируемый аватар без свойств, только с возможностью вставить изображение. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Avatar Doc Block 1}}.

**Q: Сколько аватаров можно показать в группе и как считается +N?**
A: В дизайне группа представлена только в размере 24 S, максимум 4 отображаемых варианта. Число элементов задаётся макетным свойством Quantity (2 / 3 / Many), а количество — общим числом элементов и числом видимых (остальные сворачиваются в счётчик «+N»). Подробнее — в Pixso-документации компонента, блок «AvatarGroup»: {{Pixso URL Avatar Doc Block 4}}.

### Для разработчиков

**Q: Какие значения принимает проп `size`?**
A: `"xxl"` / `"l"` / `"m"` / `"s"`. Дополнительно в коде есть `"fit"` — вероятно, соответствует варианту **Scalable** в дизайне (масштабируемый аватар); точное соответствие уточните в Storybook или в чате поддержки дизайн-системы. Примеры кода — в Storybook: {{Storybook URL Avatar}}.

**Q: Как задать изображение или инициалы?**
A: Изображение — через `url`. Инициалы — через `name` (без `url`), формат «Имя Фамилия». Примеры кода — в Storybook: {{Storybook URL Avatar}}.

**Q: Как задать статус и его озвучку?**
A: Проп `status` (`"active"` / `"inactive"`); без него — состояние Default. Для вспомогательных технологий — `statusLabels` (по умолчанию `{ active: 'Активен', inactive: 'Неактивен' }`). Примеры кода — в Storybook: {{Storybook URL Avatar}}.

**Q: Как добавить Badge или Counter и настроить их?**
A: Включить `hasExtra`, угол — через `extraPlacement` (`"top-left"` / `"top-right"` / `"bottom-left"` / `"bottom-right"`), тип — через `type` (`"badge"` / `"counter"`). Вид настраивается через `badgeView` / `counterView`, значение — через `text` (Badge) / `count` (Counter). Badge недоступен в размере S. Примеры кода — в Storybook: {{Storybook URL Avatar}}.

**Q: Как сделать масштабируемый аватар и настроить доступность?**
A: Масштабирование при наведении — булев проп `isScalable`. Доступность — `role`, `tabIndex`, `aria-label` (при наличии `name` его можно опустить). Примеры кода — в Storybook: {{Storybook URL Avatar}}.

**Q: Как в коде управлять количеством аватаров в AvatarGroup?**
A: `AvatarGroup` — обёртка для `Avatar`; количество аватаров может быть любым и регулируется параметрами. Точные пропсы — см. Storybook: {{Storybook URL Avatar}}.
