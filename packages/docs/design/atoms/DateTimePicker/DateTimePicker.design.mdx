# DateTimePicker

Элемент выбора даты и времени посредством ввода или путём выбора даты из календаря.

Визуал: {{Pixso URL DateTimePicker Doc Block 1}}

DateTimePicker наследует все свойства и стили вложенных компонентов. Календарь открывается отдельным компонентом Calendar: он наследует свойства компонента CalendarGrid, фиксирован по высоте, по ширине зависит от отображаемых элементов в каждом размере, выведен в абсолют и не влияет на размер компонента.

---

## Анатомия

1. **DatePickerTrigger** — поле ввода (компонент Textfield), задаёт размер всего компонента. Содержит лейбл, плейсхолдер, подсказку и слот справа.
2. **Calendar** — выпадающий календарь для выбора даты. Это отдельный компонент (см. «Связанные компоненты»), он лишь открывается из триггера и не влияет на размер DateTimePicker.
3. **TimeGrid** — блок выбора времени. Состоит из колонок TimeColumn.
   - **TimeColumn** — колонка вывода значений времени одной единицы измерения (часы, минуты или секунды). Ширина фиксирована, высота зависит от количества включённых TimeItem. Может включать ScrollBar.
   - **TimeItem** — айтем единичного значения времени. Выбор времени происходит вводом цифр либо выбором в раскрывающемся списке.
4. **ShortcutsItem** — выпадающий элемент-пресет (быстрый выбор). Из таких айтемов собирается список быстрых пресетов рядом с календарём.

## Размеры и отступы

Размер компонента равен размеру DatePickerTrigger (компонент Textfield).

| Размер | Минимальная высота | Максимальная высота |
|---|---|---|
| **S** | 40px | 84px |
| **XS** | 32px | 70px |

Размер влияет на внутренние элементы выбора времени:

| Элемент | S | XS |
|---|---|---|
| **TimeItem** | шрифт Body/BodyS N, Corner Radius S (8px) | шрифт Body/BodyXS N, Corner Radius cRXS (6px) |
| **ShortcutsItem** | шрифт Body/BodyS N, Corner Radius S (8px) | шрифт Body/BodyXS N, Corner Radius cRXS (6px) |
| **TimeGrid** | Title Font Body/BodyS N | Title Font Body/BodyXS N |

Ширина выпадающего блока задаётся боковым отступом в Auto Layout (слой dropdownWIDTH), высота — отступом сверху в Auto Layout (слой dropdownHEIGHT), кроме варианта DropDownAlign = Justified.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="DateTimePicker" />`.

### Opened

Открытое или закрытое состояние выпадающего блока.

| Значение | Результат |
|---|---|
| True | Выпадающий блок открыт. |
| False | Выпадающий блок закрыт. |

### PickerType

Количество отображаемых календарей.

| Значение | Результат |
|---|---|
| Single | Отображается одинарный календарь. |
| Double | Отображается двойной календарь. |

### Пресеты (Shortcuts)

Быстрые пресеты выбора рядом с календарём.

| Свойство | Значение | Результат |
|---|---|---|
| **hasShortcuts** | True / False | Включает или выключает пресеты в календаре. |
| **ShortcutsPlacement** | Left / Right | Положение пресетов слева или справа от календаря. |
| **hasScrollBar** | True / False | Включает или выключает ScrollBar в пресетах. |

Каждый элемент пресетов (ShortcutsItem) имеет состояния Hovered и Disabled.

### Автозакрытие после выбора

Поведение закрытия выпадающего календаря после выбора значения (настраивается в коде).

| Значение | Результат |
|---|---|
| True | Закрытие происходит автоматически после выбора значения в календаре. |
| False | Закрытие происходит по клику вне области календаря или регулируется на усмотрение пользователя. |

### Выбор времени (TimeGrid)

| Свойство | Значение | Результат |
|---|---|---|
| **ColumnQuantity** | 3 | Отображает 3 колонки TimeColumn (формат 00:00:00). |
| **ColumnQuantity** | 2 | Отображает 2 колонки TimeColumn (формат 00:00). |
| **Selected** | True / False | Включает или выключает состояние выбранного значения (свойство на уровне TimeGrid). |

Колонка TimeColumn имеет свойство **hasScrollbar** (включает или выключает ScrollBar). Айтем TimeItem имеет состояния **ItemSelected** и **Disabled**.

## Состояния

- **Триггер (поле ввода)** — наследует состояния компонента Textfield: дефолт, фокус, заполненное, обязательное (с индикатором), подсказка.
- **Выпадающий блок** — открыт (Opened = True) или закрыт (Opened = False).
- **ShortcutsItem** — Hovered, Disabled.
- **TimeItem** — ItemSelected (выбран), Disabled.
- **TimeGrid** — Selected (есть выбранное значение).

---

## Механика и взаимодействия

Дизайн-суть взаимодействия:

- **Выбор даты** — вводом в поле или открытием календаря и выбором даты в нём. При выборе даты в календаре или вводе через поле дата приводится к заданному формату.
- **Выбор времени** — вводом цифр в TimeItem либо выбором значения в раскрывающемся списке (колонки TimeColumn). Количество колонок определяется форматом времени: 2 колонки для 00:00, 3 — для 00:00:00. Поведение выбора времени совпадает с компонентом TimePicker (см. «Связанные компоненты»).
- **Быстрые пресеты (Shortcuts)** — список ShortcutsItem рядом с календарём для мгновенного выбора частых значений; положение слева или справа, при длинном списке доступен ScrollBar.
- **Закрытие** — автоматически после выбора (настраивается в коде) либо по клику вне области календаря.

## FAQ

### Для дизайнеров

**Q: Какие размеры есть у DateTimePicker?**
A: Два: S (минимальная высота 40px, максимальная 84px) и XS (минимальная высота 32px, максимальная 70px). Размер компонента равен размеру триггера (компонент Textfield) и влияет на шрифты и скругление внутренних элементов выбора времени. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL DateTimePicker Doc Block 2}}.

**Q: Как показать два календаря рядом?**
A: Выбрать PickerType → Double — отображается двойной календарь. Single — одинарный. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL DateTimePicker Doc Block 1}}.

**Q: Как добавить быстрые пресеты к календарю?**
A: Включить hasShortcuts. Положение списка задаётся свойством ShortcutsPlacement (Left или Right), при длинном списке включается ScrollBar через hasScrollBar. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL DateTimePicker Doc Block 1}}.

**Q: Как настроить выбор времени до секунд?**
A: Свойство ColumnQuantity на уровне TimeGrid: 3 колонки TimeColumn дают формат 00:00:00, 2 колонки — формат 00:00. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL DateTimePicker Doc Block 1}}.

**Q: Как сделать, чтобы календарь закрывался сразу после выбора даты?**
A: Автозакрытие выпадающего календаря после выбора — это настройка в коде: по умолчанию календарь закрывается после выбора значения, иначе — по клику вне области. Уточните в Storybook: {{Storybook URL DateTimePicker}}.

**Q: Из чего собран блок выбора времени?**
A: Из TimeGrid, внутри которого колонки TimeColumn (по одной на единицу измерения), а в них — айтемы TimeItem с состояниями ItemSelected и Disabled. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL DateTimePicker Doc Block 1}}.

**Q: Почему Calendar не описан в анатомии подробно?**
A: Календарь — отдельный компонент: он выведен в абсолют, не влияет на размер DateTimePicker и лишь открывается из триггера. Подробно он задокументирован отдельно.

### Для разработчиков

**Q: Как задать размер компонента?**
A: Через проп `size` со значениями `s` / `xs` — прямое соответствие размерам S / XS. Примеры кода — в Storybook: {{Storybook URL DateTimePicker}}.

**Q: Как включить двойной календарь?**
A: Передать проп `isDouble` (boolean) — отображаются два календаря рядом. Примеры кода — в Storybook: {{Storybook URL DateTimePicker}}.

**Q: Как настроить автозакрытие после выбора даты?**
A: Через проп `closeAfterDateSelect` (boolean): при `true` календарь закрывается автоматически после выбора значения. Примеры кода — в Storybook: {{Storybook URL DateTimePicker}}.

**Q: Как настроить пресеты, формат даты/времени и состояния выбора времени в коде?**

**Q: Как задать формат и язык даты?**

**Q: Как добавить подсказки и индикатор обязательности?**
