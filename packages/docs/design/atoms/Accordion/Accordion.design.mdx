# Accordion

Вертикальный список с возможностью показать или скрыть связанный контент. Каждый раздел состоит из заголовка и контента, который раскрывается по нажатию.

Визуал: {{Pixso URL Accordion Doc Block 1}}

---

## Анатомия

Аккордеон собирается из повторяющихся элементов.

1. **Accordion Item** — элемент, из которого собирается аккордеон. Состоит из заголовка (Title) и связанного контента, который раскрывается и сворачивается.
2. **Title** — заголовок элемента, текстовый лейбл раздела.
3. **Description** — связанный контент раздела, который показывается в раскрытом состоянии.
4. **Иконка слева** — индикатор раскрытия слева от заголовка (стрелка вниз/вверх).
5. **Иконка справа** — индикатор раскрытия справа от заголовка (плюс/минус).

Иконка может быть слева или справа от заголовка — но не одновременно в обеих позициях.

---

## Типы

Тип определяет масштаб и набор шрифтов заголовка. Есть два семейства размеров.

| Тип | Описание | Визуал |
|---|---|---|
| **Accordion XS-L** | Размерное семейство для обычных списков. Размеры XS, S, M, L. | {{Pixso URL Accordion Doc Block 2}} |
| **Accordion H2-H5** | Заголовочное семейство для крупных разделов. Размеры H2, H3, H4, H5. | {{Pixso URL Accordion Doc Block 4}} |

## Размеры и отступы

### Accordion XS-L

| Размер | Высота заголовка | Шрифт заголовка | Шрифт контента | Corner Radius | Размер иконки |
|---|---|---|---|---|---|
| **L** | 56 | Body/BodyL B | Body/BodyL N | Calc:[M+2] (14px) | 16px |
| **M** | 48 | Body/BodyM B | Body/BodyM N | M (12px) | 16px |
| **S** | 40 | Body/BodyS B | Body/BodyS N | Calc:[S+2] (10px) | 16px |
| **XS** | 32 | Body/BodyXS B | Body/BodyXS N | S (8px) | 16px |

### Accordion H2-H5

| Размер | Высота заголовка | Шрифт заголовка | Шрифт контента | Corner Radius | Размер иконки |
|---|---|---|---|---|---|
| **H2** | 68 | Header/Large Screen/H2 B | Body/BodyL N | Calc:[M+2] (14px) | 24px |
| **H3** | 58 | Header/Large Screen/H3 B | Body/BodyL N | M (12px) | 24px |
| **H4** | 48 | Header/Large Screen/H4 B | Body/BodyM N | Calc:[S+2] (10px) | 16px |
| **H5** | 40 | Header/Large Screen/H5 B | Body/BodyM N | S (8px) | 16px |

Заголовок элемента растягивается на всю доступную ширину (Fill).

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Accordion" />` и `<PropsTable name="AccordionItem" />`.

### Quantity

Количество элементов в аккордеоне — от 2 до 10.

### hasBackground

Управляет фоном компонента.

| Значение | Результат |
|---|---|
| True | Включает фон у компонента. |
| False | Выключает фон у компонента. |

### Иконка слева / справа

Управляет положением иконки-индикатора раскрытия относительно заголовка.

| Значение | Результат |
|---|---|
| Иконка слева | Иконка-индикатор отображается слева от заголовка (стрелка). |
| Иконка справа | Иконка-индикатор отображается справа от заголовка (плюс/минус). |

Иконка может быть только в одной из позиций: при выключении иконки слева включается иконка справа, и наоборот.

### Opened (у элемента)

Управляет раскрытием конкретного элемента.

| Значение | Результат |
|---|---|
| True | Открывает связанный контент. |
| False | Закрывает связанный контент. |

## Состояния

| Состояние | Описание |
|---|---|
| **Закрыто** | Виден только заголовок (Title). Иконка-индикатор — стрелка вниз / плюс. |
| **Открыто** | Под заголовком показан связанный контент. Иконка-индикатор — стрелка вверх / минус. |

## Механика и взаимодействия

Дизайн-суть аккордеона — показать или скрыть связанный контент по нажатию на заголовок.

- Нажатие на заголовок переключает элемент между состояниями «открыто» и «закрыто».
- Иконка-индикатор отражает текущее состояние: стрелка вниз / плюс — контент скрыт; стрелка вверх / минус — контент показан.
- Элементы можно раскрывать независимо друг от друга или ограничить раскрытие одним активным элементом за раз.

Детали реализации (анимация раскрытия, управление активными элементами, контролируемый режим) — в Storybook.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Размер (XS / S / M / L) | `size` | xs / s / m / l | Прямое соответствие размерному семейству Accordion XS-L. |
| Размер (H2 / H3 / H4 / H5) | `size` | h2 / h3 / h4 / h5 | Прямое соответствие заголовочному семейству Accordion H2-H5. |
| Заголовок (Title) | `title` | строка | Текстовый лейбл элемента. Задаётся у Accordion Item. |
| Связанный контент (Description) | дочерний контент | ReactNode | Текст/контент внутри Accordion Item. |
| Opened (у элемента) | `opened` | boolean | Открывает/закрывает связанный контент элемента. |

> Иконку слева/справа, фон (hasBackground) и количество элементов (Quantity) уточните в Storybook или в чате поддержки ДС — соответствие этих свойств кодовым пропам подтверждается там.

## FAQ

### Для дизайнеров

**Q: Из чего собирается аккордеон?**
A: Из элементов Accordion Item — каждый состоит из заголовка (Title) и связанного контента, который раскрывается по нажатию. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Чем отличаются типы Accordion XS-L и Accordion H2-H5?**
A: Accordion XS-L — размерное семейство (XS, S, M, L) для обычных списков; Accordion H2-H5 — заголовочное семейство (H2, H3, H4, H5) с крупными заголовками для разделов. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Какие размеры есть у аккордеона?**
A: В семействе XS-L — четыре размера (L 56px, M 48px, S 40px, XS 32px по высоте заголовка); в семействе H2-H5 — четыре размера (H2 68px, H3 58px, H4 48px, H5 40px). Каждый со своим шрифтом заголовка, шрифтом контента, скруглением углов и размером иконки. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Как сделать аккордеон без фона?**
A: Выключить свойство hasBackground (False) — фон компонента отключается. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Как переместить иконку-индикатор с левой стороны на правую?**
A: Управлять положением иконки: при включённой иконке слева отображается стрелка слева от заголовка; при включённой иконке справа — плюс/минус справа. Одновременно иконка только в одной позиции. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Как задать количество элементов в аккордеоне?**
A: Через свойство Quantity — от 2 до 10 элементов. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Accordion Doc Block 1}}.

**Q: Как показать элемент сразу раскрытым?**
A: У элемента включить свойство Opened (True) — связанный контент будет показан. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Accordion Doc Block 1}}.

### Для разработчиков

**Q: Как задать размер аккордеона?**
A: Через проп `size`: для семейства XS-L — `xs` / `s` / `m` / `l`; для семейства H2-H5 — `h2` / `h3` / `h4` / `h5`. Примеры кода — в Storybook: {{Storybook URL Accordion}}.

**Q: Как задать заголовок и контент элемента?**
A: Заголовок — через проп `title` у элемента; связанный контент — дочерним содержимым элемента. Примеры кода — в Storybook: {{Storybook URL Accordion}}.

**Q: Как открыть элемент по умолчанию?**
A: Передать у элемента проп `opened` (boolean) — он открывает связанный контент. Примеры кода — в Storybook: {{Storybook URL Accordion}}.

**Q: Как сделать так, чтобы был раскрыт только один элемент за раз?**
A: Уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL Accordion}}.

**Q: Как управлять раскрытием элемента из состояния приложения?**
A: Уточните в Storybook или в чате поддержки ДС. Примеры кода — в Storybook: {{Storybook URL Accordion}}.

**Q: Как отключить фон у аккордеона?**
A: Уточните в Storybook или в чате поддержки ДС — соответствие свойства hasBackground кодовому пропу подтверждается там. Примеры кода — в Storybook: {{Storybook URL Accordion}}.
