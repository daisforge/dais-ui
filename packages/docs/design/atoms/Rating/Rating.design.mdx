# Rating

Компонент для отображения средней оценки в виде числового значения и иконок-звёзд. Работает только на отображение оценки, без возможности взаимодействия. Чтобы дать пользователю возможность ввести собственную оценку, используйте компонент RatingInput.

Визуал: {{Pixso URL Rating Doc Block 1}}

---

## Анатомия

1. **Value** — числовое значение оценки (например, 4.9). Можно скрыть.
2. **Stars** — графическое отображение оценки в виде иконок-звёзд. Можно скрыть.
3. **HelpText** — вспомогательный текст под значением и звёздами (например, количество оценок). Можно скрыть.

## Размеры и отступы

Размер задаёт шрифт числового значения (Value), шрифт вспомогательного текста (HelpText) и размер иконки-звезды. Размер иконки зависит от количества звёзд (одна звезда крупнее, чем шкала из нескольких) и от ширины экрана (Large / Medium / Small Screen).

| Размер | Шрифт Value | Шрифт HelpText | Размер иконки (5–10 звёзд) | Размер иконки (1 звезда) |
|---|---|---|---|---|
| **DisplayL** | Display/DisplayL B | Header/H3 N | 64 / 48 / 36 | 120 / 112 / 88 |
| **DisplayM** | Display/DisplayM B | Body/BodyL N | 48 / 36 / 28 | 84 / 72 / 64 |
| **DisplayS** | Display/DisplayS B | Body/BodyL N | 32 / 24 / 20 | 64 / 56 / 44 |
| **H1** | Header/H1 B | Body/BodyM N | 48 / 48 / 36 | — |
| **H2** | Header/H2 B | Body/BodyS N | 32 / 28 / 24 | — |
| **H3** | Header/H3 B | Body/BodyXS N | 28 / 24 / 20 | — |
| **H4** | Header/H4 B | Body/BodyXS N | 24 / 20 / 20 | — |
| **H5** | Header/H5 B | Body/BodyXS N | 20 / 16 / 16 | — |
| **L** | Body/BodyL B | Body/BodyXS N | 20 | — |
| **M** | Body/BodyM B | Body/BodyXS N | 20 | — |
| **S** | Body/BodyS B | Body/BodyXS N | 16 | — |
| **XS** | Body/BodyXS B | Body/BodyXXS N | 12 | — |
| **XXS** | Body/BodyXXS B | Body/BodyXXS N | 12 | — |

Размер иконки указан в формате **Large / Medium / Small Screen** (по ширине экрана) в пикселях. Для размеров H1–XXS отдельной разметки для одной звезды нет — размер иконки одинаков при 1–10 звёздах. Подробные значения и масштабы (Scale Icon) — в Pixso-документации компонента.

## Настройки (Props)

### View

Цветовое оформление компонента.

| View | Назначение |
|---|---|
| **Default** | Звёзды и число одного цвета. |
| **Accent** | Звёзды акцентного жёлтого цвета. |

### hasValue

Отвечает за отображение числового значения рейтинга.

| Значение | Результат |
|---|---|
| **True** | Числовое значение рейтинга показывается. |
| **False** | Числовое значение рейтинга скрыто. |

### ValuePlacement

Расположение числового значения относительно звёзд.

| ValuePlacement | Результат |
|---|---|
| **Before** | Числовое значение слева от звёзд. |
| **After** | Числовое значение справа от звёзд. |

### StarQuantity

Количество звёзд в шкале.

| StarQuantity | Результат |
|---|---|
| **1 (Icon)** | Отображается только одна звезда. В этом варианте это просто иконка без поддержки отображения значения рейтинга. |
| **5** | Шкала из пяти звёзд. |
| **10** | Шкала из десяти звёзд. |

### Score

Степень заполнения шкалы, задаёт уровень оценки.

| Score | Результат |
|---|---|
| **0%** | Шкала не заполнена. |
| **25%** | Шкала заполнена на четверть. |
| **50%** | Шкала заполнена наполовину. |
| **75%** | Шкала заполнена на три четверти. |
| **100%** | Шкала заполнена полностью. |

### hasStars

Отвечает за графическое отображение рейтинга в виде звёзд.

| Значение | Результат |
|---|---|
| **True** | Звёзды показываются. |
| **False** | Звёзды скрыты. |

### hasHelperText

Отвечает за отображение вспомогательного текста (например, количества оценок).

| Значение | Результат |
|---|---|
| **True** | Вспомогательный текст показывается. |
| **False** | Вспомогательный текст скрыт. |

## FAQ

### Для дизайнеров

**Q: Можно ли с помощью Rating дать пользователю поставить оценку?**
A: Нет, Rating работает только на отображение средней оценки. Для ввода оценки пользователем используйте компонент RatingInput.

**Q: Какие размеры есть у компонента?**
A: Тринадцать: DisplayL, DisplayM, DisplayS, H1, H2, H3, H4, H5, L, M, S, XS, XXS. Каждый размер задаёт шрифт числового значения, шрифт вспомогательного текста и размер иконки-звезды. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Rating Doc Block 2}}.

**Q: Почему размер иконки разный для одной звезды и для шкалы из нескольких?**
A: При одной звезде (StarQuantity = 1) иконка крупнее, потому что это самостоятельный графический акцент, а не шкала. Размеры для одной звезды заданы только для Display-размеров. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Rating Doc Block 2}}.

**Q: Как сделать звёзды жёлтыми?**
A: Выбрать View → Accent — звёзды станут акцентного жёлтого цвета. По умолчанию (Default) звёзды и число одного цвета. Подробнее — в Pixso-документации компонента, блок «View»: {{Pixso URL Rating Doc Block 1}}.

**Q: Можно ли показать только звёзды без числа или только число без звёзд?**
A: Да. За число отвечает свойство hasValue, за звёзды — hasStars. Их можно включать и выключать независимо. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Rating Doc Block 1}}.

**Q: Как расположить число справа от звёзд?**
A: Выбрать ValuePlacement → After. Значение Before ставит число слева от звёзд. Подробнее — в Pixso-документации компонента, блок «ValuePlacement»: {{Pixso URL Rating Doc Block 1}}.

**Q: Что показывать во вспомогательном тексте (HelpText)?**
A: Например, количество оценок. Отображение HelpText включается свойством hasHelperText. Подробнее — в Pixso-документации компонента, блок «hasHelperText»: {{Pixso URL Rating Doc Block 1}}.

**Q: Сколько звёзд можно показать в шкале?**
A: Одну (вариант 1 (Icon) — просто иконка без поддержки значения), пять или десять — задаётся свойством StarQuantity. Степень заполнения шкалы задаётся свойством Score (0 / 25 / 50 / 75 / 100%). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Rating Doc Block 1}}.
