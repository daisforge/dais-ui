# Combobox

Поле ввода, которое позволяет выбирать значения из выпадающего списка или вводить собственные значения. Пользователь может выбрать готовый вариант из списка, ввести своё значение или добавить новое значение в список.

Combobox состоит из поля ввода (TextField) и выпадающего списка (DropDown).

Визуал: {{Pixso URL Combobox Doc Block 1}}

---

## Анатомия

Combobox собирается из двух основных частей.

1. **TextField (поле ввода)** — триггер компонента. Принимает ввод пользователя и открывает выпадающий список. Поддерживает Label, Placeholder, вспомогательный текст и статусы, как у обычного текстового поля.
2. **DropDown (выпадающий список)** — список значений, который раскрывается под полем ввода. Выведен в абсолют и не влияет на размер компонента: его ширина задаётся триггером, а высота — размером и количеством вложенных элементов.

Внутри DropDown располагаются вспомогательные элементы, из которых он собирается:

| Элемент | Назначение |
|---|---|
| **Item Select** | Айтем выпадающего списка для обычного выбора. Внутри — настраиваемая ячейка (Cell). |
| **Item CheckBox** | Айтем выпадающего списка с чекбоксом — используется для множественного выбора. Внутри — настраиваемая ячейка (Cell). |
| **EmptyState** | Пустое состояние списка («Ничего не нашлось»), опционально с кнопкой. |
| **LazyLoading** | Элемент подзагрузки списка в DropDown: индикатор загрузки или кнопка обновления. |

## Типы

### Одиночный и множественный выбор

| Тип | Описание | Визуал |
|---|---|---|
| **Combobox Single** | Одиночный выбор — выбирается одно значение из списка. | {{Pixso URL Combobox Doc Block 7}} |
| **Combobox Multiple** | Множественный выбор — можно выбрать несколько значений из списка, в списке используются айтемы с чекбоксами. | {{Pixso URL Combobox Doc Block 8}} |

В множественном выборе выбранные значения отображаются в поле одним из трёх способов:

- каждое значение в отдельном чипе (со скроллом внутри поля);
- один чип с подписью «Выбрано N» (по наведению — тултип с полным списком);
- чипы с крестиком для удаления или без него.

> Механика отображения выбранных значений в тултипе планируется к добавлению в Q4.

### Combobox Single XS-S и Combobox Multiple XS-S

Отдельный тип, где триггером выступает Button, мимикрирующая под TextField. Такой тип используется, когда нужно поведение раскрывающегося списка (Select) и важно сохранить консистентность в формах, где рядом с компонентом могут находиться обычные текстовые поля.

## Размеры и отступы

Размер компонента равен размеру триггера. DropDown выведен в абсолют и не влияет на размер компонента.

### Combobox и DropDown

| Размер | Высота | Шрифт айтема | Corner Radius айтема |
|---|---|---|---|
| **S** | 40 | Body/BodyS N | S (8px) |
| **XS** | 32 | Body/BodyXS N | XS (6px) |

### Сжатый список (Tight)

Сжатый вариант списка отображает айтемы меньшей высоты.

| Размер | Высота айтема | Шрифт айтема | Corner Radius айтема |
|---|---|---|---|
| **S** | 32 | Body/BodyS N | S (8px) |
| **XS** | 24 | Body/BodyXS N | XS (6px) |

### EmptyState и LazyLoading

| Размер | Шрифт лейбла | Шрифт текста |
|---|---|---|
| **S (40)** | Body/BodyS B | Body/BodyS N |
| **XS (32)** | Body/BodyXS B | Body/BodyXS N |

Размер иконки в элементе LazyLoading: 24px в обычном списке и 16px в сжатом (Tight).

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Combobox" />`.

### Выпадающий список (DropDown)

| Свойство | Значения | Назначение |
|---|---|---|
| **View** | Normal / Tight | Normal — обычный список с айтемами стандартной высоты; Tight — сжатый список с айтемами меньшей высоты. |
| **ScrollBar** | вкл. / выкл. | Включает или выключает полосу прокрутки списка. |
| **LazyLoading** | вкл. / выкл. | Включает или выключает элемент подзагрузки списка. |

### Айтем списка (Item Select и Item CheckBox)

| Свойство | Назначение |
|---|---|
| **Selected** | Состояние выбранного айтема. |
| **Focused** | Состояние фокуса на айтеме. |
| **Disabled** | Айтем недоступен для выбора. |
| **Disclosure** | Показывает справа стрелку раскрытия вложенного выпадающего списка. |
| **Divider** | Показывает разделитель между айтемами в списке. |

### Пустое состояние (EmptyState)

Свойство **Button** включает или выключает кнопку в пустом состоянии. Текст пустого состояния по умолчанию — «Ничего не нашлось».

### Подзагрузка списка (LazyLoading)

| Свойство (View) | Назначение |
|---|---|
| **Loading** | Вид подзагрузки списка (индикатор «Загрузка»). |
| **Reload** | Кнопка «Обновить» для перезагрузки списка. |

### Состояние компонента (Single XS-S / Multiple XS-S)

| Свойство | Значения | Назначение |
|---|---|---|
| **Value** | Empty / Filled | Empty — ни один элемент не выбран, триггер не заполнен; Filled — один или несколько элементов выбраны, триггер заполнен. |
| **Opened** | вкл. / выкл. | Открывает или закрывает DropDown. |
| **EmptyState** | вкл. / выкл. | Показывает в DropDown пустое состояние вместо списка. |

## Состояния

Поле ввода (триггер) наследует статусы обычного текстового поля. Айтемы списка имеют состояния:

- **Default** — обычный айтем списка.
- **Focused** — айтем в фокусе (например, при навигации с клавиатуры).
- **Selected** — выбранный айтем.
- **Disabled** — недоступный для выбора айтем; взаимодействие с ним невозможно.

У компонента целиком (для типов Single XS-S / Multiple XS-S) состояние поля описывается значением Value (Empty / Filled), а раскрытие списка — свойством Opened.

## Механика и взаимодействия

### Ввод значения и выбор из списка

- При клике в поле раскрывается весь список значений.
- При вводе текста список фильтруется — остаются варианты, соответствующие написанному. Например, при вводе «Севе» в списке останется «Северная Америка».
- Можно выбрать готовый вариант из списка или ввести и добавить собственное значение, которого нет в списке.
- В множественном выборе выбранные значения отображаются чипами либо свёрнутым счётчиком «Выбрано N» (подробности — в разделе «Типы»).

### Ленивая загрузка (LazyLoading)

Когда список значений подгружается порциями, в DropDown отображается элемент подзагрузки — индикатор «Загрузка» во время загрузки или кнопка «Обновить» для повторной загрузки списка.

### Пустое состояние (EmptyState)

Если по введённому запросу ничего не найдено, вместо списка в DropDown показывается пустое состояние с текстом «Ничего не нашлось». Опционально в пустом состоянии может отображаться кнопка (например, для действия по добавлению значения).

> Детали реализации (фильтрация, обработчики событий, подгрузка данных) — в Storybook.

## Когда использовать Combobox, когда Select или Autocomplete

| Сценарий | Что использовать |
|---|---|
| Множественный выбор значений | **Combobox** |
| Одиночный выбор, когда нужно дать пользователю посмотреть список до ввода | **Combobox** |
| Поиск и добавление нового значения в список | **Combobox** |
| Значений в справочнике больше 25 (нужен поиск по значениям) | **Combobox** |
| Выбор одного значения из 2–25 заранее известных вариантов (формы, фильтры, предустановки) | **Select** |
| Выбор из справочника без поиска и список меньше 25 | **Select** |
| Поиск и выбор одного значения, когда пользователь знает примерный список (Город, Область) | **Autocomplete** |

Combobox применяют для выбора значения из справочника и для добавления собственного значения, которого в справочнике нет.

## Маппинг: дизайн → код

Тип выбора (одиночный/множественный) в коде задаётся не отдельным дизайн-типом, а формой данных и пропом `multiple`.

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Список значений (айтемы) | `items` | массив объектов `{ value, label, ... }` | Обязательный проп. Поддерживает вложенные `items` для иерархии. |
| Тип: Single / Multiple | `multiple` | boolean | Множественный выбор. При нём `value` — массив, при одиночном — строка. |
| Выбранное значение | `value`, `onChange` | строка / массив строк | Тип зависит от режима выбора. |
| Айтем недоступен (Disabled) | `disabled` (внутри `items`) | boolean | Задаётся на конкретном айтеме. |
| Слот контента слева у айтема | `contentLeft` | ReactNode | Внутри объекта айтема. |
| Слот контента справа у айтема | `contentRight` | ReactNode | Внутри объекта айтема. |
| Disclosure (вложенный список) | вложенные `items` | массив | Вложенный массив `items` раскрывает дочерний список. |
| Пустое состояние (EmptyState) | `emptyStateDescription` | строка | Текст пустого состояния. |
| Label / Placeholder / вспомогательный текст | `label`, `placeholder`, `helperText` | строка | Параметры поля ввода. |

## FAQ

### Для дизайнеров

**Q: Из чего состоит Combobox?**
A: Из поля ввода (TextField) — это триггер компонента — и выпадающего списка (DropDown). DropDown собирается из айтемов (Item Select / Item CheckBox), а также может показывать элементы пустого состояния (EmptyState) и подзагрузки (LazyLoading). Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Какие размеры есть у Combobox?**
A: Два — S (высота 40) и XS (высота 32). Для сжатого списка (Tight) высота айтемов меньше: S — 32, XS — 24. Каждый размер со своим шрифтом айтема и скруглением углов. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Чем одиночный выбор отличается от множественного?**
A: В одиночном выбирается одно значение, в множественном — несколько; в множественном айтемы списка снабжены чекбоксами, а выбранные значения показываются чипами или свёрнутым счётчиком «Выбрано N». Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Как показываются выбранные значения в множественном выборе?**
A: Тремя способами: каждое значение в отдельном чипе со скроллом внутри поля, один чип со счётчиком «Выбрано N» с тултипом по наведению, или чипы с крестиком для удаления / без него. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Что происходит при вводе текста в поле?**
A: При клике в поле раскрывается весь список, а при вводе текста список фильтруется — остаются варианты, соответствующие написанному (например, «Севе» → «Северная Америка»). Также можно ввести и добавить собственное значение. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Что показать, если список ничего не нашёл?**
A: Использовать элемент EmptyState с текстом «Ничего не нашлось»; опционально в нём можно показать кнопку. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Combobox Doc Block 1}}.

**Q: Когда выбрать Combobox, а когда Select или Autocomplete?**
A: Combobox — для множественного выбора, для добавления нового значения, а также когда значений больше 25 и нужен поиск. Select — для одного значения из 2–25 заранее известных вариантов без поиска. Autocomplete — для одиночного выбора с поиском, когда пользователь знает примерный список. Подробнее — в Pixso-документации компонента, блок «Когда использовать»: {{Pixso URL Combobox Doc Block 1}}.

### Для разработчиков

**Q: Как задать одиночный или множественный выбор?**
A: Тип выбора зависит от формы данных и пропа `multiple`. В одиночном `value` — строка, в множественном — массив строк (а проп `multiple` включён). Примеры кода — в Storybook: {{Storybook URL Combobox}}.

**Q: Какой проп обязателен?**
A: Обязателен только `items` — массив объектов `{ value, label }`. Внутри айтема может быть вложенный массив `items` для иерархического списка. Примеры кода — в Storybook: {{Storybook URL Combobox}}.

**Q: Как сделать айтем недоступным для выбора?**
A: Указать `disabled: true` у конкретного объекта в массиве `items`. Взаимодействие с таким айтемом изнутри компонента невозможно. Примеры кода — в Storybook: {{Storybook URL Combobox}}.

**Q: Как задать текст пустого состояния?**
A: Через проп `emptyStateDescription` — это строка, которая показывается, когда подходящих вариантов нет. Примеры кода — в Storybook: {{Storybook URL Combobox}}.

**Q: Как добавить контент слева и справа у айтема?**
A: Через слоты `contentLeft` и `contentRight` (ReactNode) внутри объекта айтема в массиве `items`. Примеры кода — в Storybook: {{Storybook URL Combobox}}.

**Q: Как задать Label, Placeholder и вспомогательный текст?**
A: Пропами `label`, `placeholder` и `helperText` — это параметры поля ввода (триггера). Примеры кода — в Storybook: {{Storybook URL Combobox}}.
