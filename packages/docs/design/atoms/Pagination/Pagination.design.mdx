# Pagination

Способ отображения большого количества однородной информации, когда контент разбивается на страницы.

Визуал: {{Pixso URL Pagination Doc Block 1}}

---

## Анатомия

1. **PageButton** — кнопка с номером страницы. Visual: {{Pixso URL Pagination Doc Block 2}}
2. **PageRange** — блок отображения диапазона страниц с элементами перехода между ними. Состоит из PageButton и при необходимости сокращает длинные диапазоны многоточием. Visual: {{Pixso URL Pagination Doc Block 3}}
3. **QuickJumper** — быстрый переход к конкретной странице по введённому номеру (опционально). Visual: {{Pixso URL Pagination Doc Block 4}}
4. **PageSizer** — выбор количества отображаемых элементов на одной странице (опционально). Visual: {{Pixso URL Pagination Doc Block 5}}
5. **Доп. текст** — вспомогательный текст рядом с пагинацией (опционально).

Общий размер пагинации складывается из размеров вложенных элементов и занимает только одну строку (в компактном режиме — две строки).

---

## Типы

Тип отвечает за компоновку вложенных элементов.

| Тип | Описание | Визуал |
|---|---|---|
| **Default** | Вложенные элементы располагаются в одну строку. Ширина пагинации может задаваться фиксированным значением или растягиваться на ширину контейнера. | {{Pixso URL Pagination Doc Block 1}} |
| **Compact** | Вложенные элементы располагаются на двух строках. Ширина пагинации зависит от ширины PageRange. | {{Pixso URL Pagination Doc Block 1}} |

---

## Размеры и отступы

Общий размер пагинации складывается из размеров вложенных элементов. Ниже — параметры для каждого размера.

| Размер | Высота PageButton | Corner Radius PageButton | Шрифт номера | Ширина QuickJumper (TextField) | Ширина PageSizer (SelectButton) | Отступ |
|---|---|---|---|---|---|---|
| **S** | 40 | Calc:[M-2] (10px) | Body/BodyS B | 56px | 84px | 12px |
| **XS** | 32 | S (8px) | Body/BodyXS B | 40px | 64px | 12px |

- Ширина QuickJumper складывается из фиксированной ширины TextField, отступа и длины текста (Hug).
- Ширина PageSizer складывается из фиксированной ширины SelectButton, отступа и длины текста (Hug).
- Шрифт подписей QuickJumper и PageSizer для размера S — Body/BodyS B, для XS — Body/BodyXS B.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Pagination" />`.

### Вид (для PageButton)

Заливка кнопки страницы.

| Вид | Назначение |
|---|---|
| Primary | Кнопка с залитым фоном. |
| Secondary | Кнопка с полупрозрачным фоном. |
| Clear | Кнопка с прозрачным фоном. |

### Форма (Shape)

Свойство Shape отвечает за форму кнопки страницы.

| Shape | Результат |
|---|---|
| Default | Квадратная кнопка с номером страницы (углы по Corner Radius из таблицы размеров). |
| Pilled | Круглая кнопка с номером страницы. |

### Ширина кнопки (Strech)

| Strech | Результат |
|---|---|
| True | Ширина кнопки всегда фиксированная, вне зависимости от длины номера страницы. |
| False | Ширина кнопки подстраивается под длину номера страницы. |

### Секции (QuantitySections, для PageRange)

Деление диапазона страниц на секции.

| QuantitySections | Результат |
|---|---|
| 1 | Общее число страниц не делится на секции и не сокращается (до 5 видимых страниц). |
| 2 | Страницы разбиваются на 2 секции (до 10 видимых страниц). |
| 3 | Страницы разбиваются на 3 секции (до 15 видимых страниц). |

Свойство **CurrentSection** (First / Second / Third) указывает, в какой секции PageRange находится текущая страница.

### Отображение элементов PageRange

| Свойство | Результат |
|---|---|
| hasSections | Отображение пронумерованных страниц. |
| hasShorter | Отображение сокращения страниц (многоточия). |
| hasPrevious | Отображение кнопок перехода на предыдущие страницы. |
| hasNext | Отображение кнопок перехода на следующие страницы. |

### Дополнительные блоки

| Свойство | Результат |
|---|---|
| hasPageSizer | Включает отображение PageSizer (выбор количества элементов на странице). |
| hasQuickJumper | Включает отображение QuickJumper (быстрый переход на страницу). |
| hasHelperText | Включает отображение вспомогательного текста. |

### Выравнивание вспомогательного текста (HelperTextAlign)

Доступно только при hasHelperText = true.

| HelperTextAlign | Результат |
|---|---|
| Start | Текст выровнен по левому краю внутри контейнера. |
| Center | Текст выровнен по центру внутри контейнера. |
| End | Текст выровнен по правому краю внутри контейнера. |

## Состояния

Состояния задаются на уровне PageButton.

| State | Описание |
|---|---|
| **Default** | Кнопка для перехода на страницу. Поддерживает Hover, Active, Focus. |
| **Disabled** | Кнопка, недоступная для перехода. |
| **Selected** | Текущая страница (может быть только одна). |

---

## Механика и взаимодействия

Дизайн-суть взаимодействий пагинации:

- **Переключение страниц.** Нажатие на PageButton переводит на соответствующую страницу; текущая страница отмечается состоянием Selected. Кнопки перехода на предыдущие и следующие страницы (hasPrevious / hasNext) позволяют двигаться по диапазону.
- **Сокращение диапазона.** При большом числе страниц PageRange делится на секции (QuantitySections) и сокращает длинный список многоточием (hasShorter). CurrentSection показывает, в какой части диапазона находится текущая страница.
- **Выбор размера страницы.** PageSizer позволяет выбрать количество отображаемых элементов на одной странице.
- **Быстрый переход.** QuickJumper позволяет ввести номер страницы и сразу перейти к ней.

Детали реализации — в Storybook.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Тип: Default / Compact | `type` | default / compact | Default = страницы с номерами в одну строку; Compact = две строки, показывает текущую страницу. |
| Вид PageButton: Primary / Secondary / Clear | `view` | default / secondary / clear | Primary в дизайне = `default` в коде. |
| Вид PageButton (для текущей страницы) | `viewCurrentPage` | default / secondary / clear | Отдельный вид для кнопки активной страницы. |
| Shape (Default / Pilled) | `pilled` | boolean | Pilled — круглая форма кнопки. |
| Size | `size` | s / xs | Прямое соответствие размерам S / XS. |
| hasPageSizer | `hasPerPage` | boolean | Включает PageSizer (выбор количества элементов на странице). |
| PageSizer (начальное значение) | `perPage` | число | Количество элементов на странице. |
| hasQuickJumper | `hasQuickJump` | boolean | Включает QuickJumper (быстрый переход). |
| Доп. текст / hasHelperText | `helperText`, `singleLine` | строка / boolean | `helperText` — текст; `singleLine` ограничивает одной строкой с многоточием. |
| Количество видимых PageButton | `slots` | число | Максимум кнопок страниц, отображаемых одновременно. |
| — | `count` | число | Общее количество элементов (или страниц, если `hasPerPage` не указан). |
| — | `value`, `onChange` | число / колбэк | Контролируемый режим: текущая страница и обработчик смены. |
| — | `leftContent`, `rightContent` | ReactNode | Произвольный контент по бокам блока страниц (например, навигационные кнопки). |

## FAQ

### Для дизайнеров

**Q: Из каких частей состоит пагинация?**
A: PageButton (кнопки с номерами страниц), PageRange (диапазон страниц с переходами), QuickJumper (быстрый переход по номеру) и PageSizer (выбор количества элементов на странице), плюс опциональный вспомогательный текст. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Какие размеры есть у пагинации?**
A: Два: S (высота кнопки 40px, шрифт номера Body/BodyS B) и XS (высота 32px, шрифт Body/BodyXS B). Каждый со своим Corner Radius и шириной QuickJumper / PageSizer. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как сделать компактную пагинацию?**
A: Выбрать тип Compact — вложенные элементы располагаются на двух строках, ширина зависит от ширины PageRange. Тип Default размещает всё в одну строку. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как сделать круглые кнопки страниц?**
A: Выбрать Shape → Pilled — кнопки PageButton станут круглыми. По умолчанию (Default) кнопки квадратные со скруглением по Corner Radius из таблицы размеров. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как добавить выбор количества элементов на странице?**
A: Включить hasPageSizer — появится PageSizer с подписью «Показывать по». Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как добавить быстрый переход на нужную страницу?**
A: Включить hasQuickJumper — появится QuickJumper с подписью «Перейти к» и полем ввода номера. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как сократить длинный диапазон страниц?**
A: Задать QuantitySections (1 / 2 / 3) для деления на секции и включить hasShorter — длинный список свернётся многоточием. CurrentSection показывает, в какой секции находится текущая страница. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Pagination Doc Block 1}}.

**Q: Как добавить и выровнять вспомогательный текст?**
A: Включить hasHelperText, затем задать HelperTextAlign (Start / Center / End). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Pagination Doc Block 1}}.

### Для разработчиков

**Q: Как задать размер пагинации?**
A: Через проп `size` со значениями `s` / `xs` — прямое соответствие размерам S / XS. Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как задать вид кнопок и вид активной страницы?**
A: Вид кнопок — проп `view` (`default` / `secondary` / `clear`); отдельный вид для текущей страницы — `viewCurrentPage` с теми же значениями. Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как переключить компактный режим?**
A: Через проп `type` со значениями `default` / `compact`: `compact` показывает только текущую страницу. Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как включить круглую форму кнопок?**
A: Передать проп `pilled` (boolean). Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как включить выбор количества элементов и задать начальное значение?**
A: Проп `hasPerPage` (boolean) включает выпадающий список; начальное значение — проп `perPage` (число). Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как включить поле быстрого перехода?**
A: Передать проп `hasQuickJump` (boolean). Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как добавить вспомогательный текст и ограничить его одной строкой?**
A: Через проп `helperText` (строка); проп `singleLine` ограничивает текст одной строкой с многоточием. Примеры кода — в Storybook: {{Storybook URL Pagination}}.

**Q: Как использовать контролируемый режим и навигационные кнопки?**
A: Контролируемый режим — через `value` (текущая страница) и `onChange` (вызывается с новым номером страницы и текущим `perPage`); `slots` задаёт число видимых кнопок, `count` — общее количество элементов. Навигационные кнопки по бокам — через `leftContent` / `rightContent` (ReactNode). Примеры кода — в Storybook: {{Storybook URL Pagination}}.
