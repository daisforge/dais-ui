# NumberInput

Поле ввода числовых значений через кнопки «+» и «−» или ручной ввод. Позволяет задать минимальное и максимальное значение, шаг изменения и текущее число.

Визуал: {{Pixso URL NumberInput Doc Block 1}}

---

## Анатомия

NumberInput собран из готовых компонентов дизайн-системы — поля ввода и двух иконок-кнопок:

1. **Поле ввода (TextField)** — показывает текущее значение. Подстраивается под заданную ширину компонента.
2. **Кнопка «−»** — уменьшает значение на шаг.
3. **Кнопка «+»** — увеличивает значение на шаг.
4. **TextBefore** — дополнительный текст слева от числа, например единица измерения (опционально).
5. **TextAfter** — дополнительный текст справа от числа, например единица измерения (опционально).

---

## Типы

Свойство Type задаёт форму компонента.

| Тип | Описание |
|---|---|
| **Default** | Дефолтный NumberInput с раздельными кнопками и полем ввода. |
| **Segmented** | NumberInput с изменёнными скруглениями для создания единой формы. |
| **Solid** | NumberInput, мимикрирующий под кнопку. Поле ввода и кнопки сведены в единый блок. |

В типах Default и Segmented кнопки — отдельные иконки-кнопки 40 S, в типе Solid — встроенные иконки-кнопки (EmbedIconButton) 40 S.

---

## Размеры и отступы

| Размер | Высота | Минимальная ширина |
|---|---|---|
| **S** | 40 | 140px |

Компонент состоит из поля ввода и иконок-кнопок 40 S. Ширина задаётся вручную: поле для ввода подстраивается под размер, а кнопки в размере не меняются. Минимальная ширина компонента — 140px.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="NumberInput" />`.

### hasTitle (вид кнопок)

Цветовая тема кнопок «+» и «−».

| Вид | Назначение |
|---|---|
| Default | NumberInput с дефолтными кнопками. |
| Secondary | NumberInput с второстепенными кнопками. |
| Accent | NumberInput с акцентными кнопками. |
| Clear | NumberInput с прозрачными кнопками. |

### Скруглённость (Checked)

Свойство отвечает за скругление углов компонента.

| Значение | Результат |
|---|---|
| Cornered | NumberInput квадратной формы. |
| Pilled | NumberInput круглой формы. |

### View

Заливка поля ввода. Доступно, если Type = Default или Segmented.

| View | Результат |
|---|---|
| Fill | Поле ввода с залитым фоном. |
| Clear | Поле ввода с прозрачным фоном. |

### TextBefore / TextAfter

Дополнительный текст до и после числа. Может использоваться для обозначения единицы измерения. Включается отдельно для каждой стороны.

## Состояния

| Состояние | Описание |
|---|---|
| **Focused** | По умолчанию число нельзя вводить вручную — только кнопками. Включение фокусного состояния у поля ввода разрешает ручной ввод значения. |
| **Loading** | По центру компонента появляется индикатор загрузки, кнопки переходят в неактивное состояние. |

## Механика и взаимодействия

NumberInput управляет числом двумя способами:

- **Кнопки «+» и «−»** изменяют значение на заданный шаг при каждом нажатии.
- **Ручной ввод** — по умолчанию выключен; при включении фокусного состояния число можно ввести напрямую в поле.
- **Минимальное и максимальное значение** ограничивают допустимый диапазон ввода.
- **Шаг изменения** задаёт величину, на которую меняется значение при нажатии на кнопку.

Детали поведения (точность дробных значений, поведение кнопок на границах диапазона, отображение при пустом значении) — см. Storybook.

## FAQ

### Для дизайнеров

**Q: Как задать диапазон вводимых значений?**
A: Задать минимальное и максимальное значение — NumberInput ограничит ввод этим диапазоном. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как изменить шаг, с которым меняется число?**
A: Задать шаг изменения — значение будет меняться на эту величину при каждом нажатии на кнопку «+» или «−». Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как разрешить вводить число вручную?**
A: По умолчанию число меняется только кнопками. Включить фокусное состояние у поля ввода — и значение можно будет ввести напрямую. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как сделать единую форму или форму кнопки?**
A: Через свойство Type: Segmented — единая форма со сведёнными скруглениями, Solid — компонент мимикрирует под кнопку. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как сделать круглую или квадратную форму?**
A: Через свойство скруглённости: Cornered — квадратная форма, Pilled — круглая. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как добавить единицу измерения рядом с числом?**
A: Включить TextBefore (текст слева) или TextAfter (текст справа) — отдельно для каждой стороны. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL NumberInput Doc Block 1}}.

**Q: Как задать ширину компонента?**
A: Ширина задаётся вручную; поле для ввода подстраивается под размер, а кнопки в размере не меняются. Минимальная ширина — 140px. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL NumberInput Doc Block 1}}.
