# Carousel

Компонент используется для представления контента. Он позволяет отображать несколько элементов, таких как изображения, текст или видео, в одном ограниченном пространстве.

Визуал: {{Pixso URL Carousel Doc Block 1}}

---

## Анатомия

1. **Слой PASTE CONTENT** — слой, на который вставляется подготовленная группа элементов карусели.
2. **Пагинатор** — точки-индикаторы под областью контента, показывающие текущий слайд.
3. **Кнопки управления** — кнопки для перехода к предыдущему и следующему слайду.

Чтобы использовать компонент, сначала нужно создать группу элементов с помощью автолейаута и преобразовать её в локальный компонент. После этого нужно вставить группу на слой PASTE CONTENT. Если локальный компонент состоит из маленьких элементов, то можно заменить элементы управления (пагинатор и кнопки) в соответствии с размерами вашей группы.

## Типы

| Тип | Описание |
|---|---|
| **Carousel для изображений** | При добавлении изображения в Carousel нужно изменить настройки слоёв с hug на fill. |
| **Carousel для локальных компонентов** | Ничего менять в компоненте не надо. |

## Размеры и отступы

Размеры карусели определяются размерами вставленной группы элементов. Если локальный компонент состоит из маленьких элементов, элементы управления (пагинатор и кнопки) можно заменить в соответствии с размерами вашей группы. Точные значения отступов и размеры элементов управления уточните в Pixso или в чате поддержки.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации.

### ContentAlign

Выравнивание встроенного контента внутри области карусели.

| ContentAlign | Назначение |
|---|---|
| Center | Встроенный контент выравнивается по центру. |
| Left | Встроенный контент выравнивается по левому краю. |
| Right | Встроенный контент выравнивается по правому краю. |

### ButtonsPlacement

Расположение кнопок управления относительно области контента.

| ButtonsPlacement | Назначение |
|---|---|
| Inner | Кнопки находятся внутри области контента. |
| Outer | Кнопки находятся за областью контента. |

При встраивании группы элементов в компонент, где кнопки находятся внутри области контента, они не обрезаются. Если же группа элементов вставляется в компонент с кнопками, расположенными снаружи области контента, то контент будет обрезан.

### hasButtons

Включает или выключает отображение кнопок управления.

| hasButtons | Результат |
|---|---|
| True | Включает отображение кнопок. |
| False | Выключает отображение кнопок. |

### hasPaginator

Включает или выключает отображение пагинатора.

| hasPaginator | Результат |
|---|---|
| True | Включает отображение пагинатора. |
| False | Выключает отображение пагинатора. |

## Состояния

Карусель показывает один активный слайд из набора и переключается между слайдами через пагинатор или кнопки управления. Активный слайд отмечается соответствующей точкой в пагинаторе.

---

## Механика и взаимодействия

- **Листание.** Переход между слайдами выполняется кнопками управления (предыдущий/следующий) и нажатием на точки пагинатора.
- **Пагинатор.** Точки-индикаторы показывают текущий слайд и количество слайдов; нажатие на точку переключает на соответствующий слайд.
- **Кнопки управления.** Расположение кнопок (внутри или снаружи области контента) определяет, обрезается ли контент при выходе за границы области.

Детали поведения (зацикливание, автопрокрутка, свайп, виртуализация) — на стороне реализации, см. Storybook.

## FAQ

### Для дизайнеров

**Q: Как собрать карусель из своего контента?**
A: Создайте группу элементов с помощью автолейаута, преобразуйте её в локальный компонент и вставьте на слой PASTE CONTENT. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Carousel Doc Block 1}}.

**Q: Как добавить изображения в карусель?**
A: Используйте тип Carousel для изображений и измените настройки слоёв изображения с hug на fill. Подробнее — в Pixso-документации компонента, блок «Типы»: {{Pixso URL Carousel Doc Block 1}}.

**Q: Как выровнять встроенный контент в карусели?**
A: Через свойство ContentAlign — Center (по центру), Left (по левому краю) или Right (по правому краю). Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Carousel Doc Block 1}}.

**Q: Как расположить кнопки управления внутри или снаружи области контента?**
A: Через свойство ButtonsPlacement — Inner (внутри) или Outer (снаружи). При расположении Inner контент не обрезается, при Outer контент обрезается по границе области. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Carousel Doc Block 1}}.

**Q: Как скрыть кнопки управления или пагинатор?**
A: Выключите hasButtons, чтобы скрыть кнопки, или hasPaginator, чтобы скрыть пагинатор. Подробнее — в Pixso-документации компонента, блок «Настройки (Props)»: {{Pixso URL Carousel Doc Block 1}}.

**Q: Как подогнать элементы управления под маленькую группу элементов?**
A: Если локальный компонент состоит из маленьких элементов, замените элементы управления (пагинатор и кнопки) в соответствии с размерами вашей группы. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Carousel Doc Block 1}}.

### Для разработчиков

**Q: Как задать отступ между слайдами?**
A: Через проп `gap` — он задаёт расстояние между соседними слайдами. Примеры кода — в Storybook: {{Storybook URL Carousel}}.

**Q: Как настроить пагинатор?**
A: Через проп `paginationOptions` — он управляет отображением и поведением пагинатора (в том числе количеством видимых точек и центрированием активной точки). Примеры кода — в Storybook: {{Storybook URL Carousel}}.

**Q: Как включить автоматическое пролистывание?**
A: Через проп `autoPlay`, а интервал задаётся пропом `autoPlayInterval`. Примеры кода — в Storybook: {{Storybook URL Carousel}}.

**Q: Как зациклить карусель?**
A: Через проп `loop` — после последнего слайда идёт первый, и наоборот. Примеры кода — в Storybook: {{Storybook URL Carousel}}.

**Q: Как включить свайп для touch- и pointer-устройств?**
A: Через проп `swipeEnabled`. Примеры кода — в Storybook: {{Storybook URL Carousel}}.

**Q: Как задать стартовый слайд и управлять текущим слайдом?**
A: Стартовый слайд один раз при инициализации задаётся через `defaultIndex`, а для управления слайдом снаружи используйте controlled-режим через `index` и `onChangeIndex`. Примеры кода — в Storybook: {{Storybook URL Carousel}}.
