# Checkbox

Элемент, который позволяет пользователю управлять параметром с двумя состояниями.

Визуал: {{Pixso URL Checkbox Doc Block 1}}

**Общее:**

- Checkbox чаще всего не применяет изменение немедленно — обычно его подтверждают отдельной кнопкой (зависит от сценария: иногда мгновенно, иногда по кнопке). Для гарантированно немедленного включения режима в интерфейсе лучше подходит Switcher.
- Checkbox используется, когда нужно дать пользователю выбрать один, несколько, все или ни одного варианта из ряда предложенных. Если нужно выбрать один вариант из ряда взаимоисключающих — лучше подойдёт Radiobox.
- Для объединения Checkbox в смысловые группы используйте группировку чекбоксов (см. раздел «Группировка чекбоксов»).

---

## Анатомия

1. **Checkbox** — квадратный индикатор выбора (сам чекбокс).
2. **Label** — текстовый лейбл рядом с чекбоксом (опционально).
3. **Description** — текстовое описание под лейблом (опционально).

---

## Размеры и отступы

Между чекбоксом и блоком текста — горизонтальный отступ 8px. По ширине компонент ведёт себя как Hug _(подстраивается под содержимое)_.

| Размер | Шрифт Label | Шрифт Description | Corner Radius | Размер индикатора |
|---|---|---|---|---|
| **L** | Body/BodyL N | Body/BodyM N | XS (6px) | 24px |
| **M** | Body/BodyM N | Body/BodyS N | XS (6px) | 24px |
| **S** | Body/BodyS N | Body/BodyXS N | XXS (4px) | 16px |

### Лейбл и описание

Лейбл и описание — опциональны. Каждый из них показывается, когда задан. Оба могут содержать как обычный текст, так и текст с разметкой (например, со ссылкой).

По умолчанию контент лейбла и описания многострочный; есть однострочный режим.

### Значение (Value)

Состояние выбора чекбокса.

| Значение | Описание |
|---|---|
| Empty | Параметр не выбран. |
| Single | Параметр выбран. |
| Multiple | Частичный выбор — только для заглавного (родительского) чекбокса в группе. |

### Disabled

Свойство Disabled выключает возможность взаимодействия с чекбоксом.

## Состояния

| Состояние | Дизайн |
|---|---|
| Не выбран | Value = Empty |
| Выбран | Value = Single |
| Частичный выбор (заглавный чекбокс группы) | Value = Multiple |
| Недоступен | Disabled = True |

## Группировка чекбоксов

Для объединения чекбоксов в смысловые группы используется группировка двух уровней. В дизайне она оформлена отдельным блоком «Checkbox Group» — это паттерн расположения, **а не отдельный компонент в коде** (в коде это группа экземпляров Checkbox).

Визуал: {{Pixso URL Checkbox Doc Block 2}}

- Группа — список чекбоксов двух уровней. Главный (родительский) чекбокс — общая категория для всей группы, вложенные (дочерние) чекбоксы — независимые друг от друга параметры.
- При нажатии на родительский чекбокс он принимает значение Single, и все дочерние автоматически переходят в выбранное состояние.
- При частичном выборе дочерних родительский принимает значение Multiple (частичный выбор).

### Размеры и отступы группы

Высота группы складывается из суммы высот вложенных чекбоксов с внутренними вертикальными отступами.

| Размер группы | Базовый чекбокс | Parent (bottom padding) | Middle (top/bottom) | Last (top padding) |
|---|---|---|---|---|
| **24 M** | Checkbox M | 6px | 6px | 6px |
| **16 S** | Checkbox S | 5px | 5px | 5px |

### Количество (Quantity)

В дизайне число элементов группы задаётся свойством Quantity (только для построения макета): родительский + 2/3/4/5 дочерних чекбоксов.

## Маппинг: дизайн → код

В таблице — свойства, у которых есть подтверждённый проп в коде. Свойства, присутствующие только в дизайне (размер L/M/S, Disabled, Quantity группы), управляются в коде иначе — точные пропсы см. в Storybook.

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Показ лейбла | `label` | строка / JSX | Лейбл управляется наличием пропа `label`. |
| Показ описания | `description` | строка / JSX | Описание управляется наличием пропа `description`. |
| Value: Empty / Single | `checked`, `defaultChecked` | boolean | Empty = `false`; Single = `true`. `defaultChecked` — неуправляемый режим. |
| Value: Multiple | `indeterminate` | boolean | Заглавный чекбокс группы; приоритетно над `checked`. |
| Однострочный контент | `singleLine` | boolean | По умолчанию `false`. |
| Вид | `view` | accent | Актуально только `accent`, остальное deprecated. |

## FAQ

### Для дизайнеров

**Q: Чем Checkbox отличается от Switcher?**
A: Checkbox чаще всего не применяет изменение немедленно — обычно оно подтверждается отдельной кнопкой. Но это зависит от сценария: иногда изменение применяется мгновенно, иногда — по кнопке. Switcher же, как правило, переключает режим в интерфейсе сразу. Если нужно гарантированно мгновенно включить режим — используйте Switcher.

**Q: Когда использовать Checkbox, а когда Radiobox?**
A: Checkbox — когда нужно выбрать один, несколько, все или ни одного варианта. Если варианты взаимоисключающие и можно выбрать только один — подойдёт Radiobox.

**Q: Какие состояния выбора есть у чекбокса?**
A: Не выбран (Value = Empty), выбран (Value = Single) и частичный выбор (Value = Multiple). Частичный выбор используется только для заглавного (родительского) чекбокса в группе и появляется, когда выбрана часть дочерних. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Checkbox Doc Block 1}}.

**Q: Какие размеры есть у чекбокса?**
A: Три: L, M и S. Отличаются шрифтами лейбла/описания и скруглением индикатора (L и M — Corner Radius XS 6px, S — XXS 4px). Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Checkbox Doc Block 1}}.

**Q: Что показывать рядом с чекбоксом — лейбл и описание?**
A: Лейбл и описание опциональны. Лейбл — текст рядом с чекбоксом, описание — текст под лейблом. По умолчанию контент многострочный, есть однострочный режим. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Checkbox Doc Block 1}}.

**Q: Есть ли отдельный компонент CheckboxGroup?**
A: Нет. В дизайне «Checkbox Group» — это отдельный блок документации для удобства и паттерн расположения, а не отдельный компонент. При нажатии на родительский чекбокс все дочерние переходят в выбранное состояние; при частичном выборе дочерних родительский показывает частичный выбор. Подробнее — в Pixso-документации компонента, блок «Группировка чекбоксов»: {{Pixso URL Checkbox Doc Block 1}}.

**Q: Как показать, что чекбокс недоступен?**
A: Используйте состояние Disabled — оно выключает возможность взаимодействия с чекбоксом. Подробнее — в Pixso-документации компонента, блок «Состояния»: {{Pixso URL Checkbox Doc Block 1}}.

### Для разработчиков

**Q: Как задать состояние выбора Empty / Single?**
A: Через `checked` (или `defaultChecked` для неуправляемого режима): Empty = `false`, Single = `true`. Примеры кода — в Storybook: {{Storybook URL Checkbox}}.

**Q: Каким пропом реализуется состояние Multiple (частичный выбор)?**
A: Пропом `indeterminate` — он приоритетен над `checked` и применяется к заглавному чекбоксу группы. Примеры кода — в Storybook: {{Storybook URL Checkbox}}.

**Q: Можно ли вставить ссылку в лейбл или описание?**
A: Да. Пропсы `label` и `description` принимают строку или JSX, поэтому внутрь можно положить ссылку или другую разметку. Сами лейбл и описание управляются наличием соответствующего пропа. Примеры кода — в Storybook: {{Storybook URL Checkbox}}.

**Q: Как сделать лейбл и описание однострочными?**
A: По умолчанию контент многострочный. Для однострочного режима используется проп `singleLine` (по умолчанию `false`). Примеры кода — в Storybook: {{Storybook URL Checkbox}}.

**Q: Какое значение пропа `view` актуально?**
A: Актуально только `accent`. Остальные значения помечены как deprecated и будут удалены. Примеры кода — в Storybook: {{Storybook URL Checkbox}}.
