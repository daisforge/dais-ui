# Tooltip

Простое всплывающее окно с текстом. Рассказывает контекстную информацию об элементе при наведении.

Небольшие всплывающие подсказки отображают дополнительную информацию без действий и затемнения фона. Триггер tooltip может реагировать как на клик, так и на наведение мышки.

Визуал: {{Pixso URL Tooltip Doc Block 1}}

---

## Анатомия

1. **Label** — текстовый лейбл tooltip. Поддерживает только текст, без форматирования.
2. **ContentLeft** — иконка слева от текста (опционально).
3. **Хвостик (Tail)** — указатель, направленный на триггер. Его положение задаётся свойством TailAlign (в начале / центре / конце тела tooltip).
4. **Триггер** — элемент, при взаимодействии с которым появляется tooltip. Кнопку-пример можно заменить на любой нужный компонент.

> **💡 Важно:** ширина tooltip с триггером задаётся изменением отступов (паддингов) в слое-автолейауте Tooltip Size.

---

## Размеры и отступы

| Размер | Высота | Шрифт лейбла | Размер иконки | Corner Radius |
|---|---|---|---|---|
| **M** | 40 | Body/BodyS N | 16px | 10px |
| **S** | 32 | Body/BodyXS N | 16px | 8px |

Ширина появляющегося окна меняется паддингами в слое Tooltip Size. Рекомендуемая максимальная ширина — **440px** (см. раздел «Контент и ограничения»).

## Настройки (Props)

> Здесь — визуальное поведение. Полный список настроек с типами — в dev-документации.

### Положение

Положение tooltip относительно триггера. В дизайне — 4 стороны: сверху (Top), снизу (Bottom), слева (Left), справа (Right).

### Хвостик (TailAlign)

Положение хвостика-указателя вдоль тела tooltip: Start (в начале), Center (в центре), End (в конце). Свойство дизайна.

### Иконка слева (ContentLeft)

Left — включает иконку слева от текста, None — выключает.

### Подтема (subTheme)

Управляет тем, как токены реагируют на переключение темы: Default (меняются по теме), OnDark / onLight (фиксированы), Inverse (инвертированы относительно Default).

> **💡 На платформе используется Inverse** — тёмный tooltip на светлой теме и светлый на тёмной. По-другому — только через согласование с дизайн-системой.

### Триггер

Tooltip появляется при взаимодействии с триггером (Hover, Active, Focus) либо позиционируется в абсолюте (без триггера).

## Состояния

| Свойство | Результат |
|---|---|
| Opened = True | Раскрывает tooltip. |
| Opened = False | Скрывает tooltip. |

При наличии триггера он дополнительно имеет состояния **Hover**, **Active**, **Focus**.

## Механика и взаимодействия

- **Способ открытия.** Помимо явного управления состоянием Opened (раскрыт / скрыт), отображением можно управлять по наведению или клику — через выбор способа открытия (Hover / Active / Focus).
- **Задержка по наведению.** При открытии по наведению задержка появления настраивается.
- **Открытие по клику.** При открытии по клику доступны свойства из Popover: закрытие по Esc и закрытие по клику на пустую область.
- **Вложенность.** Tooltip оборачивает собой любой компонент-триггер.
- **Иконки в триггере.** Предполагается оборачивать иконки из стандартного набора иконок дизайн-системы.

### Приоритет размещения

Приоритетное положение tooltip — снизу (**Bottom**) с хвостиком **Start**. Если места снизу не хватает, сторона выбирается по убыванию приоритета: **Bottom → Top → Right → Left**. У всех сторон выравнивание хвостика — **Start**.

## Контент и ограничения

- Tooltip **не поддерживает форматирование** текста и любые компоненты, кроме иконки. Если нужно форматирование, скролл и т.п. — используйте компонент **Popover**.
- В tooltip **не могут присутствовать интерактивные элементы**.
- Только для кратких подсказок — **не более 250 символов** (максимальная ширина **440px**).
- Если нужен Popover-функционал — обязательно указываем для разработки, что это компонент **PopoverBeta** в коде.

### Когда использовать

- Для графически обозначенных или сокращённых действий — пояснить, что делает элемент.
- Для краткой информации, помогающей быстро понять назначение элемента интерфейса.
- Как контекстная / дополнительная полезная информация.
- Как дополнительная текстовая информация к иконкам, кнопкам, лейблам.

### Когда не использовать

- Для отображения ошибок — используйте формат ошибки компонента, а для ошибки на уровне страницы — **Notification**.
- Для предоставления сложной информации — вместо этого Notification или Popover.

### Рекомендации

- Не делайте tooltip слишком сложным — только те элементы, в которых пользователь действительно нуждается.
- Сохраняйте единый стиль с другими компонентами дизайн-системы.

## Маппинг: дизайн → код

В таблице — свойства с подтверждённым пропом в коде. Свойства только из дизайна (TailAlign, subTheme, ContentLeft, размер M/S) управляются в коде иначе — точные пропсы см. в Storybook.

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| Placement | `placement` | top / bottom / left / right (+ top-start / top-end / bottom-start / bottom-end и массив) | В дизайне 4 стороны; в коде расширенный набор и приём массива для автоопределения. |
| Триггер | `target` | оборачиваемый компонент | Триггер = компонент, переданный в `target`. Без `target` — tooltip в абсолюте. |
| Способ открытия (Hover / Active / Focus) | `trigger` | hover / click | В дизайне — состояния триггера; в коде — отдельный проп способа открытия. |
| Показ хвостика | `hasArrow` | boolean | Вкл/выкл хвостик. (Выравнивание хвостика — свойство TailAlign — только в дизайне.) |
| Opened | `opened` | boolean | Прямое соответствие. |
| Label | `text` | строка | Текстовый лейбл tooltip. |
| Задержка наведения | `hoverTimeout` | число (мс) | Задаётся в коде. Работает при `trigger="hover"`. |
| Закрытие по Esc | `closeOnEsc` | boolean | Задаётся в коде. Доступно при `trigger="click"`. |
| Закрытие по клику вне | `closeOnOverlayClick` | boolean | Задаётся в коде. Доступно при `trigger="click"`. |

## Связанные компоненты

- **Popover** — всплывающее окно для более богатого контента (форматирование, скролл, интерактив, без затемнения). По иконке «i» обычно открывается именно popover. [Дизайн]({{Pixso URL PopoverDF}}) · [Storybook]({{Storybook URL PopoverDF}})
- **Popup** — всплывающее окно, которое прерывает сценарий и требует действия (блокирует фон); не привязан к триггеру. [Дизайн]({{Pixso URL PopupDF}}) · [Storybook]({{Storybook URL PopupDF}})

> Приоритет: простая справка — tooltip; богатый контент или интерактив — popover; критичный блокирующий сценарий — popup.

## FAQ

### Для дизайнеров

**Q: Зачем нужен tooltip и когда его использовать?**
A: Это небольшая всплывающая подсказка с текстом — поясняет назначение элемента при наведении или клике, без действий и затемнения фона. Используйте для кратких пояснений к иконкам, кнопкам, лейблам и сокращённым действиям. Для ошибок и сложной информации tooltip не подходит — там нужны формат ошибки компонента, Notification или Popover. Подробнее — в Pixso-документации компонента, блок «Когда использовать»: {{Pixso URL Tooltip Doc Block 1}}.

**Q: Какие размеры есть у tooltip и сколько текста в него поместится?**
A: Два размера: M (высота 40, шрифт Body/BodyS N, скругление 10px) и S (высота 32, шрифт Body/BodyXS N, скругление 8px). Размер иконки в обоих — 16px. Текст — только краткие подсказки, не более 250 символов. Ширина меняется паддингами в слое-автолейауте Tooltip Size, рекомендуемая максимальная — 440px. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Tooltip Doc Block 1}}.

**Q: Можно ли вставить в tooltip форматированный текст, ссылки или кнопки?**
A: Нет. Tooltip не поддерживает форматирование и не может содержать интерактивные компоненты, кроме иконки. Если нужно форматирование, скролл или интерактив — используйте Popover. Подробнее — в Pixso-документации компонента, блок «Контент и ограничения»: {{Pixso URL Tooltip Doc Block 1}}.

**Q: Как направить хвостик и выровнять его?**
A: Хвостик-указатель направлен на триггер, а его положение вдоль тела tooltip задаётся свойством TailAlign: в начале (Start), в центре (Center) или в конце (End). Подробнее — в Pixso-документации компонента, блок «Хвостик (TailAlign)»: {{Pixso URL Tooltip Doc Block 1}}.

**Q: Какую тему использовать?**
A: На платформе — Inverse (тёмный tooltip на светлой теме, светлый на тёмной). Другие подтемы — только через согласование с дизайн-системой. Подробнее — в Pixso-документации компонента, блок «Подтема (subTheme)»: {{Pixso URL Tooltip Doc Block 1}}.

### Для разработчиков

**Q: Как управлять положением tooltip относительно триггера?**
A: Проп `placement`: в дизайне 4 стороны (top / bottom / left / right), в коде доступны также комбинированные top-start / top-end / bottom-start / bottom-end. Если передать массив значений, сторона определяется автоматически. Примеры кода — в Storybook: {{Storybook URL Tooltip}}.

**Q: Как задать триггер и способ открытия?**
A: Триггер — это компонент, переданный в `target` (без `target` tooltip позиционируется в абсолюте). Способ открытия задаётся пропом `trigger` (`"hover"` / `"click"`). При `trigger="hover"` задержку появления регулирует `hoverTimeout` (значение в мс). Примеры кода — в Storybook: {{Storybook URL Tooltip}}.

**Q: Как закрывать tooltip при открытии по клику?**
A: При `trigger="click"` доступны свойства из Popover: `closeOnEsc` (закрытие по Esc) и `closeOnOverlayClick` (закрытие по клику на пустую область). Примеры кода — в Storybook: {{Storybook URL Tooltip}}.

**Q: Как включить хвостик и задать лейбл?**
A: Показ хвостика — проп `hasArrow` (boolean), текстовый лейбл — проп `text` (строка), раскрытие/скрытие — `opened` (boolean). Примеры кода — в Storybook: {{Storybook URL Tooltip}}.

**Q: Как в коде управляются дизайн-свойства, у которых нет прямого пропа в маппинге?**
A: Выравнивание хвостика (TailAlign), подтема (subTheme), иконка слева (ContentLeft) и размер M/S — свойства дизайна; в коде они управляются иначе. Точные пропы и их значения уточните в Storybook или в чате поддержки дизайн-системы: {{Storybook URL Tooltip}}.
