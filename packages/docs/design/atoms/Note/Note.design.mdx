# Note

Компонент для отображения краткой статусной информации внутри контентного блока. Используется как инлайн-плашка (информационный, предупреждающий или статусный блок), а не как всплывающее уведомление.

Визуал: {{Pixso URL Note Doc Block 1}}

---

## Анатомия

1. **ContentBefore** — контент слева от текста (опционально). Чаще всего иконка. Размерность задаётся свойством **ContentBefore** (None / Fixed / Scalable).
2. **Title** — заголовок плашки (опционально, управляется свойством **Заголовок**).
3. **Text** — основной текст плашки (опционально, управляется свойством **Текст**).
4. **Close** — иконка закрытия в правом верхнем углу (опционально, управляется свойством **Иконка закрытия**).

---

## Размеры и отступы

Размер задаётся свойством **Size**. От размера зависят шрифты заголовка и текста, скругление углов и внутренние отступы.

| Размер | Шрифт Title | Шрифт Text | Corner Radius | Вертикальный padding | Горизонтальный padding | Отступ Title → Text |
|---|---|---|---|---|---|---|
| **L** | TextL B | TextL N | Calc:[m+2] (14) | 24 | 30 | 4 |
| **M** | TextM B | TextM N | m (12) | 20 | 24 | 2 |
| **S** | TextS B | TextS N | Calc:[m-2] (10) | 16 | 20 | 2 |
| **XS** | TextXS B | TextXS N | s (8) | 12 | 16 | 2 |

Ширина и высота задаются в трёх вариантах: автоматически (по размеру вложенного контента), фиксированно или заполняя весь контейнер.

## Настройки (Props)

> Здесь — визуальное поведение. Полный список пропсов с типами — в dev-документации через `<PropsTable name="Note" />`.

### Вид

Цветовая тема плашки.

| Вид | Назначение |
|---|---|
| Default | Дефолтная (нейтральная) плашка. |
| Positive | Информирует о позитивном сценарии. |
| Warning | Предупреждение. |
| Negative | Информирует о негативном сценарии / ошибке. |
| Info | Информационная плашка. |

### ContentBefore

Размерность и положение контента слева от текста задаётся свойством **ContentBefore**.

| Значение | Описание |
|---|---|
| None | Контент слева от текста выключен. |
| Fixed | Контент слева от текста с фиксированными размерами. |
| Scalable | Контент слева от текста принимает размеры от вставленного компонента. |

### Заголовок

Отображение блока **Title**.

| Состояние | Результат |
|---|---|
| Включено | Заголовок отображается. |
| Выключено | Заголовок скрыт. |

### Текст

Отображение блока **Text**.

| Состояние | Результат |
|---|---|
| Включено | Текст отображается. |
| Выключено | Текст скрыт. |

### Иконка закрытия

Отображение иконки закрытия в правом верхнем углу.

| Состояние | Результат |
|---|---|
| Включено | Иконка закрытия отображается. |
| Выключено | Иконка закрытия скрыта. |

### Слот контента (SwapComponent)

Только для варианта **ContentBefore = Scalable**. При включённой группе кнопок рекомендуется заменять контент слева от текста через это свойство, чтобы сохранить верные отступы слева у кнопок.

## Механика и взаимодействия

### Закрытие

При включённой иконке закрытия нажатие на крестик инициирует закрытие плашки. Само скрытие плашки — на стороне продукта (controlled-вариант): родительский компонент управляет видимостью Note и убирает его из разметки по событию закрытия.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Значения | Примечание |
|---|---|---|---|
| View | `view` | default / positive / warning / negative / info | Прямое соответствие. |
| Size | `size` | l / m / s / xs | Прямое соответствие. |
| ContentBefore | `contentBefore` | иконка / компонент (ReactNode) | Содержимое слота слева от текста. |
| ContentBefore (None / Fixed / Scalable) | `contentBeforeSizing` | none / fixed / scalable | Свойство дизайна **ContentBefore** управляет размерностью; в коде это отдельный проп `contentBeforeSizing`, а сам контент передаётся в `contentBefore`. |
| hastTitle | `hastTitle` | boolean | Включение блока Title. |
| Title | `title` | строка | Текст заголовка. |
| hasText | `hasText` | boolean | Включение блока Text. |
| Text | `text` | строка | Основной текст. |
| hasCloseIcon | `hasClose` | boolean | Иконка закрытия. Имя в дизайне **hasCloseIcon**, в коде — `hasClose`. |
| (обработчик закрытия) | `onCloseButtonClick` | функция | Вызывается при нажатии на иконку закрытия. Поведение задаётся в коде — уточните в Storybook или в чате поддержки дизайн-системы. |
| (ширина) | `width` | число / строка | Собственная ширина. В дизайне задаётся вариантом «фиксированно». |
| (высота) | `height` | число / строка | Собственная высота. В дизайне задаётся вариантом «фиксированно». |
| (заполнить контейнер) | `stretch` | boolean | Note занимает всю доступную ширину и высоту. В дизайне — вариант «заполняя весь контейнер». |

## FAQ

### Для дизайнеров

**Q: Как мне выбрать вид плашки?**
A: Выберите цветовую тему по сценарию: нейтральная, позитивная, предупреждающая, негативная или информационная. Подробнее — в Pixso-документации компонента, блок «Вид»: {{Pixso URL Note Doc Block 1}}.

**Q: Как мне задать размер плашки?**
A: Выберите один из размеров — L, M, S или XS. От размера зависят шрифты заголовка и текста, скругление углов и внутренние отступы. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Note Doc Block 1}}.

**Q: Как мне управлять шириной и высотой?**
A: Ширину и высоту можно задать автоматически (по вложенному контенту), фиксированно или заполняя весь контейнер. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL Note Doc Block 1}}.

**Q: Как мне добавить иконку слева от текста?**
A: Включите контент слева от текста и выберите его размерность — с фиксированными размерами или по размеру вставленного компонента. Подробнее — в Pixso-документации компонента, блок «Контент слева»: {{Pixso URL Note Doc Block 1}}.

**Q: Как мне скрыть заголовок или текст?**
A: Заголовок и текст — опциональные блоки, каждый можно выключить отдельно. Подробнее — в Pixso-документации компонента, блок «Анатомия»: {{Pixso URL Note Doc Block 1}}.

**Q: Как мне сделать закрывающуюся плашку?**
A: Включите иконку закрытия в правом верхнем углу. Сам момент скрытия плашки решает продукт по нажатию на крестик. Подробнее — в Pixso-документации компонента, блок «Механика и взаимодействия»: {{Pixso URL Note Doc Block 1}}.

**Q: Когда использовать Note, а когда Toast или Notification?**
A: Note — инлайн-плашка внутри контента страницы: остаётся на месте и сама не исчезает. Toast и Notification — всплывающие уведомления поверх контента. Note встраивается в контент сообщения и остаётся на месте.

### Для разработчиков

**Q: Как задать вид и размер плашки?**
A: Вид — пропом `view` (`default`, `positive`, `warning`, `negative`, `info`), размер — пропом `size` (`l`, `m`, `s`, `xs`). Примеры кода — в Storybook: {{Storybook URL Note}}.

**Q: Как задать собственную ширину и высоту?**
A: Через `width` и `height`. Чтобы плашка заняла весь контейнер — проп `stretch`. Примеры кода — в Storybook: {{Storybook URL Note}}.

**Q: Как добавить контент слева от текста?**
A: Передайте иконку или компонент в `contentBefore` и задайте размерность через `contentBeforeSizing` (`none`, `fixed`, `scalable`). При группе кнопок и `contentBeforeSizing="scalable"` заменяйте контент через слот SwapComponent, чтобы сохранить верные отступы. Примеры кода — в Storybook: {{Storybook URL Note}}.

**Q: Как скрыть заголовок или текст?**
A: Отключите `hastTitle` (заголовок) или `hasText` (текст). Сами строки передаются в `title` и `text`.

**Q: Как сделать закрывающуюся плашку?**
A: Включите `hasClose` и передайте обработчик `onCloseButtonClick`; видимостью управляет продукт (controlled-вариант). Примеры кода — в Storybook: {{Storybook URL Note}}.
