# Загрузка данных на экране

Визуальные уведомления пользователей о том, что загрузка контента началась.

---

## Состояние интерфейса

### Правила

- Загрузка данных отображается локально, при этом навигация, фильтры и основные действия не блокируются.
- Используется один индикатор на область.

Общее: состояние загрузки не должно ломать структуру страницы и блокировать пользователя без необходимости или скрывать ключевые действия.

### Допускается блокирование интерфейса, если:

- Происходит критическая системная операция.
- Пользователь выполняет необратимое действие, требуется подтверждение.
- Данные необходимы для корректного отображения всей страницы.
- Существуют юридические ограничения или ограничения безопасности.

В таких случаях блокировка должна быть временной, причина должна быть объяснена пользователю, а состояние — обратимым.

## Время загрузки

Что показываем пользователю при загрузке — в зависимости от её длительности.

| Длительность анимации | Что показываем |
|---|---|
| 0.5–1 сек | Мгновенный отклик системы в виде обычного Loader / Skeleton. |
| >1–2 сек | Необходимо добавить пояснительный текст. |
| >30 сек | Показываем пользователю проценты / этапы / оценочное время. |
| >60 сек | Показываем пользователю кнопки «Отменить», «Продолжить в фоне» или переводим в фон / очередь с уведомлениями. |

## FAQ

### Для дизайнеров

**Q: Нужно ли блокировать интерфейс на время загрузки?**
A: По умолчанию нет: загрузка отображается локально, а навигация, фильтры и основные действия не блокируются. Блокировка допустима только в исключительных случаях — критическая системная операция, необратимое действие с подтверждением, данные нужны для корректного отображения всей страницы, юридические ограничения или ограничения безопасности. В этих случаях блокировка должна быть временной, обоснованной и обратимой. Подробнее — блок «Состояние интерфейса»: {{Pixso URL UploadEffectGuide Doc Block 1}}

**Q: Сколько индикаторов загрузки показывать в одной области?**
A: Один индикатор на область. Подробнее — блок «Состояние интерфейса»: {{Pixso URL UploadEffectGuide Doc Block 1}}

**Q: Какой индикатор выбрать при короткой загрузке (0.5–1 сек)?**
A: Мгновенный отклик системы в виде обычного Loader / Skeleton. Подробнее — блок «Время загрузки»: {{Pixso URL UploadEffectGuide Doc Block 2}}

**Q: Когда добавлять пояснительный текст к загрузке?**
A: При длительности более 1–2 секунд. Подробнее — блок «Время загрузки»: {{Pixso URL UploadEffectGuide Doc Block 2}}

**Q: Что показывать при долгой загрузке (более 30 секунд)?**
A: Проценты, этапы или оценочное время. Подробнее — блок «Время загрузки»: {{Pixso URL UploadEffectGuide Doc Block 2}}

**Q: Что делать, если загрузка длится дольше 60 секунд?**
A: Показать кнопки «Отменить», «Продолжить в фоне» или перевести процесс в фон / очередь с уведомлениями. Подробнее — блок «Время загрузки»: {{Pixso URL UploadEffectGuide Doc Block 2}}
