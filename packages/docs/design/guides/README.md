# Гайды

Дизайн-гайды по паттернам и сценариям, не привязанным к одному компоненту: как выбирать между близкими компонентами, паттерны загрузки, статусные модели, работа с сущностями и т.д.

> **Гайды — только дизайн-документация** (`*.design.mdx`), без dev-части (кода). Этим они отличаются от компонентов (атомы/организмы), у которых есть парный dev-файл `<Component>.mdx`.

Именование — `kebab-case`, например `saving-data.design.mdx`; `id` в frontmatter совпадает с именем файла. Подробнее — [CONVENTIONS.md](../CONVENTIONS.md).
