# Создание сущностей

Гайд о том, как в продукте пользователь создаёт новую сущность. Основной способ — акцентная кнопка справа на экране (в Page Title или FiltersActions); по клику открывается модальное окно, в котором и происходит создание. Есть и альтернативный способ — добавление сущности прямо в таблице.

---

## Вне таблицы

Создание сущности в продукте происходит **только по акцентной кнопке справа** на экране — в Page Title или в FiltersActions.

### Кнопка запуска

- Для запуска создания используем кнопку (Button) — в FiltersActions или в Page Title.
- **Одновременно кнопки в Page Title и FiltersActions на экране быть не могут.** На экране остаётся одна точка запуска создания сущности — либо в Page Title, либо в FiltersActions.

### Модальное окно

По клику на кнопку открывается модальное окно (Modal), в котором пользователь заполняет поля и создаёт сущность. Примеры такого сценария — в документации гайда, блок «Вне таблицы»: {{Pixso URL CreateEntity Doc Block 1}}

---

## Альтернативный способ

### Добавление сущностей в таблице

Кроме кнопки на экране, сущность можно добавить прямо в таблице — новой строкой. Подробно про добавление строк — в документации таблицы: {{Pixso URL TableCanvas AddRows}}

Подробнее об этом способе — в документации гайда, блок «Альтернативный способ»: {{Pixso URL CreateEntity Doc Block 2}}

## FAQ

### Для дизайнеров

**Q: Где на экране размещается кнопка создания сущности?**
A: Справа на экране — в Page Title или в FiltersActions. Это единственная точка запуска создания «вне таблицы». Подробнее — в документации гайда, блок «Вне таблицы»: {{Pixso URL CreateEntity Doc Block 1}}

**Q: Можно ли поставить кнопку создания и в Page Title, и в FiltersActions одновременно?**
A: Нет. Одновременно кнопки в Page Title и FiltersActions на экране быть не могут — оставляем одну точку запуска. Подробнее — в документации гайда, блок «Вне таблицы»: {{Pixso URL CreateEntity Doc Block 1}}

**Q: Что происходит по клику на кнопку создания?**
A: Открывается модальное окно, в котором пользователь заполняет поля и создаёт сущность. Подробнее — в документации гайда, блок «Вне таблицы»: {{Pixso URL CreateEntity Doc Block 1}}

**Q: Есть ли способ создать сущность без кнопки на экране?**
A: Да — добавить её прямо в таблице, новой строкой. Подробнее — в документации гайда, блок «Альтернативный способ»: {{Pixso URL CreateEntity Doc Block 2}}
