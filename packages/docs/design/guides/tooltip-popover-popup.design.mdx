# Что использовать: Tooltip, Popover или Popup

Гайд помогает выбрать подходящий компонент для всплывающего контента: Tooltip, Popover или Popup. Все три показывают дополнительную информацию поверх интерфейса, но различаются объёмом контента, наличием интерактивных элементов и привязкой к триггеру.

Коротко про выбор:

- **Tooltip** — небольшая всплывающая подсказка с краткой информацией, без интерактивных элементов.
- **Popover** — всплывающее окно с более подробной информацией и интерактивными элементами; привязано к триггеру (появляется рядом с ним), контент размещается кастомно.
- **Popup** — всплывающее окно по клику на элемент, внутри которого можно разместить кастомную информацию; не привязано к триггеру (появляется в нужной части экрана) и вмещает больше информации, чем popover. Сценарий при этом не прерывается.

## Tooltip

Небольшие всплывающие подсказки отображают дополнительную информацию — без действий и затемнения фона.

На платформе используется Inverse-тултип: тёмный на светлой теме и светлый на тёмной. По-другому — только через согласование с дизайн-системой.

Определение и общий вид — в документации гайда, блок «Tooltip»: {{Pixso URL TooltipPopoverPopup DocTooltip Block 1}}

### Когда использовать

- Триггер tooltip может реагировать как на клик, так и на наведение мышки.
- Как дополнительная текстовая информация к иконкам, кнопкам, лейблам и другим компонентам, где нужны пояснения.
- Как контекстная информация, дающая пользователю полезные пояснения.
- Чтобы кратко передать назначение элемента интерфейса.
- Для графически обозначенных или сокращённых действий — пояснить, что делает элемент.
- Для сообщения об ошибке в ячейке таблицы.

Ограничения при использовании:

- Только для кратких подсказок — не более 250 символов (максимальная ширина 440px).
- В тултипах не может быть интерактивных элементов.
- Tooltip не поддерживает форматирование текста и любые компоненты (кроме иконки внутри компонента без интерактива). Если нужно форматирование, скролл и т.п. — используйте Popover. Для разработки обязательно указываем, что в коде это компонент PopoverBeta (пример его стилизации есть в документации).

Когда не используем:

- Для отображения ошибок вне таблицы: в каждом компоненте предусмотрен свой формат сообщения об ошибке — придерживайтесь его, а для ошибки на уровне страницы используйте вариацию Notification. Исключение — ошибка в ячейке таблицы: там используется tooltip.

Рекомендации:

- Не пишите в тултипе слишком много текста — только то, что действительно нужно пользователю.
- Сохраняйте единый стиль: tooltips должны соответствовать другим компонентам дизайн-системы.
- Не используйте для сложной информации — вместо этого Notification или Popover.

Подробнее — в документации гайда, блок «Когда использовать»: {{Pixso URL TooltipPopoverPopup DocTooltip Block 2}}

### Порядок приоритетов

Приоритет положения tooltip относительно триггера:

- Приоритетный — Placement Bottom, TailAlign Start. Если неудобно — любой tooltip с Placement Bottom.
- Далее — Placement Top, TailAlign Start. Если неудобно — любой с Placement Top.
- Далее — Placement Right, TailAlign Start. Если неудобно — любой с Placement Right.
- Далее — Placement Left, TailAlign Start. Если неудобно — любой с Placement Left.

Варианты расположения tooltip и схема приоритетов — в документации гайда, блок «Порядок приоритетов»: {{Pixso URL TooltipPopoverPopup DocTooltip Block 3}}

### Особенности поведения

- В tooltip можно заменить триггер с кнопки на иконку.
- В слое Tooltip Size паддингами можно менять ширину появляющегося окна.

Подробнее — в документации гайда, блок «Особенности поведения»: {{Pixso URL TooltipPopoverPopup DocTooltip Block 4}}

## Popover

Всплывающее окно — появляется при наведении или клике на элемент. Показывает один контент поверх другого, без затемнения фона.

Определение и общий вид — в документации гайда, блок «Popover»: {{Pixso URL TooltipPopoverPopup DocPopover Block 1}}

### Когда использовать

- Компонент с триггером: всегда появляется при взаимодействии с элементом и выводится рядом с ним (например, кнопка = триггер → popover рядом с кнопкой).
- При взаимодействии с кнопкой или другим элементом интерфейса, который запускает всплывающее окно.
- Для второстепенной или менее важной информации и действий — они скрыты, пока пользователь не нажмёт.
- Для отображения пояснений и дополнительной информации.
- Если требуется больше контекста или нужны дополнительные элементы взаимодействия.

Когда не используем:

- Вместо отдельного экрана: если содержимое слишком сложное или большое, лучше показать его в модальном окне.
- Если действий во всплывающем окне слишком много или они сложны — лучше отдельный экран или модальное окно.

Рекомендации:

- По иконке «i», открывающей блок с дополнительной информацией, появляется popover — если пояснение большое или есть форматирование; если текст простой, лучше tooltip.
- Если информации слишком много, в поповере можно показать переход к более полным объяснениям — через модальные окна или отдельные страницы.

Подробнее — в документации гайда, блок «Когда использовать»: {{Pixso URL TooltipPopoverPopup DocPopover Block 2}}

### Порядок приоритетов

Приоритет положения popover относительно триггера:

- Приоритетный — Position Bottom, Tail Position Start. Если неудобно — любой popover с Position Bottom.
- Далее — Position Top, Tail Position Start. Если неудобно — любой с Position Top.
- Далее — Position Right, Tail Position Start. Если неудобно — любой с Position Right.
- Далее — Position Left, Tail Position Start. Если неудобно — любой с Position Left.

Варианты расположения popover и схема приоритетов — в документации гайда, блок «Порядок приоритетов»: {{Pixso URL TooltipPopoverPopup DocPopover Block 3}}

### Особенности поведения

- По умолчанию есть кнопка активного действия — в неё можно поместить не только «закрыть» / «хорошо», но и «подробнее» и т.п.
- Закрыть popover можно кликом по пустой области — значит, кнопки (Buttons) можно скрыть внутри компонента.
- Также скрывается текстовая часть (например, Description).
- Настройка Resize зависит от пожеланий продукта.

Подробнее — в документации гайда, блок «Особенности поведения»: {{Pixso URL TooltipPopoverPopup DocPopover Block 4}}

## Popup

Всплывающее окно, появляющееся по клику на элемент (триггер), внутри которого можно разместить кастомную информацию. Не привязано к триггеру — появляется в нужной части экрана. Чаще используется, чтобы разместить больше информации, чем в поповере. Ключевое отличие от поповера — отсутствие привязки к триггеру; сценарий при этом не прерывается.

Определение и общий вид — в документации гайда, блок «Popup»: {{Pixso URL TooltipPopoverPopup DocPopup Block 1}}

### Когда использовать

- Когда нужно разместить больше информации, чем удобно показать в поповере.
- Когда окно не должно быть привязано к триггеру — открывается в любой части экрана.

Когда не используем:

- Если нужна простая справочная информация — лучше tooltip; или popover, если нужна стилизация.
- Когда отображается несущественная или второстепенная информация.

Рекомендации:

- Размер popup может быть средним или большим.
- Если информации слишком много, в popup можно показать переход к более полным объяснениям — через модальные окна или отдельные страницы.

Подробнее — в документации гайда, блок «Когда использовать»: {{Pixso URL TooltipPopoverPopup DocPopup Block 2}}

### Особенности поведения

- Можно подменять контент: кастомный слот заменяется на любой компонент через Instance swap.
- Resize — изменение размера окна.
- Draggable — перемещение окна по экрану.

Подробнее — в документации гайда, блок «Особенности поведения»: {{Pixso URL TooltipPopoverPopup DocPopup Block 3}}

## FAQ

### Для дизайнеров

**Q: Как выбрать между Tooltip, Popover и Popup?**
A: Tooltip — для краткой подсказки без интерактива. Popover — когда нужно больше контекста, форматирование или дополнительные элементы взаимодействия рядом с триггером. Popup — когда информации больше, чем удобно показать в поповере, и окно не должно быть привязано к триггеру (появляется в нужной части экрана). Общий обзор — в документации гайда: {{Pixso URL TooltipPopoverPopup}}

**Q: Когда лучше Tooltip, а когда Popover?**
A: Tooltip — для кратких пояснений (не более 250 символов, максимальная ширина 440px), без интерактивных элементов и форматирования. Если нужно форматирование, скролл или дополнительные взаимодействия — Popover. Подробнее — блок «Когда использовать» Tooltip: {{Pixso URL TooltipPopoverPopup DocTooltip Block 2}} и блок «Когда использовать» Popover: {{Pixso URL TooltipPopoverPopup DocPopover Block 2}}

**Q: Когда использовать Popup вместо Popover?**
A: Popup — когда контента больше, чем удобно показать в поповере, и окно не должно быть привязано к триггеру. Подробнее — блок «Когда использовать» Popup: {{Pixso URL TooltipPopoverPopup DocPopup Block 2}}

**Q: Можно ли добавить в Tooltip кнопки, ссылки или форматирование?**
A: Нет. Tooltip не поддерживает форматирование и не может содержать интерактивные элементы (кроме иконки внутри компонента). Для такого контента используйте Popover. Подробнее — блок «Когда использовать» Tooltip: {{Pixso URL TooltipPopoverPopup DocTooltip Block 2}}

**Q: Как позиционировать Tooltip и Popover?**
A: По приоритету: сначала положение снизу с выравниванием указателя Start, затем сверху, справа и слева (у Tooltip — Placement и TailAlign, у Popover — Position и Tail Position). Если приоритетное положение неудобно — берётся любое положение с той же стороны. Подробнее — блоки «Порядок приоритетов»: {{Pixso URL TooltipPopoverPopup DocTooltip Block 3}} и {{Pixso URL TooltipPopoverPopup DocPopover Block 3}}

**Q: Можно ли в Popover скрыть кнопки или текст и менять размер?**
A: Да. Кнопки (Buttons) можно скрыть, так как закрыть popover можно кликом по пустой области; также скрывается текстовая часть (например, Description). Настройка Resize зависит от пожеланий продукта. Подробнее — блок «Особенности поведения» Popover: {{Pixso URL TooltipPopoverPopup DocPopover Block 4}}

**Q: Что умеет Popup?**
A: В Popup можно подменять контент (кастомный слот через Instance swap), менять размер окна (Resize) и перемещать окно по экрану (Draggable). Подробнее — блок «Особенности поведения» Popup: {{Pixso URL TooltipPopoverPopup DocPopup Block 3}}

**Q: Какой компонент использовать для ошибок?**
A: В ячейке таблицы — tooltip. В остальных случаях используйте формат ошибки, предусмотренный в компоненте, а для ошибки на уровне страницы — Notification. Подробнее — блок «Когда использовать» Tooltip: {{Pixso URL TooltipPopoverPopup DocTooltip Block 2}}
