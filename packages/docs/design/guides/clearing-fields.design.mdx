# Очистка полей

Гайд о том, как показывать очистку полей на макетах. Очистка выполняется иконкой Close (крестик) в слоте RightContent и включается в дизайне свойством Close.

---

## Когда правильно использовать очистку в полях?

### Очистка разрешена

- Когда поле может быть пустым по смыслу.
- Состояние empty/none является валидным.

Например: поиск, фильтр, необязательные параметры.

- Когда очистка не приводит к ошибке.
- Когда очистка не требует подтверждения.
- Когда пользователь часто меняет значение.
- Когда очистка безопасна и не приводит к потере данных.

### Очистка НЕ разрешена

- Когда пустое значение невалидно.
- Когда при очистке поля сбрасываются смежные поля (очистка влияет не только на себя).
- Когда вместо пустого состояния есть «не выбрано» или дефолтное значение.
- В обязательных полях (очистка будет блокировать продолжение сценария).

Подробнее — в документации гайда, блок «Когда правильно использовать очистку в полях?»: {{Pixso URL ClearingFields Doc Block 1}}

---

## Как работает в SDDS FinAl

Очистка доступна в полях TextField, TextArea и Autocomplete.

Крестик появляется при вводе первого символа в поле и сохраняется в состоянии по умолчанию, если в поле введён текст. Если поле дополнено иконкой, крестик отображается слева от иконки.

Примеры состояний полей с очисткой — в документации гайда, блок «Как работает в SDDS FinAl»: {{Pixso URL ClearingFields Doc Block 2}}

## FAQ

### Для дизайнеров

**Q: Когда можно добавить очистку в поле?**
A: Когда поле может быть пустым по смыслу, а состояние empty/none валидно (поиск, фильтр, необязательные параметры), и когда очистка безопасна, не приводит к ошибке или потере данных и не требует подтверждения. Подробнее — в документации гайда, блок «Когда правильно использовать очистку в полях?»: {{Pixso URL ClearingFields Doc Block 1}}

**Q: В каких полях очистку добавлять не нужно?**
A: В обязательных полях, где пустое значение невалидно; когда очистка сбрасывает смежные поля; когда вместо пустого состояния есть «не выбрано» или дефолтное значение. Подробнее — в документации гайда, блок «Когда правильно использовать очистку в полях?»: {{Pixso URL ClearingFields Doc Block 1}}

**Q: Как включить очистку на макете?**
A: Очистка отображается иконкой Close (крестик) в слоте RightContent и включается свойством Close. Подробнее — в документации гайда, блок «Как работает в SDDS FinAl»: {{Pixso URL ClearingFields Doc Block 2}}

**Q: Когда появляется крестик очистки?**
A: Крестик появляется при вводе первого символа в поле и сохраняется в состоянии по умолчанию, если в поле введён текст. Подробнее — в документации гайда, блок «Как работает в SDDS FinAl»: {{Pixso URL ClearingFields Doc Block 2}}

**Q: Где отображается крестик, если у поля есть иконка?**
A: Слева от иконки. Подробнее — в документации гайда, блок «Как работает в SDDS FinAl»: {{Pixso URL ClearingFields Doc Block 2}}

**Q: В каких компонентах поддерживается очистка?**
A: В TextField, TextArea и Autocomplete. Подробнее — в документации гайда, блок «Как работает в SDDS FinAl»: {{Pixso URL ClearingFields Doc Block 2}}
