# Группировка сущностей

Гайд о том, как пользователь объединяет несколько сущностей в группу. Сущности выбирают одним из двух способов — выделением курсором или чекбоксами — и затем группируют.

---

## Выделение курсором

Первый способ выбрать сущности для группировки — выделение курсором.

1. Выделите сущности.
2. Кликните правой кнопкой мыши — откроется контекстное меню (Dropdown) с вариантами действий.

Подробнее — в документации гайда, блок «Выделение курсором»: {{Pixso URL GroupEntity Doc Block 1}}

---

## Выделение с помощью чекбоксов

Второй способ — отметить сущности чекбоксами и сгруппировать их через панель массовых действий.

1. Выберите сущности с помощью чекбоксов.
2. Сгруппируйте их через панель массовых действий — акцентной кнопкой группировки.

Примеры панели массовых действий и кнопки группировки — в документации гайда, блок «Выделение с помощью чекбоксов»: {{Pixso URL GroupEntity Doc Block 2}}

## FAQ

### Для дизайнеров

**Q: Как сгруппировать сущности выделением курсором?**
A: Выделите сущности и кликните правой кнопкой мыши — откроется контекстное меню с вариантами действий. Подробнее — блок «Выделение курсором»: {{Pixso URL GroupEntity Doc Block 1}}

**Q: Как сгруппировать сущности через чекбоксы?**
A: Отметьте нужные сущности чекбоксами и сгруппируйте их через панель массовых действий. Подробнее — блок «Выделение с помощью чекбоксов»: {{Pixso URL GroupEntity Doc Block 2}}

**Q: Какое действие запускает группировку выбранных сущностей?**
A: Акцентная кнопка группировки в панели массовых действий. Примеры — блок «Выделение с помощью чекбоксов»: {{Pixso URL GroupEntity Doc Block 2}}
