# Сохранение данных

На платформе есть два способа сохранения данных: автоматическое (автосохранение) и ручное (по кнопке «Сохранить»). Гайд описывает оба способа, валидацию при сохранении и подтверждение выхода без сохранения.

---

## Сохранение по кнопке

Ручной способ: пользователь сохраняет данные сам, по кнопке «Сохранить».

### Когда лучше выбрать кнопку «Сохранить»

- Применение фильтров или настроек.
- Необходимость управления версиями.

### Дропдаун по клику на кнопку

При клике на кнопку может появляться дропдаун с дополнительными параметрами сохранения.

### Дата последнего сохранения

Для этого способа нужно добавлять бейдж с датой последнего сохранения проекта. Он может находиться в Page Title или в Block Title.

Примеры и макеты — в документации гайда, блок «Сохранение по кнопке»: {{Pixso URL SavingData Doc Block 1}}

---

## Автосохранение

Автоматический способ: данные сохраняются без явного действия пользователя.

### Когда лучше выбрать автосохранение

- Длительная работа пользователя.
- Ускорение действий пользователя в разделе.
- Работа с критически важными данными.

Примеры и макеты — в документации гайда, блок «Автосохранение»: {{Pixso URL SavingData Doc Block 2}}

---

## Валидация при сохранении

Желательно показать пользователю ответ системы на сохранение — уведомлением об успехе или неудаче.

Примеры и макеты — в документации гайда, блок «Валидация при сохранении»: {{Pixso URL SavingData Doc Block 3}}

## Модальное окно подтверждения

Нужно предусмотреть ситуацию, когда пользователь не сохранил данные и хочет закрыть раздел, — показать Confirmation modal с акцентной кнопкой сохранения.

Примеры текста и кнопок — в документации гайда, блок «Модальное окно подтверждения»: {{Pixso URL SavingData Doc Block 4}}

## FAQ

### Для дизайнеров

**Q: Как пользователь сохраняет данные вручную?**
A: По кнопке «Сохранить». Подробнее — блок «Сохранение по кнопке»: {{Pixso URL SavingData Doc Block 1}}

**Q: Когда выбрать ручное сохранение по кнопке, а когда автосохранение?**
A: Кнопку «Сохранить» — при применении фильтров или настроек и когда нужно управление версиями. Автосохранение — при длительной работе пользователя, для ускорения его действий в разделе и при работе с критически важными данными. Подробнее — блоки «Сохранение по кнопке»: {{Pixso URL SavingData Doc Block 1}} и «Автосохранение»: {{Pixso URL SavingData Doc Block 2}}

**Q: Как показать дату последнего сохранения?**
A: Добавить бейдж с датой последнего сохранения проекта — в Page Title или в Block Title. Подробнее — блок «Сохранение по кнопке»: {{Pixso URL SavingData Doc Block 1}}

**Q: Как дать пользователю дополнительные параметры сохранения?**
A: По клику на кнопку показать дропдаун с дополнительными параметрами сохранения. Подробнее — блок «Сохранение по кнопке»: {{Pixso URL SavingData Doc Block 1}}

**Q: Как сообщить пользователю результат сохранения?**
A: Показать уведомление об успехе или неудаче. Подробнее — блок «Валидация при сохранении»: {{Pixso URL SavingData Doc Block 3}}

**Q: Что показать, если пользователь выходит из раздела без сохранения?**
A: Confirmation modal с акцентной кнопкой сохранения; точные формулировки текста и кнопок — по ссылке. Подробнее — блок «Модальное окно подтверждения»: {{Pixso URL SavingData Doc Block 4}}
