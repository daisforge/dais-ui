# Статусная модель

Статусы на платформе FinAL используются при работе с задачами и документами. В статус может входить не только текст, но и иконка, дата, время, номер и другие числовые данные.

---

## Общие рекомендации

- **Статус согласуется с сущностью, к которой относится.** Форма слова зависит от сущности: если это задача — «задача выполнена», если расчёт — «расчёт выполнен».
- **Для статуса рекомендуется 3–4 слова**, при необходимости — с предлогом.
- **В статусах допустим страдательный залог.** Например: «бюджет выделен».
- **Кроме текста, в статус можно включить дополнительную информацию** — дату, время, номер и другие числовые данные.
- **Статус может быть без текста** и состоять только из даты и иконки.

Требования к текстам статусов (залог, формулировки, согласование с сущностью) — см. редполитику: Статусы.

## FAQ

### Для дизайнеров

**Q: Сколько слов должно быть в статусе?**
A: Рекомендуется 3–4 слова, при необходимости — с предлогом.

**Q: Можно ли использовать в статусе страдательный залог?**
A: Да, он допустим. Например: «бюджет выделен». Требования к текстам статусов — см. редполитику: Статусы.

**Q: Может ли статус быть без текста?**
A: Да. Статус может состоять только из даты и иконки.

**Q: Что, кроме текста, можно показать в статусе?**
A: Дополнительную информацию — дату, время, номер и другие числовые данные.

**Q: Как согласовать статус с сущностью, к которой он относится?**
A: Форма слова зависит от сущности: задача — «выполнена», расчёт — «выполнен». Подробнее — на странице гайда: {{Pixso URL StatusModel}}
