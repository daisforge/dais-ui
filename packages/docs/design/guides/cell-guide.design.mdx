# Гайд на Cell

Гайд о том, как использовать компонент Cell — небольшой блок контента или функциональности. Ниже собраны рекомендации по составу ячейки, отступам, скруглениям, заливке, обводке и стилям текста.

---

## Общее

Компонент Cell состоит из трёх частей — Left Content, Center Content и Right Content, в которые по умолчанию вложены компоненты с вариантами реализации.

При необходимости в любую из трёх частей можно поместить и другие компоненты.

Подробнее — в документации гайда, блок «Общее»: {{Pixso URL CellGuide Doc Block 1}}

---

## Отступы (padding)

Как меняем паддинги:

- Размер паддинга должен быть кратен четырём (например: 12px, 16px, 8px).

Рекомендуемые расстояния по размерам:

| Размер | Отступ (padding) |
|---|---|
| **L** | 16px / 16px |
| **M** | 12px / 12px |
| **S** | 12px / 8px |
| **XS** | 8px / 8px |

Подробнее — в документации гайда, блок «Отступы (padding)»: {{Pixso URL CellGuide Doc Block 2}}

---

## Скругления

Какие ставить скругления:

- Скругления должны подходить к скруглениям внешнего контейнера и размерам компонента.

Рекомендуемые расстояния по размерам:

| Размер | Скругление |
|---|---|
| **L** | 12 |
| **M** | 12 |
| **S** | 8 |
| **XS** | 8 |

Подробнее — в документации гайда, блок «Скругления»: {{Pixso URL CellGuide Doc Block 3}}

---

## Заливка и обводка

Какие цвета можно использовать:

- Для заливки компонента можно использовать цвета из группы Surface.
- Для обводки используем цвета группы Outline.
- Возможно использование некоторых цветов из группы Data — требует согласования с командой ДС.

Подробнее — в документации гайда, блок «Заливка и обводка»: {{Pixso URL CellGuide Doc Block 4}}

---

## Стили текста

Стиль текста внутри Cell:

- По потребности можно менять стиль текста из токенов библиотеки.
- Цвет текста можно менять в группе Text/Icon.

Подробнее — в документации гайда, блок «Стили текста»: {{Pixso URL CellGuide Doc Block 5}}

## FAQ

### Для дизайнеров

**Q: Из каких частей состоит Cell?**
A: Из трёх: Left Content, Center Content и Right Content. По умолчанию в них вложены компоненты с вариантами реализации. Подробнее — в документации гайда, блок «Общее»: {{Pixso URL CellGuide Doc Block 1}}

**Q: Можно ли поместить в ячейку собственный компонент?**
A: Да — при необходимости в любую из трёх частей можно поместить другой компонент. Подробнее — в документации гайда, блок «Общее»: {{Pixso URL CellGuide Doc Block 1}}

**Q: Какие отступы (padding) задавать для разных размеров?**
A: Для L — 16px / 16px, для M — 12px / 12px, для S — 12px / 8px, для XS — 8px / 8px. Подробнее — в документации гайда, блок «Отступы (padding)»: {{Pixso URL CellGuide Doc Block 2}}

**Q: Есть ли правило для величины паддинга?**
A: Да — размер паддинга должен быть кратен четырём (например: 12px, 16px, 8px). Подробнее — в документации гайда, блок «Отступы (padding)»: {{Pixso URL CellGuide Doc Block 2}}

**Q: Какие скругления ставить?**
A: Скругления подбираем под скругления внешнего контейнера и размер компонента: для L и M — 12, для S и XS — 8. Подробнее — в документации гайда, блок «Скругления»: {{Pixso URL CellGuide Doc Block 3}}

**Q: Какие цвета можно использовать для заливки и обводки?**
A: Для заливки — цвета группы Surface, для обводки — цвета группы Outline. Подробнее — в документации гайда, блок «Заливка и обводка»: {{Pixso URL CellGuide Doc Block 4}}

**Q: Можно ли использовать цвета из группы Data?**
A: Да, некоторые цвета группы Data использовать можно, но это требует согласования с командой ДС. Подробнее — в документации гайда, блок «Заливка и обводка»: {{Pixso URL CellGuide Doc Block 4}}

**Q: Как менять стиль и цвет текста в ячейке?**
A: Стиль текста по потребности можно менять из токенов библиотеки, а цвет — в группе Text/Icon. Подробнее — в документации гайда, блок «Стили текста»: {{Pixso URL CellGuide Doc Block 5}}
