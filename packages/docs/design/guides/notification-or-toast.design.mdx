# Как использовать Toast и Notification

Гайд о том, когда показывать уведомление (Notification), а когда — тост (Toast), и как они располагаются и ведут себя на экране.

---

## Основное правило

Если нужно обозначить результат целевого действия, используйте уведомление (Notification). В остальных случаях используйте тост (Toast).

Результат создания сущности — это целевое действие пользователя, поэтому показывается уведомление. Обновление таблицы — техническое оповещение, не целевое действие, поэтому показывается тост.

Тексты уведомлений и тостов — см. редполитику: Уведомления и тосты.

Если в вашем кейсе нужен тост, которого нет в редполитике, напишите в круг поддержки дизайна — обсудим.

Подробнее и примеры — блок «Основное правило»: {{Pixso URL NotificationOrToast Doc Block 1}}

Notification — всплывающий элемент, уведомление поверх контента, которое может содержать кнопки.

## Контент уведомления

- Заголовок (Title) — не более 2 строк, подзаголовок (subTitle) — не более 2 строк.
- Рекомендуемая ширина уведомления — не более 700px, высота — не более 114px.
- Используются залитые иконки, которые выставлены в компоненте по умолчанию. Если в рамках кейса нужна другая иконка, можно написать в Поддержку Дизайна DS.

Подробнее — блок «Контент»: {{Pixso URL NotificationOrToast Doc Block 3}}

## Расположение уведомлений

Уведомления выводятся в правом нижнем углу страницы, с отступом 40px от краёв.

> **🚧 В разработке:** паттерн расположения пересматривается.

Подробнее — блок «Расположение»: {{Pixso URL NotificationOrToast Doc Block 4}}

## Отображение нескольких уведомлений

- **1–2 уведомления** располагаются друг под другом с отступом 12px.
- **3 и более:** самые старые уведомления пропадают, показываются новые. Максимальное количество уведомлений на экране определяет продукт — максимум 1–3.

Технические настройки — время затухания исчезающего уведомления и тайминги (через сколько появляются новые и через сколько старые исчезают сами, освобождая место) — задаёт команда рабочих столов; их добавят в гайд позже.

Подробнее — блок «Отображение нескольких уведомлений»: {{Pixso URL NotificationOrToast Doc Block 5}}

## Toast

Toast — компонент для коротких сообщений. Внутри тоста нет действий (кнопок).

Подробнее о компоненте — в гайде: {{Pixso URL Toast DocGuide Block 1}}

### Контент тоста

Toast используется для коротких технических оповещений — например, при сохранении, обновлении, копировании, синхронизации, удалении, переходе в режим редактирования или просмотра, а также для коротких ошибок. Тексты тостов — см. редполитику: Уведомления и тосты.

Если у вас другой кейс и нужен новый Toast — напишите в круг поддержки дизайна, обсудите.

### Расположение тоста

Тост выводится сверху, с отступом 12px от Header FinAI.

### Отображение нескольких тостов

- **1–2 тоста** располагаются друг под другом с отступом 8px.
- **3 и более:** самые старые тосты пропадают, показываются новые. Максимальное количество на экране определяет продукт — максимум 1–3.

---

## Связанные компоненты

- **Notification** — всплывающее уведомление поверх контента; может содержать кнопки.
- **Toast** — компонент для коротких сообщений без действий.

## FAQ

### Для дизайнеров

**Q: Когда использовать уведомление, а когда тост?**
A: Уведомление (Notification) — когда нужно обозначить результат целевого действия. Тост (Toast) — во всех остальных случаях (технические оповещения). Подробнее — блок «Основное правило»: {{Pixso URL NotificationOrToast Doc Block 1}}

**Q: Где на экране появляется уведомление?**
A: В правом нижнем углу страницы, с отступом 40px от краёв. Паттерн расположения пересматривается. Подробнее — блок «Расположение»: {{Pixso URL NotificationOrToast Doc Block 4}}

**Q: Где появляется тост?**
A: Сверху, с отступом 12px от Header FinAI.

**Q: Сколько уведомлений можно показать одновременно?**
A: 1–2 располагаются друг под другом; при 3 и более самые старые пропадают, показываются новые. Максимум на экране определяет продукт — до 1–3. Подробнее — блок «Отображение нескольких уведомлений»: {{Pixso URL NotificationOrToast Doc Block 5}}

**Q: Какие ограничения по контенту уведомления?**
A: Заголовок и подзаголовок — не более 2 строк каждый; рекомендуемая ширина — не более 700px, высота — не более 114px. Подробнее — блок «Контент»: {{Pixso URL NotificationOrToast Doc Block 3}}

**Q: Можно ли поменять иконку в уведомлении?**
A: По умолчанию используются залитые иконки из компонента. Если нужна другая иконка — напишите в Поддержку Дизайна DS. Подробнее — блок «Контент»: {{Pixso URL NotificationOrToast Doc Block 3}}

**Q: Можно ли объединить несколько уведомлений?**
A: Да. Если нужно показать количество выполненных пунктов, уведомления объединяют в пару — с успехом и неудачей. Подробнее — блок «Объединение уведомлений»: {{Pixso URL NotificationOrToast Doc Block 6}}

**Q: Откуда брать тексты уведомлений и тостов?**
A: См. редполитику: Уведомления и тосты.

**Q: Нужен новый кейс тоста — что делать?**
A: Напишите в круг поддержки дизайна, чтобы обсудить новый Toast.
