# Лог ошибок

Лог ошибок — журнал ошибок, предупреждений, инфо-сообщений и сообщений об успехе, возникающих в таблице. Гайд описывает, в каких интерфейсах платформы лог используется сейчас и в чём особенности каждого случая.

---

## Где используется

Сейчас лог ошибок используется в трёх интерфейсах платформы. В каждом из них лог решает свою задачу и по-своему отображает сообщения.

### В интерфейсе AE

Фиксирует логи таблицы. Располагается в выдвижной панели снизу.

Особенность: запись лога представляет собой указание на ячейку, к которой сформировано сообщение.

### В интерфейсе Инициатив

Фиксирует логи таблицы. Располагается в сплите, вызывается по кнопке в шапке таблицы.

Особенности:

- Сообщение выводится без описания ошибки.
- Есть ссылка на ячейку — по ней пользователь переходит к ячейке, к которой сформировано сообщение.
- В названии группы сообщений указано, к какому разделу относится группа (например, «Кросс-заявки», «Импорт инициатив», «Инициативы. Общее»).

### В интерфейсе UDU

Фиксирует логи процесса загрузки и проверки файлов. Располагается в модальном окне, вызывается по кнопке в интерфейсе прикладного продукта.

Особенности:

- Сообщения не привязаны к ячейке таблицы: лог относится к загрузке и проверке файлов.
- Заголовки групп сообщений не указывают файл, к которому относятся сообщения.

Подробнее — в документации гайда, блок «Где используется»: {{Pixso URL GuideErrorLog Doc Block 1}}

---

## Связанные компоненты

- **Modal** — модальное окно, в котором лог ошибок открывается в интерфейсе UDU.
- **Таблица Canvas** — лог фиксирует логи таблицы: записи указывают на ячейки, а сообщения группируются по разделам.

## FAQ

### Для дизайнеров

**Q: Что такое лог ошибок?**
A: Это журнал ошибок, предупреждений, инфо-сообщений и сообщений об успехе, возникающих в таблице.

**Q: В каких интерфейсах сейчас используется лог ошибок?**
A: В интерфейсах AE, Инициатив и UDU. Подробнее — блок «Где используется»: {{Pixso URL GuideErrorLog Doc Block 1}}

**Q: Где располагается лог ошибок в каждом из интерфейсов?**
A: В AE — в выдвижной панели снизу; в Инициативах — в сплите, по кнопке в шапке таблицы; в UDU — в модальном окне, по кнопке в интерфейсе прикладного продукта. Подробнее — блок «Где используется»: {{Pixso URL GuideErrorLog Doc Block 1}}

**Q: Привязаны ли сообщения лога к ячейкам таблицы?**
A: В AE запись лога указывает на ячейку, к которой сформировано сообщение; в Инициативах есть ссылка для перехода к этой ячейке; в UDU лог относится к загрузке и проверке файлов и с ячейками таблицы не связан. Подробнее — блок «Где используется»: {{Pixso URL GuideErrorLog Doc Block 1}}

**Q: Как группируются сообщения в логе?**
A: В Инициативах название группы указывает раздел, к которому относятся сообщения (например, «Кросс-заявки», «Импорт инициатив», «Инициативы. Общее»); в UDU заголовки групп файл не указывают. Подробнее — блок «Где используется»: {{Pixso URL GuideErrorLog Doc Block 1}}
