# Гайд по реестру

Реестр — это список объектов одного типа и их свойств. Чаще всего он представлен в виде таблицы.

---

## Описание

Реестр решает несколько задач:

- Хранит записи.
- Показывает их списком.
- Позволяет искать, фильтровать и сортировать.
- Позволяет добавлять, редактировать и удалять элементы.

Пример реестра в виде таблицы — в документации гайда, блок «Описание»: {{Pixso URL GuideRegistry Doc Block 1}}

## Механика

### Создание таблицы

Используем готовый пример «Актуальная таблица» ({{Pixso URL ActualTable}}) либо собираем реестр самостоятельно из компонентов таблицы.

Стараемся не использовать горизонтальный скролл — работаем с шириной столбцов и их количеством.

#### Выравнивание ячеек

**Center** подходит, когда:

- Все ячейки колонки гарантированно однострочные: короткий текст, числа, бейджи, чипы, иконки, аватары.
- Аккуратные «карточные» таблицы и компактные KPI/дашборд-таблицы с небольшим объёмом текста.

Center — дефолт компонента. Оставляем его, если ни одна колонка не может стать вариативно-многострочной.

**Top** подходит, когда:

- В колонке может встречаться многострочный текст: описания, комментарии, длинные наименования.
- Включён режим переноса по словам (wrap + top — рекомендуемая пара).
- В таблице соседствуют короткие и длинные значения: при center короткие ячейки «прыгают» по центру относительно соседей.
- Высота строк непредсказуема или больше 2 строк — top обязателен.

Пример таблицы, собранной из компонентов, — в документации гайда, блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

### Просмотр объекта

Просмотр объекта реестра осуществляется в сплит-вью либо на новой странице.

Ссылки в ячейках оформляем так:

- Внешняя ссылка — IconButton с пиктограммой OpenOutline.
- Текстовая ссылка — цвет textAccent без подчёркивания; подчёркивание появляется по наведению (hover).

Пример открытия сущности реестра в сплит-вью — в документации гайда, блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

## Альтернативные представления реестра

Кроме таблицы, реестр может быть представлен в других форматах.

### Стэк свёрнутых таблиц

Таблицы отображаются свёрнутыми в стэк. Каждая таблица раскрывается, как аккордеон.

Пример стэка свёрнутых таблиц — в документации гайда, блок «Альтернативные представления реестра»: {{Pixso URL GuideRegistry Doc Block 3}}

### Плитка

Реестр представляется плиткой карточек. Используем компонент Task Card (существует только в дизайне).

Пример представления плиткой — в документации гайда, блок «Альтернативные представления реестра»: {{Pixso URL GuideRegistry Doc Block 3}}

## FAQ

### Для дизайнеров

**Q: Как собрать реестр в виде таблицы?**
A: Взять готовый пример «Актуальная таблица» либо собрать таблицу самостоятельно из компонентов таблицы. Подробнее — блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

**Q: Нужен ли в реестре горизонтальный скролл?**
A: Стараемся его не использовать — работаем с шириной столбцов и их количеством. Подробнее — блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

**Q: Когда выравнивать ячейки по center, а когда по top?**
A: Center — когда все ячейки колонки гарантированно однострочные (короткий текст, числа, бейджи, иконки) и в аккуратных карточных / KPI-таблицах; это дефолт компонента. Top — когда возможен многострочный текст, включён перенос по словам, соседствуют короткие и длинные значения или высота строк больше 2 строк. Подробнее — блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

**Q: Как оформить ссылку в ячейке?**
A: Внешняя ссылка — IconButton с пиктограммой OpenOutline; текстовая ссылка — цвет textAccent без подчёркивания, подчёркивание появляется по наведению. Подробнее — блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

**Q: Как открыть объект реестра для просмотра?**
A: Объект открывается в сплит-вью либо на новой странице. Подробнее — блок «Механика»: {{Pixso URL GuideRegistry Doc Block 2}}

**Q: Какие есть альтернативные представления реестра, кроме таблицы?**
A: Реестр можно показать стэком свёрнутых таблиц (раскрываются, как аккордеон) или плиткой карточек. Подробнее — блок «Альтернативные представления реестра»: {{Pixso URL GuideRegistry Doc Block 3}}

**Q: Как представить реестр плиткой?**
A: Используем компонент Task Card (существует только в дизайне). Подробнее — блок «Альтернативные представления реестра»: {{Pixso URL GuideRegistry Doc Block 3}}
