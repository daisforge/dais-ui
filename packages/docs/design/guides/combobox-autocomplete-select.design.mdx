# Combobox, Autocomplete или Select

Гайд помогает выбрать компонент: **Select**, **Combobox** или **Autocomplete**. Бонусом — раздел про **Search** и его два вида поиска. По каждому компоненту описано, когда его использовать, когда — нет, и его особенности. Ключевые ориентиры выбора: количество вариантов, нужен ли поиск, можно ли добавлять свои значения и нужен ли множественный выбор.

---

## Select

Раскрывающийся список для выбора значения из заранее известного набора вариантов. Поддерживает и единичный выбор (одно значение), и множественный (несколько значений из списка).

Визуал компонента — в документации гайда, блок «Select»: {{Pixso URL ComboAutoSelect DocSelect Block 1}}

### Когда использовать

Раскрывающийся список подходит для выбора одного значения из 2–25 вариантов:

- при заполнении форм — например, выбор месяца;
- при переключении состояний — например, фильтры;
- при выборе предустановленных настроек — например, выбор вертикали или часового пояса.

Типичные кейсы — в документации гайда, блок «Когда использовать»: {{Pixso URL ComboAutoSelect DocSelect Block 2}}

### Когда не используем

- Если значений больше 25 — используйте Combobox: в нём есть поиск по значениям.
- Если нужен поиск и добавление нового значения в список — используйте Combobox.
- Если нужен поиск и выбор одного значения для полей, где пользователь примерно знает список значений (Город, Область и т. п.), — используйте Autocomplete.

Подробнее — в документации гайда, блок «Когда не используем»: {{Pixso URL ComboAutoSelect DocSelect Block 3}}

### Особенности

- Внутри Select — полноценное текстовое поле (триггер): настраивается так же, как обычное поле, и имеет те же статусы (как и в Autocomplete, и в Combobox).
- Рекомендуем настраивать сначала обёртку компонента, а потом триггер.
- При включении лейбла в триггере положение выпадающего списка регулируется паддингами соответствующего слоя.

Подробнее — в документации гайда, блок «Особенности»: {{Pixso URL ComboAutoSelect DocSelect Block 4}}

## Combobox

Поле ввода, которое позволяет выбрать значение из выпадающего списка или добавить в список новое. Поддерживает единичный и множественный выбор; введённое новое значение добавляется в список.

Визуал компонента — в документации гайда, блок «Combobox»: {{Pixso URL ComboAutoSelect DocCombo Block 1}}

### Когда использовать

- Для выбора значения из справочника.
- Для добавления своего значения, которого нет в справочнике.
- Когда значений в справочнике больше 25.

Типичные кейсы — в документации гайда, блок «Когда использовать»: {{Pixso URL ComboAutoSelect DocCombo Block 2}}

### Когда не используем

- Если значений меньше 25 — используйте Select.
- Если нужен поиск и выбор одного значения для полей, где пользователь примерно знает список значений (Город, Область и т. п.), — используйте Autocomplete.

Пример неправильного использования (когда подошёл бы Select) — в документации гайда, блок «Когда не используем»: {{Pixso URL ComboAutoSelect DocCombo Block 4}}

### Особенности

- При клике в поле выводится весь список значений.
- При вводе список сужается до вариантов, соответствующих написанному (например, «Севе» → «Северная Америка»).
- В множественном выборе есть три варианта отображения выбранных значений:
  - каждое значение отдельным чипом (со скроллом внутри поля);
  - один чип «Выбрано N» — при наведении показывает тултип с полным списком;
  - чипы с крестиком для удаления или без него.
- Важно: область удаления чипа настраивается — чип удаляется либо по клику на весь чип, либо только по клику на крестик. Точное имя настройки — в Storybook или в чате поддержки ДС.
- Механику показа выбранных значений в тултипе планируется добавить (Q4).

Подробнее — в документации гайда, блок «Особенности»: {{Pixso URL ComboAutoSelect DocCombo Block 3}}

## Autocomplete

Поле ввода с выбором значения из выпадающего списка по мере ввода данных. Работает как поиск-подсказка по списку: новые значения не добавляются. Поддерживается только единичный выбор — множественный выбор чипами недоступен.

Визуал компонента — в документации гайда, блок «Autocomplete»: {{Pixso URL ComboAutoSelect DocAuto Block 1}}

### Когда использовать

- Для выбора значения из справочника поиском через ввод части слова (без иконки лупы).
- Когда выбрать можно только одно значение.

Типичные кейсы — в документации гайда, блок «Когда использовать»: {{Pixso URL ComboAutoSelect DocAuto Block 2}}

### Когда не используем

- Если для единичного выбора нужно дать возможность посмотреть выпадающий список до ввода — используйте Combobox.
- Если требуется множественный выбор значений — используйте Combobox.
- Если нужен выбор значения из справочника без поиска и список меньше 25 — используйте Select.

Примеры — в документации гайда, блок «Когда не используем»: {{Pixso URL ComboAutoSelect DocAuto Block 4}}

### Особенности

- Список значений появляется по мере ввода, а не по клику на пустое поле. Поэтому Autocomplete подходит для полей, где пользователь примерно знает значение: например, для поля «Город» при вводе «Мо» в списке появятся значения, начинающиеся на «Мо» («Москва» и т. п.).

Подробнее — в документации гайда, блок «Особенности»: {{Pixso URL ComboAutoSelect DocAuto Block 3}}

## Search

Search включает два вида поиска — на базе текстового поля (Textfield) или на базе Autocomplete. Подсветку совпадений реализует продукт; пример подсветки — в документации. Более подробная документация — в файле компонента Search: {{Pixso URL Search Doc Block 1}}

Визуал — в документации гайда, блок «Search»: {{Pixso URL ComboAutoSelect DocSearch Block 1}}

### Когда использовать

**Textfield Search** — когда не нужно подсказывать пользователю прямо в поле, какое значение можно выбрать. Используем для компонентов Tree, List или кастомных списочных данных. Такой поиск можно «прикрутить» к другим элементам на странице — List, Tree или кастомному списку. Например, поиск по значениям в List: нужно найти что-то из списка и показать это в том же списке — в таком случае используем Textfield Search.

**Autocomplete Search** — когда нужно подсказывать пользователю прямо в поле, какое значение выбрать или вписать своё. Используем для карточек и сущностей, отличных от списка (обычно с большим набором данных внутри). Например, если в карточке есть город и нужно применить поиск по городу, полезно давать подсказку: при вводе «Мо» предлагать «Москва», «Можайск», «Моздок» и т. п. Autocomplete Search предлагает искать по заранее заданным значениям или вписать своё.

Подробнее — в документации гайда, блок «Когда использовать»: {{Pixso URL ComboAutoSelect DocSearch Block 2}}

## Связанные компоненты

- **Select** — раскрывающийся список для выбора значения из заранее известного набора (2–25 вариантов), единичный или множественный выбор.
- **Combobox** — поле ввода с выбором из списка и добавлением новых значений; единичный и множественный выбор; для наборов больше 25 значений.
- **Autocomplete** — поле ввода с поиском-подсказкой по мере ввода; единичный выбор без добавления новых значений.
- **Search** — компонент поиска с двумя видами: на базе текстового поля (Textfield Search) и на базе Autocomplete (Autocomplete Search).

## FAQ

### Для дизайнеров

**Q: Сколько вариантов в наборе — и какой компонент выбрать?**
A: До 25 вариантов без поиска — Select. Больше 25 или нужен поиск по значениям — Combobox. Подробнее — блоки «Когда использовать»: {{Pixso URL ComboAutoSelect DocSelect Block 2}} и {{Pixso URL ComboAutoSelect DocCombo Block 2}}

**Q: Нужен множественный выбор — что взять?**
A: Select или Combobox — оба поддерживают выбор нескольких значений; Combobox ещё и добавляет свои значения. Autocomplete работает только с единичным выбором. Подробнее — блок «Autocomplete · Когда не используем»: {{Pixso URL ComboAutoSelect DocAuto Block 4}}

**Q: Нужно, чтобы пользователь мог добавить своё значение, — какой компонент?**
A: Combobox: он позволяет ввести новое значение, которое добавится в список. Подробнее — блок «Combobox»: {{Pixso URL ComboAutoSelect DocCombo Block 1}}

**Q: Пользователь примерно знает значение (Город, Область) и нужен поиск с выбором одного значения — что использовать?**
A: Autocomplete: список-подсказка появляется по мере ввода. Подробнее — блок «Autocomplete · Когда использовать»: {{Pixso URL ComboAutoSelect DocAuto Block 2}}

**Q: Как показать несколько выбранных значений в Combobox?**
A: Тремя способами: каждое значение отдельным чипом (со скроллом внутри поля); один чип «Выбрано N» с тултипом-списком при наведении; чипы с крестиком удаления или без него. Подробнее — блок «Combobox · Особенности»: {{Pixso URL ComboAutoSelect DocCombo Block 3}}

**Q: Как настроить поле-триггер у Select?**
A: Внутри Select — полноценное текстовое поле (триггер) с теми же настройками и статусами, что и у обычного поля. Настраивайте сначала обёртку компонента, потом триггер; при включённом лейбле положение списка регулируется паддингами слоя. Подробнее — блок «Select · Особенности»: {{Pixso URL ComboAutoSelect DocSelect Block 4}}

**Q: Когда использовать Textfield Search, а когда Autocomplete Search?**
A: Textfield Search — когда подсказки в поле не нужны (поиск по Tree, List или кастомному списку). Autocomplete Search — когда нужно подсказывать значения прямо в поле (карточки и сущности с большим набором данных). Подробнее — блок «Search · Когда использовать»: {{Pixso URL ComboAutoSelect DocSearch Block 2}}

**Q: Где найти полную документацию по Search?**
A: В файле компонента Search: {{Pixso URL Search Doc Block 1}}
