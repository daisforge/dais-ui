# Шаблоны Empty State

Гайд о готовых шаблонах пустых состояний дизайн-системы. Покрывает две группы: полноэкранные страницы ошибок (ErrorPage) с заложенными 3D-иллюстрациями и пустые состояния внутри контента.

---

## Страницы ошибок (ErrorPage)

Пустые состояния с заложенными 3D-иллюстрациями для каждого вида ошибок.

На FinAI используется 2 варианта текстов для экранов ошибок: без кода ошибки — для бизнес-пользователей, с кодом — для разработчиков. Если код ошибки важен для целевой аудитории продукта, используем текст с кодом; если не важен — без кода.

Заложены шаблоны для следующих ошибок:

- 400 — Bad Request
- 401 — Unauthorized
- 403 — Forbidden
- 404 — Not Found
- 409 — Conflict
- 500 — Internal Server Error
- 502 — Bad Gateway
- 503 — Service Unavailable
- Неопознанная ошибка

Все шаблоны страниц ошибок с 3D-иллюстрациями и текстами — в документации гайда, блок «Error Pages»: {{Pixso URL EmptyStateTemplates}}. Открыть ErrorPage в Storybook: {{Storybook URL ErrorPage}}

---

## Пустые состояния (Empty States)

Шаблоны пустых состояний внутри контента покрывают типовые ситуации:

- Нет контента
- Нет результатов
- Нет доступа / Нужен доступ
- Не удалось загрузить
- Другие ошибки

Готовые тексты и 3D-иллюстрации для каждой ситуации показаны в документации гайда, блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}

## Рекомендации по использованию шаблонов

- В дизайне это один компонент — Empty State (с переключением типа: пустое состояние или состояние ошибки), а в коде — два разных: EmptyState и ErrorPage.
- Шаблоны носят рекомендательный характер. При необходимости их можно дополнять контентом в зависимости от контекста продукта и места его применения.
- Текст, взятый в [квадратные скобки], означает динамические значения, которые необходимо заменить под контекст страницы.
- 3D-элементы меняются в зависимости от контекста, но используем только предложенные в компоненте. Добавление новых — только через дизайн-систему; если нужна новая иллюстрация, обратитесь в поддержку дизайна дизайн-системы.

Рекомендации показаны рядом с шаблонами — в документации гайда, блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}

## FAQ

### Для дизайнеров

**Q: Когда использовать текст ошибки с кодом, а когда без?**
A: С кодом — для разработчиков, без кода — для бизнес-пользователей. Ориентируемся на целевую аудиторию продукта: если код ошибки важен для неё, показываем его. Подробнее — блок «Error Pages»: {{Pixso URL EmptyStateTemplates}}

**Q: Какие страницы ошибок уже заложены в шаблоны?**
A: 400, 401, 403, 404, 409, 500, 502, 503 и «Неопознанная ошибка» — все с 3D-иллюстрациями. Подробнее — блок «Error Pages»: {{Pixso URL EmptyStateTemplates}}

**Q: Какие пустые состояния есть в шаблонах?**
A: Нет контента, Нет результатов, Нет доступа / Нужен доступ, Не удалось загрузить, Другие ошибки. Примеры — блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}

**Q: Можно ли менять 3D-иллюстрации?**
A: 3D-элементы меняются в зависимости от контекста, но используем только предложенные в компоненте. Добавление новых — только через дизайн-систему. Подробнее — блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}

**Q: Что означает текст в квадратных скобках в шаблонах?**
A: Это динамические значения, которые нужно заменить под контекст страницы. Подробнее — блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}

**Q: Обязательно ли следовать шаблонам точно?**
A: Нет, шаблоны носят рекомендательный характер — их можно дополнять контентом под контекст продукта и место применения. Подробнее — блок «Шаблоны пустых состояний»: {{Pixso URL EmptyStateTemplates Doc Block 1}}
