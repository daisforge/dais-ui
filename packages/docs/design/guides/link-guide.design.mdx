# Гайд Link. Как использовать ссылки

Link — компонент ссылки в тексте. Гайд описывает, как обозначить ссылку в макете Pixso.

---

## Как показать ссылку в Pixso?

Чтобы обозначить ссылку в макете:

- Раздетачьте цвет текста ссылки, перекрасьте нужный фрагмент текста и оставьте комментарий для разработки.

Подробнее — в документации гайда, блок «Как показать ссылку в Pixso?»: {{Pixso URL LinkGuide Doc Block 1}}

## FAQ

### Для дизайнеров

**Q: Как обозначить ссылку в макете Pixso?**
A: Раздетачьте цвет текста ссылки, перекрасьте нужный фрагмент и оставьте комментарий для разработки. Подробнее — в документации гайда, блок «Как показать ссылку в Pixso?»: {{Pixso URL LinkGuide Doc Block 1}}

**Q: Где располагать ссылку на странице?**
A: В правом нижнем углу с отступом 40px от краёв страницы. Подробнее — в документации гайда, блок «Расположение»: {{Pixso URL LinkGuide Doc Block 2}}
