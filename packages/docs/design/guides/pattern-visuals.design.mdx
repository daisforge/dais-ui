# Общий визуал в паттернах

Гайд собирает визуальные решения для паттернов, на которые в дизайн-системе нет отдельного компонента: как подбирать размеры компонентов на экране, как оформлять блоки внутри страницы (заливка контейнера и отступы) и как добавлять визуальный стиль.

---

## Компоненты на экране

### Размеры компонентов

Компоненты из одной группы желательно брать одинакового размера.

Примеры — в документации гайда, блок «Компоненты на экране»: {{Pixso URL VisualsGuide Doc Block 1}}

---

## Блоки внутри страницы

### Заливка контейнера

Компоненты на белом фоне оборачиваются в лэйаут с заливкой `surfaceSolidPrimary`.

### Отступы

- Отступ от края центральной части до блока — 32px.
- Отступ внутри контейнера — 12px (плюс подложка).
- Отступы между блоками в контейнере — 24px.
- Отступы между компонентами в блоках — 12px.

Пример разметки блоков и отступов — в документации гайда, блок «Блоки внутри страницы»: {{Pixso URL VisualsGuide Doc Block 2}}

---

## Визуальный стиль

### 3D-шейпы

Если на экране требуется добавить больше визуального стиля, можно использовать градиенты из группы «Дата» и 3D-шейпы.

**Важно:** Чтобы добавить в интерфейс иллюстрации из 3D-шейпов и градиентов, обратитесь к дизайнеру команды дизайн-системы и заведите задачу в Jira: опишите продукт и экран, приложите ссылку на макеты в Pixso.

Пример — в документации гайда, блок «Визуальный стиль»: {{Pixso URL VisualsGuide Doc Block 3}}

---

## Связанные компоненты

- **Layout** — лэйаут, в который оборачиваются компоненты на белом фоне (заливка `surfaceSolidPrimary`).
- **Space & Radius** — отступы и радиусы, на токенах которых строится разметка блоков и контейнеров.
- **Analytical Widget** — виджет, в оформлении которого применяются градиенты и 3D-шейпы.

## FAQ

### Для дизайнеров

**Q: Как подобрать размеры компонентов на экране?**
A: Компоненты из одной группы желательно брать одинакового размера. Подробнее — в документации гайда, блок «Компоненты на экране»: {{Pixso URL VisualsGuide Doc Block 1}}

**Q: Как оформить блок с компонентами на белом фоне?**
A: Обернуть компоненты в лэйаут с заливкой `surfaceSolidPrimary`. Подробнее — в документации гайда, блок «Блоки внутри страницы»: {{Pixso URL VisualsGuide Doc Block 2}}

**Q: Какие отступы использовать между блоками и компонентами?**
A: От края центральной части до блока — 32px, внутри контейнера — 12px (плюс подложка), между блоками в контейнере — 24px, между компонентами в блоках — 12px. Подробнее — в документации гайда, блок «Блоки внутри страницы»: {{Pixso URL VisualsGuide Doc Block 2}}

**Q: Как добавить на экран больше визуального стиля?**

Подробнее — в документации гайда, блок «Визуальный стиль»: {{Pixso URL VisualsGuide Doc Block 3}}
