# Task Card

Task Card это карточка задачи с минимальным набором информации и кнопками действия. Платформа: Web.

Карточка собрана сверху вниз: статус задачи, тег с продуктом и дата, заголовок Title, описание Description, имя исполнителя и дата «от DD.MM.YYYY». Внизу карточки кнопки действий.

## Размеры и отступы Task Card

- Ширина Task Card фиксированная (Fixed): 292 px
- Высота Task Card фиксированная (Fixed): 252 px
- Внутренний отступ: 8 px сверху, 4 px слева, справа и снизу
- Внешний отступ на странице и между карточками по горизонтали и вертикали: 20 px на экране шириной 1920 px
- На экранах шириной меньше 1280 px внешние отступы уменьшаются до 16 px

## Общие настройки Task Card

### Selected: выбранная карточка

Selected включает и выключает выбранное состояние карточки. Выбранным состоянием показываем, с какой карточки открылся Split-view. Подробнее в разделе «Просмотр детальной информации карточки».

### Hover (check): чекбокс для массовых действий

Hover (check) включает и выключает чекбокс для массовых действий. В интерфейсе чекбокс появляется при наведении на карточку.

> **💡 Подсказка:** чтобы показать в макете отмеченный чекбокс, откройте в слоях компонент чекбокса и включите в нём Value = Single или Value = Multiple.

### Name: имя исполнителя

Name включает и выключает имя исполнителя. Имя стоит под описанием, рядом с датой «от DD.MM.YYYY».

## Настройки Urgent Date в Task Card

Urgent Date это дата с иконкой календаря в правом верхнем углу карточки.

### Urgent: горящая дата

Urgent переключает дату в режим «горящей».

### Text: текст даты

Text задаёт текст даты по маске DD.MM.YYYY. Настройка нужна, чтобы текст не слетал в Pixso.

## Настройки Status в Task Card

### View: статус задачи

View переключает статус задачи: Новая, В работе, Выполнено. Название статуса стоит вверху карточки.

> **💡 Подсказка:** рекомендуем писать в теге два слова и предлог. Если так не получается или слова слишком длинные, обрезайте текст многоточием.

## Механика Task Card

Механика кнопок действий, массовых действий и просмотра детальной информации карточки.

### Кнопки «Согласовать» и «Отклонить»

Задачу можно согласовать или отклонить. По клику на кнопку открывается модальное окно этого действия. Статус задачи становится «Согласовано» или «Отклонено».

> **⚠️ Важно:** при отклонении задачи комментарий обязателен.

В окне «Отклонить задачу?» обязательное поле «Комментарий» и загрузка документа-обоснования: файл до 50 МБ в форматах pdf, doc, docx, xlsx. Кнопки окна: «Отменить» и «Отклонить».

В окне «Согласовать задачу?» поле «Комментарий» заполняется по желанию. Кнопки окна: «Отменить» и «Согласовать».

### Массовые действия

При наведении на карточку появляется Checkbox. Когда пользователь отмечает чекбокс карточки, для выбора доступны задачи этого же типа. Внизу экрана появляется Mass Actions со списком действий для этого типа задач.

Например, пользователь отметил чекбокс у карточки со статусом «В работе». Чекбоксы появятся только у карточек этого же типа. У карточек со статусом «Архив» и «Новая» чекбоксы скрыты.

## Маппинг: дизайн → код

Компонента Task Card в коде библиотеки dais-ui нет.

## Связанные компоненты

- **[Split-view](?path=/docs/композиции-splitview-для-дизайнеров--docs)**: открывается справа по клику на карточку. Карточку, с которой он открылся, отмечаем свойством Selected
- **[Mass Actions](?path=/docs/локальные-компоненты-massactions-для-дизайнеров--docs)**: появляется внизу экрана, когда отмечен чекбокс карточки, и показывает действия для этого типа задач
- **Checkbox**: чекбокс для массовых действий в Hover (check). Отмеченный чекбокс в макете: Value = Single или Value = Multiple
- **Tooltip**: полный текст длинного Title, Description и тега при наведении
- **Modal**: окна «Согласовать задачу?» и «Отклонить задачу?»
- **Badge**: тег с продуктом в карточке
- **Button**: кнопки действий «Согласовать», «Отклонить», «Перейти», «Выполнить»

## FAQ

### Для дизайнеров

**Q: Какого размера Task Card?**
A: Ширина и высота фиксированные (Fixed): 292 px и 252 px.

**Q: Какие отступы ставить между карточками задач?**
A: 20 px по горизонтали и вертикали на экране шириной 1920 px. На экранах меньше 1280 px отступы уменьшаются до 16 px.

**Q: Как показать в макете отмеченный чекбокс на карточке?**
A: Включите Hover (check), откройте в слоях компонент чекбокса и включите в нём Value = Single или Value = Multiple.

**Q: Сколько строк текста помещается в карточке?**
A: Максимум 6 строк: 3 в Title и 3 в Description. Если текста больше, он обрезается многоточием, полный текст показываем в Tooltip при наведении.

**Q: Что делать с длинным названием продукта в теге?**
A: Рекомендуем два слова и предлог. Если так не получается, текст обрезается многоточием, полное название показываем в Tooltip при наведении.

**Q: Что происходит, когда пользователь отклоняет задачу?**
A: Открывается окно «Отклонить задачу?», комментарий в нём обязателен. Статус задачи становится «Отклонено».

**Q: Как показать, с какой карточки открылся Split-view?**
A: Включите у карточки свойство Selected.

**Q: У каких карточек появляются чекбоксы для массовых действий?**
A: Чекбокс появляется при наведении на карточку. После выбора первой карточки чекбоксы появляются только у карточек этого же типа.

**Q: Как переключить статус задачи на карточке?**
A: Выберите статус в свойстве View группы Status: Новая, В работе или Выполнено.

### Для разработчиков

**Q: Есть ли Task Card в библиотеке dais-ui?**
A: Нет. Верстайте по макету и этой странице.

**Q: Какие размеры и отступы у Task Card?**
A: Ширина 292 px и высота 252 px, обе фиксированные. Внутренний отступ 8 px сверху, 4 px слева, справа и снизу. Внешний отступ на странице и между карточками 20 px на экране 1920 px и 16 px на экранах меньше 1280 px.

**Q: Как обрезать длинный текст в Task Card?**
A: Title и Description занимают до 3 строк каждый, длинный текст обрезается многоточием. Длинное название в теге тоже обрезается многоточием. Полный текст показываем в Tooltip при наведении.

**Q: Что делают кнопки действий в Task Card?**
A: «Согласовать» и «Отклонить» открывают модальное окно действия, при отклонении комментарий обязателен, статус становится «Согласовано» или «Отклонено». «Перейти» ведёт в сторонний сервис. «Выполнить» выполняет задачу и меняет статус на «Выполнено».

**Q: Как работает выбор карточек для массовых действий?**
A: Чекбокс появляется при наведении на карточку. После выбора чекбоксы показываем только у карточек того же типа, внизу экрана появляется Mass Actions с действиями для этого типа.

**Q: Что происходит по клику на карточку?**
A: Справа открывается Split-view, карточка переходит в выбранное состояние.
