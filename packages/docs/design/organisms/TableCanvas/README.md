# Таблица Canvas

Документация компонента таблицы Canvas готовится в Figma и будет добавляться сюда в формате MDX по мере готовности (по той же конвенции `*.design.mdx` / `*.mdx`, см. [CONVENTIONS.md](../CONVENTIONS.md)).

Планируемые / готовящиеся разделы: размеры ячеек, расположение и выравнивание текста, пустые состояния и ошибки, полноэкранный режим, тулз-меню, режим редактирования, поиск, чекбоксы и массовые действия, закрепление, вложенность и иерархия, добавление и удаление строк, итоговые строки, раскрытие деталей строки, контекстное меню (ПКМ), переключатель Ключ/Текст, табы, действия с колонками, перенос текста, обновление данных, сортировка.
