# Drawer

Выдвижная панель, которая по умолчанию появляется от правой границы экрана и занимает всю его высоту. Drawer сохраняет контекст основной страницы и показывает дополнительную информацию или функционал, который не должен быть постоянно на виду.

Визуал: {{Pixso URL DrawerDF Doc Block 1}}

---

## Когда использовать

Используйте Drawer, когда нужно сохранить контекст страницы и показать большой объём данных или функционала: просмотр данных сущности, фильтры, разделение информации на несколько блоков.

Типичные кейсы:

- Просмотр данных сущности.
- Фильтр.

## Когда не используем

Старайтесь не использовать Drawer для создания новых сущностей, подтверждений и коротких сообщений — для этих сценариев подходит [Modal]({{Storybook URL ModalDF}}), которое фокусирует внимание на одном действии. Drawer выбирают там, где важно не терять контекст основного экрана.

Сравнение сценариев Modal и Drawer: {{Pixso URL DrawerDF DocGuide Block 1}}

## Анатомия

Drawer объединяет три части, каждую из которых можно настраивать отдельно:

1. **Шапка (Header)** — заголовок, подзаголовок, бейдж, правый блок действий и нижний блок (табы). Не скроллится, имеет такой же залитый фон, как панель.
2. **Тело (Body)** — основная область с контентом. По умолчанию это кастомный блок, который заменяется на любой компонент через Instance swap.
3. **Подвал (Footer)** — кнопки действий (только в цельной версии Solid). Не скроллится, залитый фон как у панели.

Если шапку и подвал нужно сделать подвижными (скроллящимися), их добавляют в тело и отключают как отдельные части.

Анатомия: {{Pixso URL DrawerDF Doc Block 1}}

### Версии

| Версия | Описание |
|---|---|
| **Solid (цельный)** | Единая панель с шапкой, телом и подвалом. |
| **Separated (сепарированный)** | Панель из нескольких контентных блоков (колонок); подвал недоступен. |

### Ориентация

Ориентация задаётся самостоятельно:

- **Вертикальная** — панель выезжает от левой или правой границы и занимает всю высоту окна.
- **Горизонтальная** — панель выезжает от верхней или нижней границы.

| Параметр | Значение |

### Колонки в сепарированной версии

В версии Separated настраивается число контентных блоков. По умолчанию первый и третий блоки подстраиваются под содержимое (Hug), центральный — растягивается (Fill). Эти настройки можно менять. При добавлении третьего блока увеличьте общую ширину панели.

## Состояния

- **Закрыто / Открыто** — панель скрыта или выдвинута от границы экрана.
- **Модальный режим** — панель с подложкой; скролл и фокус основной страницы заблокированы.
- **Немодальный режим** — панель без подложки; скролл и фокус страницы не блокируются.
- **Hover / Active / Focus** — состояния интерактивных элементов внутри панели.

---

## Механика и взаимодействия

- **Затемнение фона.** Если панель накладывается поверх затемнённого экрана, используются токены цвета из группы Overlay.
- **Модальный и немодальный режимы.** В модальном режиме появляется подложка, скролл и фокус основной страницы блокируются. В немодальном — подложки нет, страница остаётся доступной.
- **Открытие во фрейме.** Панель можно открыть как на всём окне, так и внутри отдельного контейнера (фрейма).
- **Кнопка «Назад».** Включается в настройках и отображается поверх кнопки «закрыть»: пользователь сначала может вернуться на предыдущий шаг, а затем при необходимости закрыть панель.
- **Закрытие.** Крестик, клавиша Esc, клик по подложке.
- **Анимация.** Можно задать собственную анимацию открытия и закрытия панели.

## Краевые сценарии

- **Сепарированные колонки (Hug / Fill).** Крайние блоки по умолчанию подстраиваются под содержимое, центральный — растягивается; поведение настраивается, и ширину локального компонента нужно согласовать с шириной блока.
- **Подвижные шапка и подвал.** По умолчанию шапка и подвал зафиксированы и не скроллятся; чтобы сделать их подвижными, их переносят в тело панели.
- **Кастомный блок вместо кнопок.** В правом блоке шапки вместо кнопок можно разместить кастомный блок; рекомендуемая высота — 32px.

## Маппинг: дизайн → код

В коде стилизованная панель — компонент `DrawerDF` (обёртка над базовой выдвижной панелью дизайн-системы). Для работы панели требуется обёртка `PopupProvider`. Базовые поведения наследуются от базовой панели (`DrawerProps`).

| Свойство в дизайне | Проп / компонент в коде | Значения | Примечание |
|---|---|---|---|
| Открытие / закрытие | `opened`, `onClose` | boolean / callback | Базовые пропсы. |
| Ориентация / расположение | `placement` | left / right / top / bottom | Вертикальная — left / right (в дизайне по умолчанию справа); горизонтальная — top / bottom. |
| Режим (модальный / немодальный) | `asModal` | boolean | `true` — подложка + блокировка scroll и фокуса; `false` — без подложки. |
| Подложка / размытие | `withBlur` | boolean | — |
| Закрытие по Esc / по клику на подложку | `closeOnEsc`, `closeOnOverlayClick` | boolean | — |
| Размер | `width`, `height` | CSS-размер | Минимальная ширина — 576px. |
| Смещение | `offset` | [x, y] | — |
| Открытие во фрейме | `frame` | id / ref контейнера | Панель в отдельном контейнере, а не на всём окне. |
| Анимация | `animationInfo` | `{ enter, exit }` | Анимации открытия и закрытия. |
| Версия Solid / Separated | состав `main` | один `DrawerDF.Content` или массив | Массив контент-блоков формирует колонки (сепарированная версия). |
| Шапка | `DrawerDF.Header` (`title`, `subTitle`, `badge`, `rightBlock`, `footerBlock`); базовый `DrawerHeader` (`hasClose`, `closePlacement`, `actions`, `onClose`) | — | `footerBlock` — нижний блок шапки (табы). |
| Контент / колонка | `DrawerDF.Content` (`fixedWidth`); базовый `DrawerContent` | — | `fixedWidth` фиксирует ширину колонки. |
| Подвал | `DrawerDF.Footer`; базовый `DrawerFooter` | — | Только в Solid. |
| Кнопка «Назад» | `showBackButton`, `onBackClick` / `DrawerDF.BackIconButton` | boolean / callback | Отображается поверх кнопки «закрыть». |
| Кнопка-меню (троеточие) | `DrawerDF.DotsIconButton` | `dropdownProps`, `iconSize` | Иконка меню с выпадающим списком. |
| Подключение | `PopupProvider` | — | Обязательная обёртка. |

## FAQ

### Для дизайнеров

**Q: Когда использовать Drawer, а когда модальное окно?**
A: Drawer — когда важно сохранить контекст страницы и показать большой объём данных (просмотр сущности, фильтры). Модальное окно — для второстепенного содержимого и фокуса на одном действии: создание, подтверждение, короткие формы. Подробнее — в Pixso-документации компонента, блок «Когда использовать»: {{Pixso URL DrawerDF}}.

**Q: Чем отличаются цельная и сепарированная версии?**
A: Цельная (Solid) — единая панель с шапкой, телом и подвалом. Сепарированная (Separated) — панель из нескольких контентных колонок, подвал в ней недоступен. Подробнее — в Pixso-документации компонента, блок «Версии»: {{Pixso URL DrawerDF}}.

**Q: Какая минимальная ширина у панели?**
A: Минимальная ширина — 576px, дальше ширина произвольная. Высота — на весь экран с отступами по 16px сверху и снизу; внешнее скругление углов — 16px. Подробнее — в Pixso-документации компонента, блок «Размеры и отступы»: {{Pixso URL DrawerDF}}.

**Q: Можно ли расположить панель сверху или снизу?**
A: Да. Вертикальная ориентация — панель выезжает от левой или правой границы; горизонтальная — от верхней или нижней. Подробнее — в Pixso-документации компонента, блок «Ориентация»: {{Pixso URL DrawerDF}}.

**Q: Что показывается в шапке панели?**
A: Заголовок, подзаголовок, бейдж, правый блок действий (кнопки или кастомный блок) и табы. Каждый элемент можно показать или скрыть. Подробнее — в Pixso-документации компонента, блок «Настройки»: {{Pixso URL DrawerGuide Doc Block 4}}.

**Q: Как добавить кнопку «Назад»?**
A: Включить её в настройках — кнопка появится поверх кнопки «закрыть». Пользователь сначала может вернуться на предыдущий шаг, затем закрыть панель. Подробнее — в Pixso-документации компонента, блок «Настройки»: {{Pixso URL DrawerGuide Doc Block 4}}.

**Q: Как настроить ширину колонок в сепарированной версии?**
A: По умолчанию крайние блоки подстраиваются под содержимое, центральный растягивается; это поведение можно менять. При добавлении третьего блока увеличьте общую ширину панели. Подробнее — в Pixso-документации компонента, блок «Рекомендации по использованию»: {{Pixso URL DrawerDF}}.

### Для разработчиков

**Q: Какой компонент использовать в коде?**
A: `DrawerDF` — стилизованная обёртка дизайн-системы. Для работы панели оберните приложение в `PopupProvider`. Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как задать расположение и режим панели?**
A: Расположение — пропом `placement` (`left` / `right` / `top` / `bottom`), режим — пропом `asModal` (`true` — с подложкой и блокировкой scroll/фокуса, `false` — без подложки). Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как собрать шапку, контент и подвал?**
A: Compound-компонентами: `DrawerDF.Header` (`title`, `subTitle`, `badge`, `rightBlock`, `footerBlock`), `DrawerDF.Content` (`fixedWidth` для колонок), `DrawerDF.Footer`. Базовые блоки — `DrawerHeader` / `DrawerContent` / `DrawerFooter`. Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как сделать сепарированную версию с колонками?**
A: Передать в `main` массив `DrawerDF.Content` — блоки автоматически выстроятся в колонки; ширину колонки фиксирует `fixedWidth`. Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как открыть панель внутри отдельного контейнера, а не на всём окне?**
A: Пропом `frame` — он принимает id или ref контейнера, в котором отрисуется панель. Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как добавить кнопку «Назад» и меню «троеточие»?**
A: Кнопка «Назад» — пропы `showBackButton` и `onBackClick` (или компонент `DrawerDF.BackIconButton`). Меню — `DrawerDF.DotsIconButton` с `dropdownProps`. Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.

**Q: Как настроить анимацию открытия и закрытия?**
A: Пропом `animationInfo` с полями `enter` и `exit` (например, `enterAnimation 0.2s forwards`). Примеры кода — в Storybook: {{Storybook URL DrawerDF}}.
