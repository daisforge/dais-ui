# Empty State

Empty State показывает пустое состояние: область интерфейса, в которой у пользователя нет контента. Оно появляется, например, при первом заходе на страницу, когда нет результатов поиска или контент удалён. Платформа: Web.

Чтобы пользователь не растерялся при виде пустого состояния, на таком экране важно пояснять, почему контента нет и что можно сделать, чтобы он появился. Empty State собирается из иллюстрации, заголовка, описания и кнопок.

## Размеры и отступы Empty State

Иллюстрация, текст и кнопки выровнены по центру. В области Empty State ставят по центру по горизонтали и по вертикали.

| | S | M | L |
|---|---|---|---|
| Иллюстрация | 68 × 55 px | 170 × 150 px | 250 × 230 px |
| От иллюстрации до заголовка | 8 px | 12 px | 32 px |
| От заголовка до описания | 8 px | 4 px | 16 px |
| От описания до кнопок | 8 px | 12 px | 32 px |
| Кнопка | XS, высота 32 px | S, высота 40 px | S, высота 40 px |
| Ширина текста | по ширине области | до 560 px | до 785 px |
| Заголовок | Body S жирный, вторичный цвет текста | H4 жирный | H2 жирный |
| Описание | Body S, вторичный цвет текста | Body M, вторичный цвет текста | Body L, вторичный цвет текста |

- Между двумя кнопками в L: 8 px
- Дополнительная кнопка в L стоит на 8 px ниже ряда кнопок
- Стили заголовков меняются с шириной экрана: на экранах шире 1280 px заголовок M 20 px, заголовок L 32 px; на экранах от 960 до 1280 px 18 px и 28 px

## Размер Empty State

Empty State бывает трёх размеров: S, M и L. Размер выбираем по тому, какую часть экрана занимает пустое состояние.

### S: виджет или таблица, если на экране две таблицы

S используем для пустого состояния виджета и для пустого состояния в таблице, если на экране 2 таблицы.

<Canvas of={Examples.SizeS} />

### M: таблица или часть экрана

M используем для пустого состояния таблицы, если на экране одна таблица, и для пустого состояния части экрана.

<Canvas of={Examples.SizeM} />

### L: вся контентная часть или вся страница

L используем для пустого состояния всей контентной части страницы или всей страницы.

<Canvas of={Examples.SizeL} />

## Настройки Empty State

### 3D Icon: иллюстрация над заголовком

3D Icon показывает иллюстрацию над заголовком. Иллюстрация есть во всех размерах, её размер задаёт размер Empty State. Иллюстрации: нет контента, ничего не найдено, загрузка, жизненный цикл, нужен доступ, нет доступа, успех. По умолчанию стоит «нет контента».

Для ошибок есть иллюстрации Error 3D Icon: 400, 401, 403, 404, 409, 500, 502, 503 и неопознанная ошибка.

<Canvas of={Examples.Illustrations} />

### Title: заголовок

Title задаёт заголовок, например «[Отчётов] пока нет». Текст в квадратных скобках меняется под контекст страницы. Готовые тексты для типовых ситуаций в гайде «Шаблоны Empty State».

### Subtitle: описание под заголовком

Subtitle включает и выключает описание под заголовком, например «Когда появятся, вы найдёте их здесь».

<Canvas of={Examples.Subtitle} />

## Кнопки в Empty State

### Когда нужна кнопка

Если пользователь может сам сделать так, чтобы в пустом состоянии появился контент, добавляем кнопку. Например, у пользователя нет отчётов, но он может их создать.

Если пользователь не может повлиять на пустое состояние, кнопка не нужна. Например, у пользователя нет задач: они появляются, когда их назначает руководитель.

Кнопка не нужна и тогда, когда страница пустая и пользователь не может повлиять на контент, пока находится на этой странице. Например, когда нет истории просмотра или избранного, пользователю нужно перейти на другие страницы, чтобы добавить контент.

<Canvas of={Examples.WhenButton} />

### Какую кнопку ставить

Для разных пустых состояний используем кнопки разных уровней:

- L: Accent Basic Button
- M: Secondary Basic Button. Если действие дублирует Accent Basic Button на странице, ставим Accent Link Button: она передаёт суть целевого действия за счёт цвета и не перетягивает внимание с основной кнопки целевого действия
- S: Accent Link Button

> **⚠️ Важно:** Accent Basic Button может быть только в состоянии, которое занимает весь экран пользователя, то есть в Empty State L.

### Сколько кнопок ставить

В L до двух кнопок в ряд и одна дополнительная кнопка под ними. В M и S одна кнопка. Размер кнопки зависит от размера Empty State: в S кнопка XS, в M и L кнопка S.

## Empty State при пустом левом блоке

Популярный сценарий, когда на странице 2 взаимосвязанных блока:

- Левый блок: список страниц, которые можно открыть в центральном блоке
- Центральный блок: открытая страница, выбранная из списка слева

Когда в левом блоке нет контента, в центральном блоке нечего открывать. Чтобы не дублировать 2 пустых состояния, ставим одно Empty State L на всю контентную часть страницы.

> **⚠️ Важно:** не дублируйте пустое состояние в левом и в центральном блоке. Одно Empty State L занимает всю контентную часть страницы.

<Canvas of={Examples.PairLeftBlock} />

Если пользователь может добавить контент на страницу, в Empty State L ставим кнопку. Если не может, Empty State L без кнопки.

<Canvas of={Examples.LeftBlockButtons} />

Фон под Empty State используем по желанию, на усмотрение дизайнера: Empty State может стоять на сером фоне страницы или в белом блоке.

## Маппинг: дизайн → код

| Свойство в дизайне | Проп в коде | Что важно |
|---|---|---|
| Размер S, M, L | `size` | Обязательный: `s`, `m`, `l` |
| 3D Icon | `variant` | Нет контента `no-content`, ничего не найдено `not-found`, загрузка `loading`, жизненный цикл `life-circle`, нужен доступ `need-access`, нет доступа `no-access`, успех `success`. По умолчанию `no-content`. Значение `not-result` устарело, вместо него `not-found` |
| Error 3D Icon | `variant` | `400`, `401`, `403`, `404`, `409`, `500`, `502`, `503`, `unidentified` |
| Title | `title` | |
| Subtitle | `subtitle` | |
| Кнопки | `buttons` | `type: 'button'` рисует Button, `type: 'link'` рисует LinkButton. В `l` до 2 кнопок, в `m` и `s` одна. Размер кнопки ставит компонент: `xs` в S, `s` в M и L |
| Уровень кнопки: Accent Basic, Secondary Basic, Accent Link | `view` в `props` кнопки | `accent` или `secondary`. Уровень по размеру Empty State выбирает разработчик |
| Дополнительная кнопка в L | `extraButton` | Работает только в `l` |
| Empty State по центру области | `centered` | Выравнивает по вертикали и горизонтали |

## Связанные компоненты

- **Шаблоны Empty State**: гайд с готовыми текстами и 3D-иллюстрациями для типовых пустых состояний (нет контента, нет результатов, нет доступа или нужен доступ, не удалось загрузить, другие ошибки) и для страниц ошибок 400, 401, 403, 404, 409, 500, 502, 503 и неопознанной ошибки
- **ErrorPage**: страницы ошибок с иллюстрациями Error 3D Icon, размеры S, M и L те же, что у Empty State
- **Button**: Accent Basic Button в Empty State L, Secondary Basic Button в M
- **LinkButton**: Accent Link Button в S, а в M, если действие дублирует Accent Basic Button на странице
- **Table Canvas**: пустое состояние таблицы. M, если на экране одна таблица, S, если таблиц две
- **[Left Panel](?path=/docs/композиции-leftpanel-для-дизайнеров--docs)**: если левый блок пустой, ставим одно Empty State L на всю контентную часть страницы

## FAQ

### Для дизайнеров

**Q: Какой размер Empty State выбрать?**
A: S для виджета и для таблицы, если на экране 2 таблицы. M для таблицы, если она на экране одна, и для части экрана. L для всей контентной части страницы или всей страницы.

**Q: Когда в Empty State нужна кнопка?**
A: Когда пользователь может сам сделать так, чтобы появился контент. Если он не может повлиять на пустое состояние или на пустую страницу, пока находится на ней, кнопка не нужна.

**Q: Какую кнопку поставить в Empty State?**
A: В L Accent Basic Button, в M Secondary Basic Button, в S Accent Link Button. В M ставим Accent Link Button, если действие дублирует Accent Basic Button на странице.

**Q: Можно поставить Accent Basic Button в Empty State M?**
A: Нельзя. Accent Basic Button может быть только в Empty State L, который занимает весь экран пользователя. В M используйте Secondary Basic Button или Accent Link Button.

**Q: Сколько кнопок можно поставить в Empty State?**
A: В L до двух кнопок в ряд и одну дополнительную кнопку под ними. В M и S одну кнопку.

**Q: Что показать, если левый блок страницы пустой?**
A: Одно Empty State L на всю контентную часть страницы, чтобы не дублировать 2 пустых состояния. Если пользователь может добавить контент, добавьте кнопку.

**Q: Нужен ли фон под Empty State?**
A: Фон используем по желанию, на усмотрение дизайнера: серый фон страницы или белый блок.

**Q: Можно убрать описание под заголовком?**
A: Да, Subtitle включается и выключается. Например, Empty State S может быть только с заголовком «Пока ничего нет».

**Q: Где взять тексты и иллюстрации для типовых пустых состояний?**
A: В гайде «Шаблоны Empty State»: там готовые тексты и 3D-иллюстрации для типовых ситуаций и страниц ошибок.

**Q: Что значит текст в квадратных скобках в примерах?**
A: Это значение, которое меняется под контекст страницы, например «[Отчётов] пока нет». Подробнее в гайде «Шаблоны Empty State».

### Для разработчиков

**Q: Как добавить кнопки в Empty State?**
A: Передайте массив `buttons`, каждый элемент `{ type: 'button' | 'link', props }`. `button` рисует Button, `link` рисует LinkButton. Размер кнопки компонент ставит сам: `xs` в `s`, `s` в `m` и `l`.

**Q: Почему в Empty State видна только одна кнопка из `buttons`?**
A: В `m` и `s` компонент показывает первую кнопку из `buttons`. Две кнопки и `extraButton` работают в `l`.

**Q: Какая иллюстрация стоит по умолчанию?**
A: Без `variant` компонент показывает `no-content`. Значение `not-result` устарело, используйте `not-found`. Пропсы `icon` и `iconProps` тоже устарели, иллюстрацию задаёт `variant`.

**Q: Почему в Storybook картинка не меняется при смене `variant`?**
A: Картинки загружаются со статики продукта по пути `/pl/static-res/finportal_icons/images/`. На страницах разработчиков в Storybook вместо них показывается запасная картинка: `no-content-m` для пустых состояний и `unidentified` для ошибок.

**Q: Как поставить Empty State по центру области?**
A: Передайте `centered`: контейнер растягивается на ширину и высоту родителя и выравнивает содержимое по центру.

**Q: Как показать пустое состояние в таблице Canvas?**
A: Через `tableConfig.emptyState`: `enabled: true` и пропсы Empty State. По умолчанию таблица показывает размер `l` по центру, заголовок «Нет данных по заданным параметрам» и иллюстрацию `not-result`. Для одной таблицы на экране дизайн использует M: передайте `size: 'm'`.

**Q: Как показать иллюстрацию ошибки в Empty State?**
A: Передайте в `variant` код ошибки: `'400'`, `'401'`, `'403'`, `'404'`, `'409'`, `'500'`, `'502'`, `'503'` или `'unidentified'`. Страницу ошибки с готовыми текстами по коду собирает ErrorPage, он построен на Empty State.
