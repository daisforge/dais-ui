# 4.4. Плейсхолдеры и тексты для полей

Раздел собирает правила оформления плейсхолдеров _(текстов-подсказок внутри полей ввода)_, масок и текстов для полей без значения в интерфейсе платформы {{Название}}.

---

## Плейсхолдеры

Плейсхолдер — текст-подсказка внутри поля ввода, которая помогает пользователю правильно заполнить его.

### Общие рекомендации

- Плейсхолдер обычно состоит из глагола и существительного: «Выберите [заголовок поля ввода]» или «Введите [заголовок поля ввода]».
- Если на экране полей много подряд, при дублировании лейбла в плейсхолдер получается много повторов. Чтобы избежать такой ситуации, **«разбавляем» формы универсальными плейсхолдерами**: «Выберите из списка» и «Введите значение».
- В плейсхолдере с заглавной буквы пишем только первое слово: «Выберите [заголовок поля ввода]».

> **⚠️ Важно:** в формах **не заменяем плейсхолдером лейбл поля**. При заполнении поля плейсхолдер скрывается под текстом — если у поля не будет заголовка, пользователь может забыть, что требовалось заполнить.
>
> **Исключение** — фильтры.

> **🔗 См. также:**
> - [Дефолтные значения]({{Anchor editorial-policy-typography#Дефолтные значения}}) в Правописании (3) — про «Введите значение» / «Выберите значение» в контексте low code объектов.
> - [Тексты для ошибок в полях ввода]({{Anchor editorial-policy-errors#Тексты для ошибок в полях ввода}}) в Ошибках (4.2) — что писать при невалидном или пустом обязательном поле.

### Универсальные плейсхолдеры

Используются, когда не нужно дублировать лейбл поля в плейсхолдере (например, в формах с большим количеством полей подряд).

- «Выберите значение» — для полей выбора.
- «Выберите из списка» — для полей выбора.
- «Введите значение» — для текстовых полей.
- «Введите или выберите из списка» — для комбобокса _(поля с возможностью ручного ввода + выбора из списка)_.
- «Вставьте ссылку» — для полей со ссылкой.
- «Например: [пример заполнения поля]» — для кейсов, когда в поле вводят данные только в определённом формате.

Примеры формата «Например: ...»:

- «Например: ID1234567»
- «Например: 334-556»
- «Например: АА123456»

### Плейсхолдеры для ячеек таблиц

Короткие варианты для ячеек, в которые пользователь будет вводить значения:

- **«Значение»** — общий короткий вариант.
- **«Выберите»** — для ячеек с выбором из списка.
- **«Введите»** — для ячеек со свободным вводом.

См. также раздел [Плейсхолдеры в ячейках таблиц]({{Anchor Плейсхолдеры в ячейках таблиц}}) ниже — там описаны три типовых значения (прочерк / 0,00 / Введите значение) и правило про коллизию с прочерком как значением.

### Краевые кейсы

Несколько ситуаций, когда универсальный плейсхолдер не подходит и нужен специфический:

**Короткое поле, где код / идентификатор должен поместиться:**

- Лейбл: «Пространство в системе»
- Плейсхолдер: «Код пространства»
- Когда применять: для коротких полей.

**Поле с подсказкой по формату содержимого:**

- Лейбл: «Описание [сложной сущности]»
- Плейсхолдер: «Опишите, как будет выглядеть виджет в этом размере на превью»
- Когда применять: для кейсов, когда не знаем точно, что напишет пользователь, но нужно подсказать ему, какая информация должна содержаться в описании.

### Заглавная буква в плейсхолдере

В плейсхолдере с заглавной буквы пишем **только первое слово** (даже если в лейбле слова были с заглавных).

| ✅ Правильно | ❌ Неправильно |
|---|---|
| Выберите роль | Выберите Роль |
| Введите полное название | Введите Полное Название |

> **🔗 См. также:** [Заглавная буква]({{Anchor editorial-policy-typography#Заглавная буква}}) в Правописании (3) — там общее правило про заглавную букву в интерфейсе.

## Маски

Маска ввода — формат, в который пользователь должен заполнить поле. Может работать вместе с плейсхолдером или без него.

### Одиночная дата

| Маска | Плейсхолдер |
|---|---|
| ДД/ММ/ГГГГ | Выберите дату |

### Период

Возможные варианты оформления:

| Маска | Плейсхолдер / тексты |
|---|---|
| ДД/ММ/ГГГГ – ДД/ММ/ГГГГ | «Дата начала → Дата окончания» |
| Без плейсхолдера | Только TextBefore и TextAfter: «от → до» |

### Плейсхолдеры в ячейках таблиц

В ячейках таблиц плейсхолдер определяется на стороне продукта. Возможные варианты:

| Плейсхолдер | Когда использовать |
|---|---|
| Прочерк (—) | Когда в ячейке нет данных. |
| 0,00 | Когда в ячейку можно внести числовое значение. |
| Введите значение | Когда пользователь может вручную заполнить ячейку. |

> **⚠️ Важно:** если в продукте **прочерк — это значение таблицы**, то его нельзя использовать, чтобы показать отсутствие данных в ячейке. В этом случае плейсхолдер следует выбирать исходя из потребностей продукта, чтобы не было противоречия.

## Тексты для полей без значения

Когда поле находится в состоянии **readonly** и в нём нет значения:

| Тип поля | Текст |
|---|---|
| Поле ввода | Не указано |
| Поле с выпадающим списком | Не выбрано |

## FAQ

**Q: Какой плейсхолдер использовать для текстового поля?**
A: «Введите [заголовок поля]» или универсальный «Введите значение» — если форма большая и нужно избежать повторов. Подробнее — раздел [Общие рекомендации]({{Anchor Общие рекомендации}}).

**Q: Какой плейсхолдер для поля выбора (dropdown)?**
A: «Выберите [заголовок поля]» или универсальный «Выберите значение» / «Выберите из списка». Подробнее — раздел [Универсальные плейсхолдеры]({{Anchor Универсальные плейсхолдеры}}).

**Q: Какой плейсхолдер для поля даты?**
A: «Выберите дату» при маске `ДД/ММ/ГГГГ`. Подробнее — раздел [Одиночная дата]({{Anchor Одиночная дата}}).

**Q: Какой плейсхолдер для периода (диапазона дат)?**
A: «Дата начала → Дата окончания» при маске `ДД/ММ/ГГГГ – ДД/ММ/ГГГГ`. Или без плейсхолдера — только TextBefore и TextAfter: «от → до». Подробнее — раздел [Период]({{Anchor Период}}).

**Q: Можно ли использовать плейсхолдер вместо лейбла поля?**
A: Нет — в формах не заменяем лейбл плейсхолдером. При заполнении поля плейсхолдер скрывается, и пользователь может забыть, что требовалось заполнить. Исключение — фильтры. Подробнее — раздел [Общие рекомендации]({{Anchor Общие рекомендации}}).

**Q: С какой буквы писать плейсхолдер?**
A: С заглавной — только первое слово. «Выберите роль», а не «Выберите Роль». Подробнее — раздел [Заглавная буква в плейсхолдере]({{Anchor Заглавная буква в плейсхолдере}}).

**Q: Что писать в плейсхолдере для короткого поля с непонятным форматом?**
A: Подсказку про содержимое — например, для лейбла «Пространство в системе» плейсхолдер «Код пространства». Подробнее — раздел [Краевые кейсы]({{Anchor Краевые кейсы}}).

**Q: Что писать в плейсхолдере, если поле принимает специфический формат?**
A: Использовать «Например: ...» с конкретным примером в нужном формате — «Например: ID1234567», «Например: 334-556», «Например: АА123456». Подробнее — раздел [Универсальные плейсхолдеры]({{Anchor Универсальные плейсхолдеры}}).

**Q: Какой плейсхолдер для ячейки таблицы, в которую пользователь будет вводить число?**
A: «0,00» — если показать, что ожидается число. Или «Введите значение» — если пользователь может вручную заполнить. Подробнее — раздел [Плейсхолдеры в ячейках таблиц]({{Anchor Плейсхолдеры в ячейках таблиц}}).

**Q: Какой текст в поле readonly, если значения нет?**
A: «Не указано» для поля ввода, «Не выбрано» для выпадающего списка. Подробнее — раздел [Тексты для полей без значения]({{Anchor Тексты для полей без значения}}).

**Q: Какой плейсхолдер для комбобокса?**
A: «Введите или выберите из списка». Подробнее — раздел [Универсальные плейсхолдеры]({{Anchor Универсальные плейсхолдеры}}).

**Q: Можно ли использовать прочерк (—) как индикатор пустой ячейки?**
A: Только если в продукте прочерк не используется как значение таблицы. Если прочерк — это значение, нужно выбрать другой плейсхолдер, чтобы не было противоречия. Подробнее — раздел [Плейсхолдеры в ячейках таблиц]({{Anchor Плейсхолдеры в ячейках таблиц}}).
