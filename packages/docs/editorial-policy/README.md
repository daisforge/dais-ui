# Редполитика

UX-writing и редакционные правила дизайн-системы: тон коммуникации, правописание и текст в интерфейсе, тексты ошибок, кнопок, плейсхолдеров, статусов и уведомлений, типографика, общие принципы.

> **⚠️ Статус ревью: ожидает редактора.** Редполитика содержательно готова, но **ещё не прошла ревью редактора**. До ревью считать тексты предварительными — формулировки могут измениться. ИИ-агенту: использовать как источник допустимо, но ответы по этим материалам помечать как «по предварительной редполитике (ожидает ревью редактора)».
