# 4.5. Статусы

Статусы на платформе {{Название}} используются при работе с задачами и документами. В статус может входить не только текст, но и иконка, дата, время, номер и другие числовые данные.

К текстам статусов применяются правила редполитики платформы.

---

## Общие рекомендации

- Статус должен быть согласован с сущностью, к которой он относится. Если сущность — задача, то она «выполнена». Если речь про расчёт — он «выполнен».
- Для статуса рекомендуется использовать 3–4 слова и при необходимости предлог.
- В статусах допустимо использовать страдательный залог. Пример: «Бюджет выделен».
- В статусах может использоваться не только текст, но и дополнительная информация: дата, время, номер и другие данные.
- Статусы могут быть без текста и состоять только из даты и иконки.

> **🔗 См. также:** [С минимумом страдательного залога]({{Anchor editorial-policy-interface-principles#С минимумом страдательного залога}}) в Общих принципах (4.1) — там общее правило про залог; статусы — как раз тот случай, где страдательный залог уместен.

---

## Правила по визуалу

Статусы оформляются бейджами (компонент [Badge]({{Storybook URL Badge}})).

- Все бейджи должны быть в одном стиле: овальные или квадратные.
- Возможно использование filled или outlined иконок — сохраняйте консистентность.
- Для статусов используйте **transparent** бейджи.
- Для типизации используйте **solid** бейджи.

---

## Правила по тексту

- Окончание зависит от того, к чему принадлежит бейдж. Если задача — то она «Создана».
- Используйте в тексте статуса **не более 3–4 слов** и предлог.
- В статусах допустимо использовать страдательный залог: «Создана», «Готова» и так далее.

---

## Примеры текстов статусов

Статусы сгруппированы по состоянию сущности и цвету бейджа.

### Не в работе (серый) / предготовность (голубой)

Пока сущность не в работе, у неё могут быть статусы:

| Статус | Тоже статус, но он описывает состояние |
|---|---|
| Создана | Черновик |
| Назначена | Бэклог |

**Стадия предготовности** — период, когда сущность уже прошла какой-то этап, но её ещё не взяли в работу: один этап закончен, сущность ждёт другие. Например, сущность нужно отправить на экспертизу и только потом передать на согласование — экспертиза это стадия предготовности.

Другие возможные статусы предготовности:

| Статус |
|---|
| Готова к исполнению |
| Отправлен на согласование |

### В работе (оранжевый)

То, что будет иметь конкретный результат — успех или провал.

| Статус |
|---|
| В работе |
| В работе [у кого] |
| На согласовании |
| На согласовании у [у кого] |

### Готово / выполнено / согласовано (зелёный)

То, что имеет успешный итог или успешный этап.

| Статус |
|---|
| Готово |
| Бюджет выделен |
| Все расчёты утверждены |
| Исполнена |
| Согласована в [где] |

### Удалено / отменено / в архиве (серый)

| Статус | Тоже статус, но он описывает состояние |
|---|---|
| Отменена | Архив |
| Не используется | Архив |
| Приостановлена | Архив |

### Отклонено / неактуально / ошибки (серый)

| Статус |
|---|
| Отклонено |
| Отклонена на [название этапа] |
| Валидация не пройдена |
| Ошибка в расчёте |
| Неактуальна |

### Вернули на доработку (оранжевый)

| Статус |
|---|
| На доработке |
| На доработке у [у кого] |
| [Сущность] на доработке |

### Статусы с дополнительной информацией

Статус может включать дату, время или номер.

| Пример |
|---|
| Идёт расчёт от 14.03.2025 11:30 |
| Расчёт утверждён 15.03.2025 12:30 |

### Статусы без текста (серый)

Статус может состоять только из даты, номера и иконки — без текста.

| Пример |
|---|
| 17.01.2025 |
| №1234567 |

---

## Спорные моменты

Статус «В работе» можно рассматривать с двух сторон:

- Если сущность в работе **у вас** — используйте бейдж **оранжевого** цвета.
- Если сущность в работе **у кого-то другого** — это ближе к ожиданию результата, используйте бейдж **голубого** цвета.

---

## Несколько бейджей вместе

Если используете 2 и более бейджей:

- Определите, какой из них главный, и задайте ему статус и цвет.
- У второго и последующих цвет **не должен совпадать** с главным — его можно изменить, несмотря на основные рекомендации.

Примеры:

- **(В работе) (Срочно)** — главное, что сущность в работе; второстепенно, что у неё статус «Срочно».
- **(Бюджет выделен) (Доп. ресурс)** — главное, что стадия успешно завершена; второстепенно — статус «Доп. ресурс».

## FAQ

**Q: Сколько слов должно быть в статусе?**
A: Не более 3–4 слов и при необходимости предлог. Подробнее — раздел [Правила по тексту]({{Anchor Правила по тексту}}).

**Q: Можно ли в статусе использовать страдательный залог?**
A: Да — это как раз тот случай, где он уместен: «Создана», «Готова», «Бюджет выделен». Подробнее — раздел [Общие рекомендации]({{Anchor Общие рекомендации}}) и [страдательный залог в 4.1]({{Anchor editorial-policy-interface-principles#С минимумом страдательного залога}}).

**Q: Какой цвет бейджа для статуса «В работе»?**
A: Зависит от того, у кого сущность. Если у вас — оранжевый. Если у кого-то другого (ожидание результата) — голубой. Подробнее — раздел [Спорные моменты]({{Anchor Спорные моменты}}).

**Q: Какие бейджи использовать для статусов — solid или transparent?**
A: Для статусов — transparent, для типизации — solid. Подробнее — раздел [Правила по визуалу]({{Anchor Правила по визуалу}}).

**Q: Что такое стадия предготовности?**
A: Период, когда сущность уже прошла какой-то этап, но её ещё не взяли в работу (например, экспертиза перед согласованием). Подробнее — раздел [Примеры текстов статусов]({{Anchor Не в работе (серый) / предготовность (голубой)}}).

**Q: Можно ли поставить два бейджа рядом?**
A: Да. Определите главный (его статус и цвет), а у второго цвет не должен совпадать с главным. Подробнее — раздел [Несколько бейджей вместе]({{Anchor Несколько бейджей вместе}}).

**Q: Может ли статус быть без текста?**
A: Да — статус может состоять только из даты, номера и иконки. Подробнее — раздел [Статусы без текста]({{Anchor Статусы без текста (серый)}}).
