# Логика компрессии MassActions

## Обзор

Компрессия — это механизм автоматического скрытия кнопок действий в выпадающее меню "Ещё", когда панель не помещается в доступное пространство. Алгоритм обеспечивает соблюдение минимального отступа в 24px с каждой стороны контейнера.

## Структура панели

Панель состоит из следующих элементов (слева направо):

1. **Левая секция** (`leftSection`) — счетчик выбранных элементов, чекбокс
2. **Gap 4px** — отступ между `leftSection` и `ActionsWrapper`
3. **ActionsWrapper** — контейнер для:
   - Средняя секция (`middleSection`) — опционально, например кнопка "Сбросить всё"
   - Divider — разделитель (если есть кнопки)
   - MoreButton — кнопка "Ещё" для скрытых действий
   - Видимые кнопки действий
4. **Gap 4px** — отступ между `ActionsWrapper` и кнопкой сворачивания
5. **Кнопка сворачивания** (`CollapseButton`) — всегда видна

### Padding контейнера

Панель имеет горизонтальный padding:

- Развернутое состояние: `24px` слева, `8px` справа = **32px**
- Свернутое состояние: `24px` слева, `10px` справа = **34px**

## Расчет ширины панели

### Формула

```
finalPanelWidth = fixedElementsWidth + buttonsAreaWidth
```

### Фиксированные элементы (`fixedElementsWidth`)

Элементы, ширина которых не зависит от количества видимых кнопок:

```
fixedElementsWidth =
  leftSectionWidth +           // Измеряется из DOM
  middleSectionWidth +         // Измеряется из DOM (если есть)
  dividerTotalWidth +          // Измеряется из DOM (если есть кнопки)
  COLLAPSE_BUTTON_WIDTH +      // 24px (константа)
  (leftPadding + rightPadding) + // 32px (24px + 8px) в развернутом состоянии
  gapsBetweenFixedElements      // 8px (4px * 2)
```

**Divider:**

- Показывается только если есть кнопки (`buttons.length > 0`)
- Обернут в `div`, измеряется через `getBoundingClientRect().width`
- Включает `margin-inline: 12px` (24px всего) и `padding-left: 1px`
- Gap слева учитывается только если есть `middleSection`

### Область кнопок (`buttonsAreaWidth`)

Ширина области с кнопками действий:

```
buttonsAreaWidth =
  totalButtonsWidth +              // Сумма ширин всех видимых кнопок
  gapsBetweenVisibleButtons +      // (n-1) * 4px, где n — количество видимых кнопок
  moreButtonArea                   // moreButtonWidth + 4px (если есть скрытые кнопки)
```

**Gaps между кнопками:**

- `ActionsWrapper` использует CSS `gap: 4px` между дочерними элементами
- Для `n` видимых кнопок: `(n-1) * 4px` gaps
- Последняя видимая кнопка имеет `margin-right: 4px`

## Алгоритм компрессии

### Шаг 1: Разделение кнопок

Кнопки разделяются на две категории:

- **Accent кнопки** (`view === 'accent'`) — всегда видимы, не скрываются
- **Обычные кнопки** — могут быть скрыты при нехватке места

### Шаг 2: Определение видимых кнопок

1. Все accent кнопки добавляются в список видимых
2. Обычные кнопки добавляются по порядку, пока:
   - `calculatedPanelWidth <= maxPanelWidth`
   - `maxPanelWidth = availableWidth - MIN_PANEL_PADDING * 2` (48px отступов)
3. К оценочной ширине добавляется буфер **3px** для учета погрешностей рендеринга

### Шаг 3: Проверка реальной ширины

После расчета сравнивается:

- `calculatedPanelWidth` — вычисленная ширина
- `actualPanelWidth` — реальная ширина из DOM

Если `actualPanelWidth > maxPanelWidth`, скрывается последняя обычная кнопка (не accent) для принудительной компрессии.

### Шаг 4: Формирование результата

- Видимые кнопки отображаются напрямую
- Скрытые кнопки помещаются в dropdown "Ещё"

## Ограничения

- **Минимальный отступ:** 24px с каждой стороны
- **Максимальная ширина панели:** `availableWidth - 48px` (24px \* 2)
- **Accent кнопки:** всегда видимы, не скрываются
- **Буфер компрессии:** 3px для учета погрешностей браузера

## Отладка

Для включения подробного логирования используйте проп `enableDebugLogs={true}`:

```tsx
<MassActions
  enableDebugLogs={true}
  // ... другие пропсы
/>
```

Логи включают:

- Размеры контейнера и доступное пространство
- Ширины всех элементов панели
- Детальный расчет компрессии
- Распределение кнопок (видимые/скрытые)
