# Дропдауны в TableCanvas: правила из макетов

Источник: макет «Dropdown в таблице» (выпадающие списки в фильтрах, на кнопках,
в контекстном меню). Правила относятся ко всем выпадающим спискам таблицы:
ContextMenu (ПКМ), фильтры в шапке, дропдауны кнопок ToolsMenu (ControlBlock)
и другие дропдауны с триггером.

## 1. Размер дропдауна зависит от размера строки

| Таблица (rowSize)       | Dropdown             | Иконка | Поиск     | Чекбокс    |
| ----------------------- | -------------------- | ------ | --------- | ---------- |
| XS (`small`, минимум)   | XS + `view=Tight`    | 16     | Search XS | Checkbox S |
| S (`medium`, средний)   | S                    | 16     | Search XS | Checkbox S |
| M (`big`, максимум)     | M                    | 24     | Search S  | Checkbox M |

- В коде используется свой дропдаун, в дизайне он показан компонентом Dropdown.
- Короткое правило для чекбокса: размер чекбокса = размеру иконки.

## 2. Ширина

Дропдаун не может быть уже минимального и шире максимального значения. Правило
общее для ContextMenu, фильтров и дропдаунов с триггером (кнопки и т.д.).

| Dropdown | min   | max   |
| -------- | ----- | ----- |
| M        | 140px | 440px |
| S        | 120px | 380px |
| XS       | 120px | 300px |

- В этих пределах ширина подстраивается под содержимое: короткий список узкий,
  длинный пункт расширяет список до max, дальше текст переносится.
- Дропдауны с кастомным рендером (DatePicker, DateTimePicker, Range и т.п.)
  задают размеры сами, но им советуют держаться этих же min/max.

## 3. Состав списка: before/after List

- **По умолчанию список фильтра без beforeList и afterList**: только пункты.
- Поиск и «Выбрать всё» необязательны и включаются через `beforeList`.
  - Поиск ставится вместо первого пункта (Item 1), над списком.
  - «Выбрать всё» идёт после поиска и отделяется разделителем.
- В `afterList` можно добавить кнопки. Пример: кнопка группировки, где после
  выбора всех столбцов уходит один общий запрос.

## 4. Мультивыбор с чекбоксом

- У Cell внутри пункта включается LeftContent, в нём Checkbox нужного размера
  (см. таблицу из п. 1), Label выключен.
- Одиночный выбор: галочка слева у выбранного пункта, у остальных место под
  галочку сохраняется.

## 5. Позиционирование

**Фильтр в шапке:**

- Дропдаун открывается под иконкой фильтра и выравнивается по **левой стороне
  иконки**: левый край списка совпадает с левым краем иконки, список растёт вправо.
- Для **последнего столбца**, если места не хватает, выравнивание по **правой
  стороне** иконки: правый край списка совпадает с правым краем иконки.

**ContextMenu (ПКМ):**

- По оси X меню открывается там, где кликнули.
- По оси Y меню открывается с отступом **4px от нижней границы ячейки**, а не от
  точки клика.

## 6. Примеры из макета

- Фильтр с поиском, «Выбрать всё», разделителем и чекбоксами (Москва, Самара…).
- Список с чекбоксами без поиска.
- Одиночный выбор с поиском, вынесенным над списком (Разработчик, Дизайнер…).
- Кастомный рендер: поле диапазона дат с календарём.
