# **Документация: Система адаптивного сжатия ControlBlock**

## **1. Обзор**

Система динамически адаптирует панель инструментов таблицы (`ControlBlock`) под доступную ширину, последовательно применяя уровни сжатия к элементам управления.

### **Ключевые особенности:**

- **Прогрессивное сжатие** - элементы упрощаются по четкому приоритету
- **Интеллектуальное кеширование** - запоминает состояния для оптимизации
- **Гибкие правила** - поддерживает кастомные элементы и сложные условия

---

## **2. Архитектура сжатия**

### **2.1. Уровни сжатия (CompressionLevels)**

Система применяет **8 уровней сжатия** в строгом порядке:

| Ур.   | Действие                     | Target | Условие               | Пример                    |
| ----- | ---------------------------- | ------ | --------------------- | ------------------------- |
| **0** | Скрыть лейбл группировки     | right  | Если есть группировка | "Группировка" → 🗂         |
| **1** | Скрыть 1 лейбл правых кнопок | right  | Обычные кнопки справа | "Фильтры" → 🔧            |
| **2** | Перенести 1 фичу в сайдбар   | right  | Необязательные фичи   | Иконка → в боковую панель |
| **3** | Перенести поиск вниз         | center | Поиск активен         | 🔍 → под таблицу          |
| **4** | Скрыть лейбл редактирования  | left   | Кнопка редактирования | "Редактировать" → ✏️      |
| **5** | Скрыть лейбл выбора строк    | left   | Выбор строк активен   | "Выбрать" → ◻             |
| **6** | Скрыть счетчик выбора        | left   | Есть выбранные строки | "(5)" → скрыт             |
| **7** | Скрыть правые кнопки в "..." | right  | Комплексные условия   | Группировка+фичи → "..."  |

### **2.2. Приоритетность**

Элементы сжимаются по принципу:  
**Наименее важные → Наиболее важные**

1. Сначала **правые** элементы (группировка, фичи)
2. Затем **центральные** (поиск)
3. В конце **левые** (выбор, редактирование)

## **3. Технические детали**

### **3.1. Состояние (ToolsMenuState)**

Полная структура состояния с комментариями:

```typescript
type ToolsMenuState = {
  leftSide: {
    // Блок выбора строк
    selectingRowFeature: {
      isActive: boolean; // Активна ли функция
      isLabelVisible: boolean; // Виден ли текст "Выбрать"
      isCounterVisible: boolean; // Показывать счетчик выбранных
    };

    // Блок редактирования
    editRowFeature: {
      isActive: boolean;
      isLabelVisible: boolean; // Виден ли текст ("Редактировать"/"Просмотреть")
      editModeEnabled: boolean; // Текущий режим (влияет на ширину)
    };

    // Доп. кнопки слева
    leftSideInner: Array<{
      isLabelVisible: boolean;
      isTargetAction: boolean; // Важные действия (не скрываются)
    }>;

    // Скрыты ли кнопки в "Действия"
    isLeftSideInnerInsideDropdown: boolean;
  };

  middle: {
    // Блок поиска
    searchingFeature: {
      isActive: boolean;
      searchPosition: 'inline' | 'below'; // Позиция поиска
    };
  };

  rightSide: {
    // Кнопки справа
    rightSideInner: Array<{
      isLabelVisible: boolean;
      isTargetAction: boolean;
    }>;

    // Кастомные иконки
    customFeatures: Array<{
      isMovedToRightSidebar: boolean; // Перенесены в сайдбар
      isMandatory: boolean; // Обязательные (не скрываются)
      canBeCompressedInToolsMenu: boolean; // Можно скрыть в "..."
    }>;

    // Блок группировки
    groupingRowsFeature: {
      isActive: boolean;
      isVisibleLabel: boolean; // Виден ли текст
      isCounterVisible: boolean; // Виден ли счетчик
    };

    // Скрыты ли элементы в "..."
    isRightSideInsideDropdown: boolean;
  };
};
```

### **3.2. Расчет ширины**

Система использует точные замеры:

```typescript
const WIDTH = {
  // Левые элементы

  GROUPING: {
    ICON_WITH_COUNTER: 74, // Иконка + счетчик
    GROUPING_ROW: 200, // Полная кнопка
  },
};
```

## **4. Примеры сжатия**

### **4.1. Полная ширина**

```
[ ◻ Выбрать (3) ] [ ✏️ Редактировать ] [ Действия 1 ] [ 🔍 Поиск... ] [ Действия 2 ] [ 🗂 Группировка (2) ] [ ⚙️ ]
```

- Сначала убираем лейбл у группировки
- Убираем лейблы у кнопок левее группировки (Действия 2)
- Кастомные фичи, которые могут быть перенесены в правый сайдбар - постепенно начинают туда уезжать
- Редактировать убираем лейбл
- Выбрать убираем лейбл
- Выбрать убираем счетчик
- Все действия в правой части с canBeCompressedInToolsMenu: true - скрываются в дропдаун кнопку ...

## **5. Особые случаи**

### **5.1. Комплексные условия для уровня 7**

Правые кнопки скрываются в "..." если:

1. Есть группировка + обычные кнопки
2. ИЛИ есть обязательные фичи + группировка
3. ИЛИ есть 2+ обычных кнопки
4. ИЛИ есть 2+ обязательных фичи

```typescript
condition: (s) =>
  (s.rightSide.groupingRowsFeature.isActive &&
   s.rightSide.rightSideInner.some(i => !i.isTargetAction)) ||
  // ... другие условия
```

### **5.2. Приоритетность сжатия**

Важные нюансы:

- Счетчик выбора (`(3)`) скрывается **после** лейбла
- Поиск переносится **до** скрытия левых элементов
- Target-actions **никогда** не теряют лейблы

## **6. Настройка системы**

### **Добавление новых фич**

1. В `useFeatureArray`:
   ```typescript
   const optionalFeatures: FeatureItem[] = [
     ...(isActive.myFeature
       ? [
           {
             value: 'my-feature',
             label: 'Моя фича',
             Icon: MyIcon,
             canBeCompressedInToolsMenu: true, // Можно ли скрыть
           },
         ]
       : []),
   ];
   ```
2. При необходимости добавить новый уровень сжатия в `compressionConfig`.

### **Отладка**

```typescript
// Логирование текущего состояния
useEffect(() => {
```
