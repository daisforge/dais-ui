# Данный проект создан для тестирования билда ui-kit до публикации в npm.

Тестируется:

- установка зависимостей (в том числе ui-kit, собранный в виде .tgz на основе dist/packages/ui-kit)
- сборка данного проекта с актуальными зависимостями

## package.json создается на основе untracked-package.json

Новые зависимости или скрипты нужно добавлять в untracked-package.json

## Запуск в монорепе:

```bash

# Запуск проверки корректности билда ui-kit
npm run vite-project:ui-kit-build-check

# Установка зависимостей
npm run vite-project:install

# Запуск дев сервера проекта (может не открываться - тогда необходимо запускать ссылку в инкогнито режиме браузера)
npm run vite-project:dev

# Сделать сборку проекта
npm run vite-project:build

```

## Работа в проекте:

- Для изоляции тестовых компонентов под кейс создаем файл в рамках [blocks](./src/blocks/)
- Вызываем тестовый компонент в рамках проекта делаем в [App.tsx](./src/App.tsx).
