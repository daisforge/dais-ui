# AutocompleteSearch

Компонент AutocompleteSearch - обертка компонента Autocomplete со своими готовыми стилями для поля поиска. C примерами реализации подробно можно ознакомиться ниже в stories.

## Ключевые особенности

- Поле поиска с автодополнением на основе Autocomplete
- Иконка лупы слева и крестик очистки справа
- Доступные размеры: `s`, `xs`

> Подробнее о типах и пропсах — [AutocompleteSearch API](?path=/docs/локальные-компоненты-autocompletesearch-api--docs)
