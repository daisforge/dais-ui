# BlockGradientScroll

Градиент-индикатор скролла — визуальная подсказка пользователю, что контент можно скроллить.

## Ключевые особенности

- Автоматически появляется при наличии скролла
- Плавно исчезает при достижении конца
- Доступен как компонент и как миксин для styled-components

## Особенности

- Основано на CSS `animation-timeline` — [поддержка браузеров](https://caniuse.com/?search=animation-timeline)
- Тема определяется один раз в момент создания компонента/стилей (`getActiveTheme()`), при переключении темы градиент не обновится автоматически
- Компонент автоматически получает padding через `getComputedStyle` — prop не нужен
- Миксин принимает padding и сам применяет его к контейнеру — дублирование не требуется
- Variant `white` (default) — белый/тёмный фон; `gray` — серый фон
- `$css` позволяет передать дополнительные стили через styled-components

## Экспорты

### Компонент

- `BlockGradientScroll` — React-компонент (`@daisforge/ui`)
- `BlockGradientScrollProps` — Тип пропсов (`@daisforge/ui`)

### Миксин

- `BlockGradientScrollMixin` — Основной миксин (`@daisforge/ui/mixins`)
- `BlockGradientScrollPadding` — Тип для padding (`@daisforge/ui/mixins`)
- `BlockGradientScrollVariant` — Тип для variant (`@daisforge/ui/mixins`)
- `BlockGradientScrollOptions` — Тип опций миксина (`@daisforge/ui/mixins`)

### Внутренние (для кастомизации)

- `blockGradientScrollContainerStyles` — Базовые стили контейнера
- `blockGradientScrollAfterStyles` — Стили псевдоэлемента ::after
- `blockGradientScrollKeyframes` — Keyframes анимации

## Использование

### Компонент

Компонент **автоматически** получает padding'и из ваших стилей — просто укажите их в `style`, `className` или `$css`:

<Source
  language="tsx"
  code={`
// Компонент сам определит padding из style
<BlockGradientScroll
  variant="white"
  style={{
    maxHeight: 300,
    overflowY: 'auto',
    padding: 24,
    background: '#ffffff',
  }}
>
  {children}
</BlockGradientScroll>
`}
/>

### Миксин

Миксин **сам применяет padding** к контейнеру — не нужно дублировать:

<Source language="tsx" code={`
// Миксин сам применит padding: 24px ко всем сторонам
const Box = styled.div\`
  max-height: 300px;
  overflow-y: auto;
  background: #ffffff;

\${BlockGradientScrollMixin({ padding: 24, variant: 'white' })}
\`;
`} />
