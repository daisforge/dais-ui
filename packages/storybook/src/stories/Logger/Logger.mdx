# Logger

Панель системных сообщений: шапка со счётчиками и фильтрами по статусам, список сообщений с группами, подробностями и копированием идентификатора трассировки.

## Ключевые особенности

- Четыре статуса: `error`, `warning`, `info`, `success`
- Группы любой вложенности
- Фильтр по статусу учитывает вложенные сообщения: группа остаётся в списке, если в ней есть подходящее сообщение
- Кнопки сообщения: «Подробнее», «Скопировать ID», код сообщения (например `F23`) и собственные `actions`
- Состояние панели, фильтра и раскрытых элементов можно задавать извне или оставить компоненту

## Основная структура

```tsx
<Logger items={items} defaultOpen />
```

## Compound-компоненты

```ts
Logger.List; // Список сообщений без шапки
Logger.Message; // Одно сообщение
Logger.Group; // Группа сообщений
Logger.Filters; // Фильтры по статусам со счётчиками
```

- `Logger.List` — подходит для модалки, drawer или своей панели, принимает те же `items` и настройки отображения
- `Logger.Message` и `Logger.Group` — можно использовать отдельно от панели
- `Logger.Filters` — чипсы «Все» и по одному на статус

## Особенности

- Счётчики считаются по всем элементам: и по группам, и по сообщениям. Если загружена только часть данных, передайте итоговые значения в `counts`
- Описание сообщения можно скопировать, только если оно передано строкой
- Закрытие панели сбрасывает фильтр, открытие выбирает «Все». Выбор фильтра в закрытой панели открывает её

Описание типов и пропсов — в разделе [API](/docs/локальные-компоненты-logger-api--docs).
