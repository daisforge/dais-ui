# Container

Компонент стандартизации композиции. Может работать как простой контейнер или как split-контейнер с разделением на колонки.

## Ключевые особенности

- Режим split с разными пропорциями колонок: `30/70`, `20/80`, `70/30`, `80/20`, `1/1/1`, `1/3/1`, `fixed-fluid`
- Растягивание на всё доступное пространство (`stretch`)
- Поддержка 2- и 3-колоночных раскладок
- Фиксированная левая колонка с гибкой правой (`fixed-fluid`)
- Кастомизация через `className` и `css`

## Особенности

- В split-режиме `children` принимает массив из 2 или 3 элементов в зависимости от `view`
- Для `view='1/1/1'` и `view='1/3/1'` требуется 3 элемента
- Для остальных view — 2 элемента
- `view` можно задать только при `split === true`
- Для `view='fixed-fluid'` ширина левой колонки настраивается через `fixedWidth` (по умолчанию `288px`)
