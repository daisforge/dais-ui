# Collapse

Компонент анимированного сворачивания/разворачивания контента. Поддерживает вертикальную и горизонтальную ориентацию, настраиваемую длительность и тип анимации.

## Ключевые особенности

- Анимация open/close с настраиваемой длительностью и easing
- Вертикальная и горизонтальная ориентация
- Возможность размонтирования контента при закрытии (`unMountOnClose`)
- Настраиваемые размеры в открытом и закрытом состоянии
- CSS-стили для внешнего и внутреннего контейнеров (`extContainerCss`, `intContainerCss`)

## Особенности

- Пропс `animation` может быть строкой (одинаковая анимация для open/close) или объектом `{ open, close }` для разных анимаций
- Пропс `intContainerCss` принимает объект с ключами `always` (стили в любом состоянии) и `onOpen` (стили только при открытии)
- По умолчанию контент остаётся в DOM при закрытии. Для размонтирования используйте `unMountOnClose`
