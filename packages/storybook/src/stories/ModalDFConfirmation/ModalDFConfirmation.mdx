# ModalDFConfirmation

Упрощённое модальное окно подтверждения, построенное на `ModalDF`. Используется, когда нужно попросить пользователя подтвердить важное действие (сохранение, удаление, выход и т. п.) без сборки сложного контента.

## Ключевые особенности

- Готовое тело окна с заголовком, описанием и двумя кнопками
- Автоматические отступы для текстового `body`
- Возможность передать собственный footer вместо стандартных кнопок
- Использует все возможности `ModalDF`: `contentContainerProps`, `fullScreen`, etc.

## Compound-компоненты

ModalDFConfirmation наследует `Footer` из `ModalDF` и переэкспортирует его для кастомных сценариев.

## Особенности

- `content` — основной объект для настройки содержимого. Если его не передавать, можно управлять разметкой через `children`.
- Остальные пропсы соответствуют `ModalDF`, кроме `children`, `content` и `hasBody`.
- `mainButton` и `secondaryButton` наследуют пропсы `Button` и автоматически получают размеры/виды по умолчанию.
- `bodyMarginBlock` помогает выставить вертикальные отступы, если текст не строкой или нужно индивидуальное значение.
