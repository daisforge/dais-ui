# Canvas.Checkbox

Чекбокс для canvas-ячеек `TableCanvas`.

## Ключевые особенности

- Состояния: `checked`, `indeterminate`
- Поддержка `view`, `buttonSize`, `disabled`
- `onClick` для обработки нажатия

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvascheckbox-api--docs).
