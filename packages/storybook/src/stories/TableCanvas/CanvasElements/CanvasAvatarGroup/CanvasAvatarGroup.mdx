# Canvas.AvatarGroup

Группа аватаров участников с отдельным счётчиком скрытых элементов в ячейке `TableCanvas`.

## Ключевые особенности

- Пять участников при `visibleCount={3}` отображаются как три аватара и круг `+2`.
- Содержимое задаётся массивом `items`; у каждого участника должен быть уникальный `id`.
- Общий размер группы: `s`, `m`, `l` или `xxl`; по умолчанию — `s`.
- Аватар раскрывается при наведении, а вырез соседнего элемента меняется.
- Отдельные обработчики клика по участнику и счётчику, индивидуальные тултипы.

## Особенности

При смене URL у участника с тем же `id` и именем его предыдущее фото сохраняется до загрузки нового. При первой загрузке отображаются инициалы.

`visibleCount` ограничивает число обычных аватаров и по умолчанию равен `3`. Счётчик занимает дополнительное место. `totalCount` учитывает всех участников, включая отсутствующих в `items`, и не может быть меньше длины массива при расчёте.

Пустая группа без `totalCount` не занимает места. При `visibleCount={0}` отображается только счётчик. В узкой колонке группа обрезается: диаметр и число видимых аватаров автоматически не меняются.

В `+N` выводится точное число. Длинный текст обрезается границами круга, а полное значение доступно в тултипе. `overflowTooltip` позволяет заменить этот тултип.

Для текстового представления ячейки и копирования задайте `column.copyData`: перечислите известные имена и число неизвестных участников.

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasavatargroup-api--docs).
