# Canvas.Avatar

Круглый аватар с фотографией, инициалами или коротким текстом для ячеек `TableCanvas`.

## Ключевые особенности

- Размеры FinAI: `s` — 24 px, `m` — 36 px, `l` — 48 px, `xxl` — 88 px.
- Размер по умолчанию — `s`.
- Приоритет содержимого: непустой `customText`, фотография, инициалы из `name`.
- Поддержка тултипов и кликов.

## Особенности

При первой загрузке фотографии или если исходный URL недоступен отображаются инициалы. Если имя не задано, остаётся фон. При заданном `customText` фотография не загружается.

При смене URL у того же аватара предыдущее фото остаётся до готовности нового, без промежуточного показа инициалов. Если новое фото недоступно, сохраняется предыдущее, пока оно есть в загрузчике.

Для разных участников задавайте разные `id` или React `key`, особенно если имена совпадают. Смена `id` или имени, удаление URL и переход на `customText` сбрасывают предыдущее фото.

Фотография растягивается до размеров аватара. Инициалы под загруженным изображением не рисуются.

Для размещения используйте `Canvas.Container`. Примитив не принимает `children`.

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasavatar-api--docs).
