# Canvas.Button

Кнопка внутри canvas-ячейки `TableCanvas`.

## Ключевые особенности

- Несколько вариантов `view` и `size`
- Поддержка `disabled`, `leftIcon` / `rightIcon`
- `onClick` выполняется перед `tableConfig.onCellClicked` — используйте `event.stopPropagation()` для предотвращения всплытия

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasbutton-api--docs).
