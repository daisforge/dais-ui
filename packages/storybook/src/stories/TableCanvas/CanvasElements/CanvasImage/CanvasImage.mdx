# Canvas.Image

Изображение по URL в ячейке `TableCanvas` с заранее заданными размерами.

## Ключевые особенности

- Три режима вписывания: `cover`, `contain` и `fill`.
- Выравнивание изображения по центру.
- Поддержка прозрачных изображений, тултипов и кликов.
- Размеры через `style.width` и `style.height` не меняются после загрузки.

## Особенности

По умолчанию используется `cover`: изображение заполняет область с обрезкой по краям. `contain` сохраняет изображение целиком, а `fill` растягивает его до заданных размеров.

Пока изображение загружается или если URL недоступен, зарезервированная область остаётся пустой. Загрузка поддерживается в ячейках данных; в заголовках она недоступна.

Для размещения используйте `Canvas.Container`. Примитив не принимает `children`.

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasimage-api--docs).
