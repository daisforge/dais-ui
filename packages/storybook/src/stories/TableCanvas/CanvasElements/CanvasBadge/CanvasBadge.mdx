# Canvas.Badge

Бейдж для отображения статусов и меток в ячейках `TableCanvas`.

## Ключевые особенности

- Несколько встроенных `view` и `size`
- Режимы `transparent`, `clear`, `pilled`
- Кастомные цвета через `customColor` / `customBackgroundColor`
- Поддержка `leftIcon` / `rightIcon`
- Подсветка фрагмента текста [`Canvas.Mark`](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasmark--docs): текст с разметкой передаётся в `children` или в `text` (если заданы оба — используются `children`)

```tsx
<Canvas.Badge text="Трайб «Диджитал вкладов»" />
<Canvas.Badge>
  Трайб «<Canvas.Mark color="#ffe27a">Диджитал</Canvas.Mark> вкладов»
</Canvas.Badge>
```

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasbadge-api--docs).
