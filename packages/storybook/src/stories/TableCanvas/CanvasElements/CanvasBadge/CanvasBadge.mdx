# Canvas.Badge

Бейдж для отображения статусов и меток в ячейках `TableCanvas`.

## Ключевые особенности

- Несколько встроенных `view` и `size`
- Режимы `transparent`, `clear`, `pilled`
- Кастомные цвета через `customColor` / `customBackgroundColor`
- Поддержка `leftIcon` / `rightIcon`
- Без `size` размер следует текущему размеру таблицы: XS (`small`) — 16 px (`xs`), S (`medium`) — 24 px (`m`), M (`big`) — 28 px (`l`). Переключение размера таблицы обновляет бейдж автоматически.
- Явный `size` имеет приоритет; без размера таблицы используется `s` (20 px).

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasbadge-api--docs).
