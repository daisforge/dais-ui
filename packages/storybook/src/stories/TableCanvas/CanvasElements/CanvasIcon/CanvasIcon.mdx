# Canvas.Icon

Иконка внутри canvas-ячейки `TableCanvas`.

## Ключевые особенности

- Принимает иконку через `Canvas.icon(<IconName />)` — преобразует React-иконку в canvas-формат
- Настраиваемый `size` и `color`

Описание типов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasicon-api--docs).
