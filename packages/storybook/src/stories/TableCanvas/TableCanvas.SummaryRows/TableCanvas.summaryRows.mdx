# Summary Rows

**tableConfig.summaryRows + пропс bottomSummaryRows**

Итоговые строки в нижней части таблицы.

Конфигурация состоит из двух частей:

- **`tableConfig.summaryRows`** (`SummaryRowsConfig`) — настройка видимости и кнопки в control block
- **Пропс `bottomSummaryRows`** (`SummaryRowType[]`) — массив данных для итоговых строк

## tableConfig.summaryRows (SummaryRowsConfig)

- **`showDefault`** `boolean` — показывать итоговые строки по умолчанию
- **`showInControl`** `boolean` — кнопка переключения видимости в control block
- **`onChange`** `(checked: boolean) => void` — вызывается, когда пользователь переключает тогл «Итоговые строки» в настройках таблицы. Не вызывается при монтировании

### Сохранение выбора пользователя

Сохраните значение в `onChange` и передайте его обратно в `showDefault`:

```tsx
const STORAGE_KEY = 'my-table:summary-rows';

const [showSummary] = useState(
  () => localStorage.getItem(STORAGE_KEY) !== 'false',
);

<TableCanvas
  tableConfig={{
    summaryRows: {
      showDefault: showSummary,
      showInControl: true,
      onChange: (checked) =>
        localStorage.setItem(STORAGE_KEY, String(checked)),
    },
  }}
  ...
/>;
```

> `showDefault` читается только при монтировании таблицы. Если поменять его позже, текущее состояние тогла не изменится.

## Пропс bottomSummaryRows

Массив объектов `SummaryRowType[]`, передаётся напрямую в компонент `TableCanvas`. Количество элементов массива = количество итоговых строк. Пустой массив — итоговые строки не отображаются.

## Рендер в columnConfig

Кастомный рендер через `renderSummaryCell` в конфигурации колонки. Данные итоговой строки доступны через `row`.

## Особенности

- Необходимо соблюдать отступы ячеек через `theme.cellHorizontalPadding`
