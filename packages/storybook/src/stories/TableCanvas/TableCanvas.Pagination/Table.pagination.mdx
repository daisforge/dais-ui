# Table Pagination

**tableConfig.pagination**

Таблица поддерживает пагинацию. Для активации функционала в `tableConfig` заполняется `pagination`.

## Особенности работы с пагинацией

### Отключение дефолтной сортировки и фильтрации

При активации `pagination` отключается дефолтная сортировка и фильтрация.
Нужно использовать версии данных фичей с ручным управлением. Например, для отправки на бэкенд выбранных фильтров и сортировки.

**Причина:** Предполагается, что если есть pagination, то в таблице представлен не весь объем данных,
по этой причине дефолтная сортировка и фильтрация не подходят и будут отображать некорректные данные.

### Адаптивные slots

По умолчанию ВЫКЛЮЧЕНА умная адаптация количества slots пагинации в зависимости от ширины контейнера таблицы и размера пагинации (`size`).

Эту функциональность можно включить, установив `responsiveSlots: true`, тогда количество slots будет фиксированным (задавать `slots` в props не нужно), важно указать `value` как значение текущей выбранной страницы.

При достижении минимальной ширины контейнера, когда остается только 1 slot, автоматически отображаются навигационные стрелки в `leftContent` и `rightContent`.

## Изменения в API относительно SDDS Pagination

- **`onChangePageValue`** — добавлен параметр `scrollToTop: () => void` для автоматического скролла к началу новой страницы
- **`onChange`** — добавлен параметр `scrollToTop: () => void` для автоматического скролла к началу новой страницы
- **`responsiveSlots`** — включение/выключение умной адаптации slots (default: `false`)
- **`onResize`** — callback при изменении ширины контейнера пагинации
