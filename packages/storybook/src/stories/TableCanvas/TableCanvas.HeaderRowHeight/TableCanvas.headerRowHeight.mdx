# HeaderRowHeight (TableCanvas)

**tableConfig.headerRowHeight**

Настройка высоты ряда шапки таблицы. Одно число задаёт высоту заголовков. По умолчанию `33`.

## Ключевые особенности

- Фиксированная высота ряда шапки (`number`)
- Значение задаётся один раз в `tableConfig`
- Применяется ко всем уровням объединённой (групповой) шапки одинаково; свою высоту уровням групп задаёт `groupHeaderRowHeight`

## tableConfig.headerRowHeight

- **`number`** — высота одного ряда шапки в пикселях
- **по умолчанию** — `33`

## Поведение с объединёнными шапками

Без `groupHeaderRowHeight` значение применяется к **каждому** уровню шапки: и к листовому (нижнему) ряду
колонок, и к каждому уровню объединённых заголовков. Поэтому при `N` уровнях
группировки итоговая высота шапки считается так:

```
итоговая высота = headerRowHeight * (1 + число уровней групп)
```

## tableConfig.groupHeaderRowHeight

Высота **каждого уровня** объединённых (групповых) заголовков. По умолчанию равна
`headerRowHeight`. Нужна, когда нижний ряд шапки выше уровней групп, например при
переносе названий колонок на несколько строк:

```
итоговая высота = headerRowHeight + groupHeaderRowHeight * число уровней групп
```
