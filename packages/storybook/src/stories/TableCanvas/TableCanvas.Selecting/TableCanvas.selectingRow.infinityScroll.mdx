# SelectingRow + SubRows + InfinityScroll

Выбор строк в древовидной таблице (`subRows`) с бесконечной подгрузкой.

Комбинация `tableConfig.selecting` с `tableConfig.subRows` и бесконечным скроллом:
выбор сохраняется по мере подгрузки новых строк.
