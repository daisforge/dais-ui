# Selecting Row

**tableConfig.selecting**

Выбор строк таблицы с помощью чекбоксов.

## Ключевые особенности

- Управляемое состояние через `ReadonlySet<string | number>`
- Кнопка переключения видимости в control block (`showInControl: true`)
- Контроль на уровне строк: `rowCheckboxDisabled`, `rowShowCheckbox`
- Поддержка иерархических таблиц через `selectingRules.levels`
- Кастомизация summary-чекбокса через `summaryChecked`
- Ограничение числа в счётчике выбранных — `summaryCounterMaxCount` (при превышении показывает «N+», например `99+`). См. [Ограничение счётчика (99+)](?path=/docs/локальные-компоненты-tablecanvas-selectingrow-countermaxcount--docs)

## Особенности

- `rowKeyGetter` должен возвращать уникальный идентификатор строки
- В иерархических таблицах `selectingRules.levels` определяет, на каких уровнях доступен выбор
- `rowGetStates` позволяет полностью переопределить логику чекбоксов (checked, indeterminate, disabled)
- Accent-кнопки в mass action panel всегда видимы при компрессии

> Подробнее о типах и пропсах — [Selecting API](?path=/docs/локальные-компоненты-tablecanvas-selecting-api--docs)
