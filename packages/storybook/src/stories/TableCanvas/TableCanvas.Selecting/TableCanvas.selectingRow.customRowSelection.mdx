# SelectingRow — ручная настройка выбора строк

Тонкая настройка выбора строк через `tableConfig.selecting`: управление тем, у каких
строк показывать чекбокс (`rowShowCheckbox`), какие дизейблить (`rowCheckboxDisabled`),
а также кастомизация summary-чекбокса в шапке через `summaryChecked`.

> Типы SelectingRow — [SelectingRow API](?path=/docs/локальные-компоненты-tablecanvas-selectingrow-api--docs)
