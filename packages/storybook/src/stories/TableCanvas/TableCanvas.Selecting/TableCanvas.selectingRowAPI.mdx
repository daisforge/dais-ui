# SelectingRow API

> **Важно:** `tableConfig.selecting` (этот раздел) — выбор строк **чекбоксами**.
> Это отдельный механизм от `tableConfig.cellsSelection` (см. ниже) — выделения
> колонок по клику на шапку.
