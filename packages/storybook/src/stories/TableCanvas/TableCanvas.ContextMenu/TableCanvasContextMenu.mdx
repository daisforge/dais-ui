# Context Menu

**tableConfig.onHeaderContextMenu / onCellContextMenu / onHeaderContextMenuDropdown / onCellContextMenuDropdown**

Контекстное меню для заголовков колонок и ячеек.

## Основные возможности

- Правый клик по заголовку колонки или ячейке открывает контекстное меню
- Поддержка многоуровневых dropdown-меню (на основе компонента Dropdown)
- Кастомизация пунктов меню в зависимости от контекста (колонка/ячейка)
- Обработка выбора пунктов меню с передачей соответствующего контекста

## Варианты использования

### 1. Простой обработчик клика (без меню)

- `onHeaderContextMenu` — для заголовков колонок
- `onCellContextMenu` — для ячеек таблицы

### 2. Dropdown-меню (расширенный вариант)

- `onHeaderContextMenuDropdown` — для заголовков
- `onCellContextMenuDropdown` — для ячеек

## Приоритет вызова

Если определены оба варианта (и обработчик, и dropdown):

1. Сначала вызывается `onHeaderContextMenu` / `onCellContextMenu`
2. Затем происходит обработка dropdown-меню

## Конфигурация Dropdown

Для конфигурации dropdown-меню используются специальные пропсы, исключающие некоторые параметры стандартного Dropdown, которые управляются таблицей (например, позиционирование, триггеры и т.д.).

## Асинхронная подгрузка пунктов

Когда пункты меню неизвестны заранее и подгружаются по правому клику. Запросом и его состоянием (загрузка / данные / ошибка) владеет потребитель — таблица только открывает меню и реактивно перечитывает пункты.

- `onOpen` — вызывается при открытии меню; здесь потребитель стартует запрос и хранит своё состояние. Если задан, меню открывается даже при пустом результате `getDropdownItems`.
- `getDropdownItems` — читается реактивно, пока меню открыто: во время загрузки верните скелетон-пункты, после — реальные. Меню обновляется само, без переоткрытия.
- Индикатор загрузки — скелетон-пункты (через `renderItem`) или произвольный узел в `beforeList`.
- Ошибка — узел в `beforeList` (например `EmptyState` с кнопкой повтора, вызывающей повторную загрузку).

Пример со скелетонами, успешной загрузкой и ошибкой — в стори ниже.
