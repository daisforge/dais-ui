# Context Menu API

## ContextMenuDropdownProps

Пропсы Dropdown, доступные для проброса в контекстное меню.
Можно передать `size`, `listWidth`, `closeOnSelect`, `offset` и другие свойства Dropdown.

По умолчанию список растёт по содержимому в пределах своего размера — XS 120–300 px, S 120–380 px и M 140–440 px. При достижении максимума длинные подписи переносятся. Явный `listWidth="580px"` задаёт 580 px во всех трёх размерах. Ось X задаёт точка клика. При открытии вниз `offset` отсчитывается от нижней границы строки, при открытии вверх — от верхней. Зазор по умолчанию составляет 4 px.
