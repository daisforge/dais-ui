# Context Menu API

## ContextMenuDropdownProps

Пропсы Dropdown, доступные для проброса в контекстное меню.
Можно передать `size`, `listWidth`, `closeOnSelect`, `offset` и другие свойства Dropdown.

По умолчанию список растёт по содержимому в пределах своего размера — XS 120–300 px, S 120–380 px и M 140–440 px. При достижении максимума длинные подписи переносятся. Явный `listWidth="580px"` задаёт 580 px во всех трёх размерах. Ось X задаёт точка клика. По умолчанию меню открывается на 4 px ниже ячейки или заголовка. При открытии вверх зазор отсчитывается от верхней границы. Если высота превышает 48 px, меню открывается у точки клика с тем же зазором.

При явном `offset` смещение всегда отсчитывается от курсора. Например, `offset: [0, 0]` открывает меню в точке клика.
