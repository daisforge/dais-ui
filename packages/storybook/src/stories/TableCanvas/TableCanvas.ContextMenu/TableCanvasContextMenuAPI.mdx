# Context Menu API

## ContextMenuDropdownProps

Пропсы Dropdown, доступные для проброса в контекстное меню.
Можно передать `size`, `listWidth`, `closeOnSelect`, `offset` и другие свойства Dropdown.

Ширина стандартного списка ограничена его размером: XS — 120–300 px, S — 120–380 px, M — 140–440 px. Например, при `size="s"` и `listWidth="580px"` меню занимает 380 px. Точка ПКМ задаёт горизонтальную координату, по вертикали меню открывается на 4 px ниже ячейки или заголовка.
