# Sidebar (TableCanvas)

Боковые панели таблицы с независимыми вкладками и произвольным React-контентом. Левая панель задаётся через `tableConfig.leftSidebarConfig`, правая — через `tableConfig.rightSidebarConfig`.

## Ключевые особенности

- Пользовательские вкладки с обеих сторон: навигация, сведения, дополнительные действия.
- Встроенные настройки таблицы, колонок и фильтров в правой панели.
- Независимое управление открытием и активной вкладкой каждой панели.
- Динамическая ширина в пикселях, CSS-единицах, процентах и `calc()`.
- Изменение ширины по ID активной вкладки без перемонтирования таблицы.
- Совместимость правой панели с прежним `tableConfig.sidebarConfig`.

## Левая и правая панели

`leftSidebarConfig` и `rightSidebarConfig` используют общий набор параметров: `enabled`, `width`, `customTabs`, `customTabsOrder`, `defaultOpen`, `openState`, `defaultActiveTabId`, `activeTabState` и `onActiveTabChange`. Пользовательскую конфигурацию можно перенести с одной стороны на другую.

Слева доступны пользовательские вкладки. Справа дополнительно поддерживается `defaultTabs` для встроенных настроек таблицы, колонок и фильтров. Обе панели могут быть открыты одновременно на разных вкладках.

Для правой панели поддерживается прежнее имя `sidebarConfig`. Если переданы оба имени, используется `rightSidebarConfig`.

## Пользовательские вкладки

В `customTabs` передайте вкладки с уникальным `id`, подписью `label`, иконкой `icon` и содержимым `content: ReactNode`. `title` задаёт заголовок открытого контента, `titleRightSlot` — дополнительный элемент справа от него. `domMetadata` позволяет добавить data-атрибуты и классы для тестирования и аналитики.

Тип пользовательской вкладки доступен как `TableCanvasSidebarTab` из `@daisforge/ui/components/TableCanvas`; в API показано его исходное объявление `SidebarTab`.

`showInSidebar: false` скрывает вкладку. Через `customTabsOrder` можно изменить порядок пользовательских вкладок. Клик по вкладке открывает её; повторный клик по активной вкладке или крестик закрывает соответствующую панель. `enabled: false` отключает интерфейс панели.

## Встроенные вкладки справа

1. **Колонки** (`columns`) — видимость, порядок и закрепление колонок. Появляется при наличии `columnsControl`.
2. **Настройки таблицы** (`tableSettings`) — итоговые строки, выбор строк и пользовательские возможности из ControlBlock. `customGeneralSettingsSlot` добавляет контент после общих настроек.
3. **Фильтры** (`filtering`) — управление фильтрацией данных. Появляется при наличии `filtering`.

Через `defaultTabs` можно переопределить подпись `label`, заголовок `title`, слот `titleRightSlot`, метаданные `domMetadata` и видимость `showInSidebar`. Для `tableSettings` также доступны `customGeneralSettingsSlot` и `iconTooltipText` — тултип кнопки-шестерёнки.

Чтобы убрать все встроенные вкладки, передайте `showInSidebar: false` для каждого ID: `tableSettings`, `columns` и `filtering`. Пустой массив `defaultTabs` не отключает автоматически появляющиеся настройки.

## Управление состоянием

По умолчанию каждая панель закрыта и хранит состояние внутри таблицы.

- `defaultOpen` открывает панель при первом рендере.
- `defaultActiveTabId` выбирает начальную вкладку. Если её нет или она скрыта, используется первая доступная.
- `openState: [open, setOpen]` управляет открытием извне; при его наличии `defaultOpen` игнорируется.
- `activeTabState: [activeTabId, setActiveTabId]` управляет активной вкладкой извне; при его наличии `defaultActiveTabId` игнорируется.
- `onActiveTabChange(id, tab)` сообщает о смене вкладки и работает также при внутреннем состоянии. При закрытии приходит `null`.

Для внешнего открытия конкретной вкладки установите её ID и состояние открытия. При закрытии активная вкладка сбрасывается в `null` с задержкой. Повторный клик по активной вкладке сначала передаёт её ID, затем закрывает панель.

## Ширина

`width` задаёт ширину контента без полоски вкладок 44px. Слева ширина контента по умолчанию 300px, справа — 400px; целиком открытые панели занимают 344px и 444px соответственно.

Число означает пиксели, строка передаётся в CSS: `'320px'`, `'25%'`, `'calc(20% + 40px)'`. Проценты считаются от общей ширины рабочей области TableCanvas. Изменение `width` через React state сразу обновляет размер открытой панели; переход анимируется за 0.5 секунды.

У отдельной вкладки нет собственного `width`. Для разных размеров вкладок меняйте ширину панели по ID в `onActiveTabChange`. При `null` оставляйте прежний размер, чтобы закрытие не вызвало дополнительный ресайз. Примеры ниже показывают 300px слева и 400px справа для вкладки «Отчёты», а для «Книги» — 35%.

В компоновке с левой или обеими панелями на узком контейнере их контент сжимается, оставляя место для canvas; полоски вкладок сохраняют ширину 44px. Если задана только правая панель, её минимальная ширина сохраняется для совместимости с прежней компоновкой.

## Хуки внутри контента

```tsx
import {
  useLeftSidebar,
  useRightSidebar,
  useSidebar,
} from '@daisforge/ui/components/TableCanvas';
```

`useLeftSidebar()` возвращает `isOpen`, `width: string | number` и `toggle()`. Шириной слева управляет `leftSidebarConfig.width`.

`useRightSidebar()` и прежний алиас `useSidebar()` сохраняют числовой контракт: `isOpen`, `width: number`, `toggle()` и `setWidth(number)`. Без `rightSidebarConfig.width` setter меняет отображаемую ширину, начиная с 400px. Если ширина задана конфигом, она имеет приоритет для отображения, а контекст продолжает хранить внутреннее числовое значение; это не измеренный CSS-размер панели.

Оба новых хука также доступны из `@daisforge/ui`. Прежний `useSidebar` для TableCanvas импортируется из entrypoint компонента; корневой `useSidebar` относится к компоненту `Table`. Контекстные типы в API показывают форму результата хуков.

## Особенности

Панели отображаются в режиме строк. При collapse рабочая область скрывается и исключается из фокуса; размеры и состояние вкладок сохраняются до разворачивания. Панели поддерживают полноэкранный режим и совместную работу с нижним слотом.

Нижняя панель и совместный пример со сворачиванием, пагинацией и другими возможностями — в разделе [BottomSheet](?path=/docs/локальные-компоненты-tablecanvas-bottomsheet--docs).

## Примеры

- **С кастомной вкладкой** — информация о строках и текущем выделении в правой панели.
- **Открыт по умолчанию** — начальная пользовательская вкладка.
- **Внешнее управление активной вкладкой** — открытие выбранной вкладки и закрытие панели кнопками.
- **Колбэк активной вкладки** — текущая вкладка по уведомлениям панели.
- **Левая панель** — пользовательская навигация с поиском, управлением открытием и шириной по ID вкладки.
- **Правая панель** — пользовательский контент с разной шириной вкладок и отключёнными встроенными настройками.

Описание типов — в разделе [Sidebar API](?path=/docs/локальные-компоненты-tablecanvas-sidebar-api--docs).
