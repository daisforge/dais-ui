# Sidebar (TableCanvas)

**tableConfig.sidebarConfig**

Правая панель таблицы с вкладками. Открывается через кнопку-шестерёнку в controlBlock. Позволяет управлять настройками таблицы, фильтрацией и колонками.

## Ключевые особенности

- Три стандартные вкладки: колонки, настройки таблицы, фильтры
- Добавление пользовательских вкладок через `customTabs`
- Управление порядком кастомных вкладок через `customTabsOrder`
- Кастомизация стандартных вкладок через `defaultTabs`
- Отключение sidebar через `enabled: false`

## Стандартные вкладки

1. **Настройка колонок** (`columns`) — управление видимостью, порядком и закреплением колонок. Появляется автоматически при наличии `columnsControl`
2. **Настройки таблицы** (`tableSettings`) — итоговые строки, выбор строк, кастомные фичи из ControlBlock. Поддерживает `customGeneralSettingsSlot` для дополнительного контента
3. **Фильтры** (`filtering`) — управление фильтрацией данных. Появляется автоматически при наличии `filtering`

## Кастомизация стандартных вкладок

Через `defaultTabs` можно переопределить:

- `label` — текст на табе
- `title` — заголовок в шапке сайдбара
- `domMetadata` — data-атрибуты для тестирования и аналитики
- `titleRightSlot` — кастомный элемент справа от заголовка

## Пользовательские вкладки

Через `customTabs` можно добавить произвольные вкладки с `label`, `icon` и `renderContent`.

## Управление состоянием сайдбара

По умолчанию сайдбар закрыт (uncontrolled). Стартовое и внешнее состояние настраивается через `sidebarConfig`:

- `defaultOpen` — сайдбар открыт сразу при первом рендере.
- `defaultActiveTabId` — какая вкладка выбрана по умолчанию. Актуально при открытом сайдбаре; если id не найден или у вкладки `showInSidebar=false`, берётся первая доступная.
- `openState` — внешний контроль открытия/закрытия (`[boolean, setter]`). Если передан, `defaultOpen` игнорируется.
- `activeTabState` — внешний контроль активной вкладки (`[string | null, setter]`). Позволяет, например, открыть нужную вкладку по кнопке над таблицей. Если передан, `defaultActiveTabId` игнорируется.
- `onActiveTabChange` — колбэк смены активной вкладки. Вызывается и в uncontrolled-режиме; при закрытии сайдбара приходит `null`.

Активная вкладка имеет смысл только при открытом сайдбаре — при закрытии она сбрасывается в `null`.
