# Sidebar (TableCanvas)

Боковые панели таблицы с независимыми вкладками и произвольным React-контентом. Левая панель задаётся через `tableConfig.leftSidebarConfig`, правая — через `tableConfig.rightSidebarConfig`.

## Ключевые особенности

- Пользовательские вкладки с обеих сторон: навигация, сведения, дополнительные действия.
- Встроенные настройки таблицы, колонок и фильтров в правой панели.
- Независимое управление открытием и активной вкладкой каждой панели.
- Динамическая ширина в пикселях, CSS-единицах, процентах и `calc()`.
- Разная ширина панели для разных вкладок.
- Совместимость правой панели с `tableConfig.sidebarConfig`.

## Левая и правая панели

Настройки пользовательских вкладок, ширины и открытия одинаковы для обеих сторон. Панелями можно управлять независимо.

Слева доступны пользовательские вкладки. Справа дополнительно поддерживается `defaultTabs` для встроенных настроек таблицы, колонок и фильтров. Обе панели могут быть открыты одновременно на разных вкладках.

Для правой панели `sidebarConfig` поддерживается как алиас `rightSidebarConfig`. Если переданы оба имени, используется `rightSidebarConfig`.

## Пользовательские вкладки

В `customTabs` передайте вкладки с уникальным `id`, текстом подсказки `label`, иконкой `icon` и содержимым `content: ReactNode`. На полоске вкладок показывается иконка. `title` задаёт заголовок открытого контента; если его нет, используется `label`. `titleRightSlot` добавляет элемент справа от заголовка. `domMetadata` позволяет добавить data-атрибуты и классы для тестирования и аналитики.

Тип пользовательской вкладки импортируется как `TableCanvasSidebarTab` из `@daisforge/ui/components/TableCanvas`.

`showInSidebar: false` скрывает вкладку. Через `customTabsOrder` можно изменить порядок пользовательских вкладок. Клик по вкладке открывает её; повторный клик по активной вкладке или крестик закрывает соответствующую панель. `enabled: false` отключает интерфейс панели.

## Встроенные настройки справа

Настройки открываются одной кнопкой-шестерёнкой. Внутри доступны разделы:

- **Общие настройки** (`tableSettings`) — итоговые строки, выбор строк и пользовательские возможности из ControlBlock. `customGeneralSettingsSlot` добавляет контент после общих настроек.
- **Колонки** (`columns`) — видимость, порядок и закрепление колонок. Доступен при включённом `columnsControl`.
- **Фильтры** (`filtering`) — управление фильтрацией данных. Доступен при включённом `filtering`.

Через `defaultTabs` можно переопределить подпись `label`, заголовок `title`, слот `titleRightSlot`, метаданные `domMetadata` и видимость `showInSidebar`. Для `tableSettings` также доступны `customGeneralSettingsSlot` и `iconTooltipText` — тултип кнопки-шестерёнки.

Чтобы убрать все встроенные вкладки, передайте `showInSidebar: false` для каждого ID: `tableSettings`, `columns` и `filtering`. Пустой массив `defaultTabs` не отключает автоматически появляющиеся настройки.

## Управление открытием и вкладкой

По умолчанию каждая панель закрыта. Можно задать начальное открытие и вкладку или управлять ими из своего компонента.

- `defaultOpen` открывает панель при первом рендере.
- `defaultActiveTabId` выбирает начальную вкладку. Если её нет или она скрыта, используется первая доступная.
- `openState: [open, setOpen]` управляет открытием извне; при его наличии `defaultOpen` игнорируется.
- `activeTabState: [activeTabId, setActiveTabId]` управляет активной вкладкой извне; при его наличии `defaultActiveTabId` игнорируется.
- `onActiveTabChange(id, tab)` сообщает о выборе вкладки. При закрытии `id` равен `null`.

Для внешнего открытия конкретной вкладки передайте `openState` и `activeTabState`, затем установите нужный ID и `open: true`.

## Ширина

`width` задаёт ширину контента без полоски вкладок 44px. Слева ширина контента по умолчанию 300px, справа — 400px; целиком открытые панели занимают 344px и 444px соответственно.

Число означает пиксели; строка позволяет задать CSS-размер: `'320px'`, `'25%'`, `'calc(20% + 40px)'`. Проценты считаются от общей ширины рабочей области TableCanvas. Изменение `width` обновляет размер открытой панели; переход анимируется за 0.5 секунды.

У отдельной вкладки нет собственного `width`. Для разных размеров вкладок меняйте ширину панели по ID в `onActiveTabChange`. При `null` оставляйте прежний размер. Примеры ниже показывают 300px слева и 400px справа для вкладки «Отчёты», а для «Книги» — 35%.

На узком контейнере с левой или обеими панелями их контент сжимается, оставляя место для данных; полоски вкладок сохраняют ширину 44px. Если задана только правая панель, её ширина не сжимается.

## Хуки внутри контента

```tsx
import {
  useLeftSidebar,
  useRightSidebar,
  useSidebar,
} from '@daisforge/ui/components/TableCanvas';
```

`useLeftSidebar()` возвращает `isOpen`, `width: string | number` и `toggle()`. Шириной слева управляет `leftSidebarConfig.width`.

`useRightSidebar()` и его алиас `useSidebar()` возвращают `isOpen`, `width: number`, `toggle()` и `setWidth(number)`. Если ширина не задана через `rightSidebarConfig.width`, её можно менять вызовом `setWidth(number)`; по умолчанию она равна 400px. Ширина из конфига имеет приоритет.

Используйте эти хуки в компонентах, переданных в `content` вкладки. `useLeftSidebar` и `useRightSidebar` также доступны из `@daisforge/ui`. Для TableCanvas импортируйте `useSidebar` из `@daisforge/ui/components/TableCanvas`: `useSidebar` из корневого `@daisforge/ui` относится к компоненту `Table`.

## Особенности

Панели отображаются в режиме строк. При сворачивании таблицы они скрываются и исключаются из фокуса; размеры и выбранные вкладки сохраняются до разворачивания. Поддерживаются полноэкранный режим и совместная работа с нижней панелью BottomSheet.

Открытие любой Sidebar автоматически сворачивает панель массовых действий. Она автоматически разворачивается после закрытия всех Sidebar. Ручное сворачивание и разворачивание остаются доступными.

Нижняя панель и совместный пример со сворачиванием, пагинацией и другими возможностями — в разделе [BottomSheet](?path=/docs/локальные-компоненты-tablecanvas-bottomsheet--docs).

## Примеры

- **С кастомной вкладкой** — информация о строках и текущем выделении в правой панели.
- **Открыт по умолчанию** — начальная пользовательская вкладка.
- **Внешнее управление активной вкладкой** — открытие выбранной вкладки и закрытие панели кнопками.
- **Колбэк активной вкладки** — текущая вкладка по уведомлениям панели.
- **Левая панель** — пользовательская навигация с поиском, управлением открытием и шириной по ID вкладки.
- **Правая панель** — пользовательский контент с разной шириной вкладок и отключёнными встроенными настройками.

Описание типов — в разделе [Sidebar API](?path=/docs/локальные-компоненты-tablecanvas-sidebar-api--docs).
