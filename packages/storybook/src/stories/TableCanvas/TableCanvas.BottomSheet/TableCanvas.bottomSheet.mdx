# BottomSheet (TableCanvas)

Нижняя панель с произвольным React-контентом, например журналом событий. Задаётся через `tableConfig.bottomSheetConfig` и располагается под canvas, над общей пагинацией, между левой и правой боковыми панелями.

## Ключевые особенности

- Высота меняется через React state без перемонтирования таблицы.
- `height` и `minHeight` принимают число в пикселях или CSS-строку; по умолчанию оба значения равны 32px.
- Раскрытие, стрелку и внутреннюю прокрутку реализует потребитель в `content`.
- Панель работает вместе с Sidebar, пагинацией, выбором строк, массовыми действиями и полноэкранным режимом.
- Collapse скрывает рабочую область и пагинацию, сохраняя размеры и состояние панелей.

## Использование

```tsx
import { TableCanvas } from '@daisforge/ui/components/TableCanvas';
import { useState } from 'react';

const [height, setHeight] = useState<string | number>(32);

<TableCanvas
  rows={rows}
  columnConfig={columns}
  tableConfig={{
    containerStyle: { height: 620 },
    bottomSheetConfig: {
      height,
      minHeight: 32,
      content: (
        <EventLog onToggle={() => setHeight(height === 32 ? 220 : 32)} />
      ),
    },
  }}
/>;
```

## Особенности

Отдельного состояния открытия в API нет: высотой управляет потребитель. Для полного удаления панели передайте `enabled: false` или уберите конфиг. Внутреннему содержимому с прокруткой задайте `overflow: auto` и `minHeight: 0`.

Процент высоты считается от рабочей области после вычитания заголовка, control block, фильтров и пагинации. Раскрытие не увеличивает внешний контейнер. Панель ограничивается доступным пространством, оставляя canvas 120px; при рабочей области меньше 120px её высота сжимается до нуля. Изменение высоты анимируется за 0.5 секунды.

При collapse canvas, обе боковые панели, BottomSheet и пагинация скрываются и исключаются из фокуса. После разворачивания сохраняются активные вкладки и размеры. Поддерживаются положения кнопки `inside` и `above`, а также полноэкранный режим.

Панели поддерживаются в режиме строк. Error и empty state располагаются внутри canvas и сохраняют независимый BottomSheet. Skeleton также сохраняет компоновку. Активный `loadingOverlay` заменяет весь layout: canvas, обе Sidebar, BottomSheet и пагинацию.

## Примеры

**Высота, стрелка и пагинация** — минимальный пример раскрытия 32 ↔ 220px, высоты 35%, ограничения большой высоты и прокрутки журнала.

**Все возможности таблицы** — одна таблица с обеими Sidebar и журналом действий. В ней доступны поиск, фильтры, сортировка, редактирование с сохранением/отменой, выбор строк и ячеек, copy/paste/fill, итоги, настройки колонок, групповые заголовки, объединение ячеек, Canvas-рендеры, контекстные меню и уведомления. Настройки представления позволяют проверить тему, границы, hover, размеры строк и шапки, tooltip и preview.

Структура данных переключается между плоскими строками, группировкой деревом или со слиянием, собственными `subRows` деревом или со слиянием. Группировка и собственное дерево используют разные конфигурации. При группировке доступен полный набор данных; страницы дерева формируются по верхним узлам. Получение данных переключается между полным набором, страницами по 20 и локальной бесконечной загрузкой.

Редактирование, вставка и заполнение доступны в плоском режиме, группировке со слиянием и дереве `subRows`. Группировка деревом и `subRows` со слиянием в этом примере используются для просмотра и копирования: текущий адаптер изменений таблицы не сопоставляет производные строки этих режимов с исходным набором.

Поиск, фильтрация и сортировка выполняются в примере над полным набором до выбора страницы: при пагинации и бесконечной прокрутке TableCanvas ожидает обработанные данные. Правки применяются по стабильным ID, включая дочерние строки; строки других страниц сохраняются. Отмена восстанавливает снимок полного набора. Итоги вычисляются по полной отфильтрованной выборке. При смене условий поиска или фильтров сбрасывается страница и загруженная часть.

Изначально выбран плоский режим с пагинацией, выделением `range-cell` и свёрнутым журналом. Левая Sidebar открыта, правая закрыта. В журнал попадают действия таблицы; автоматические проверки вынесены в отдельные visual stories.

Описание типов — в разделе [BottomSheet API](?path=/docs/локальные-компоненты-tablecanvas-bottomsheet-api--docs).
