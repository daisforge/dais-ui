# BottomSheet (TableCanvas)

Нижняя панель с произвольным React-контентом, например журналом событий. Задаётся через `tableConfig.bottomSheetConfig` и располагается под областью данных, над общей пагинацией, между левой и правой боковыми панелями.

## Ключевые особенности

- `height`, `minHeight` и `maxHeight` принимают число в пикселях или CSS-строку; по умолчанию `height` и `minHeight` равны 32px.
- `height: 'auto'` подстраивает панель под содержимое, а `maxHeight` ограничивает её высоту. При переполнении панель прокручивается.
- Содержимое, кнопку раскрытия и высоту открытой панели задаёт потребитель.
- Панель работает вместе с Sidebar, пагинацией, выбором строк, массовыми действиями и полноэкранным режимом.
- Collapse скрывает рабочую область и пагинацию, сохраняя размеры и состояние панелей.

## Использование

```tsx
import { TableCanvas } from '@daisforge/ui/components/TableCanvas';
import { useState } from 'react';

function TableWithEventLog() {
  const [height, setHeight] = useState<string | number>(32);

  return (
    <TableCanvas
      rows={rows}
      columnConfig={columns}
      tableConfig={{
        containerStyle: { height: 620 },
        bottomSheetConfig: {
          height,
          minHeight: 32,
          content: (
            <EventLog onToggle={() => setHeight(height === 32 ? 220 : 32)} />
          ),
        },
      }}
    />
  );
}
```

## Особенности

### Размеры и прокрутка

Проценты в `height`, `minHeight` и `maxHeight` считаются от пространства, доступного строкам таблицы и BottomSheet. Блок управления, фильтры и пагинация в него не входят. Раскрытие не увеличивает внешний контейнер. Панель оставляет для области данных не менее 120px; если всё доступное пространство меньше 120px, высота панели равна нулю. `maxHeight` дополнительно ограничивает высоту, а `minHeight` не может превышать получившийся максимум.

Например, при высоте таблицы 620px, блоке управления 40px и пагинации 56px доступно `620 − 40 − 56 = 524px`. BottomSheet высотой 220px оставляет для области данных `524 − 220 = 304px`.

Для высоты по содержимому передайте `height: 'auto'`. Панель растёт и уменьшается вместе с содержимым, а при достижении `maxHeight` или границы доступного пространства прокручивается. Содержимому в этом режиме не задавайте `height: 100%`: оно должно сохранять естественную высоту.

При фиксированной высоте прокрутку настраивают внутри `content`: задайте прокручиваемому блоку `overflow: auto` и `minHeight: 0`.

### Раскрытие

Раскрытие задаётся изменением `height`, а кнопка раскрытия размещается в `content`. Чтобы убрать панель, передайте `enabled: false` или удалите `bottomSheetConfig`.

Изменение числовой или процентной высоты анимируется за 0.5 секунды. Плавный переход между фиксированной высотой и `auto` поддерживается в современных Chrome/Edge; в других браузерах высота может переключаться сразу. Добавление и удаление содержимого в режиме `auto` меняет высоту без отдельной анимации.

Для плавного закрытия сохраняйте содержимое панели при изменении высоты. Не скрывайте его через `hidden` и не удаляйте условно. Закрытую часть содержимого исключайте из чтения скринридером через `aria-hidden` и из фокуса и взаимодействия через `inert`; кнопка раскрытия должна оставаться доступной.

### Совместная работа с таблицей

При collapse область данных, обе боковые панели, BottomSheet и пагинация скрываются и исключаются из фокуса. После разворачивания сохраняются активные вкладки и размеры. Поддерживаются положения кнопки `inside` и `above`, а также полноэкранный режим.

BottomSheet доступен в режиме строк. Error, empty state и skeleton сохраняют панель. Активный `loadingOverlay` заменяет всю таблицу вместе с Sidebar, BottomSheet и пагинацией.

## Примеры

**Высота, стрелка и пагинация** — минимальный пример раскрытия 32 ↔ 220px, высоты 35%, ограничения большой высоты и прокрутки журнала.

**Высота по содержимому и maxHeight** — раскрытие 32 ↔ `auto`, добавление и удаление сообщений, короткий и длинный журнал, ограничение высоты в пикселях и процентах. Переполнение прокручивается на самой панели.

**Все возможности таблицы** — совместная работа BottomSheet и обеих Sidebar с поиском, фильтрами, сортировкой, редактированием, выбором строк и ячеек, copy/paste/fill, итогами, настройками колонок и представления. Действия записываются в журнал.

В примере можно переключить плоские строки, группировку и дерево `subRows`, полный набор данных, страницы по 20 строк и локальную бесконечную загрузку. При группировке доступен только полный набор данных; страницы дерева формируются по верхним узлам.

Редактирование, вставка и заполнение доступны в плоском режиме, группировке со слиянием и дереве `subRows`. Группировка деревом и `subRows` со слиянием в этом примере доступны для просмотра и копирования.

Описание типов — в разделе [BottomSheet API](?path=/docs/локальные-компоненты-tablecanvas-bottomsheet-api--docs).
