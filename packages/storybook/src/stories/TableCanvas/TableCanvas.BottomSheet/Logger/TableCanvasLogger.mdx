# TableCanvasLogger

Панель системных сообщений таблицы: шапка со счётчиками и фильтрами по статусам, список сообщений с группами, подробностями и копированием идентификатора трассировки.

Компонент входит в `TableCanvas` и предназначен для нижней панели таблицы: передайте его в `tableConfig.bottomSheetConfig.content` (пример — сторис «В нижней панели таблицы»). Если обёртка растягивается на высоту панели, а ``, шапка остаётся на месте и прокручивается только список.

## Ключевые особенности

- Четыре статуса: `error`, `warning`, `info`, `success`
- Группы любой вложенности
- Фильтр по статусу учитывает вложенные сообщения: группа остаётся в списке, если в ней есть подходящее сообщение
- Кнопки сообщения: «Подробнее», «Скопировать ID», код сообщения (например `F23`) и собственные `actions`
- Состояние панели, фильтра и раскрытых элементов можно задавать извне или оставить компоненту

## Основная структура

```tsx
import {
  TableCanvas,
  TableCanvasLogger,
} from '@daisforge/ui/components/TableCanvas';

<TableCanvas
  rows={rows}
  columnConfig={columns}
  tableConfig={{
    bottomSheetConfig: {
      height: open ? 280 : 40,
      content: (
        <TableCanvasLogger items={items} open={open} onOpenChange={setOpen} />
      ),
    },
  }}
/>;
```

## Составные части

- `TableCanvasLoggerList` — список сообщений без шапки, принимает те же `items` и настройки отображения
- `TableCanvasLoggerMessage` и `TableCanvasLoggerGroup` — можно использовать отдельно: раскрытие управляется пропами `open` и `onOpenChange` или хранится внутри
- `TableCanvasLoggerFilters` — чипсы «Все» и по одному на статус
- `useTableCanvasLogger`, `TableCanvasLoggerProvider` и `TableCanvasLoggerItems` — для полностью своей вёрстки

## Особенности

- Счётчики считаются по всем элементам: группа учитывается наравне с сообщениями. Например, одна группа `error` с тремя вложенными сообщениями даёт «Все (4)». Если нужен другой подсчёт или загружена только часть данных, передайте итоговые значения в `counts`
- Описание сообщения можно скопировать, только если оно передано строкой
- Закрытие панели сбрасывает фильтр на «Все», в закрытой панели чипсы не выделены. Выбор фильтра в закрытой панели открывает её
- Начальное состояние задаётся `defaultOpen`, `defaultFilter` и `defaultExpandedIds`
- Без сообщений показывается «Сообщений нет»: текст меняется через `labels.empty`, разметка целиком — через `emptyContent`
- Названия статусов для скринридера задаются в `labels.error`, `labels.warning`, `labels.info`, `labels.success`
- Внутренние отступы панели входят в компонент и рассчитаны на нижнюю панель таблицы. Переопределить их можно через `$css`
- Логгер занимает высоту родителя, а список прокручивается. Ограничить высоту списка можно через `maxHeight`

Описание типов и пропсов — в разделе [API](?path=/docs/локальные-компоненты-tablecanvas-bottomsheet-logger-api--docs).
