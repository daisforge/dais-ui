# ControlBlock APE

Примеры ControlBlock в размере `xs` для команды APE. Это компактный режим панели: контрл-блок, табы и заголовок в уменьшенном размере.

API и поведение те же, что у обычного ControlBlock, отличается только `tableConfig.controlBlock.size: 'xs'`. Полное описание фич, компрессии и кастомизации иконок смотрите в разделе [ControlBlock](?path=/docs/локальные-компоненты-tablecanvas-controlblock--docs).
