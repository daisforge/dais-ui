# ControlBlock APE API

APE это тот же ControlBlock в компактном размере (`tableConfig.controlBlock.size: 'xs'`). Отдельного API у него нет: типы, фичи и поведение те же, что у обычного ControlBlock. Полное описание типов в разделе [ControlBlock API](?path=/docs/локальные-компоненты-tablecanvas-controlblock-api--docs).
