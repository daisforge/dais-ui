# Popover

Всплывающий блок с произвольным содержимым, который открывается по клику или наведению на элемент внутри ячейки: кнопку, иконку, любой другой Canvas-элемент. Пригодится для подсказки с разметкой, карточки с деталями строки, небольшой формы.

Если нужен не произвольный блок, а список пунктов с выбором (меню действий по кнопке «три точки»), используйте Dropdown: раздел [Dropdown](/docs/локальные-компоненты-tablecanvas-dropdown--docs). Открытие, якорь и правила закрытия у него те же.

## Ключевые особенности

- Задаётся пропом `popover` на любом Canvas-элементе, без включателей в `tableConfig`.
- Открывается по клику или по наведению (`trigger`).
- Содержимое любое: готовый узел или функция с `close`.
- Закрывается кликом мимо, Esc, скроллом, при смене строки и при изменении размеров таблицы.
- Общие настройки для всей таблицы в `tableConfig.popover`.

## Как подключить

Добавьте проп `popover` к Canvas-элементу в `renderCell`, `renderHeaderCell` или в `name` группы колонок. Ничего включать в `tableConfig` не нужно.

```tsx
renderCell: ({ row }) => (
  <Canvas.Button
    view="secondary"
    popover={{
      renderContent: ({ close }) => (
        <div>
          Задача «{row.task}»
          <Button size="s" view="secondary" text="Закрыть" onClick={close} />
        </div>
      ),
    }}
  >
    Подробнее
  </Canvas.Button>
);
```

Курсор над таким элементом становится `pointer`.

## Как это устроено

- На таблице открыт только один всплывающий слой. Новый Popover закрывает предыдущий, а также открытый Dropdown и окно фильтра в шапке.
- Popover привязан к якорю: невидимому DOM-элементу, который таблица ставит точно на место нарисованного элемента. От границ якоря считаются `placement` и `offset`. Якорь не перехватывает клики, они идут на канвас.
- Если элемент частично скрыт за краем таблицы, якорь обрезается видимой частью.
- Если клик по элементу с Popover попал в дочерний элемент, который остановил всплытие (`event.stopPropagation()`), Popover не открывается.

## Содержимое

Содержимое задаётся одним из двух полей:

- `content`, готовый узел;
- `renderContent`, функция `({ close }) => ReactNode`. Через `close` Popover закрывается из своего содержимого, например кнопкой в футере.

Popover даёт карточку с фоном, тенью и отступами из дизайн-системы, внутрь можно положить любую разметку.

Содержимое вычисляется в момент открытия и при перерисовке таблицы не пересчитывается. Если содержимому нужно меняться (счётчик, загрузка данных), держите состояние внутри него: сделайте содержимое отдельным компонентом со своим `useState` или запросом.

## Открытие по клику и по наведению

Поле `trigger` на элементе: `'click'` (по умолчанию) или `'hover'`.

Popover по наведению подходит для подсказок с разметкой: в отличие от тултипа, курсор можно перевести внутрь и нажать кнопку или ссылку.

Наведение подходит только для дополнительной информации. С клавиатуры и на сенсорном экране (планшет, телефон) навести курсор нельзя, поэтому такой Popover там не откроется. Действия, которые должны быть доступны всем, вешайте на клик.

```tsx
<Canvas.Icon
  icon={<IconInfoCircleOutline />}
  popover={{
    trigger: 'hover',
    placement: 'top',
    hasTail: true,
    content: <PriorityHint priority={row.priority} />,
  }}
/>
```

Как ведёт себя Popover по наведению:

- открывается через `mouseEnterDelay` (по умолчанию 300 мс), если курсор всё ещё над элементом; быстрый проход курсора мимо его не открывает;
- держится, пока курсор над элементом или над самим Popover, в том числе на пути между ними;
- закрывается через `mouseLeaveDelay` (по умолчанию 200 мс) после того, как курсор ушёл и с элемента, и с Popover;
- клик мимо его не закрывает, он закроется, когда уйдёт курсор;
- не перебивает открытый Popover по клику, Dropdown или фильтр в шапке;
- не открывается, пока в этой таблице тянут границу колонки;
- если его закрыли, пока курсор остался на элементе (Esc, кнопка внутри), заново он откроется только после того, как курсор уйдёт с элемента и вернётся.

Пока открыт Popover, тултипы таблицы не показываются. У элемента с Popover не показывается и колоночный тултип (`cellTooltip`).

## Закрытие

Popover закрывается:

- кликом вне Popover (`closeOnOutsideClick`, по умолчанию `true`), для Popover по клику;
- повторным кликом по тому же элементу, для Popover по клику;
- уходом курсора с элемента и Popover, для Popover по наведению;
- по Esc (`closeOnEsc`, по умолчанию `true`);
- скроллом таблицы по любой оси (`closeOnScroll`, по умолчанию `true`): якорь нарисован на канвасе и за скроллом не едет;
- при ресайзе таблицы, переходе в полный экран, ресайзе или перестановке колонки;
- если на месте строки под Popover оказалась другая строка (сортировка, удаление, новые данные). Строки сравниваются по ключу из `rowKeyGetter` (`editing`, `selecting`, `subRows` или `mergeCells`), а без него по ссылке: тогда новый массив с теми же данными тоже закроет Popover;
- когда таблица скрывается (смена вида, оверлей загрузки);
- вызовом `close` из содержимого.

`onOpen` и `onClose` вызываются ровно по одному разу на каждое открытие.

`closeOnScroll: false` оставляет Popover открытым при скролле, но положение якоря при этом не обновляется. Подходит для коротких подсказок, где сдвиг не критичен.

## Фокус и клавиатура

Открытие Popover не забирает фокус у таблицы: стрелки и редактор ячейки продолжают работать. В Popover можно перейти клавишей Tab или кликом по его элементу, поле с `autoFocus` в содержимом получает фокус как обычно. Если Popover закрывается с фокусом внутри (например, кнопкой «Закрыть»), фокус возвращается туда, где был до открытия. Пока пользователь печатает в поле ввода (редактор ячейки, поиск), Popover по наведению не открывается.

Esc закрывает Popover, если нажат внутри него или в его таблице. Такой Esc до таблицы не доходит, следующий Esc работает как обычно. Esc в поле ввода таблицы (редактор ячейки, поиск) и в контекстном меню обрабатывают они сами. Esc в поле ввода или раскрытом списке внутри самого Popover тоже остаётся содержимому, окно закроется следующим Esc. Esc в другом месте страницы Popover не закрывает. Если фокуса нет нигде, Esc закрывает только последнее открытое окно на странице.

Открыть Popover с клавиатуры или программно пока нельзя. Для экранных дикторов задайте подпись Popover через `ariaLabel`.

## Настройки и значения по умолчанию

На элементе задаются: `trigger`, `placement`, `offset`, `hasTail`, `flip`, `shift`, `zIndex`, `resizable`, `closeOnScroll`, `closeOnOutsideClick`, `closeOnEsc`, `mouseEnterDelay`, `mouseLeaveDelay`, `ariaLabel`, `onOpen`, `onClose` и содержимое (`content` или `renderContent`).

Чтобы не повторять одни и те же настройки на каждом элементе, их можно задать один раз для всей таблицы в `tableConfig.popover`. Это только значения по умолчанию: значение на элементе важнее. Там доступны `placement`, `offset`, `hasTail`, `flip`, `shift`, `zIndex`, `closeOnScroll`, `closeOnOutsideClick`, `closeOnEsc`, `mouseEnterDelay`, `mouseLeaveDelay`. `trigger` задаётся только на элементе.

```tsx
tableConfig={{
  popover: {
    placement: 'right',
    hasTail: true,
    offset: 8,
  },
}}
```

Встроенные значения, если не задано ни на элементе, ни в `tableConfig.popover`: `trigger: 'click'`, `placement: 'bottom-start'`, `offset: 4`, `hasTail: false`, `flip: true`, `shift: true`, `closeOnScroll: true`, `closeOnOutsideClick: true`, `closeOnEsc: true`, `mouseEnterDelay: 300`, `mouseLeaveDelay: 200`.

Подробное описание типов в разделе [API](/docs/локальные-компоненты-tablecanvas-popover-api--docs).
