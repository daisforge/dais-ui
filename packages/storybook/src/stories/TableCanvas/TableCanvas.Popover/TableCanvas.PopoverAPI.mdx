# Popover API

Под капотом атомарный `PopoverBeta` из `@salutejs/sdds-finai`: `placement`, `offset`, `hasTail`, `flip`, `shift` и `resizable` работают как в нём, описание в [документации SDDS Popover](https://plasma.sberdevices.ru/sdds-finai/beta/popover/). Открытие, якорь и закрытие таблица берёт на себя, поэтому наружу отдаётся собственный набор типов ниже.
