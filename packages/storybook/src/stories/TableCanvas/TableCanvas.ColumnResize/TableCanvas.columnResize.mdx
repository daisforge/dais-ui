# Column Resize (minWidth / maxWidth / maxAutoWidth)

Ограничения ширины колонок. Задаются на уровне колонки (`columnConfig`) или глобально в `tableConfig`.

## Быстрый старт

```tsx
const columnConfig: ColumnConfig<Row>[] = [
  {
    key: 'name',
    name: 'Название',
    width: 250,
    minWidth: 150,
    maxWidth: 400,
  },
  {
    key: 'description',
    name: 'Описание',
    maxAutoWidth: 500,
  },
];
```

## Поля колонки

### minWidth

Минимальная ширина колонки (px). Колонка не может стать уже этого значения — ни при ресайзе мышкой, ни при автоматическом расчёте ширины.

Если не задан — берётся глобальный `minColumnWidth` из `tableConfig`.

### maxWidth

Максимальная ширина колонки (px). **Жёсткий потолок** — ограничивает всё: и автоматический расчёт ширины, и ручной ресайз мышкой. Колонка никогда не станет шире `maxWidth`.

Если не задан — берётся глобальный `maxColumnWidth` из `tableConfig`.

### maxAutoWidth

Максимальная ширина колонки при **автоматическом расчёте** (px). **Мягкий потолок** — колонка стремится не превышать это значение при автоматическом распределении ширин, но **пользователь может растянуть её шире** вручную.

Если не задан — берётся глобальный `maxColumnAutoWidth` из `tableConfig`.

#### Отличие maxAutoWidth от maxWidth

- `maxWidth` — жёсткий потолок. Ограничивает и автоматическую ширину, и ручной ресайз.
- `maxAutoWidth` — мягкий потолок. Ограничивает только автоматическую ширину. Ручной ресайз не ограничен.

Если заданы оба — при автоматическом расчёте берётся **меньшее** из двух значений. При ручном ресайзе действует только `maxWidth`.

## Начальная ширина

Если у колонки задан `width`, она рендерится с этой шириной (клампится в диапазон `minWidth`..`maxWidth`).

Если `width` не задан — начальная ширина вычисляется автоматически. Колонки без фиксированной ширины заполняют свободное место в контейнере. При этом `maxAutoWidth` ограничивает, насколько широко колонка может автоматически растянуться.

## Глобальные ограничения

В `tableConfig` можно задать ограничения по умолчанию для всех колонок:

```tsx
<TableCanvas
  tableConfig={{
    minColumnWidth: 80,
    maxColumnWidth: 600,
    maxColumnAutoWidth: 400,
  }}
  columnConfig={columnConfig}
  rows={rows}
/>
```

Если у конкретной колонки задано своё значение (`minWidth`, `maxWidth`, `maxAutoWidth`), оно перебивает глобальное.

## Приоритеты

- Колоночные значения (`minWidth`, `maxWidth`, `maxAutoWidth`) приоритетнее глобальных из `tableConfig`
- Если `minWidth` больше `maxWidth`, приоритет у `minWidth`
- `maxAutoWidth` не влияет на ручной ресайз — пользователь всегда может растянуть колонку шире

Полная типизация колонок: [columnConfig API](?path=/docs/локальные-компоненты-tablecanvas-api-columnconfig--docs).
