# MergedCells (TableCanvas)

Объединение ячеек тела таблицы: вертикальное (rowSpan), горизонтальное (colSpan) и
прямоугольные блоки. Блок рисуется одной ячейкой, а клики, выделение, навигация,
копирование, вставка, протяжка и редактирование понимают его как одну логическую ячейку.

Объединение — визуальный фасад над повторяющимися данными: значение в строках
повторяется, merge лишь схлопывает его на экране. Данные не мутируются.

## Ключевые особенности

- Три способа включить объединение — от ручного управления до полного автомата
- Блоки переживают сортировку, фильтрацию, реордер, закрепление и скрытие колонок
- Copy/paste/fill/редактирование работают с блоком как с одной ячейкой
- Выравнивание контента в блоке по горизонтали и вертикали
- Групповой чекбокс и нумерация по блокам в merged-видах

## Способы включения (от ручного к автоматическому)

Механика под всеми способами одна. Отличие — кто вычисляет границы блоков:
потребитель или таблица.

### 1. mergeCells.mergedCellsRegions — управляемые регионы

«Слей вот эти конкретные ячейки». Список регионов по стабильным ключам строк и
колонок; состоянием владеет потребитель, как выделением. Таблица переводит ключи в
текущие видимые позиции. Если сортировка, реордер или скрытие колонки разорвали
регион — он не рисуется (как ограничение сортировки в Excel).

```tsx
tableConfig={{
  mergeCells: {
    mergedCellsRegions: [
      { rowKeys: ['r1', 'r2'], colKeys: ['dept'] },
      { rowKeys: ['r4', 'r5'], colKeys: ['plan', 'fact'] }, // прямоугольник 2×2
    ],
    rowKeyGetter: (row) => row.id,
  },
}}
```

Пример — стори «Базовые → controlled-регионы».

### 2. mergeCells.mergeByCellValues — по одинаковым значениям

«В этих колонках сливай подряд идущие одинаковые значения». Границы блоков таблица
вычисляет сама из данных; после сортировки или фильтра блоки пересобираются.

```tsx
tableConfig={{
  mergeCells: {
    mergeByCellValues: [
      'dept',                                             // по значению колонки
      { colKey: 'role', value: (row) => row.roleGroup },  // по произвольной функции
    ],
  },
}}
```

Примеры — стори «Базовые → rowSpan / сортировка и фильтр / редактирование».

### 3. Merged-виды группировки и subRows — полный автомат

Потребитель включает вид — всю работу с блоками делает таблица: строки
упорядочиваются по группам, колонки уровней сливаются по границам групп, чекбокс и
нумерация сливаются по верхней группе.

Через группировку (структуру задают значения группирующих колонок):

```tsx
tableConfig={{
  rowsGrouping: {
    view: 'merged',
    groupByState: [groupBy, setGroupBy], // например ['dept', 'role']
  },
}}
```

Через subRows (структуру задаёт дерево потребителя; пагинация на его стороне):

```tsx
tableConfig={{
  subRows: {
    view: 'merged',
    mergedColumns: ['dept', 'role'], // колонки уровней дерева
    getSubRows: (row) => row.children,
    rowKeyGetter: (row) => row.id,
  },
}}
```

Примеры — стори «Showcase потребителя» (плоский вид, rowsGrouping, subRows).

## Приоритеты, если включено несколько способов

Правила считаются по колонке:

- регион из `mergedCellsRegions` главнее всего остального на своей колонке;
- колонка merged-вида (группировка/subRows) главнее пользовательского
  `mergeByCellValues` на той же колонке;
- иначе действует `mergeByCellValues`;
- разные колонки живут независимо: регион на одной и byValues на другой — нормально.

## Выравнивание контента в блоке

По умолчанию контент блока выравнивается по горизонтали из `contentAlign` колонки
(иначе слева), по вертикали — по центру. Настраивается лестницей «точечное важнее
общего»:

- `align` конкретного региона (только для `mergedCellsRegions`);
- `mergedCellsAlign` на колонке — все блоки этой колонки, работает для всех способов
  включения (в merged-видах потребитель знает колонки — он сам их назвал);
- дефолт фичи: `mergeCells.align` или `rowsGrouping.mergedCellsAlign`.

```tsx
columnConfig={[
  { key: 'dept', name: 'Отдел', mergedCellsAlign: { horizontal: 'center', vertical: 'top' } },
]}
```

Выравнивание действует на текстовый контент. Кастомный `renderCell` получает весь
прямоугольник блока и выравнивает содержимое сам.

## Поведение

- Клик в любую точку блока выделяет блок целиком; фокус-рамка рисуется вокруг блока.
- Один шаг стрелкой перепрыгивает блок; внутрь блока с клавиатуры попасть нельзя.
- Копирование отдаёт значение в позиции левой верхней ячейки блока, остальные пустые
  (как в Excel).
- Вставка и протяжка пишут только в первую ячейку блока; протяжка растягивается до
  целых блоков — залить пол-блока нельзя.
- Редактирование ячейки блока записывает значение во все ячейки блока: данные под
  блоком совпадают с экраном.
- Блок, пересекающий границу закреплённых колонок, рисуется корректно в обеих
  областях.

## Ограничения / edge-кейсы

- Все ячейки блока обязаны нести одинаковые данные объединения — это контракт
  `mergeByCellValues` (значения реально повторяются в строках) и регионов.
- Разорванный регион исчезает молча; следите за смежностью ключей после сортировки.
- Выравнивание пока не поддерживает RTL.
- Горизонтальная протяжка через colSpan-блок не растягивается до границ блока
  (в работе).
