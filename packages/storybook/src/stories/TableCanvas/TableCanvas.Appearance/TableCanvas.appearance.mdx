# Appearance (TableCanvas)

**tableConfig.appearance**

Готовые варианты внешнего вида таблицы: «чистый» вид и зебра.

```tsx
<TableCanvas
  tableConfig={{
    appearance: { variant: 'clean', zebra: true },
  }}
/>
```

Все поля необязательные. Без `appearance` таблица выглядит как обычно:
`variant` по умолчанию `'default'`, `zebra` по умолчанию `false`.

## Чистый вид — `variant: 'clean'`

Таблица без линий сетки и внешних рамок. Шапка на белом фоне с серым текстом.
Остальное выглядит как в обычном виде.

## Зебра — `zebra: true`

Строки через одну окрашены серым. Работает в любом варианте, по умолчанию
выключена.

## Как чистый вид работает с другими настройками

- **`borders`** — линии сетки выключены. Если нужно вернуть отдельные линии,
  задайте их в `borders` явно.
- **Наведение и выделение** работают как обычно. Нумерация и чекбоксы
  подсвечиваются вместе со строкой.
- **Отмеченные и выбранные строки** красятся своим цветом, в том числе поверх
  зебры.
- **Итоговые строки** остаются голубыми, как в обычном виде. Зебра на них не
  распространяется.
