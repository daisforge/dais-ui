# Borders API

## tableConfig.borders

Точка входа для управления линиями сетки. Только включение и выключение линий
на четырёх уровнях; кастомные цвета наружу не отдаются. Все поля опциональны.

## CellBorderVisibility

Стороны рамки одной ячейки, которые возвращает `getCellBorder`. Каждая сторона:
`true` рисовать, `false` не рисовать, не задано работает уровень ниже (колонка,
строка или общая настройка).

## columnConfig[].verticalBorder

Вертикальная линия справа от колонки: `verticalBorder: false` убирает разделитель
после этой колонки. Перекрывает общую настройку `borders.vertical`. Поле живёт
на колонке, а не в `borders`.

```tsx
columnConfig={[
  { key: 'priority', verticalBorder: false },
]}
```
