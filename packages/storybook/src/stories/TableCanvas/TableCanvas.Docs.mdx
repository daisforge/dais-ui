### Компонент для отрисовки табличных данных

Единый инструмент для отображения данных, имеющий набор фичей. Любой продукт сможет использовать таблицу для достижения своих целей.

---

#### В основе HTML-canvas

В основе `TableCanvas` используется html `canvas` для обеспечения плавной непрерывной отрисовки контента.
В связи с этим, необходимо учитывать особенности во время отрисовки canvas-ячеек. К canvas-ячейкам относятся ячейки шапки, основных данных, итоговых данных.

---

#### Миграция с Table

Основа API TableCanvas унаследована от API Table для легкой миграции и переиспользования протестированных решений на основе Table.

- `TableProps` и `TableProps.tableConfig` обратно совместимы на 95+% c API Table (на основе имеющихся в TableCanvas фичей)
- `TableProps.columnConfig` - претерпел изменения в связи с особенностями рендера на `canvas`.

В `TableProps.columnConfig` обновлены свойства `renderHeaderCell, renderCell, renderSummaryCell`, теперь:

- они должны быть функциями, которые возвращают Canvas-элементы (импортировать из директории TableCanvas. Примеры: Canvas.Button,Canvas.Badge и тд.).
- в них нельзя использовать компоненты, только Canvas-элементы.
- В них нельзя вызывать хуки, это функции рендера - не компоненты.
- если нужны данные для ячеек, то передаем данные либо в `headerContextValue`, либо в `rowContextValue`. И получаем через `args` функции.

#### Импорт

Типы, хуки и компоненты, связанные с `TableCanvas`, необходимо импортировать из папки компонента:

```ts
import {
  ColumnConfig,
  TableCanvas,
  useHeaderContext,
  SIZES,
} from '@daisforge/ui/components/TableCanvas';
```

Остальные компоненты (`Badge`, `Button`, `Switch` и т.д.) импортируются как обычно — из корня пакета:

```ts
import { Badge, Button, Switch } from '@daisforge/ui';
```

Иконки — из `/icons`:

```ts
import { IconSber, IconPlus } from '@daisforge/ui/icons';
```
