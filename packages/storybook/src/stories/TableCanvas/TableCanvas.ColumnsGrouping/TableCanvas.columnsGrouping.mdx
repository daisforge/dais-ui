# ColumnsGrouping (TableCanvas)

**columnConfig.children**

Группировка колонок — вложенная структура шапки таблицы. Позволяет объединять несколько колонок под одним общим заголовком, создавая иерархию в шапке.

## Ключевые особенности

- Поддержка многоуровневой вложенности (2, 3+ уровня)
- Совместимость с `columnsControl`, `resizableColumn`
- Кастомизация `name` через `ReactNode`

## Как работает

Для создания группы колонок используется `ColumnGroupConfig` вместо обычного `ColumnConfig`. Группа определяется наличием ключа `children`, в котором перечисляются дочерние колонки или вложенные группы.

```tsx
const columnConfig = [
  {
    name: 'Основные данные',
    children: [
      { key: 'name', name: 'Имя' },
      { key: 'age', name: 'Возраст' },
    ],
  },
  {
    name: 'Статистика',
    children: [
      { key: 'score', name: 'Баллы' },
      { key: 'rank', name: 'Ранг' },
    ],
  },
];
```

## Особенности

- Группа не имеет собственного `key` — это чисто визуальный элемент шапки
- `name` группы может быть строкой или `ReactNode` для кастомного рендера
- При использовании с `columnsControl` скрытие/показ работает на уровне дочерних колонок, не на уровне группы
- При `resizableColumn` ресайз работает на уровне дочерних колонок

## Слитные шапки (spanGroupHeader)

Когда рядом с группой стоит одиночная колонка без группы, её заголовок по умолчанию занимает только нижний ряд шапки, а сверху остаётся пустая полоса. `spanGroupHeader` сливает такую шапку в ОДНУ ячейку на всю высоту шапки — без пустой полосы сверху и без горизонтального шва. Примеры — стори «Слитая листовая колонка», «Слияние всех листьев», «Выравнивание заголовка» в этом разделе.

Три уровня управления:

- **На колонке** — `columnConfig[].spanGroupHeader: true` включает слияние точечно (действует только для колонки БЕЗ группы).
- **На таблице** — `tableConfig.spanGroupHeader: true` включает слияние сразу у ВСЕХ листовых колонок без группы; на колонке можно перекрыть точечно значением `false`.
- **Мелкие группы** — `tableConfig.spanShallowGroups: true` сливает по вертикали «мелкую» групп-ячейку (под которой нет более глубоких подгрупп) в одну ячейку до ряда колонок.

### Выравнивание заголовка в слитой ячейке

- на колонке — `spanGroupHeaderAlign: { horizontal, vertical }`;
- общий дефолт на таблице — `tableConfig.spanAlign` (перекрывается значением на колонке).

`horizontal` — `left | center | right`; `vertical` — `top | center | bottom`. Дефолт листа — `left` / по центру по высоте.

### Кастомный контент в слитой шапке

Если `name` колонки — canvas-элемент (`Canvas.Text` / `Canvas.Container`), в слитой шапке он центрируется по всей высоте объединённой ячейки, а не прижимается к нижней полосе.

### Реордер и группы

Слитые шапки совместимы с реордером колонок за шапку (`columnsControl.reorderingHeader`, включён по умолчанию при `columnsControl.enable`). Drag-иконка показывается на листовых колонках (в том числе слитых), у групп собственной drag-иконки нет — перетаскиваются листья. Пример — стори «Группы + реордер» в этом разделе.

## Ограничения / edge-кейсы

- `spanGroupHeader` действует ТОЛЬКО для колонки без группы; на колонке внутри группы игнорируется.
- Слияние имеет смысл при наличии групп в шапке (иначе групп-ряда нет и сливать нечего).
- RTL-выравнивание в слитой ячейке не поддержано.
