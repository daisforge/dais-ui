# Dropdown API

Под капотом атомарный `Dropdown` из `@salutejs/sdds-finai`: пункты, `placement`, `offset`, `listWidth`, `variant`, `size` и `closeOnSelect` работают как в нём, описание в [документации SDDS Dropdown](https://plasma.sberdevices.ru/sdds-finai/components/dropdown/). Открытие, якорь и закрытие таблица берёт на себя, поэтому наружу отдаётся собственный набор типов ниже.
