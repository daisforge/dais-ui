# KeyText (TableCanvas)

**tableConfig.keyText**

Режим отображения данных ячеек в формате «ключ — значение». Полезен для компактного представления сложных данных.

## Ключевые особенности

- Переключение между обычным табличным и key-text представлением
- Кнопка переключения в controlBlock и/или sidebar
- Кастомная конфигурация отображения через `KeyTextConfig`
- Поддержка кастомных ключей и значений для каждой колонки

## Особенности

- При активации keyText колонки отображаются в формате `название колонки: значение`
- Переключение режима не влияет на данные, только на визуальное представление
- Работает совместно с другими фичами (сортировка, фильтрация, выделение)
