# IsLoading (TableCanvas)

**tableConfig.isLoading / tableConfig.loadingOverlay**

Состояние загрузки таблицы. Поддерживает скелетон-строки и полноэкранный оверлей.

## Ключевые особенности

- Скелетон-строки при загрузке данных (`isLoading`)
- Настраиваемое количество скелетон-строк (`skeletonRowsCount`)
- Полноэкранный оверлей с кастомным спиннером (`loadingOverlay`)
- Задержка показа подзаголовка (`showSubtitleDelay`)
- Оверлей поверх таблицы без её размонтирования (`loadingOverlay.mode: 'cover'`)

## Когда использовать loadingOverlay

- Динамическая загрузка схемы таблицы — колонки загружаются с бэкенда
- Конфигурируемые таблицы — пользователь сам настраивает колонки
- Ошибки загрузки структуры — не удалось загрузить метаданные

## Когда использовать mode: 'cover'

Обычный `loadingOverlay` показывается вместо таблицы: таблица размонтируется, и после снятия оверлея выделение, страница пагинации и прокрутка начинаются заново.

С `mode: 'cover'` таблица остаётся на месте, а оверлей ложится поверх неё полупрозрачным размытым слоем. Он закрывает control block, боковые панели, нижнюю панель и пагинацию, в fullscreen тоже, и блокирует мышь, клавиатуру и фокус. Когда оверлей снимается, таблица продолжает работу с того же состояния.

Подходит для долгих действий с уже открытой таблицей: удаление или сохранение строк, пересчёт данных.

Режимы можно совмещать: на первой загрузке показывать `'replace'`, а когда таблица загружена, тем же `loadingOverlay` с `mode: 'cover'` закрывать её на время действий.

```tsx
loadingOverlay: {
  mode: isFirstLoad ? 'replace' : 'cover',
  active: isFirstLoad || isUpdating,
}
```

```tsx
<TableCanvas
  tableConfig={{
    loadingOverlay: {
      mode: 'cover',
      active: isUpdating,
      subtitle: 'Обычно это занимает не более 10 секунд',
    },
  }}
/>
```
