# UnstickyHeader (TableCanvas)

**tableConfig.unstickyHeader**

При активации `unstickyHeader: true` шапка таблицы перестаёт быть закреплённой и уезжает вверх вместе со скроллом контента.

## Ключевые особенности

- Открепление шапки от верхней границы при скролле
- Работает с группировкой колонок (все уровни group headers уезжают)
- Совместимость с многоуровневой вложенностью
