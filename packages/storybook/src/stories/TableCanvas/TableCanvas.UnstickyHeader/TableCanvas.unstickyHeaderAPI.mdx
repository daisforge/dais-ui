# UnstickyHeader API

## tableConfig.unstickyHeader

```ts
unstickyHeader?: boolean; // default: false
```

При `true` шапка таблицы перестаёт быть закреплённой и уезжает вверх вместе со скроллом контента. Работает со всеми уровнями group headers.
