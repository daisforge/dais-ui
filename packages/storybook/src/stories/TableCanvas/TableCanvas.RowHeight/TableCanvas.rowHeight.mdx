# RowHeight (TableCanvas)

**tableConfig.rowHeight + tableConfig.rowSize**

Настройка высоты строк таблицы. Поддерживает фиксированную высоту, динамическое вычисление и переключение размера через UI.

## Ключевые особенности

- Фиксированная высота строки (`number`)
- Динамическая высота через функцию (`RowHeightFunc`)
- Высота по содержимому ячеек (`'auto'`): перенос текста растит строку
- Доступ к данным строки и текущему размеру (`currentRowSize`)
- Переключатель размера строк в controlBlock (`rowSize`)

## tableConfig.rowHeight

Определяет высоту каждой строки:

- **`number`** — фиксированная высота в пикселях для всех строк
- **`RowHeightFunc`** — функция, вычисляющая высоту на основе `row`, `currentRowSize` и `rowIndex`
- **`'auto'`** — высота по содержимому (см. ниже)

## rowHeight: 'auto'

Ячейка сообщает высоту своего дерева Canvas, когда таблица её рисует (`Canvas.Text wordWrap` переносит слова и растит строку). Отдельного замера нет: рисуются и меряются только видимые ячейки. Вертикальные отступы ячейки (`cellVerticalPadding` темы) ui-kit добавляет к высоте строки, в дереве ячейки их задавать не нужно. Содержимое центрируйте по вертикали (`alignItems="center"`): у выровненного по верху весь запас окажется снизу. Подсветку фрагментов текста с переносом по строкам делает [`Canvas.Mark`](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasmark--docs) внутри `Canvas.Text`.

- Высота не ниже высоты по `rowSize` и не выше `tableConfig.maxAutoRowHeight` (по умолчанию **480px**): более длинный текст обрезается

```tsx
<TableCanvas tableConfig={{ rowHeight: 'auto', maxAutoRowHeight: 800 }} columnConfig={columnConfig} rows={rows} />
```

- Строка, показанная впервые, сразу появляется с высотой по содержимому. Колонка, до которой ещё не прокрутили, высоту строки не меняет — строка дорастёт, когда колонка появится на экране
- Высота кешируется по ячейке (объект строки + колонка): ресайз и новый `renderCell` перемеряют только ячейки этой колонки, смена `rowSize` или темы и загрузка любого шрифта (в том числе заданного у `Canvas.Text`) — все. До перемера строка держит прежнюю высоту. Чтобы перемерить строку после изменения содержимого, передайте новый объект строки
- Ячейка, объединённая на несколько строк (`mergeCells`), строку не растит; объединённая на несколько колонок меряется по ширине блока
- С панелью детализации строки не растут: `'auto'` там равен высоте по `rowSize`

## tableConfig.rowSize

Переключатель размера строк в controlBlock (кнопка с выпадающим списком):

- **`showInControl`** — показывать ли кнопку в controlBlock
- **`default`** — размер по умолчанию (`'s'`, `'m'`, `'l'`)
- **`available`** — список доступных размеров
- **`onRowSizeChange`** — callback при смене размера

## Особенности

- `RowHeightFunc` получает `currentRowSize` — объект с `rowSizeName` и `rowSizeValue`, что позволяет адаптировать высоту к текущему выбранному размеру
- При использовании `rowHeight` как функции, рекомендуется мемоизировать её для производительности
