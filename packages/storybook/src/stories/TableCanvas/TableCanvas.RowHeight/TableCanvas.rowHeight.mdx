# RowHeight (TableCanvas)

**tableConfig.rowHeight + tableConfig.rowSize**

Настройка высоты строк таблицы. Поддерживает фиксированную высоту, динамическое вычисление и переключение размера через UI.

## Ключевые особенности

- Фиксированная высота строки (`number`)
- Динамическая высота через функцию (`RowHeightFunc`)
- Высота по содержимому ячеек (`'auto'`): перенос текста растит строку
- Доступ к данным строки и текущему размеру (`currentRowSize`)
- Переключатель размера строк в controlBlock (`rowSize`)

## tableConfig.rowHeight

Определяет высоту каждой строки:

- **`number`** — фиксированная высота в пикселях для всех строк
- **`RowHeightFunc`** — функция, вычисляющая высоту на основе `row`, `currentRowSize` и `rowIndex`
- **`'auto'`** — высота по содержимому (см. ниже)

## rowHeight: 'auto'

Ячейка сообщает высоту своего дерева Canvas, когда таблица её рисует (`Canvas.Text wordWrap` переносит слова и растит строку). Отдельного замера нет: рисуются и меряются только видимые ячейки, поэтому стоимость не зависит от числа колонок и строк. Вертикальные отступы ячейки (`cellVerticalPadding` темы) ui-kit добавляет к высоте строки, в дереве ячейки их задавать не нужно. Содержимое центрируйте по вертикали (`alignItems="center"`): у выровненного по верху весь запас окажется снизу. Подсветку фрагментов текста с переносом по строкам делает [`Canvas.Mark`](?path=/docs/локальные-компоненты-tablecanvas-canvaselements-canvasmark--docs) внутри `Canvas.Text`.

- Высота не ниже высоты по `rowSize` и не выше **480px**: более длинный текст обрезается
- Строка, показанная впервые, рисуется с высотой по `rowSize` и дорастает на следующем кадре. При прокрутке вверх строки над видимой областью могут вырасти и сдвинуть контент. Колонка, до которой ещё не прокрутили, высоту строки не меняет — строка дорастёт, когда колонка появится на экране
- Высота кешируется по ячейке (объект строки + колонка): ресайз перемеряет только ячейки этой колонки, загрузка шрифта таблицы — все. Чтобы перемерить строку после изменения содержимого, передайте новый объект строки
- Ячейка, объединённая на несколько строк (`mergeCells`), строку не растит; объединённая на несколько колонок меряется по ширине блока
- С панелью детализации строки не растут: `'auto'` там равен высоте по `rowSize`

### tableConfig.rowHeightsRef

Если поверх таблицы рисуется что-то, привязанное к строкам (например, метки на скроллбаре), высоты строк можно читать из `rowHeightsRef`: таблица кладёт туда функцию «индекс строки → текущая высота».

```tsx
import type { RowHeightsRef } from '@daisforge/ui/components/TableCanvas';

const rowHeightsRef: RowHeightsRef = useRef(null);
const heightOf = (rowIndex: number) => rowHeightsRef.current?.(rowIndex) ?? 40;

<TableCanvas tableConfig={{ rowHeight: 'auto', rowHeightsRef }} /* ... */ />;
```

## tableConfig.rowSize

Переключатель размера строк в controlBlock (кнопка с выпадающим списком):

- **`showInControl`** — показывать ли кнопку в controlBlock
- **`default`** — размер по умолчанию (`'s'`, `'m'`, `'l'`)
- **`available`** — список доступных размеров
- **`onRowSizeChange`** — callback при смене размера

## Особенности

- `RowHeightFunc` получает `currentRowSize` — объект с `rowSizeName` и `rowSizeValue`, что позволяет адаптировать высоту к текущему выбранному размеру
- При использовании `rowHeight` как функции, рекомендуется мемоизировать её для производительности
