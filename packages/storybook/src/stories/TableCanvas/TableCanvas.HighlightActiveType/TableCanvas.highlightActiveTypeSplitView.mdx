# HighlightActiveType + SplitView

Подсвеченная строка (`highlightActiveType='row'`) выступает источником «открытой»
строки: по клику она открывается в боковой панели `SplitView`, при закрытии панели
подсветка гаснет. Пример — на древовидной таблице (блок → трайб → продукт).

## Ключевые особенности

- **Источник — подсветка, а не чекбоксы.** Открытую строку определяет
  `highlightActiveType`, а не `tableConfig.selecting`. Это разные оси: можно
  одновременно иметь чекбоксы и открывать в панели именно подсвеченную строку.
- **Двусторонняя связь через controlled-стейт.** `tableConfig.highlightActiveRow.state`
  — внешний `useState`. Клик по строке вызывает сеттер (панель открывается),
  закрытие панели вызывает `setActiveRow(undefined)` (подсветка гаснет).
- **Открытость панели = наличие подсветки:** `sidebar.isOpened = activeRow !== undefined`.
- **Объект строки — из `highlightActiveRow.onChange`.** Колбэк отдаёт и флэт-индекс,
  и сам узел дерева (`row`) — таблица резолвит его по индексу сама. Отдельный
  `onCellClicked` не нужен.

## Особенности

- **Навигация стрелками не меняет открытую строку.** Подсветка обновляется только
  на клик мышью — стрелки двигают выделение ячеек, но открытая в панели строка
  «залипает» до следующего клика.
- **Дерево.** Узел может быть блоком, трайбом или продуктом — карточка в панели
  строит заголовок и поля по уровню узла. Уровень в примере выводится из данных
  (`id`/`subRows`); в реальном приложении он обычно есть в доменной модели.
- **Что гасит подсветку — то закрывает панель.** Клик по шапке колонки, по
  нумерации строк или select-all сбрасывают `highlightActiveRow` → панель
  закрывается. Если панель должна жить до явного закрытия — заведите отдельный
  `panelOpen`-стейт вместо привязки к `activeRow`.
- **Флэт-индекс резолвит таблица.** `highlightActiveRow` — индекс во флэт-строках
  (с учётом раскрытых subRows). `highlightActiveRow.onChange` отдаёт по этому
  индексу готовый объект строки, поэтому маппить индекс→узел вручную не нужно.
