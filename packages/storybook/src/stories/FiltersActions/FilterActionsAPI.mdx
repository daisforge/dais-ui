## Ренейминг

В целях улучшения читаемости и единообразия именования некоторые compound-компоненты были переименованы.

**Обратная совместимость сохранена** — старые имена продолжают работать. Оба варианта ссылаются на один и тот же компонент. Рекомендуем использовать новые имена:

- `FiltersActions.FilterPopover` → `FiltersActions.FiltersButtonWithPopover`
- `FiltersActions.Tooltip` → `FiltersActions.TooltipList`

```diff
- <FiltersActions.FilterPopover
+ <FiltersActions.FiltersButtonWithPopover
    content={...}
    footer={...}
    buttonProps={{ hideLabel: true }}
  />

- <FiltersActions.Tooltip ... />
+ <FiltersActions.TooltipList ... />
```
