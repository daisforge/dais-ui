- `titleSize` — размер заголовка. По умолчанию `'H4'` - `badgeMarginTop` — отступ
сверху для Badge. По умолчанию `2`

Рекомендуемые значения `badgeMarginTop` в зависимости от `titleSize`:

- `H3` → `badgeMarginTop: 5`
- `H4` → `badgeMarginTop: 2`
- `H5` → `badgeMarginTop: 1`
