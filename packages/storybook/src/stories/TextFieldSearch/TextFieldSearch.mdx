# TextFieldSearch

Компонент TextFieldSearch - обертка компонента TextField со своими готовыми стилями для поля поиска. C примерами реализации подробно можно ознакомиться ниже в stories.

## Ключевые особенности

- Готовые стили для поля поиска на основе TextField
- Иконка лупы слева и крестик очистки справа
- Доступные размеры: `s`, `xs`

> Подробнее о типах и пропсах — [TextFieldSearch API](?path=/docs/локальные-компоненты-textfieldsearch-api--docs)
