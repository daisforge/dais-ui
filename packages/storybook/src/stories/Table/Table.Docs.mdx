# Table

`Table` - legacy HTML-таблица на базе `react-data-grid` и `react-table`-подходов, которая поддерживается для существующих продуктов. Для новых таблиц по умолчанию используйте `TableCanvas`.

## Ключевые особенности

- Отображение строк и колонок через `rows`, `columnConfig` и `tableConfig`
- Сортировка, фильтрация, поиск, пагинация и infinity scroll
- Выбор строк, вложенные строки, группировка строк и группировка колонок
- Настройка колонок, изменение ширины, кастомный render ячеек и итоговые строки
- ControlBlock, sidebar, context menu, row instruments и состояния загрузки/пустых данных

## Legacy-статус

`Table` оставлен для поддержки проектов, которые уже используют HTML-таблицу. Если задача не требует совместимости с legacy API, выбирайте `TableCanvas`: он является основной таблицей библиотеки и лучше подходит для больших данных, canvas-render и новых сценариев.

## Основные сущности

- `TableProps` - публичные props компонента
- `TableConfig` - конфигурация фич таблицы
- `ColumnConfig` - конфигурация колонок, render-ов, сортировки, фильтрации и редактирования

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-api--docs).
