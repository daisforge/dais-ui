# SubRows

Иерархичные строки legacy `Table`.

## Ключевые особенности

- Вложенные строки подключаются через `tableConfig.subRows`
- `getSubRows` возвращает дочерние строки
- `rowKeyGetter` задает уникальный ключ строки
- `columnConfig.subRow` управляет отображением данных дочерних строк
- Можно показать chevron раскрытия и кастомный render дочерней ячейки

## Особенности

Для вложенных строк важно иметь стабильный `rowKeyGetter`. Если нужно группировать плоский набор данных, используйте `rowsGrouping`, а не `subRows`.

## Ленивая подгрузка детей («Показать ещё»)

Когда детей у группы много и грузить их все сразу нельзя, подгрузка собирается из штатных возможностей без доработок ядра: `getSubRows` возвращает загруженных детей плюс служебную строку `loadMore`, `colSpan` первой колонки растягивает её на всю ширину, а `renderSubRowCell` рисует кнопку «Показать ещё N» со счётчиком. По клику потребитель догружает порцию и пересобирает `subRows`. Пример — стори «Ленивая подгрузка детей группы».

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-subrows-api--docs).
