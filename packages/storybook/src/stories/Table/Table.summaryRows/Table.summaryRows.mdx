# Summary Rows

**tableConfig.summaryRows**

Итоговые строки в верхней и/или нижней части таблицы.

## Ключевые особенности

- Отображение итогов через `topSummaryRows` и `bottomSummaryRows` пропсы
- Кнопка переключения видимости в control block (`showInControl: true`)
- Кастомный рендер через `renderSummaryCell` в `columnConfig`
- Колбэк `onChange(checked)`: вызывается, когда пользователь переключает тогл «Итоговые строки» в настройках таблицы. Не вызывается при монтировании

## Сохранение выбора пользователя

Сохраните значение в `onChange` и передайте его обратно в `showDefault`:

```tsx
const STORAGE_KEY = 'my-table:summary-rows';

const [showSummary] = useState(
  () => localStorage.getItem(STORAGE_KEY) !== 'false',
);

<Table
  tableConfig={{
    summaryRows: {
      showDefault: showSummary,
      showInControl: true,
      onChange: (checked) =>
        localStorage.setItem(STORAGE_KEY, String(checked)),
    },
  }}
  ...
/>;
```

> `showDefault` читается только при монтировании таблицы. Если поменять его позже, текущее состояние тогла не изменится.

## Особенности

- Количество элементов массива = количество итоговых строк
- Пустой массив — итоговые строки не отображаются
- `renderSummaryCell` получает `RenderSummaryCellProps` с данными итоговой строки
