# Table Pagination

## Ключевые особенности

- Клиентская и ручная пагинация
- Контроль страницы и размера страницы
- Отключение дефолтного поиска, сортировки и фильтрации при активной пагинации

**tableConfig.pagination**

Таблица поддерживает пагинацию. Для активации функционала в `tableConfig` заполняется `pagination`.

## Особенности работы с пагинацией:

### Отключение дефолтной сортировки и фильтрации

При активации `pagination` отключается дефолтная сортировка и фильтрация.
Нужно использовать версии данных фичей с ручным управлением. Например, для отправки на бэкенд выбранных фильтров и сортировки.

**Причина:** Предполагается, что если есть pagination, то в таблице представлен не весь объем данных,
по этой причине дефолтная сортировка и фильтрация не подходят и будут отображать некорректные данные.

### Адаптивные slots

По умолчанию ВЫКЛЮЧЕНА умная адаптация количества slots пагинации в зависимости от ширины контейнера таблицы и размера пагинации (`size`).

Принцип работы:

При достижении минимальной ширины контейнера, когда остается только 1 slot под номер текущей страницы, автоматически отображаются навигационные стрелки в `leftContent` и `rightContent` для переключения между страницами.

Эту функциональность можно включить, установив `responsiveSlots: true`, тогда количество slots будет фиксированным (задавать `slots` в props в таком случае не нужно), важно будет указать `value` в props для пагинации, как значение текущей выбранной страницы, все будет работать под капотом.

## Основная информация

С основной информацией по компоненту Пагинации можно ознакомиться по [ссылке на SDDS Pagination](https://plasma.sberdevices.ru/sdds-finai/components/pagination/)

## Изменения в API относительно SDDS Pagination:

### 1. Измененные пропсы:

- **`onChangePageValue`** - добавлен параметр `scrollToTop: () => void` для автоматического скролла к началу новой страницы
- **`onChange`** - добавлен параметр `scrollToTop: () => void` для автоматического скролла к началу новой страницы

### 2. Дополнительные пропсы:

- **`responsiveSlots`** - включение/выключение умной адаптации slots (по умолчанию `true`)
- **`onResize`** - callback при изменении ширины контейнера пагинации

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-pagination-api--docs).
