# ColumnsControl

Пользовательская настройка колонок legacy `Table`.

## Ключевые особенности

- Включение через `tableConfig.columnsControl.enable`
- Скрытие, закрепление и переупорядочивание колонок
- Запрет скрытия или закрепления отдельных колонок
- Дефолтные состояния `orderDefault`, `hiddenDefault`, `pinnedDefault`
- Колбэк `onConfirm` для сохранения настроек вне таблицы
- Режим применения `applyMode`: `confirm` (кнопки «Отменить»/«Применить», по умолчанию) или `instant` (без кнопок, каждое действие в панели сразу меняет таблицу и вызывает `onConfirm`)

## Особенности

`columnsControl` может работать вместе с изменением ширины колонок и с `keyText`. Для группированных колонок проверяйте итоговый порядок leaf-колонок.

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-columnscontrol-api--docs).
