# Custom Render

Кастомный рендеринг ячеек таблицы.

## Ключевые особенности

- `renderCell` — кастомный рендер ячеек данных (доступны `row`, `rowIdx`, `column`)
- `renderHeaderCell` — кастомный рендер заголовков (`name` принимает `string | ReactElement`)
- `renderSummaryCell` — кастомный рендер итоговых строк
- Контексты: `useRowContext` и `useHeaderContext` для передачи состояния без лишних ре-рендеров

## Особенности

- Контейнер ячейки должен использовать `width: '100%'` и `height: '100%'`
- `headerContextValue` предоставляет доступ к состоянию фильтров, сортировки и размера строк
- `rowContextValue` позволяет передавать кастомное состояние в ячейки без перерисовки таблицы
