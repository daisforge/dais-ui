# TableKeyText

## Ключевые особенности

- Выделение ключевых колонок текстовой меткой
- Включение через tableConfig.keyText
- Интеграция с columnsControl

`tableConfig.keyText` включает отображение ключевой текстовой колонки и задаёт способ отображения `key`, `text` или обеих частей.

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-keytext-api--docs).
