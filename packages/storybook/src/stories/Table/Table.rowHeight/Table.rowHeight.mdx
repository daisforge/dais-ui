# RowHeight

Настройка высоты строк legacy `Table`.

## Ключевые особенности

- Фиксированная высота через число
- Динамическая высота через функцию `RowHeightFunc`
- Доступ к текущему размеру строки при расчете высоты
- Возможность подстраивать высоту под многострочный контент

## Особенности

Функция высоты вызывается для строк таблицы, поэтому держите вычисления легкими и мемоизируйте конфигурацию колонок.

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-rowheight-api--docs).
