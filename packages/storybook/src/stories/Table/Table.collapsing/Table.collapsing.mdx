# TableCollapsing

## Ключевые особенности

- Сворачивание и разворачивание тела таблицы
- Кнопка управления в controlBlock
- Поддержка внутреннего и внешнего состояния

**tableConfig.collapsing**

Для активации функции сворачивания/разворачивания тела таблицы необходимо:

1. Включить collapsing в конфигурации таблицы:

2. Кнопка управления collapsing будет отображаться в controlBlock (крайняя левая часть таблицы)

Описание типов - в разделе [API](?path=/docs/локальные-компоненты-table-collapsing-api--docs).
