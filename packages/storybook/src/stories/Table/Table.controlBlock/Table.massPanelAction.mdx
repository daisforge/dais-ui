# Table MassPanelAction

## Ключевые особенности

- Панель действий для выбранных строк
- Автоматическое появление при активном selecting
- Компрессия кнопок и отдельное поведение accent-кнопок

**tableConfig.controlBlock.massActionPanel**

Панель массовых действий (MassPanelAction) - это компонент, который отображается внизу таблицы и позволяет применять действия к выбранным строкам. Панель появляется автоматически, когда в таблице выбраны строки.

## Когда открывается панель

Панель массовых действий появляется автоматически, когда:

- Включена функция выбора строк (`selecting` в `tableConfig`)
- Выбрана хотя бы одна строка в таблице
- `selectingRowsIsActive` равен `true`

Панель скрывается автоматически, когда все строки сняты с выбора.

## Управление видимостью

По умолчанию панель показывается автоматически при активном `selecting` и хотя бы одной выбранной строке. Это поведение переопределяется через `massActionPanel.show`:

- `undefined` (по умолчанию) — штатное поведение (selecting + выбранные строки)
- `false` — панель не рендерится, действиями вы управляете сами
- `true` — панель показывается всегда, даже без активного selecting и выбранных строк

## Замена leftSideInner

**Важно:** Панель массовых действий (`massActionPanel`) была создана как **замена** для `leftSideInner` в `controlBlock`.

### ⚠️ Не рекомендуется использовать вместе

**НЕ ЖЕЛАТЕЛЬНО** использовать `leftSideInner` и `massActionPanel` одновременно, так как:

- Это создает дублирование функциональности
- `massActionPanel` специально разработан для работы с выбранными строками
- `massActionPanel` имеет адаптивную компрессию и автоматическое позиционирование
- `massActionPanel` лучше интегрирован с функцией выбора строк

### Рекомендация

Используйте `massActionPanel` вместо `leftSideInner` для кнопок, которые должны работать с выбранными строками. Кнопки, которые не зависят от выбора строк, можно оставить в `leftSideInner` или `rightSideInner`.

## Особенности работы

### Accent кнопки всегда видимы

Кнопки с `view: 'accent'` **никогда не скрываются** в дропдауне скрытых действий, даже если панель не помещается по ширине. Они всегда остаются видимыми и сохраняют свой оригинальный порядок относительно других кнопок.

### Адаптивная компрессия

При нехватке места панель автоматически:

- Скрывает обычные кнопки в дропдаун скрытых действий
- Оставляет accent кнопки всегда видимыми
- Сохраняет порядок кнопок (accent кнопки остаются на своих позициях)
- Автоматически центрируется с учетом открытого сайдбара

### Взаимодействие с сайдбаром

При открытии сайдбара:

- Панель автоматически сворачивается (если была развернута)
- Позиция корректируется с учетом ширины сайдбара
- При закрытии сайдбара панель автоматически разворачивается

### Размеры кнопок

Размеры кнопок и дропдаунов панель подбирает сама — по размеру панели (`massActionPanel.size`: `m`/`s`/`xs`) и компактности. Передавать `size` кнопкам отдельно **не нужно**. Если `size` всё же задан — он используется как есть.

## Конфигурация

Панель массовых действий настраивается через `tableConfig.controlBlock.massActionPanel`:

```tsx
tableConfig={{
  selecting: {
    state: selectingRowState,
    rowKeyGetter: (row) => row.id,
  },
  controlBlock: {
    massActionPanel: {
      buttons: [
        {
          type: 'button',
          text: 'Действие',
          view: 'secondary', // или 'accent', 'critical', 'primary' и т.д.
          onClick: () => {
            // Обработчик клика
          },
        },
      ],
    },
  },
}}
```

Помимо `buttons`, у панели есть необязательные пропсы: `size` (размер панели, см. «Размеры кнопок»), `show` (управление видимостью), `bottom` (отступ панели снизу от контейнера, по умолчанию 24px) и `collapsedDropdownProps` (пропсы дропдауна скрытых действий). Полное описание типов — в разделе API.

## Типы кнопок

### Button

Используется компонент `Button` с `type: 'button'`:

- Доступны view: `'accent'`, `'secondary'`, `'critical'`, `'primary'` и т.д.
- `view: 'accent'` - accent кнопки, которые всегда остаются видимыми

### LinkButton

Кнопка-ссылка с `type: 'linkButton'` (компонент `LinkButton`). View задаётся в link-нотации:

```tsx
{
  type: 'linkButton',
  text: 'Ссылка-действие',
  view: 'linkSecondary', // 'linkAccent' / 'linkDefault' и т.д.
  onClick: () => {},
}
```

## Disabled состояние

Если кнопка имеет `disabled: true`, можно передать `disabledTooltipProps` для отображения подсказки при наведении на disabled кнопку:

```tsx
{
  type: 'button',
  text: 'Действие',
  view: 'secondary',
  disabled: true,
  disabledTooltipProps: {
    text: 'Выберите строки для выполнения действия',
  },
  onClick: () => {},
}
```

**Важно:** disabled кнопка остаётся неактивной и после перемещения в дропдаун скрытых действий — `disabled` пробрасывается на пункт меню. Подсказка `disabledTooltipProps` при этом показывается только у кнопок на самой панели, в меню её нет.

## Dropdown в кнопках

Кнопки могут иметь вложенный dropdown:

```tsx
{
  type: 'button',
  text: 'Действие с меню',
  view: 'secondary',
  dropdown: {
    items: [
      { label: 'Опция 1', value: '1' },
      { label: 'Опция 2', value: '2' },
    ],
    onItemSelect: (item) => {
      // Обработчик выбора
    },
  },
}
```
