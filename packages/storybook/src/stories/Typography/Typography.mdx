# Typography

Компонент `Typography` является оберткой над [атомарными типографическими компонентами SDDS](https://plasma.sberdevices.ru/sdds-finai/components/typography/).

## Ключевые особенности

- Единый интерфейс для работы со всей типографической системой проекта
- Все варианты шрифтов (от Display до TextXS)
- Настройка начертания (regular, bold)
- Гибкое управление отображением текста
- Компонент автоматически использует шрифт SB Sans Text

> Подробнее о типах и пропсах — [Typography API](?path=/docs/локальные-компоненты-typography-api--docs)
