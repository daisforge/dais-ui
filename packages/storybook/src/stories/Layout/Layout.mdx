# Layout

Компонент сетки страницы с поддержкой одноколоночных и многоколоночных макетов.

## Ключевые особенности

- 9 вариантов раскладки: `V1_1` (одна колонка), `V2_1`/`V2_2` (две колонки), `V3_1`/`V3_2`/`V3_3` (асимметричные), `V4_1`/`V4_2` (равные колонки), `V5_1` (фиксированная + центрированная)
- Адаптивное поведение на разных устройствах
- Кастомизация отступов через отдельные пропсы margin/padding
- Гибкое управление через CSS-переменные и классы

## Доступные варианты раскладки

- **V1_1** — одноколоночная
- **V2_1** — две колонки (основная слева)
- **V2_2** — две колонки (основная справа)
- **V3_1** — очень широкая колонка слева
- **V3_2** — очень широкая колонка справа
- **V3_3** — три колонки (центр шире)
- **V4_1** — две равные колонки
- **V4_2** — три равные колонки
- **V5_1** — фиксированная левая + центрированная

## CSS-переменные

- `--layout-margin-horizontal` — горизонтальные отступы (по умолчанию: auto)
- `--layout-margin-vertical` — вертикальные отступы (зависит от breakpoint)
- `--layout-gutter` — расстояние между колонками (зависит от breakpoint)
- `--layout-header-height` — высота хедера (auto)
- `--layout-max-width` — максимальная ширина (1856px)
- `--layout-grid-template-columns` — шаблон колонок

## Особенности

- При передаче строки в проп `classes` она применяется к корневому элементу; для точечной стилизации передайте объект `LayoutClasses`
- Встроенные CSS-классы: `layout__root`, `layout__header`, `layout__main`, `layout__item`, `layout__centeredItem` (для V5_1)
- Адаптивные отступы и гаттеры автоматически меняются по брейкпоинтам
- Максимальная ширина по умолчанию — 1856px

Описание типов — в разделе [API](/docs/композиции-layout-api--docs).
