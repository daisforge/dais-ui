# PageLoader

Компонент первоначальной загрузки страницы. Показывается, пока данные ещё не получены.

## Ключевые особенности

- Заменяет контент страницы на время первоначальной загрузки.
- Занимает свободное место во flex-контейнере и центрирует спиннер и текст. Размер области задаёт родитель.
- Показывает описание, если передана непустая строка `subtitle`.
- Использует `role="status"` для обозначения статуса загрузки.
- Подходит для `fallback` в `Suspense`.

## Первоначальная загрузка

Заголовок страницы, приветствие и навигацию размещайте выше условного рендера,
чтобы они оставались видимыми.

```tsx
import { Box, PageLoader, PageTitle } from '@daisforge/ui';

<Box display="flex" flexDirection="column" height="480px" gap="24px">
  <PageTitle title="Отчёты" />
  {isInitialLoading ? <PageLoader /> : <Reports />}
</Box>;
```

При повторном запросе с уже полученными данными оставляйте контент смонтированным
и показывайте локальный индикатор обновления. Ошибку запроса обрабатывайте отдельно.

## Suspense

Чтобы центрировать fallback, разместите `Suspense` во flex-контейнере с заданной
высотой.

```tsx
import { Box, PageLoader } from '@daisforge/ui';
import { Suspense } from 'react';

<Box display="flex" flexDirection="column" height="480px">
  <Suspense fallback={<PageLoader />}>
    <Reports />
  </Suspense>
</Box>;
```

## Особенности

Спиннер по макету имеет размер 36×36 px. Заголовок использует H3 Bold,
описание — BodyM и цвет secondary. После спиннера предусмотрено 8 px,
между текстами — 4 px. Текст про время загрузки в примере передаётся через `subtitle`.

### Доступность

Скринридер может пропустить текст в `role="status"`, если область монтируется
с уже заполненным текстом. Приложение может пометить область контента
через `aria-busy` и объявлять начало и окончание загрузки через постоянно
смонтированную live-область за её пределами.

```tsx
<>
  <div role="status" aria-atomic="true">
    {statusMessage}
  </div>
  <Box aria-busy={isInitialLoading} display="flex" height="480px">
    {isInitialLoading ? <PageLoader aria-live="off" /> : <Reports />}
  </Box>
</>
```

Инициализируйте `statusMessage` пустой строкой. Обновляйте его при начале
и завершении загрузки, например на «Загрузка отчётов» и «Отчёты загружены».
`aria-live="off"` отключает автоматические объявления от визуального индикатора
в этом примере, чтобы сообщение объявлялось из одной области.

Описание типов — в разделе [API](?path=/docs/композиции-pageloader-api--docs).
