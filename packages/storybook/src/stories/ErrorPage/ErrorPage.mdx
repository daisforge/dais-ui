# ErrorPage

Компонент для отображения страниц ошибок. Предполагается использовать при ошибках основных запросов на странице (например, в `onError` RTKQuery) и при ошибках на уровне всего приложения (например, в `ErrorBoundary`).

## Ключевые особенности

- Встроенные описания для статусов: 400, 401, 403, 404, 500, 502, 503
- При неизвестном статусе или `'unknown'` / `undefined` показывается общее описание
- Поддержка кастомных статусов через `customStatuses`
- Переопределение описания неизвестных ошибок через `unknownStatus`
- Отображение кода статуса (`showStatusCode`)
- Кастомизация контейнера через `containerProps`
- Размерная сетка `size`: `l` (по умолчанию), `m`, `s`

## Особенности

- Картинки подставляются в зависимости от статуса на продуктовых сборках. В Storybook при смене вариантов картинка не меняется
- `buttonHandler` вызывается с текущим `statusCode` и объектом статуса — можно реализовать кастомную навигацию
