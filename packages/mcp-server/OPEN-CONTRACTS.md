# Аудит открытых контрактов

Проверена база PR #164 с SDDS 0.369.0. Открытая строковая сигнатура не означает,
что все именованные поля стали непроверяемыми. Их потеря, неверный отображаемый
тип и `required` проверяются в `auditContracts.ts`, включая все перечисленные записи.

| Причина                                   | Записей | Что можно проверить                                                        | Что остаётся ограничением                                                                                  |
| ----------------------------------------- | ------: | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| SDDS `PropsType<Variants>`                |       6 | Явные поля AvatarGroup, Image, DrawerContent/Footer/Header, ToolbarDivider | Сигнатура допускает дополнительные имена                                                                   |
| Пересечение с `BoxProps`                  |      19 | Сохранившиеся CSS-поля и поля обёрток                                      | Полиморфный `ComponentProps<typeof Box>` оставляет открытые ключи                                          |
| `Omit<BoxProps, 'children'>`              |      12 | Поля, объявленные после Omit: title, rightBlock и другие                   | Базовые именованные ключи теряются из-за `keyof = string`; из Omit их полноту не восстановить              |
| `ComponentProps` от styled ServiceButtons |       2 | Сохранившийся публичный `as`                                               | `hasBackground` стёрт; тип принимает произвольные значения. Нужна правка публичной типизации UI-компонента |
| Chips с Omit от styled ChipGroup          |       1 | `chips`, `opened`, `commonSize`, `commonView`, включая required            | Дополнительные ключи остаются открытыми                                                                    |
| `FiltersActions` со styled/attrs          |       6 | Именованные Props в исходниках + сохранившийся публичный `as`              | Тип JSX стёрт; проверка объявленного Props не доказывает строгость публичного вызова                       |

Точный список всех 46 имён, причины и файлы находятся в
[`src/validate/openContractAudit.ts`](src/validate/openContractAudit.ts).
В список входят и compound-пути, и отдельные экспорты, поэтому это не 46 независимых
первопричин. Число само по себе не является целевой метрикой.

Аудит выдаёт поимённое покрытие в `contractCoverage` итогового JSON-отчёта:

- `checkedProps` — проверенные поля;
- `declaredProps` — подмножество, проверенное по именованным Props исходника,
  а не по публичной вызываемой сигнатуре;
- `unverifiedProps` — неподтверждённые поля индекса, каждое вызывает ошибку;
- `truncatedProps` — длинные типы, для которых проверен канонический отображаемый
  фрагмент (400 символов), а не полная структура;
- `reason` и `source` — причина открытости и место, где она возникает.

Нельзя добавлять имя в список только ради успешного CI. Новый открытый контракт,
закрывшийся контракт со старым исключением и исключение без соответствующей записи
считаются ошибками. При обновлении SDDS нужно заново проверить причину.

Независимые JSX-примеры показывают, что открытость не отменяет проверки известных
полей: неправильный `DrawerDF.Content.fixedWidth`, отсутствие `AnalyticalWidget.Chips.chips`
и неверный `opened` обязаны отклоняться TypeScript. Mutation-тест требует, чтобы
MCP-валидатор отдельно обнаруживал потерю этих полей, неверный тип/required и выдуманные
поля открытого контракта.

Изменение исходной типизации Box/SDDS/FiltersActions может убрать оставшуюся открытость,
но способно сузить публичный API библиотеки. Этот PR не маскирует такое изменение
настройками валидатора и не утверждает, что оно уже выполнено.
